# Excel解析技能

## 功能

解析 Excel 格式的组件清单文件，提取组件名和版本号，进行初步数据校验，输出结构化的组件列表。

## 适用场景

当需要将用户上传的 Excel 组件清单转换为可处理的结构化数据时使用本技能。

## 输入

- **Excel文件路径**：.xlsx 或 .xls 格式的组件清单文件
- **列名映射（可选）**：指定组件名列和版本号列的列名，默认自动识别

## 处理步骤

### 第1步：文件读取与工作表定位

1. 读取 Excel 文件，列出所有工作表
2. 默认使用第一个工作表，若第一个工作表为空则依次尝试
3. 定位表头行（通常是第一行包含"组件名"、"版本号"等关键词的行）

### 第2步：列识别

自动识别以下列名（不区分大小写，支持中英文）：

| 字段 | 可能的列名 |
|------|-----------|
| 组件名 | 组件名、组件名称、名称、component、name、package、包名 |
| 版本号 | 版本号、版本、version、ver、v |

如果自动识别失败，按以下规则兜底：
- 第一列视为组件名
- 第二列视为版本号

### 第3步：数据提取与初步校验

逐行提取数据，同时进行初步校验：

| 校验项 | 校验规则 | 不通过处理 |
|--------|---------|-----------|
| 组件名非空 | 组件名字段不能为空或纯空白 | 标记为无效，记录行号和原因 |
| 版本号非空 | 版本号字段不能为空 | 标记为无效，记录行号和原因 |
| 版本号格式 | 应符合语义化版本规范（如 1.2.3、v2.0.0） | 标记警告，不拒绝（有些组件版本号格式特殊） |
| 跳过空行 | 整行为空的行 | 跳过，不计入统计 |

### 第4步：安全清洗

对提取的数据进行安全清洗，防止 Prompt Injection：

1. 过滤控制字符（\x00-\x1F、\x7F）
2. 过滤 SQL 注入关键字（仅做标记，不删除）
3. 检查是否包含系统命令模式（如 `; rm -rf`、`| bash` 等）
4. 超长字段截断（组件名 > 200字符、版本号 > 50字符 时截断并标记）

### 第5步：输出结构化数据

按统一格式输出结构化的组件列表。

  },

    }

## 注意事项

- 本技能仅做"解析和初步校验"，不生成 SBOM，不做漏洞分析
- 语义化版本校验是"宽松模式"——只警告不拒绝，因为现实中版本号格式五花八门
- 安全清洗是"防御性"的，发现可疑内容会标记但不会删除（避免误删合法数据）
- 如果 Excel 文件有多个工作表，默认用第一个，如有特殊需求请在调用时指定
