
# 04_permanent - 永久知识

## 用途
存放经过验证的核心永久知识。这是知识库中最有价值的部分，内容已经过审核确认。

## 文件命名规则
- 格式：主题_子主题.md（不包含日期，因为是永久知识）
- 示例：transformer_architecture.md、llm_training_basics.md

## 内容要求
- 经过人工验证，确保准确性
- 结构完整，逻辑清晰
- 建立与其他知识的双向链接
- 注明最后更新时间和审核人

## 知识质量标准
- 准确性：内容经过多方验证
- 时效性：定期更新以保持最新
- 完整性：涵盖主题的核心要点
- 实用性：对学习和应用有实际帮助

## 更新机制
- 定期回顾和更新
- 记录更新历史
- 保留重要的历史版本（可选）
