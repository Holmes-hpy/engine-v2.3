# 注意力机制

## 概述

注意力机制是Transformer架构的核心，它允许模型在处理每个位置时，灵活地关注输入序列的不同部分。

## 自注意力机制

### 查询、键、值
自注意力通过三个向量计算：
- **查询（Query）**：当前位置需要什么信息
- **键（Key）**：序列中每个位置的特征信息
- **值（Value）**：序列中每个位置的实际内容

### 计算过程

1. **计算注意力分数**
```
Attention(Q, K, V) = softmax(QK^T/√d_k)V
```

2. **缩放**：除以√d_k防止点积过大
3. **Softmax**：归一化为概率分布
4. **加权求和**：用注意力分数加权值向量

## 多头注意力

### 概念
将查询、键、值分别投影到多个不同的子空间，每个子空间计算一个注意力头，然后将结果拼接起来。

### 优势
- 捕获不同类型的关系
- 并行计算
- 更好的表达能力

### 示例
GPT-3使用96个注意力头，每个注意力头处理64维。

## 因果注意力

### 特点
在生成任务中，每个位置只能关注之前的位置，不能看到未来的信息。

### 实现
通过注意力掩码实现，将未来位置的注意力分数设为-∞。

## Flash Attention

### 优化原理
- 重新组织计算顺序，提高GPU利用率
- 减少内存读写
- 保持数学等价性

### 性能提升
相比标准注意力，Flash Attention通常快2-4倍，内存消耗更少。

## 注意力变体

### 1. 稀疏注意力
只计算部分位置的注意力，降低复杂度。

### 2. 滑动窗口注意力
每个位置只关注一定范围内的位置。

### 3. 多查询注意力（MQA）
多个查询头共享键和值头，减少KV缓存大小。

### 4. 分组查询注意力（GQA）
查询分组，每组共享键和值，平衡MQA和全注意力。

## 关键要点

1. **注意力权重表示相关性**：分数越高，两个位置越相关
2. **可解释性**：可以可视化注意力权重，了解模型关注什么
3. **二次复杂度**：标准自注意力复杂度是O(n²)，对长序列较贵
4. **KV缓存**：在推理中缓存键和值，避免重复计算
