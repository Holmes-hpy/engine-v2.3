# Agents技术

## 概述

LLM Agents是能够自主执行任务的智能体，它们使用LLM作为大脑，结合工具、记忆和推理能力。

## Agent架构

### 核心要素

1. **思考**：内部推理，决定下一步做什么
2. **行动**：调用工具、执行操作
3. **观察**：获取反馈、分析结果
4. **循环**：重复直到任务完成

### 典型流程
```
思考 → 规划 → 行动 → 观察 → 思考 → ... → 完成
```

## 核心技术

### 工具使用

Agents能够调用各种工具：
- **搜索工具**：Google、Bing、Wikipedia
- **计算工具**：计算器、Python解释器
- **代码工具**：Jupyter、Terminal
- **特定工具**：数据库、API、邮件

## 设计模式

### ReAct
Reasoning + Acting
- 思维：先思考再行动
- 行动：调用工具
- 观察：获取结果
- 重复

### Plan-and-Execute
- 规划：生成完整计划
- 执行：按计划一步一步
- 调整：根据情况调整

### Reflexion
- 反思：评估之前行为
- 学习：从错误中学习
- 优化：下次做得更好
