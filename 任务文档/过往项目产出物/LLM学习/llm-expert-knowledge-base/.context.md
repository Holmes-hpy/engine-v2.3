
# 大模型专家知识库 - 根目录上下文

## 知识库概述
这是一个由Trae自主维护的大模型领域专业知识库，用于存储和管理所有学习成果。

## 目录结构与用途
- 01_inbox/：待处理的原始信息（自动采集的文章、论文、新闻等）
- 02_raw/：初步整理后的原始内容归档
- 03_ai_wiki/：AI自动生成的结构化知识（待验证）
- 04_permanent/：经过验证的核心永久知识
- 05_papers/：学术论文的深度解读和复现报告
- 06_tools/：大模型相关工具和框架的使用指南
- 07_case_studies/：实际应用案例分析
- 08_audit/：知识质量审计记录和报告
- 99_archive/：过时或不再需要的内容归档

## 通用规则
1. 所有文件使用Markdown格式，文件名使用英文和数字，避免特殊字符
2. 所有知识必须注明来源和发布时间
3. 定期清理过时信息，保持知识库的准确性和时效性
4. 建立知识之间的双向链接，形成知识网络
