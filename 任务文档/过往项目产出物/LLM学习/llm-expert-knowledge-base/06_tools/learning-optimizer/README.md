# 学习计划优化Skill

## 概述

作为大模型专家系统的"学习总监"，负责制定科学合理的学习战略，优化资源配置，确保系统高效、有针对性地学习。让知识库始终保持最新、最全面、最符合用户需求的状态，持续提升大模型专家的专业能力。

## 核心功能

### 1. 知识库健康度评估
- 全面扫描整个知识库，生成健康度报告
- 识别知识薄弱环节和空白领域
- 五维健康度评分（覆盖度、质量度、时效性、关联度、实用度）

### 2. 技术趋势分析
- 识别大模型领域的技术热点和发展趋势
- 预测未来3个月可能的技术发展方向
- 生成技术趋势优先级列表

### 3. 用户需求分析
- 分析用户的需求和兴趣
- 识别潜在需求和未来可能的需求
- 生成用户需求优先级列表

### 4. 学习计划生成
- 综合知识库健康度、技术趋势和用户需求
- 明确学习目标与优先级
- 分解任务并分配给相应Skill执行
- 合理分配计算资源和时间

### 5. 任务调度与执行
- 将学习计划转化为具体的定时任务
- 更新其他Skill的配置参数
- 监控任务执行状态

### 6. 学习效果评估与反馈
- 评估上周学习计划的执行情况
- 分析问题和不足
- 优化学习计划生成算法

### 7. 紧急情况处理
- 重大技术事件触发
- 用户紧急需求触发
- 知识库严重问题处理

## 使用方法

### 基本使用

```bash
# 完整学习计划优化
python3 src/main.py --full --verbose

# 单项分析
python3 src/main.py --health    # 知识库健康度评估
python3 src/main.py --trends     # 技术趋势分析
python3 src/main.py --user       # 用户需求分析

# 其他功能
python3 src/main.py --generate   # 仅生成学习计划
python3 src/main.py --evaluate   # 评估上周学习计划

# 紧急计划
python3 src/main.py --emergency tech   # 重大技术事件
python3 src/main.py --emergency user   # 用户紧急需求
python3 src/main.py --emergency health # 知识库严重问题
```

## 配置说明

在 `config/config.json` 中可以配置：

- `health_assessment`: 健康度评估权重和阈值
- `trend_analysis`: 技术趋势分析配置
- `user_analysis`: 用户需求分析配置
- `learning_schedule`: 学习计划调度配置
- `resource_allocation`: 资源分配配置

## 五维健康度评分

| 维度 | 权重 | 说明 |
|------|------|------|
| 覆盖度 | 30% | 各领域知识的覆盖情况 |
| 质量度 | 25% | 知识的平均质量评分 |
| 时效性 | 20% | 知识的更新频率和新鲜度 |
| 关联度 | 15% | 知识之间的关联程度 |
| 实用度 | 10% | 被引用和使用的频率 |

## 优先级排序原则

1. 用户极高优先级需求 > 技术极高优先级趋势 > 知识库严重空白
2. 用户高优先级需求 > 技术高优先级趋势 > 知识库薄弱环节
3. 用户中优先级需求 > 技术中优先级趋势 > 知识库一般更新

## 特殊处理规则

1. **重大技术事件触发**：立即触发，暂停非紧急任务
2. **用户紧急需求触发**：立即触发，调整学习计划
3. **知识库严重问题处理**：健康度<60分触发紧急优化
4. **学习资源限制处理**：自动调整优先级，通知用户

## 与其他Skill的协同

本Skill与其他Skill紧密协作：

- **大模型信息雷达**: 调整采集频率和重点
- **知识蒸馏**: 修改模板和提取规则
- **知识质量审计**: 调整评分标准和审核重点
- **论文精读与复现**: 更新筛选标准和优先级

## 质量控制标准

1. 学习计划必须基于客观数据和分析
2. 学习重点必须与用户需求和技术趋势一致
3. 任务安排必须合理可行
4. 资源分配必须高效
5. 预期成果必须明确具体

## 输出结果

- **知识库健康度报告**: 包含在周度计划中
- **技术趋势报告**: 包含在周度计划中
- **用户需求报告**: 包含在周度计划中
