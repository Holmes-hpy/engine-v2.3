
# 知识蒸馏工具

将原始信息转化为结构化知识文档的工具。

## 功能

- 自动扫描inbox目录中的未处理文件
- 提取文章元数据（标题、来源、作者、发布时间）
- 智能分类到相应主题目录
- 自动生成标准化知识文档
- 移动已处理文件到归档目录
- 生成处理报告

## 分类体系

- **基础理论**：大模型的数学基础、理论框架等
- **模型架构**：Transformer、GPT、BERT、LLaMA等模型架构
- **训练技术**：预训练、微调、RLHF、LoRA等训练方法
- **推理优化**：量化、蒸馏、剪枝、推理引擎等
- **应用开发**：RAG、Agent、多模态应用等开发技术
- **部署工程**：模型部署、容器化、云服务等
- **行业动态**：行业趋势、市场分析、厂商动态等

## 使用方法

```bash
cd knowledge-distiller
python src/main.py
```

## 输出

生成的知识文档保存到：
- `../../03_ai_wiki/[分类]/[标题].md`

处理报告保存到：
- `../../03_ai_wiki/YYYY-MM-DD-知识蒸馏报告.md`

已处理文件移动到：
- `../../02_raw/已处理-[原文件名].md`
