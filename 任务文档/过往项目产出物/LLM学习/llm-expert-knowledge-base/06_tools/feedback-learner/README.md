# 知识应用与反馈学习Skill

## 概述

这是一个事件驱动的反馈学习系统，从每一次与用户的交互中提取有价值的信息，评估回答质量，发现系统不足，自动触发知识补充和能力优化，让大模型专家系统越来越懂用户，越来越专业。

## 核心功能

### 1. 对话历史获取与分析
- 自动获取对话历史
- 提取关键信息（主题、技术概念、用户意图）
- 对话分类（技术咨询、问题解决、研究支持、行业分析等）
- 评估对话复杂度和所需深度

### 2. 回答质量评估（六维评分系统）

| 维度 | 权重 | 说明 |
|------|------|------|
| 准确性 | 30% | 回答内容是否准确，是否有事实性错误 |
| 完整性 | 20% | 是否完整回答了用户的所有问题 |
| 相关性 | 15% | 回答内容是否与用户问题直接相关 |
| 清晰度 | 15% | 表述是否清晰易懂，逻辑是否严密 |
| 实用性 | 10% | 是否提供了可操作的建议 |
| 时效性 | 10% | 信息是否最新，是否符合当前技术现状 |

**综合得分计算公式**：
综合得分 = 准确性×0.30 + 完整性×0.20 + 相关性×0.15 + 清晰度×0.15 + 实用性×0.10 + 时效性×0.10

### 3. 用户反馈分析
- **正面反馈**：记录优点，更新回答模板
- **负面反馈**：分析具体问题，触发知识修正
- **修正反馈**：整合用户提供的正确信息
- **追问反馈**：优化回答深度和详细程度

### 4. 知识缺口识别与自动补充
- **完全缺失**：触发专项信息采集
- **不完整**：触发知识蒸馏
- **检索不到**：优化知识库索引
- **已过时**：标记为需要更新

### 5. 回答优化与风格调整
- 根据质量评估优化回答模板
- 学习用户的表达方式和专业术语
- 调整回答的详细程度和深度
- 记录用户偏好设置

### 6. 学习记录与报告生成
- 详细的学习日志记录
- 周度学习总结报告
- 系统性问题的整体改进方案

## 使用方法

### 基本使用

```python
# 在对话结束时调用
python3 src/main.py --session-complete \
    --user-query "用户问题" \
    --assistant-response "助手回答" \
    --user-feedback "用户反馈" \
    --conversation-id "conv_001" \
    --verbose
```

### 生成周度报告

```bash
python3 src/main.py --weekly-report --verbose
```

## 触发规则

这是一个**被动触发的事件驱动型Skill**，不是定时任务。

**触发场景**：
1. 当用户与大模型对话结束时自动触发
2. 定期分析学习日志时触发
3. 生成周度报告时触发

**使用建议**：
- 将此Skill集成到大模型对话系统中
- 在每次对话结束后自动调用
- 定期查看 `08_audit/learning_logs/` 目录中的学习日志
- 关注周度学习报告中的系统性问题

## 配置说明

在 `config/config.json` 中可以配置：

- `quality_assessment.dimensions`: 各维度权重和评分标准
- `feedback_analysis.keywords`: 反馈关键词
- `knowledge_gap.types`: 知识缺口类型和处理方式
- `conversation_types`: 对话类型分类

## 输出结果

### 学习日志
保存到 `08_audit/learning_logs/YYYY-MM-DD-对话ID.md`

### 周度报告
保存到 `08_audit/YYYY-MM-DD-周度学习报告.md`

### 错误日志
保存到 `08_audit/feedback_learner_error.log`

## 特殊处理规则

1. **用户明确指出错误**：立即承认并道歉，触发知识修正流程
2. **知识库中没有的问题**：诚实告知用户，触发专项学习
3. **用户提供了有价值的信息**：验证后添加到知识库
4. **用户对同一问题多次提问**：分析不足并提供更详细回答

## 质量控制标准

1. 学习和优化必须基于客观的对话数据和用户反馈
2. 知识补充必须经过严格的质量验证
3. 回答优化必须保持客观中立
4. 用户偏好记录必须准确，不得猜测

## 与其他Skill的集成

此Skill可以与其他Skill协同工作：

- **大模型信息雷达**：当发现完全缺失的知识时触发
- **知识蒸馏**：当知识不完整或不准确时触发
- **知识质量审计**：定期验证知识库的完整性
