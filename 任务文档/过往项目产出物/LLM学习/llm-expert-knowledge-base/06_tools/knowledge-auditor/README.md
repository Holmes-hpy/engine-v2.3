# 知识质量审计工具

## 简介

作为大模型知识库的"质量守门人"，严格审核所有AI生成的知识内容，确保知识库的准确性、完整性和可靠性。

## 核心功能

### 1. 六维质量评分体系

对每篇知识文档进行六个维度的全面评分：

| 维度 | 权重 | 说明 |
|------|------|------|
| 准确性 | 25% | 事实是否准确，数据是否可靠，技术表述是否正确 |
| 完整性 | 15% | 是否涵盖核心要点，是否有重要信息遗漏 |
| 一致性 | 20% | 与知识库中现有知识是否一致，内部是否自洽 |
| 时效性 | 15% | 信息是否最新，是否存在过时内容 |
| 相关性 | 10% | 与大模型技术领域的相关程度 |
| 可理解性 | 15% | 表述是否清晰，技术术语是否有解释 |

### 2. 四种分类处理

根据综合得分对知识文档进行分类：

- **优秀知识** (≥85分)：标记为"已验证"，移动到永久知识库
- **合格知识** (70-84分)：标记为"已验证（需优化）"，移动到永久知识库
- **待修正知识** (50-69分)：标记为"需要修正"，保留在03_ai_wiki目录
- **不合格知识** (<50分)：标记为"拒绝"，移动到归档目录

### 3. 审计报告生成

自动生成详细的审计报告，包括：

- 审计概览和分类统计
- 平均得分和各维度分析
- 主要问题总结
- 知识库优化建议

## 配置说明

编辑 `config/config.json` 可以调整审计参数：

```json
{
    "validation": {
        "audit_threshold": 70,           // 合格线
        "excellent_threshold": 85,      // 优秀线
        "need_correction_threshold": 50, // 需修正线
        "exclude_audited_in_hours": 24   // 排除24小时内已审计的
    },
    "scoring": {
        "weights": {
            "accuracy": 0.25,      // 准确性权重
            "completeness": 0.15,  // 完整性权重
            ...
        }
    }
}
```

## 审计流程

1. **扫描文档**：查找03_ai_wiki目录中所有"待人工验证"的文档
2. **六维分析**：从六个维度评估文档质量
3. **计算得分**：根据权重计算综合得分
4. **分类处理**：根据得分进行相应处理
5. **生成报告**：保存审计报告到08_audit目录

## 知识质量审计报告

审计报告自动保存在 `08_audit/YYYY-MM-DD-单次审计报告.md`

报告包含：
- 审计时间和范围
- 文档分类统计
- 平均分和各维度分析
- 主要问题和优化建议

## 注意事项

- 审计工具会自动跳过最近24小时内已审计过的文档
- 支持集成真实的LLM API进行更准确的验证
- 建议定期运行审计，保持知识库质量
