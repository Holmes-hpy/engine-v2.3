
# 06_tools - 工具与框架

## 用途
存放大模型相关工具和框架的使用指南、教程和最佳实践。

## 文件命名规则
- 格式：工具名_版本_内容类型.md
- 示例：transformers_v4.35_tutorial.md、langchain_getting_started.md

## 内容类型
- 入门教程
- 高级用法
- 最佳实践
- 常见问题解决
- 性能优化技巧
- 版本更新说明

## 内容要求
- 清晰的步骤说明
- 可运行的代码示例
- 实际应用场景
- 注意事项和陷阱
- 相关资源链接

## 工具分类
- 模型框架（Transformers, PyTorch, TensorFlow等）
- 应用框架（LangChain, LlamaIndex等）
- 开发工具
- 评测工具
- 部署工具
