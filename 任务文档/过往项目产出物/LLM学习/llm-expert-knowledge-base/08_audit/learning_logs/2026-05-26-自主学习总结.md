### 核心学习内容

#### RAG技术的四次演进

| 演进阶段 | 核心改进 | 主要技术 |
|---------|---------|---------|
| Naive RAG | 基础检索 | TF-IDF、BM25 |
| Advanced RAG | 提升精度 | Query Rewriting、Reranking、RAG-Fusion |
| Modular RAG | 结构化路由 | Router、Graph RAG |
| Self-Correcting RAG | 可信度提升 | Fact-Checking、Self-Reflection |
| **Agentic RAG** | 自主智能 | Planning、Tool Use、Memory |

#### Agentic RAG的核心能力

1. **记忆能力**：短期与长期上下文管理
2. **规划能力**：多步推理、任务分解
3. **工具使用**：搜索、API调用、数据库操作
4. **反馈循环**：自我修正、学习优化

#### Agentic RAG的类型

- 单智能体模式
- 多智能体模式
- 自修正型智能体RAG
- 自适应型智能体RAG
- 基于图谱的智能体RAG
- 智能体文档工作流

#### 工作流程

Agentic RAG的工作是一个"感知-思考-行动-学习"的循环：
1. 理解需求
2. 拆解任务
3. 动态检索
