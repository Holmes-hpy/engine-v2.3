
# 01_inbox - 收件箱

## 用途
存放待处理的原始信息，包括自动采集的文章、论文、新闻、教程链接等。这是知识进入知识库的第一站。

## 文件命名规则
- 使用英文和数字，避免特殊字符
- 格式：日期_来源_标题.md
- 示例：20240115_arxiv_attention-is-all-you-need.md

## 处理流程
1. 自动/手动收集信息到此目录
2. 定期审核并分类整理
3. 整理后移动到02_raw或其他合适的目录
4. 删除或归档不再需要的内容

## 内容要求
- 必须注明来源URL和发布时间
- 保持原始内容的完整性
- 可以添加初步的标签或备注
