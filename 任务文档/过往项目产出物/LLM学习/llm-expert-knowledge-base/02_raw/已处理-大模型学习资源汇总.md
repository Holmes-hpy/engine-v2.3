## 一、mlabonne/llm-course - 完整的LLM课程

### 📌 仓库信息
- **GitHub地址：https://github.com/mlabonne/llm-course
- **作者**：Maxime Labonne
- **简介**：一个分三个阶段的完整LLM学习课程，配套Colab笔记本

### 🎯 课程结构

#### 1️⃣ 🧩 LLM Fundamentals（基础知识）
- **数学**：线性代数、微积分、概率统计
- **Python**：基础语法、数据科学库
- **神经网络**：基础结构、训练优化

#### 2️⃣ 🧑‍🔬 The LLM Scientist（LLM科学家）
- 模型构建与微调技术
- 最新技术应用

#### 3️⃣ 👷 The LLM Engineer（LLM工程师）
- 应用开发与部署

### 📝 实用工具与笔记本

#### 🔧 推荐工具
| 工具 | 描述 |
|------|------|
| LLM AutoEval | 自动评估LLM |
| LazyMergekit | 一键模型合并 |
| LazyAxolotl | 云端微调 |
| AutoQuant | 多种格式量化 |
| ZeroSpace | Gradio聊天界面 |

#### 🎛️ 微调笔记
- Llama 3.1 微调 (Unsloth)
- Llama 3 微调 (ORPO)
- Mistral-7b 微调 (DPO, QLoRA)
- CodeLlama 微调 (Axolotl)

#### ⚡ 量化笔记
- 8-bit 量化入门
- 4-bit 量化 (GPTQ)
- GGUF 量化 (llama.cpp)
- ExLlamaV2 量化

### 📚 配套书籍
- **LLM Engineer's Handbook**：完整LLM工程师手册
