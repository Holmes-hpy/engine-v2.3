
# 05_papers - 论文解读

## 用途
存放学术论文的深度解读和复现报告。这是深入研究大模型技术的核心资料。

## 文件命名规则
- 格式：年份_第一作者_论文标题简写.md
- 示例：2017_vaswani_attention-is-all-you-need.md

## 内容要求
### 论文基本信息
- 论文标题（中英文）
- 作者信息
- 发表会议/期刊
- 发表年份
- arXiv链接或DOI
- 原文链接

### 解读内容
- 核心观点总结
- 关键方法详解
- 实验结果分析
- 个人见解与启示
- 相关论文链接

### 复现报告（如有）
- 复现环境
- 复现代码链接
- 复现结果
- 遇到的问题与解决方案

## 质量标准
- 解读准确，理解深刻
- 有自己的思考和见解
- 复现报告详实可靠
