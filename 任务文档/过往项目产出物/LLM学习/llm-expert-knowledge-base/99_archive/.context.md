
# 99_archive - 归档

## 用途
存放过时或不再需要的内容归档。这些内容已经不再适用于当前的知识库，但保留作为历史记录。

## 文件命名规则
- 保持原文件名，或添加archive前缀
- 格式：archive_原文件名.md
- 示例：archive_old_transformer_tutorial_2023.md

## 归档原因
- 内容过时，已被新内容替代
- 验证失败且不再需要修改
- 重复内容
- 与知识库主题不再相关
- 其他原因（需注明）

## 归档记录要求
- 归档时间
- 归档原因
- 替代内容链接（如有）
- 归档处理人

## 归档内容处理
- 定期清理（如每半年审查一次）
- 确认永久不需要的内容可以删除
- 保留有历史价值的内容
