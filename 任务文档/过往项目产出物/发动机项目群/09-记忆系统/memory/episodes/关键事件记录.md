## 事件1：元协议研究（2026-07-19）

**背景**：用户提出"Agent最小颗粒度通信方案"概念，认为现有框架（LangGraph/AgentScope/CrewAI）把通信拓扑写死在框架里，限制Agent的自主性。

**过程**：
- 第1轮：提出核心概念——Port+Envelope+Contract 三层模型
- 第2轮：动态切换机制设计（规则引擎+LLM辅助+频率限制）
- 第3轮：Loop Engineering（文件持久化+外部验证器+熔断器）
- 第4轮：AgentScope Middleware 洋葱模型挂载点分析
- 第5轮：12要素→8要素合并优化
- 第6-7轮：零侵入实现路径设计（Middleware→适配器渐进）
- 第8-9轮：元协议约束规则设计
- 第10轮：发现漏存捡破烂，制定保证机制
- 第11-15轮：8要素→10要素回退（务实主义完胜美学）
- 第16轮：元协议v2.0技术文档生成

**关键产出**：
- 元协议v2.0 技术文档（10要素+8条约束规则）
- 345个测试用例，0失败
- 8个源码文件（约900行）
- 比A2A节省约69% Token

**关键决策**：
- 8→10要素回退：合并过度导致丢失合法场景
- 零侵入式核心原则：能不修改源码就不修改
- 命名 RalphLoop = "捡破烂"谐音 + Recovery
