## 专家点评与纠正

### 4个认知误区纠正

**误区1：上下文窗口小是ChatBot的根本原因**
- ❌ 错误。根本原因是**缺乏自主性（Autonomy）+ 工具调用能力（Tool Calling）**
- ✅ 上下文窗口小是限制条件，但不是本质原因。即使给ChatBot无限上下文，它仍然只是一问一答，不会主动采取行动

**误区2：Agent = 固化的提示词 + Memory**
- ❌ 错误。Agent的核心是**自主性（Autonomy）**，即动态决策能力，而非固定工作流
- ✅ 固化的提示词是"工作流（Workflow）"，不是Agent。Agent的关键在于能根据观察动态决定下一步做什么

**误区3：CoT（思维链）驱动了Agent诞生**
- ❌ 错误。真正的转折点是 **Function Calling（2023年6月）**
- ✅ CoT让LLM"想清楚"，Function Calling让LLM"能行动"。想清楚但不能行动，仍然是ChatBot

**误区4：上下文扩展导致了Agent诞生**
- ❌ 错误。上下文扩展是**条件/使能因素**，不是原因
- ✅ 即使有大上下文，如果没有工具调用和自主决策能力，仍然只是"能聊更长的ChatBot"

### 正确的时间线

```
2022年     CoT（思维链）提出 —— 让LLM"想清楚"
2023.06    Function Calling发布 —— 真正的转折点！让LLM"能行动"
2023.11    OpenAI Assistants API —— 官方Agent雏形
2024年     Agent框架爆发（LangGraph/CrewAI/AutoGen等）
2025年     多Agent协作成为主流
2026年     协议标准化（MCP/A2A）+ Harness Engineering
```

### 关键概念扩展

**ReAct模式**：Reasoning + Acting，即"推理-行动"循环。Thought→Action→Observation→Thought→...，这是Agent自主性的核心实现方式。

**Memory三层结构的意义**：
- 短期记忆：当前对话上下文（窗口内）
- 长期记忆：向量数据库存储的历史经验
- 工作记忆：当前任务相关的临时信息

**Prompt → Context → Harness演化**：
- Prompt Engineering：写好提示词（2023）
- Context Engineering：管理好上下文（2025）
- Harness Engineering：构建好整个运行环境（2026）

## 本轮核心知识点

- Agent的本质：自主性 + 工具调用能力，不是"固化提示词"
- 真正转折点：Function Calling（2023.06），不是CoT，不是上下文扩展
- ReAct循环：Agent自主性的核心实现
- AI工程三代演化：Prompt → Context → Harness
- Memory三层：短期/长期/工作记忆的分层意义
