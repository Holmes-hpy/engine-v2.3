# 财务-有效税率计算器

## name
财务-有效税率计算器

## description
计算企业的有效税率（Effective Tax Rate），即企业实际缴纳所得税占税前利润的比例，区别于法定税率。适用于企业税务分析、财务建模、同行业税务对比、跨境税务规划。触发词：有效税率、实际税率、Effective Tax Rate、所得税率、税务负担。排除词：法定税率、增值税率、消费税率、名义税率、边际税率。

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| income_tax_expense | number | 所得税费用（利润表中的所得税费用） | 250000 |
| pretax_income | number | 税前利润（利润总额） | 1000000 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| statutory_tax_rate | number | 法定税率（小数形式） | 按企业注册地估算：中国一般企业25%，高新技术企业15%；美国联邦21%+州税；新加坡17%；香港16.5%。用于与有效税率对比 |
| jurisdiction | string | 税务管辖区 | 用于辅助LLM查找法定税率。可选值：CN（中国大陆）/ HK（香港）/ US（美国）/ SG（新加坡）/ EU（欧盟）等 |

## formula
有效税率 = income_tax_expense / pretax_income

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| effective_tax_rate | number | 有效税率（小数形式） |
| effective_tax_rate_percentage | number | 有效税率（百分比形式） |
| income_tax_expense | number | 回显所得税费用 |
| pretax_income | number | 回显税前利润 |
| statutory_tax_rate | number | 法定税率（若估值则标注） |
| tax_rate_diff | number | 有效税率与法定税率差异（percentage points） |
| analysis | string | 差异分析：正差异表示有效税率高于法定税率（可能因不可抵扣费用），负差异表示有效税率低于法定税率（可能因税收优惠/减免） |

## example
**输入：**
- 所得税费用：$250,000
- 税前利润：$1,000,000
- 法定税率：25%（LLM估值，假设中国一般企业）

**计算过程：**
有效税率 = 250,000 / 1,000,000 = 0.25

**输出：**
- 有效税率：0.25
- 有效税率百分比：25%
- 所得税费用：$250,000
- 税前利润：$1,000,000
- 法定税率：25%（LLM估值，中国一般企业）
- 税率差异：0个百分点
- 差异分析：有效税率与法定税率完全一致，说明企业未享受明显税收优惠，也无重大不可抵扣费用。

**解读：**
有效税率=法定税率说明企业税务结构简单。若有效税率显著低于法定税率（如15% vs 25%），可能享受高新技术企业优惠、研发加计扣除等；若有效税率显著高于法定税率（如30% vs 25%），可能存在大量不可税前抵扣的费用、境外高税率地区利润等。
