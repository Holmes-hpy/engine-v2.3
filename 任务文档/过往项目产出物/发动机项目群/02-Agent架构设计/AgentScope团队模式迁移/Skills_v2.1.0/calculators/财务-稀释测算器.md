# 财务-稀释测算器

## name
财务-稀释测算器

## description
计算创业公司融资后原有股东的股权稀释比例，以及ESOP（员工期权池）对稀释的影响。适用于创业公司融资规划、股权结构设计、投资人谈判、员工期权激励方案设计。触发词：股权稀释、融资稀释、稀释比例、Dilution、ESOP稀释、股权比例变化。排除词：股份回购、股份拆分、分红。

atomic-calculator

财务

财务指标

concept_registry.财务.稀释

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| funding_amount | number | 新融资金额 | 10000000 |
| pre_money_valuation | number | 投前估值（融资前公司估值） | 40000000 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| esop_pool_pct | number | ESOP期权池比例（小数形式，如0.10表示10%） | 默认0%。若用户在融资前需要扩大ESOP池，通常融资前的ESOP占比为10-20% |
| esop_pool_mode | string | ESOP池设置方式 | 可选值：pre_money（投前设置，稀释所有现有股东）/ post_money（投后设置，投资人也参与稀释）。默认post_money |
| founder_current_pct | number | 创始人当前持股比例 | 默认未提供。若提供，则计算创始人融资后持股比例 |
| num_rounds | number | 融资轮数 | 默认1轮。若为多轮融资，需逐轮计算稀释 |

## formula
稀释比例 = funding_amount / (pre_money_valuation + funding_amount)

若ESOP池在投前设置：
  创始人/现有股东稀释后持股 = 原有持股 × (1 - esop_pool_pct - dilution_ratio)

若ESOP池在投后设置：
  创始人/现有股东稀释后持股 = 原有持股 × (1 - dilution_ratio)
  投资人持股 = dilution_ratio × (1 - esop_pool_pct)
  ESOP持股 = esop_pool_pct

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| dilution_ratio | number | 本轮融资稀释比例（小数） |
| dilution_percentage | number | 本轮融资稀释比例（百分比） |
| post_money_valuation | number | 投后估值 = pre_money_valuation + funding_amount |
| investor_ownership | number | 新投资人持股比例（不考虑ESOP） |
| esop_ownership | number | ESOP持股比例（若提供） |
| founder_post_ownership | number | 创始人融资后持股比例（若提供创始人当前持股） |
| cap_table | object | 简要股权结构表（融资前后对比） |

## example
**输入：**
- 融资金额：$10,000,000
- 投前估值：$40,000,000
- ESOP池：10%（投后设置）
- 创始人当前持股：70%

**计算过程：**
稀释比例 = 10,000,000 / (40,000,000 + 10,000,000) = 10,000,000 / 50,000,000 = 0.20
投后估值 = 40,000,000 + 10,000,000 = $50,000,000

ESOP投后设置：
- 投资人持股 = 20% × (1 - 10%) = 18%
- ESOP持股 = 10%
- 创始人持股 = 70% × (1 - 20%) = 56%
- 其他现有股东 = 100% - 70% - 20% = 原来10%，稀释后 = 10% × (1 - 20%) = 8%

**输出：**
- 稀释比例：0.20
- 稀释百分比：20%
- 投后估值：$50,000,000
- 投资人持股：18%
- ESOP持股：10%
- 创始人持股：56%（融资前70%，本轮稀释14个百分点）
- 股权结构表（融资后）：
  - 创始人：56%
  - 新投资人：18%
  - ESOP池：10%
  - 其他现有股东：8%
  - 未分配：8%

**解读：**
创始人从70%降至56%，本轮稀释14个百分点。加上ESOP的10%，总稀释效应使创始人持股减少20%。若后续还有B轮、C轮融资，每轮约稀释15-25%，到IPO时创始人持股通常在20-40%之间，属于正常范围。
