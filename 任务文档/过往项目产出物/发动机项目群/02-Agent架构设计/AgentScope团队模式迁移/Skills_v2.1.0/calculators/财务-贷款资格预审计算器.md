# 财务-贷款资格预审计算器

## name
财务-贷款资格预审计算器

## description
计算个人或企业的贷款资格预审指标，包括债务收入比（DTI）和贷款价值比（LTV），并给出预审结论。适用于房贷预审、个人贷款评估、企业贷款资格初筛。触发词：贷款资格、贷款预审、DTI、债务收入比、贷款价值比、Loan-to-Value、房贷资格、贷款审批。排除词：信用评分、征信报告、贷款合同。

## category
atomic-calculator

## sub_category
财务

财务指标

concept_registry.财务.贷款

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| monthly_income | number | 月收入（税前） | 30000 |
| monthly_debt_payment | number | 月债务支出（含现有贷款月供、信用卡最低还款等） | 5000 |
| asset_value | number | 资产价值（如房产评估价） | 5000000 |
| loan_amount | number | 申请贷款金额 | 3500000 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| loan_type | string | 贷款类型 | 默认"mortgage"。可选值：mortgage（房贷）/ personal（个人消费贷）/ business（企业经营贷）。不同贷款类型DTI和LTV阈值不同 |
| new_monthly_payment | number | 新贷款预计月供 | 若未提供，按贷款金额、当前市场利率、贷款期限估算。房贷按30年期、利率按当前LPR+加点估算；个人贷按3-5年期估算 |
| dti_threshold | number | DTI阈值 | 按贷款类型：房贷通常≤43%（中国≤50%）；个人消费贷≤40%；企业经营贷视情况 |

## formula
DTI = (monthly_debt_payment + new_monthly_payment) / monthly_income
LTV = loan_amount / asset_value

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| dti | number | 债务收入比（小数形式） |
| dti_percentage | number | 债务收入比（百分比形式） |
| ltv | number | 贷款价值比（小数形式） |
| ltv_percentage | number | 贷款价值比（百分比形式） |
| monthly_income | number | 回显月收入 |
| total_monthly_debt | number | 总月债务支出（现有+新增） |
| dti_pass | boolean | DTI是否通过预审 |
| ltv_pass | boolean | LTV是否通过预审 |
| prequalification_result | string | 预审结论：通过 / 条件通过 / 未通过 |

## example
**输入：**
- 月收入：$30,000
- 月债务支出：$5,000
- 资产价值：$5,000,000
- 贷款金额：$3,500,000
- 贷款类型：mortgage（房贷）
- 新贷款预计月供：$18,000（LLM估值，按30年期、利率4.5%估算）

**计算过程：**
DTI = (5,000 + 18,000) / 30,000 = 23,000 / 30,000 = 0.767
LTV = 3,500,000 / 5,000,000 = 0.70

**输出：**
- DTI：0.767
- DTI百分比：76.7%
- LTV：0.70
- LTV百分比：70%
- 月收入：$30,000
- 总月债务支出：$23,000
- DTI是否通过：否（76.7% > 43%阈值）
- LTV是否通过：是（70% ≤ 80%阈值）
- 预审结论：未通过 — DTI远超阈值，建议降低贷款金额、增加首付比例或增加共同借款人收入

**解读：**
LTV=70%符合房贷要求（通常首套房LTV≤80%），但DTI=76.7%严重超标，月供负担过重。建议将贷款金额降至约$2,000,000以使DTI降至43%以下，或增加共同借款人提升月收入基数。
