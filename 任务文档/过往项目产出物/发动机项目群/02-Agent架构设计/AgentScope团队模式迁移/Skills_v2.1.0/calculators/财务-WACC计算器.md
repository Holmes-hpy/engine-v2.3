# 财务-WACC计算器

## name
财务-WACC计算器

## description
计算企业的加权平均资本成本（Weighted Average Cost of Capital），综合股权成本和债务成本，反映企业整体融资成本。适用于企业估值（DCF折现率）、投资决策（项目最低回报率要求）、资本结构优化。触发词：WACC、加权平均资本成本、Weighted Average Cost of Capital、折现率、资本成本、融资成本。排除词：CAPM、Beta（路由到风险-Beta计算器）、股权成本（单独计算）。

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| equity_market_value | number | 股权市值（E） | 800000000 |
| debt_market_value | number | 债务市值（D） | 200000000 |
| corporate_tax_rate | number | 企业所得税率（小数形式） | 0.25 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| cost_of_equity | number | 股权成本（Re，小数形式） | 若未提供，LLM按CAPM模型估算：Re = Rf + β × (Rm - Rf)。其中Rf取当前10年期国债收益率（约3-4%），Rm-Rf取市场风险溢价（约5-7%），β由风险-Beta计算器提供或按行业估算（科技1.2-1.5，公用事业0.5-0.8，金融1.0-1.3） |
| cost_of_debt | number | 债务成本（Rd，小数形式，税前） | 若未提供，按企业信用评级或市场利率估算：投资级企业3-5%；高收益企业6-10%；中小企业5-8%。也可按最近发债利率或银行贷款利率估算 |
| risk_free_rate | number | 无风险利率（Rf） | 默认取4%（参考当前中国10年期国债收益率约3-4%，美国10年期约4-5%） |
| market_risk_premium | number | 市场风险溢价（Rm-Rf） | 默认取6%（成熟市场5-6%，新兴市场7-8%） |
| beta | number | 贝塔系数（β） | 需从风险-Beta计算器获取或按行业估算。若无法获取，科技/互联网1.2-1.5，消费1.0-1.2，金融1.0-1.3，公用事业0.5-0.8 |

## formula
WACC = (E / V) × Re + (D / V) × Rd × (1 - T)

其中：
- V = E + D（企业总市值）
- E/V = 股权占比
- D/V = 债务占比
- Re = 股权成本
- Rd = 债务成本（税前）
- T = 企业所得税率

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| wacc | number | 加权平均资本成本（小数形式） |
| wacc_percentage | number | 加权平均资本成本（百分比形式） |
| equity_weight | number | 股权占比（E/V） |
| debt_weight | number | 债务占比（D/V） |
| cost_of_equity | number | 回显股权成本（Re） |
| cost_of_debt | number | 回显税前债务成本（Rd） |
| after_tax_cost_of_debt | number | 税后债务成本 = Rd × (1 - T) |
| corporate_tax_rate | number | 回显企业所得税率 |
| beta | number | 回显贝塔系数（若估值则标注） |

## example
**输入：**
- 股权市值：$8亿
- 债务市值：$2亿
- 企业所得税率：25%
- 股权成本：12%（LLM估值，假设Rf=4%、β=1.3、Rm-Rf=6%，则Re=4%+1.3×6%=11.8%≈12%）
- 债务成本：5%（LLM估值，假设投资级企业）

**计算过程：**
V = 8亿 + 2亿 = $10亿
E/V = 8/10 = 0.80
D/V = 2/10 = 0.20

WACC = 0.80 × 0.12 + 0.20 × 0.05 × (1 - 0.25)
     = 0.096 + 0.20 × 0.05 × 0.75
     = 0.096 + 0.0075
     = 0.1035

**输出：**
- WACC：0.1035
- WACC百分比：10.35%
- 股权占比：80%
- 债务占比：20%
- 股权成本（Re）：12%（LLM估值，基于CAPM）
- 税前债务成本（Rd）：5%（LLM估值）
- 税后债务成本：3.75%
- 企业所得税率：25%
- 贝塔系数：1.3（LLM估值，科技行业）

**解读：**
WACC=10.35%意味着企业综合融资成本为10.35%，这是企业所有投资项目的最低回报率要求（Hurdle Rate）。任何预期回报率低于10.35%的项目都会降低企业价值。

**公式原理说明：**
WACC的妙处在于把股权和债务两种融资方式的成本按比例加权：
- 股权成本高（12%），因为股东承担剩余风险，要求更高回报；
- 债务成本低（5%），但还有个"税盾"效应——利息可以税前扣除，所以实际税后成本只有3.75%；
- 加权后就是10.35%，代表了企业每融$1资金的平均成本。

**与DCF估值器的关联：**
WACC通常作为DCF估值器的折现率输入参数。若WACC=10.35%，意味着DCF模型中未来现金流要按10.35%折现回今天。
