# 法律-信托账户对账器

## name
法律-信托账户对账器

## description
对信托账户进行银行余额与账簿余额的对账，计算未达账项调整后的差异，判定账户是否平衡，输出对账差异明细。适用场景：律师信托账户（IOLTA）对账、客户资金账户月度对账、合规审计中的资金核对。触发词：信托对账、IOLTA对账、律师账户对账、银行余额调节。排除词：企业银行对账、个人账户对账。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 银行余额 | float | 银行对账单显示的账户余额 | 150000.00 |
| 账簿余额 | float | 账务系统记录的账户余额 | 148500.00 |
| 未达账项 | array[object] | 银行已记/账簿未记或账簿已记/银行未记的款项 | [{type:"银行已收账簿未收", amount:5000, desc:"利息收入"}] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 对账日期 | string | 对账截止日期 | 默认当天 |
| 可容忍差异 | float | 可接受的微小差异金额 | 默认0.01，即一分钱以内的差异视为可接受 |
| 多客户标识 | boolean | 是否区分客户维度对账 | 默认false，开启后需按客户拆分未达账项 |

## formula
银行已收账簿未收 = Σ(银行已收账簿未收_金额)
银行已付账簿未付 = Σ(银行已付账簿未付_金额)
账簿已收银行未收 = Σ(账簿已收银行未收_金额)
账簿已付银行未付 = Σ(账簿已付银行未付_金额)

银行调节后余额 = 银行余额 + 账簿已收银行未收 - 账簿已付银行未付
账簿调节后余额 = 账簿余额 + 银行已收账簿未收 - 银行已付账簿未付

差异 = 银行调节后余额 - 账簿调节后余额

对账平衡判定:
- |差异| ≤ 可容忍差异: 对账平衡
- |差异| > 可容忍差异: 对账不平，存在差异

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 银行余额 | float | 银行对账单余额 |
| 账簿余额 | float | 账簿记录余额 |
| 银行调节后余额 | float | 调整后的银行余额 |
| 账簿调节后余额 | float | 调整后的账簿余额 |
| 差异金额 | float | 调节后差异 |
| 对账状态 | string | 对账平衡/对账不平 |
| 未达账项汇总 | object | 四类未达账项的合计金额 |
| 差异明细 | array[object] | 差异构成的详细说明 |
| 调节建议 | string | 对账不平时的调节建议 |

## example
【输入】
银行余额: 150000.00
账簿余额: 148500.00
未达账项: [
  {type:"银行已收账簿未收", amount:5000, desc:"客户A汇款"},
  {type:"银行已付账簿未付", amount:1500, desc:"银行手续费"},
  {type:"账簿已收银行未收", amount:3000, desc:"客户B支票"},
  {type:"账簿已付银行未付", amount:2000, desc:"客户C付款支票未兑"}
]
可容忍差异: 0.01

【输出】
银行余额: 150000.00
账簿余额: 148500.00

银行调节后余额 = 150000 + 3000 - 2000 = 151000.00
账簿调节后余额 = 148500 + 5000 - 1500 = 152000.00

差异金额: -1000.00
对账状态: 对账不平

未达账项汇总:
- 银行已收账簿未收: 5000.00
- 银行已付账簿未付: 1500.00
- 账簿已收银行未收: 3000.00
- 账簿已付银行未付: 2000.00

调节建议: 存在1000.00元差异，可能原因包括：(1)存在遗漏的未达账项；(2)某笔金额记录错误；(3)银行费用未记录。建议逐笔核对未达账项金额，并与银行流水逐笔勾对。
