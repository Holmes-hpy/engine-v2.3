# 物流-仓网布局优化计算器

## name
物流-仓网布局优化计算器

## description
根据订单地理分布数据，计算单仓模式与多仓模式下的总成本、平均时效和覆盖范围，输出仓网布局优化对比结果。适用场景：电商/零售企业仓库选址决策、仓储网络规划、配送中心布局优化。触发词：仓网布局、仓库选址、仓储网络优化、多仓对比、配送中心规划。排除词：物流方案对比、运输路线优化、路径规划。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 订单分布数据 | array[object] | 各区域订单量、地址坐标、商品重量/体积 | [{region:"华东", orders:5000, lat:31.2, lng:121.4, avg_weight_kg:2.5}] |
| 候选仓库列表 | array[object] | 候选仓库位置、租金、运营成本 | [{name:"上海仓", lat:31.2, lng:121.4, rent_monthly:150000, labor_cost:80000}] |
| 配送单价 | float | 每单每公里配送成本（元） | 0.85 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 单仓对比仓 | string | 指定单仓方案对比的仓库名 | 默认选订单质心最近的候选仓库 |
| 多仓最大数量 | int | 多仓方案最多仓库数 | 默认3，根据订单量自动调整 |
| 时效权重 | float | 时效在综合评分中的权重 | 默认0.5，成本权重=1-时效权重 |
| 折扣系数 | float | 多仓模式下批量发运的折扣系数 | 默认0.85，基于规模效应估值 |

## formula
单仓总成本 = 仓库租金 + 人力成本 + Σ(各区域订单数 × 配送单价 × 距离)
多仓总成本 = Σ(各仓租金 + 各仓人力成本) + Σ(各区域订单数 × 配送单价 × 距离_最近仓 × 折扣系数)
平均时效 = Σ(距离 × 订单数) / Σ订单数 / 平均配送速度
覆盖范围 = 可48小时内送达的区域数 / 总区域数

综合评分 = 成本得分 × (1-时效权重) + 时效得分 × 时效权重

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单仓方案总成本 | float | 单仓模式下的月度总成本（元） |
| 多仓方案总成本 | float | 多仓模式下的月度总成本（元） |
| 单仓平均时效 | float | 单仓模式下的平均配送时效（小时） |
| 多仓平均时效 | float | 多仓模式下的平均配送时效（小时） |
| 单仓覆盖范围 | float | 单仓模式下48小时覆盖比例 |
| 多仓覆盖范围 | float | 多仓模式下48小时覆盖比例 |
| 推荐方案 | string | 综合评分最高的方案名称 |
| 成本节约 | float | 推荐方案对比另一种方案的成本节约额 |
| 时效提升 | float | 推荐方案对比另一种方案的时效提升（小时） |

## example
【输入】
订单分布数据: [
  {region:"华东", orders:8000, lat:31.2, lng:121.4, avg_weight_kg:2.0},
  {region:"华南", orders:5000, lat:23.1, lng:113.3, avg_weight_kg:2.2},
  {region:"华北", orders:3000, lat:39.9, lng:116.4, avg_weight_kg:2.1},
  {region:"西南", orders:2000, lat:30.6, lng:104.1, avg_weight_kg:2.3}
]
候选仓库列表: [
  {name:"上海仓", lat:31.2, lng:121.4, rent_monthly:150000, labor_cost:80000},
  {name:"广州仓", lat:23.1, lng:113.3, rent_monthly:120000, labor_cost:75000},
  {name:"北京仓", lat:39.9, lng:116.4, rent_monthly:140000, labor_cost:85000},
  {name:"成都仓", lat:30.6, lng:104.1, rent_monthly:100000, labor_cost:65000}
]
配送单价: 0.85
折扣系数: 0.85

【输出】
单仓方案（上海仓）:
- 总成本: 452,360 元/月
- 平均时效: 36.5 小时
- 覆盖范围: 52%

多仓方案（上海+广州+成都）:
- 总成本: 398,200 元/月
- 平均时效: 18.2 小时
- 覆盖范围: 91%

推荐方案: 多仓方案
成本节约: 54,160 元/月
时效提升: 18.3 小时
