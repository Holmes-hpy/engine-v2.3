# 电商-退货原因分类器

## name
电商-退货原因分类器

## description
根据退货记录中的原因代码，对退货数据进行分类统计，输出退货原因分布和帕累托图数据。帮助电商运营团队识别退货问题的根本原因，聚焦关键改进方向。适用于退货原因分析、质量改进优先级排序、供应商谈判依据等场景。触发词：退货原因、退货分类、退货原因分布、帕累托分析、退货归因。排除词：退货率（指比率计算）、退货金额（指金额计算）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| return_records | array[object] | 退货记录列表，每条含退货原因代码 | [{"order_id":"001","reason_code":"Q01","amount":89}, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| reason_mapping | object | 自定义原因代码映射表 | 默认使用标准分类：质量问题(Q01-Q05)、尺寸不合(S01-S03)、描述不符(D01-D03)、不想要(U01)、其他(O01-O99) |
| top_n | int | 帕累托图展示前N个原因 | 默认展示所有原因，按占比降序排列 |
| include_amount | boolean | 是否同时按金额维度统计 | 默认true，若退货记录中包含amount字段则自动计算金额维度 |

## formula
退货原因分类逻辑：
1. 按预定义分类维度对退货原因代码进行归组：
   - 质量问题: Q01(破损), Q02(瑕疵), Q03(功能异常), Q04(色差严重), Q05(材质不符)
   - 尺寸不合: S01(偏大), S02(偏小), S03(版型不合)
   - 描述不符: D01(颜色偏差), D02(规格偏差), D03(图片与实物不符)
   - 不想要: U01(不想要了/七天无理由)
   - 其他: O01-O99

2. 帕累托分析（80/20法则）：
   - 按原因占比降序排列
   - 计算累计占比
   - 标识累计占比达到80%的主要原因（关键少数）

计算步骤：
1. 遍历return_records，按reason_code映射到五大分类维度
2. 统计各分类的订单数量和金额（若有）
3. 计算各分类占比 = 该分类订单数 / 总退货订单数 × 100%
4. 按占比降序排列，计算累计占比
5. 标记累计占比达到80%的分类为"关键少数"
6. 生成帕累托图数据

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| category_distribution | array[object] | 退货原因分类分布 |
| pareto_data | array[object] | 帕累托图数据（含累计占比） |
| key_factors | array[string] | 关键少数原因（累计占比达80%） |
| order_count_distribution | object | 按订单数统计 |
| amount_distribution | object | 按金额统计（若有金额数据） |
| recommendation | string | 改进建议 |

## example
**输入：**
```
return_records: [
  {"order_id": "001", "reason_code": "Q01", "amount": 89},
  {"order_id": "002", "reason_code": "S02", "amount": 120},
  {"order_id": "003", "reason_code": "Q01", "amount": 75},
  {"order_id": "004", "reason_code": "D01", "amount": 150},
  {"order_id": "005", "reason_code": "U01", "amount": 60},
  {"order_id": "006", "reason_code": "Q02", "amount": 95},
  {"order_id": "007", "reason_code": "S02", "amount": 110},
  {"order_id": "008", "reason_code": "Q01", "amount": 88},
  {"order_id": "009", "reason_code": "D03", "amount": 200},
  {"order_id": "010", "reason_code": "U01", "amount": 55}
]
```

**计算过程：**
| 分类 | 包含原因 | 订单数 | 占比 | 累计占比 |
|------|----------|--------|------|----------|
| 质量问题 | Q01×3, Q02×1 | 4 | 40% | 40% |
| 尺寸不合 | S02×2 | 2 | 20% | 60% |
| 描述不符 | D01×1, D03×1 | 2 | 20% | 80% |
| 不想要 | U01×2 | 2 | 20% | 100% |
| 其他 | -- | 0 | 0% | 100% |

关键少数（累计占比80%）：质量问题、尺寸不合、描述不符

**输出：**
```
category_distribution: [
  {"category": "质量问题", "count": 4, "ratio": "40%", "amount": 347},
  {"category": "尺寸不合", "count": 2, "ratio": "20%", "amount": 230},
  {"category": "描述不符", "count": 2, "ratio": "20%", "amount": 350},
  {"category": "不想要", "count": 2, "ratio": "20%", "amount": 115}
]
pareto_data: [
  {"category": "质量问题", "ratio": 40, "cumulative": 40},
  {"category": "尺寸不合", "ratio": 20, "cumulative": 60},
  {"category": "描述不符", "ratio": 20, "cumulative": 80},
  {"category": "不想要", "ratio": 20, "cumulative": 100}
]
key_factors: ["质量问题", "尺寸不合", "描述不符"]
recommendation: "质量问题占比40%为最大退货原因，建议：(1)加强入库质检环节，重点关注破损和瑕疵问题；(2)尺寸不合占20%，需优化尺码表和详情页尺码说明；(3)描述不符占20%，需改善商品图片和描述的准确性，减少图文不符"
```
