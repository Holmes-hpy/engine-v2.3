# 数据-实验统计分析器

## name
数据-实验统计分析器

## description
基于AB测试数据，使用Z检验方法计算实验组和对照组的差异显著性（p值）、置信区间和效果大小，判定实验结果是否具有统计意义。适用场景：AB测试结果分析、产品实验评估、营销策略对比、UI/UX改版效果验证。触发词：AB测试、实验分析、显著性检验、Z检验、实验效果。排除词：多变量测试、MAB、贝叶斯AB。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 对照组样本量 n1 | int | 对照组（A组）的样本数量 | 10000 |
| 实验组样本量 n2 | int | 实验组（B组）的样本数量 | 10000 |
| 对照组转化率 p1 | float | 对照组的转化率 | 0.10 |
| 实验组转化率 p2 | float | 实验组的转化率 | 0.12 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 显著性水平 α | float | 统计显著性水平 | 默认0.05，即95%置信度 |
| 检验类型 | string | 单侧或双侧检验 | 默认"双侧"，有明确方向预期时可选"单侧" |
| 最小检测效果 | float | 最小可检测效果大小（MDE） | 默认0.01，即1%的转化率差异 |
| 多重检验修正 | boolean | 是否进行Bonferroni修正 | 默认false，多组比较时建议开启 |
| 指标类型 | string | 指标类型 | 默认"转化率"，可选"转化率"/"均值"/"比例" |

## formula
合并比例 p_pool = (n1×p1 + n2×p2) / (n1 + n2)

标准误差 SE = sqrt(p_pool × (1-p_pool) × (1/n1 + 1/n2))

Z = (p2 - p1) / SE

p值 = 2 × (1 - Φ(|Z|)) （双侧检验）

置信区间: (p2-p1) ± Z_α/2 × SE

效果大小（Cohen's h）:
h = 2 × arcsin(sqrt(p2)) - 2 × arcsin(sqrt(p1))

显著性判定:
- p值 < α: 显著（有统计差异）
- p值 ≥ α: 不显著（无统计差异）

效果大小判定:
- |h| < 0.2: 微小效果
- 0.2 ≤ |h| < 0.5: 小效果
- 0.5 ≤ |h| < 0.8: 中效果
- |h| ≥ 0.8: 大效果

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 对照组转化率 | float | 对照组转化率 |
| 实验组转化率 | float | 实验组转化率 |
| 绝对提升 | float | 实验组-对照组转化率差值 |
| 相对提升 | float | 绝对提升/对照组转化率 |
| Z值 | float | Z检验统计量 |
| p值 | float | 统计显著性p值 |
| 置信区间 | string | 差异的95%置信区间 |
| 显著性判定 | string | 显著/不显著 |
| 效果大小h | float | Cohen's h效果大小 |
| 效果等级 | string | 微小/小/中/大 |
| 实验结论 | string | 综合实验结论和建议 |

## example
【输入】
对照组样本量 n1: 10000
实验组样本量 n2: 10000
对照组转化率 p1: 0.10
实验组转化率 p2: 0.12
显著性水平 α: 0.05

【输出】
对照组转化率: 10.00%
实验组转化率: 12.00%
绝对提升: 2.00%
相对提升: 20.00%

合并比例 p_pool: 0.11
标准误差 SE: 0.00442
Z值: 4.52
p值: 0.000006

置信区间: [1.13%, 2.87%]
显著性判定: 显著（p < 0.001）

效果大小h: 0.064
效果等级: 微小效果

实验结论: 实验组转化率显著优于对照组（p < 0.001），绝对提升2个百分点，相对提升20%。虽然统计显著，但效果大小仅为微小（h=0.064），建议结合业务影响（如收入增量）评估是否全量上线。如实验成本很低，可以上线。
