# 工程-齿轮强度计算器

## name
工程-齿轮强度计算器

## description
按照GB/T 3480/ISO 6336标准，基于齿轮基本参数（模数、齿数、齿宽、材料等）计算齿面接触应力和齿根弯曲应力，判定齿轮强度是否满足安全要求。适用场景：机械设计中齿轮传动系统的强度校核、齿轮选型与设计验证。触发词：齿轮强度、齿面接触应力、齿根弯曲应力、齿轮校核、ISO 6336。排除词：轴强度、轴承校核、键强度。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 模数 m | float | 齿轮模数（mm） | 3.0 |
| 小齿轮齿数 z1 | int | 主动轮齿数 | 20 |
| 大齿轮齿数 z2 | int | 从动轮齿数 | 60 |
| 齿宽 b | float | 齿宽（mm） | 30 |
| 小齿轮材料 | object | 材料类型、热处理方式、硬度 | {type:"20CrMnTi", heat_treatment:"渗碳淬火", hardness_HRC:58} |
| 大齿轮材料 | object | 材料类型、热处理方式、硬度 | {type:"45钢", heat_treatment:"调质", hardness_HB:240} |
| 输入扭矩 T1 | float | 小齿轮输入扭矩（N·m） | 200 |
| 转速 n1 | float | 主动轮转速（rpm） | 1450 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 精度等级 | int | 齿轮精度等级（GB/T 10095） | 默认7级，通用机械常用精度 |
| 使用系数 KA | float | 工况系数 | 默认1.25，根据工况查表：均匀平稳取1.0，中等冲击取1.25，严重冲击取1.75 |
| 动载系数 Kv | float | 动载系数 | 默认根据精度等级和线速度按ISO 6336图自动计算 |
| 齿向载荷分布系数 KHβ | float | 齿向载荷分布系数 | 默认1.15，根据齿宽系数和支撑方式估值 |
| 寿命系数 | float | 设计寿命要求的寿命系数 | 默认1.0，对应无限寿命设计 |
| 最小安全系数 SH_min | float | 接触强度最小安全系数 | 默认1.0，高可靠性取1.25 |
| 最小安全系数 SF_min | float | 弯曲强度最小安全系数 | 默认1.25，高可靠性取1.4 |

## formula
传动比 u = z2 / z1
分度圆直径 d1 = m × z1
线速度 v = π × d1 × n1 / 60000

齿面接触应力（ISO 6336）:
σH = ZH × ZE × Zε × Zβ × sqrt(Ft × (u+1) / (d1 × b × u))
其中 Ft = 2000 × T1 / d1

许用接触应力: σHP = σHlim × ZNT × ZL × ZV × ZR × ZW / SH_min

接触安全系数: SH = σHlim / σH × ZNT × ZL × ZV × ZR × ZW

齿根弯曲应力: σF = Ft × YF × YS × Yβ × Yε / (b × m)

许用弯曲应力: σFP = σFlim × YST × YNT × YδrelT × YRrelT × YX / SF_min

弯曲安全系数: SF = σFlim × YST × YNT × YδrelT × YRrelT × YX / σF

## example
【输入】
模数 m: 3.0
小齿轮齿数 z1: 20
大齿轮齿数 z2: 60
齿宽 b: 30
小齿轮材料: {type:"20CrMnTi", heat_treatment:"渗碳淬火", hardness_HRC:58}
大齿轮材料: {type:"45钢", heat_treatment:"调质", hardness_HB:240}
输入扭矩 T1: 200 N·m
转速 n1: 1450 rpm
精度等级: 7

【输出】
传动比: 3.0
分度圆直径 d1: 60 mm
线速度: 4.56 m/s
齿面接触应力 σH: 892.5 MPa
许用接触应力 σHP: 1200 MPa
接触安全系数 SH: 1.34
接触强度判定: 合格

齿根弯曲应力 σF: 215.3 MPa
许用弯曲应力 σFP: 360 MPa
弯曲安全系数 SF: 1.67
弯曲强度判定: 合格

综合判定: 合格 — 齿轮副满足GB/T 3480/ISO 6336标准要求，接触和弯曲强度均有充足裕量。
