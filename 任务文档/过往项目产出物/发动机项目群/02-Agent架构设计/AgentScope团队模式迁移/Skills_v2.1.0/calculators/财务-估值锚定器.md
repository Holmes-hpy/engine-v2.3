# 财务-估值锚定器

## name
财务-估值锚定器

## description
基于ARR和增长率，结合可比公司倍数和增长率溢价系数，估算SaaS企业的合理估值区间。适用于SaaS企业估值对标、融资定价参考、Benchmark分析。触发词：估值锚定、SaaS估值、ARR估值、增长率估值、估值区间、SaaS Valuation。排除词：DCF估值、可比公司详情、分部估值。

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| arr | number | 年度经常性收入（ARR） | 10000000 |
| growth_rate | number | 年增长率（小数形式，如0.50表示50%） | 0.50 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| comparable_multiple | number | 可比公司ARR倍数（EV/ARR） | 按增长率和市场阶段估算：高增长（>50%年增长）15-30x；中增长（20-50%）8-15x；低增长（<20%）3-8x。当前市场环境下，SaaS公司ARR倍数中位数约8-10x |
| market_sentiment | string | 市场情绪 | 可选值：bull（牛市，倍数上浮20%）/ neutral（中性，默认）/ bear（熊市，倍数下浮30%）。默认neutral |

## formula
建议估值区间 = arr × comparable_multiple × (1 + growth_premium)

其中：
- growth_premium = (growth_rate - market_avg_growth) / market_avg_growth × 0.5
- market_avg_growth默认取20%（行业平均增长率）
- 系数0.5为增长率溢价的敏感度，可根据实际调整

简化版（当无法精确计算growth_premium时）：
估值低端 = arr × comparable_multiple_low
估值中端 = arr × comparable_multiple_median
估值高端 = arr × comparable_multiple_high

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| valuation_low | number | 估值区间低端 |
| valuation_median | number | 估值区间中位数 |
| valuation_high | number | 估值区间高端 |
| implied_multiple_low | number | 隐含ARR倍数（低端） |
| implied_multiple_high | number | 隐含ARR倍数（高端） |
| arr | number | 回显ARR |
| growth_rate | number | 回显增长率 |
| market_sentiment | string | 回显市场情绪 |

## example
**输入：**
- ARR：$10,000,000
- 增长率：50%（0.50）
- 市场情绪：neutral（中性）
- 可比倍数：LLM估值（高增长SaaS，中位数12x，范围8-20x）

**计算过程：**
估值低端 = 10,000,000 × 8 = $80,000,000
估值中端 = 10,000,000 × 12 = $120,000,000
估值高端 = 10,000,000 × 20 = $200,000,000

**输出：**
- 估值区间低端：$80,000,000（$8,000万）
- 估值区间中位数：$120,000,000（$1.2亿）
- 估值区间高端：$200,000,000（$2亿）
- 隐含ARR倍数（低端）：8x
- 隐含ARR倍数（高端）：20x
- ARR：$10,000,000
- 增长率：50%
- 市场情绪：中性

**解读：**
该SaaS公司ARR为$1,000万，年增长50%，属于高增长企业。以ARR倍数8-20x估算，估值区间为$8,000万-$2亿。50%的增长率支撑了较高的倍数区间。若增长率降至30%，倍数区间可能收窄至5-12x，估值区间相应降至$5,000万-$1.2亿，说明维持高增长对SaaS企业估值至关重要。
