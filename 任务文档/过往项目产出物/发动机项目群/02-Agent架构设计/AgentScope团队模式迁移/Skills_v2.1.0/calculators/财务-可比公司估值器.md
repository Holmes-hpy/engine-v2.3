# 财务-可比公司估值器

## name
财务-可比公司估值器

## description
使用可比公司倍数法（Comparable Company Analysis）对目标企业进行估值，基于可比上市公司估值倍数的中位数推算目标公司估值区间。适用于企业估值、IPO定价、并购交易、股权投资决策。触发词：可比公司估值、可比估值、Comps、Comparable Company、倍数法估值、PE估值、PS估值、EV/EBITDA。排除词：DCF、现金流折现、分部加总。

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| target_financial_metric | number | 目标公司对应财务指标（如EBITDA、净利润、收入等） | 50000000 |
| metric_type | string | 财务指标类型 | EBITDA / net_income / revenue / book_value |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| comparable_multiples | array[number] | 可比公司对应倍数列表 | 若未提供，LLM按行业和指标类型估算：软件/SaaS行业EV/Revenue通常5-15x，EV/EBITDA 15-40x；制造业EV/EBITDA 6-12x；金融PB 0.8-2x。也可按metric_type默认估值区间 |
| comparable_companies | array[string] | 可比公司名称列表 | 仅用于说明和参考，不参与计算。若用户提供，则输出时列出 |
| premium_discount | number | 流动性折价/控制权溢价调整 | 默认0%。非上市公司通常有20-30%的流动性折价；控股股权可能有20-30%的控制权溢价 |

## formula
估值区间 = comparable_multiples_median × target_financial_metric × (1 + premium_discount)

估值低端 = comparable_multiples_25th_percentile × target_financial_metric × (1 + premium_discount)
估值高端 = comparable_multiples_75th_percentile × target_financial_metric × (1 + premium_discount)

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| median_valuation | number | 中位数估值 |
| valuation_low | number | 估值区间低端（25分位） |
| valuation_high | number | 估值区间高端（75分位） |
| multiple_used | number | 使用的可比公司倍数中位数 |
| metric_type | string | 回显财务指标类型 |
| target_financial_metric | number | 回显目标公司财务指标 |
| comparable_companies | array[string] | 可比公司列表（若提供） |

## example
**输入：**
- 目标公司EBITDA：$50,000,000
- 指标类型：EBITDA
- 可比公司倍数：LLM估值（SaaS行业EV/EBITDA中位数25x，25分位18x，75分位35x）

**计算过程：**
中位数估值 = 50,000,000 × 25 = $1,250,000,000
估值低端 = 50,000,000 × 18 = $900,000,000
估值高端 = 50,000,000 × 35 = $1,750,000,000

**输出：**
- 中位数估值：$12.5亿
- 估值区间低端：$9.0亿
- 估值区间高端：$17.5亿
- 使用倍数：25x EV/EBITDA（LLM估值，基于SaaS行业中位数）
- 指标类型：EBITDA
- 目标公司EBITDA：$50,000,000

**解读：**
基于可比SaaS公司的EV/EBITDA倍数，目标公司估值区间为$9.0-17.5亿。估值区间较宽反映可比公司倍数差异较大，建议结合DCF估值交叉验证。若目标公司为非上市公司，可考虑20-30%的流动性折价。
