# 电商-欺诈指标计算器

## name
电商-欺诈指标计算器

## description
计算退货行为中的单项欺诈指标，包括退货频率异常、地址异常、金额异常、时间异常等多个维度，输出各指标的量化异常值。与退货防欺诈评分器（综合）不同，本计算器专注于单项指标的精细化计算，为综合评分提供底层数据。适用于电商风控数据建模、异常行为检测、欺诈特征工程等场景。触发词：欺诈指标、异常检测、退货频率异常、地址异常、金额异常、时间异常。排除词：防欺诈评分（指综合评分）、欺诈综合评分。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| user_behavior_data | object | 用户退货行为数据 | {"return_count_30d":5,"total_orders_30d":8,...} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| platform_benchmark | object | 平台基准数据 | 默认使用行业均值：退货频率均值=5%，地址异常率=2%，平均退货金额=200元等 |
| anomaly_threshold | float | 异常判定阈值（标准差倍数） | 默认2.0（超过均值2个标准差视为异常） |
| indicators | array[string] | 指定要计算的指标列表 | 默认计算全部四项指标 |

## formula
单项欺诈指标计算逻辑：

1. **退货频率异常**：
   退货频率 = 近30天退货次数 / 近30天总订单数
   异常指数 = (退货频率 - 平台均值) / 平台标准差
   若退货频率 > 平台均值 + 2σ → 异常

2. **地址异常**：
   地址异常指数 = 命中高风险地址库次数 + 退货地址与收货地址不一致次数
   若异常指数 > 0 → 触发信号

3. **金额异常**：
   金额异常指数 = (用户平均退货金额 - 平台平均退货金额) / 平台标准差
   若用户平均退货金额 > 平台均值 + 2σ → 异常

4. **时间异常**：
   时间异常指数 = 收货后1小时内退货的订单数 / 总退货订单数
   若时间异常指数 > 0.15（15%）→ 异常

计算步骤：
1. 根据indicators参数确定要计算的指标项
2. 对每个指标，从user_behavior_data中提取相关数据
3. 与platform_benchmark对比，计算异常指数
4. 根据anomaly_threshold判定是否触发异常信号
5. 输出各指标的计算详情

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| frequency_anomaly | object | 退货频率异常指标详情 |
| address_anomaly | object | 地址异常指标详情 |
| amount_anomaly | object | 金额异常指标详情 |
| time_anomaly | object | 时间异常指标详情 |
| triggered_indicators | array[string] | 已触发的异常指标列表 |
| overall_anomaly_score | float | 综合异常评分（0-1） |

## example
**输入：**
```
user_behavior_data: {
  "return_count_30d": 5,
  "total_orders_30d": 8,
  "return_addresses": ["北京市朝阳区", "上海市浦东新区"],
  "delivery_address": "北京市朝阳区",
  "avg_return_amount": 450.00,
  "return_within_1h": 2,
  "total_returns": 5
}
platform_benchmark: {
  "avg_return_frequency": 0.05,
  "std_return_frequency": 0.03,
  "avg_return_amount": 200,
  "std_return_amount": 100
}
```

**计算过程：**
1. 退货频率 = 5/8 = 0.625（62.5%）
   异常指数 = (0.625 - 0.05) / 0.03 = 19.17 → 远超2σ阈值 → 触发异常

2. 地址异常：退货地址涉及2个不同城市，与收货地址不一致 → 触发异常

3. 金额异常 = (450 - 200) / 100 = 2.50 → 超过2σ阈值 → 触发异常

4. 时间异常 = 2/5 = 0.40（40%）→ 超过15%阈值 → 触发异常

**输出：**
```
frequency_anomaly: {
  "value": 0.625,
  "benchmark": 0.05,
  "z_score": 19.17,
  "triggered": true,
  "severity": "极高"
}

  "unique_cities": 2,
  "triggered": true,
  "severity": "高"
}
amount_anomaly: {
  "value": 450.00,
  "benchmark": 200.00,
  "z_score": 2.50,
  "triggered": true,
  "severity": "高"
}

  "triggered": true,
  "severity": "极高"
}
triggered_indicators: ["退货频率异常", "地址异常", "金额异常", "时间异常"]
overall_anomaly_score: 0.92
```
