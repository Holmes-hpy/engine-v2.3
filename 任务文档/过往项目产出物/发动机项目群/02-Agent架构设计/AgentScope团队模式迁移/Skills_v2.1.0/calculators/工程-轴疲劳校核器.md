# 工程-轴疲劳校核器

## name
工程-轴疲劳校核器

## description
基于轴的结构参数（直径、材料、载荷等），计算弯扭合成应力、疲劳安全系数和挠度，判定轴在交变载荷下的疲劳强度是否满足设计要求。适用场景：传动轴设计校核、转轴疲劳寿命评估、轴类零件强度验证。触发词：轴疲劳、轴校核、弯扭合成应力、疲劳安全系数、轴挠度。排除词：齿轮强度、轴承寿命、键连接。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 轴径 d | float | 轴的最小直径（mm） | 40 |
| 轴材料 | object | 材料类型、屈服强度、抗拉强度 | {type:"40Cr", yield_strength_MPa:785, tensile_strength_MPa:980} |
| 弯矩 M | float | 危险截面弯矩（N·m） | 150 |
| 扭矩 T | float | 危险截面扭矩（N·m） | 200 |
| 支撑方式 | string | 轴的支撑方式 | "简支" / "悬臂" / "两端固定" |
| 支点间距 L | float | 两支撑点间距（mm） | 500 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 应力集中系数 Kσ | float | 有效应力集中系数 | 默认根据轴肩圆角半径和轴径比值查表，典型值1.5-2.5 |
| 尺寸系数 εσ | float | 尺寸系数 | 默认根据轴径查表，d=40mm时约0.84 |
| 表面质量系数 β | float | 表面加工质量系数 | 默认0.9（精车），磨削取1.0，粗车取0.8 |
| 最小安全系数 S_min | float | 许用疲劳安全系数 | 默认1.5，重要轴取1.8-2.5 |
| 许用挠度 y_max | float | 许用最大挠度（mm） | 默认(0.0001-0.0005)×L，一般传动轴取0.0002L |
| 载荷类型 | string | 载荷变化类型 | 默认"对称循环"，可选"脉动循环"/"对称循环" |

## formula
抗弯截面系数 W = π × d³ / 32
抗扭截面系数 Wt = π × d³ / 16

弯曲应力 σ = M × 1000 / W
扭转切应力 τ = T × 1000 / Wt

弯扭合成应力（第三强度理论）:
σ_v = sqrt(σ² + 3τ²)

疲劳安全系数校核:
Sσ = σ-1 / (Kσ × σ / (εσ × β) + ψσ × σm)
Sτ = τ-1 / (Kτ × τ / (ετ × β) + ψτ × τm)
综合安全系数 S = Sσ × Sτ / sqrt(Sσ² + Sτ²)

其中 σ-1 = 0.4 × σb（对称循环弯曲疲劳极限估算）
τ-1 = 0.23 × σb（对称循环扭转疲劳极限估算）

挠度（简支梁集中载荷）:
y = F × L³ / (48 × E × I)
其中 I = π × d⁴ / 64，E为弹性模量（钢取206000 MPa）

## example
【输入】
轴径 d: 40 mm
轴材料: {type:"40Cr", yield_strength_MPa:785, tensile_strength_MPa:980}
弯矩 M: 150 N·m
扭矩 T: 200 N·m
支撑方式: "简支"
支点间距 L: 500 mm
应力集中系数 Kσ: 1.8
尺寸系数 εσ: 0.84
表面质量系数 β: 0.9

【输出】
抗弯截面系数 W: 6283 mm³
抗扭截面系数 Wt: 12566 mm³
弯曲应力 σ: 23.87 MPa
扭转切应力 τ: 15.92 MPa
弯扭合成应力 σ_v: 36.31 MPa
弯曲疲劳安全系数 Sσ: 8.62
扭转疲劳安全系数 Sτ: 7.35
综合安全系数 S: 5.61
最大挠度 y: 0.08 mm

静强度判定: 合格（σ_v = 36.31 MPa << σs = 785 MPa）
疲劳强度判定: 合格（S = 5.61 > S_min = 1.5）
刚度判定: 合格（y = 0.08 mm < y_max = 0.10 mm）
综合判定: 合格 — 轴满足静强度、疲劳强度和刚度要求。
