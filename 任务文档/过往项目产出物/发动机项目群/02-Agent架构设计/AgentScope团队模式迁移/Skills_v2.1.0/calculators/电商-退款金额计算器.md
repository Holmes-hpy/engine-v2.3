# 电商-退款金额计算器

## name
电商-退款金额计算器

## description
根据支付方式、退货商品价值和退款规则，精确计算应退还给用户的金额。支持部分退款、全额退款、运费补贴等多种退款场景，自动处理平台优惠券分摊和积分抵扣等复杂逻辑。适用于电商退货退款流程、售后金额核算、退款审批等场景。触发词：退款金额、退货退款、退款计算、退款核算、售后退款。排除词：退款率（指退款率统计）、退款原因（指原因分类）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| payment_method | string | 支付方式（alipay/wechat/credit_card/cod/balance） | "alipay" |
| item_value | float | 退货商品原价（元） | 199.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| refund_ratio | float | 退款比例（0-1） | 默认1.0（全额退款）；若为部分退款则按比例计算 |
| coupon_deduction | float | 已使用优惠券金额（元） | 默认0元；若使用了不可退的优惠券，需从退款中扣除 |
| shipping_fee_refund | float | 退货运费补贴（元） | 默认0元；若商家承担退货运费，按实际运费或平台运费险标准 |
| platform_fee_refund | boolean | 平台扣点是否退还 | 默认false；多数平台扣点不退，部分平台仅退部分比例 |
| paid_amount | float | 用户实际支付金额（元） | 若未提供，默认等于item_value |
| points_deduction | float | 积分抵扣金额（元） | 默认0元；积分通常退回积分账户而非退款金额 |

## formula
退款金额 = 实际支付金额 × 退款比例 - 优惠券不可退部分 - 积分抵扣（现金部分）+ 运费补贴

其中：
- 全额退款：退款比例 = 1.0，退款金额 = 实际支付金额
- 部分退款：退款金额 = 实际支付金额 × 退款比例
- 平台扣点不可退时，商家实际承担 = 退款金额 + 平台扣点（若不退）

计算步骤：
1. 确定退款比例（全额=1.0/部分=<1.0）
2. 基础退款 = 实际支付金额 × 退款比例
3. 扣除不可退的优惠券金额
4. 扣除积分抵扣的现金部分（积分退回积分账户）
5. 加上运费补贴（若有）
6. 最终退款金额 = 基础退款 - 优惠券扣除 - 积分扣除 + 运费补贴
7. 计算商家实际净损失（退款金额 + 不可退的平台扣点 + 物流成本）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| refund_amount | float | 退还给用户的金额（元） |
| coupon_refund | float | 退回的优惠券金额（元） |
| points_refund | float | 退回的积分 |
| shipping_refund | float | 运费补贴（元） |
| merchant_net_loss | float | 商家实际净损失（元） |
| refund_type | string | 退款类型（全额/部分） |

## example
**输入：**
```
payment_method: "alipay"
item_value: 199.00
paid_amount: 169.00
refund_ratio: 1.0
coupon_deduction: 30.00
shipping_fee_refund: 10.00
platform_fee_refund: false
```

**计算过程：**
1. 退款比例 = 1.0（全额退款）
2. 基础退款 = 169.00 × 1.0 = 169.00元
3. 优惠券扣除 = 30.00元（优惠券不可退）
4. 运费补贴 = 10.00元
5. 退款金额 = 169.00 - 30.00 + 10.00 = 149.00元
6. 平台扣点 = 199.00 × 0.05 = 9.95元（不可退）
7. 商家净损失 = 149.00 + 9.95 + 6.00（物流）= 164.95元

**输出：**
```
refund_amount: 149.00
coupon_refund: 0
points_refund: 0
shipping_refund: 10.00
merchant_net_loss: 164.95
refund_type: "全额退款"
```
