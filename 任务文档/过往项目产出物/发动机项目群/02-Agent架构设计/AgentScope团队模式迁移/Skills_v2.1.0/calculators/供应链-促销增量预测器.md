# 供应链-促销增量预测器

## name
供应链-促销增量预测器

## description
预测促销活动带来的需求增量，通过基线需求乘以促销弹性系数计算促销期间的增量需求。帮助供应链团队提前做好促销备货和产能规划，避免促销期间的缺货或过度备货。适用于电商大促备货、促销活动库存规划、营销ROI预估等场景。触发词：促销增量、促销需求、大促备货、促销弹性、双十一备货、618备货。排除词：基线需求预测（指常规预测）、促销ROI（指营销投资回报率）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| baseline_demand | float | 基线需求（非促销期的日均/周均需求量） | 150.00 |
| promotion_type | string | 促销类型（flash_sale/coupon/bundle/full_reduction/new_user/general） | "flash_sale" |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| promotion_elasticity | float | 促销弹性系数 | 默认按促销类型：限时秒杀(3.0-5.0)、优惠券(1.5-2.5)、满减(1.8-3.0)、套装(1.3-2.0)、新用户专享(2.0-4.0)、通用促销(1.5-2.0) |
| promotion_duration | int | 促销持续天数 | 默认1天 |
| discount_depth | float | 折扣深度（如0.70表示7折） | 默认0.70；折扣越深弹性系数越大，每增加10%折扣，弹性系数增加0.5 |
| cannibalization_rate | float | 蚕食率（促销对非促销期销量的影响） | 默认0.15（15%），表示促销后15%的常规需求被提前消费 |
| historical_promo_lift | float | 历史同类促销的增量倍数 | 若提供，优先使用历史数据替代弹性系数估算 |
| category | string | 商品品类 | 用于辅助选择弹性系数：快消品类弹性更高，耐用品类弹性较低 |

## formula
促销增量需求 = 基线需求 × 促销弹性系数

促销总需求 = 基线需求 + 促销增量需求 = 基线需求 × (1 + 促销弹性系数)

促销期间总需求 = 促销总需求 × 促销持续天数

蚕食调整：
- 促销实际增量 = 促销增量需求 × (1 - 蚕食率)
- 促销后低谷需求 = 基线需求 × (1 - 蚕食率)（促销后N天）

默认弹性系数参考表：
| 促销类型 | 弹性系数范围 | 推荐默认值 | 说明 |
|----------|-------------|-----------|------|
| 限时秒杀 | 3.0-5.0 | 4.0 | 时间紧迫感最强，需求爆发力最大 |
| 新用户专享 | 2.0-4.0 | 3.0 | 价格敏感型新用户，弹性较高 |
| 满减 | 1.8-3.0 | 2.5 | 凑单心理驱动，中等弹性 |
| 优惠券 | 1.5-2.5 | 2.0 | 根据券面额和门槛浮动 |
| 套装 | 1.3-2.0 | 1.5 | 组合销售，弹性相对较低 |
| 通用促销 | 1.5-2.0 | 1.8 | 无特殊限制的常规促销 |

弹性系数调整因子：
- 折扣深度调整：每增加10%折扣，弹性系数×1.15
- 品牌力调整：知名品牌×0.8，白牌×1.2
- 季节性调整：旺季×1.3，淡季×0.8

计算步骤：
1. 确定促销弹性系数（优先使用历史数据，其次按促销类型查表，再按折扣深度调整）
2. 促销总需求 = 基线需求 × (1 + 弹性系数)
3. 促销期间总需求 = 促销总需求 × 持续天数
4. 蚕食调整：实际增量 = 增量 × (1 - 蚕食率)
5. 输出促销期间各日需求预测

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| baseline_demand | float | 基线需求（单期） |
| promotion_elasticity | float | 使用的促销弹性系数 |
| incremental_demand | float | 促销增量需求（单期） |
| total_promotion_demand | float | 促销期间总需求 |
| daily_demand_forecast | array[object] | 促销期间每日需求预测 |
| post_promotion_dip | float | 促销后低谷需求 |
| inventory_recommendation | float | 建议备货量 |
| confidence | float | 预测置信度 |

## example
**输入：**
```
baseline_demand: 150.00
promotion_type: "flash_sale"
promotion_duration: 3
discount_depth: 0.60
```

**计算过程：**
1. 促销弹性系数：限时秒杀默认4.0，折扣深度0.60（6折）→ 调整因子 = 1.15^(4) = 1.749 → 弹性系数 = 4.0 × 1.749 = 7.0
2. 促销总需求（单日）= 150 × (1 + 7.0) = 150 × 8.0 = 1200
3. 促销期间总需求 = 1200 × 3 = 3600
4. 蚕食调整：实际增量 = 1200 × 7.0 × (1 - 0.15) = 1200 × 5.95 = 7140（待确认计算）
   再算：单日增量 = 150 × 7.0 = 1050，实际单日增量 = 1050 × (1 - 0.15) = 892.5
   实际单日总需求 = 150 + 892.5 = 1042.5
   3天总需求 = 1042.5 × 3 = 3127.5
5. 建议备货量 = 3127.5 × 1.2（安全系数）= 3753

**输出：**
```
baseline_demand: 150.00
promotion_elasticity: 7.0
incremental_demand: 892.5
total_promotion_demand: 3127.5
daily_demand_forecast: [
  {"day": 1, "demand": 1042.5},
  {"day": 2, "demand": 1042.5},
  {"day": 3, "demand": 1042.5}
]
post_promotion_dip: 127.5
inventory_recommendation: 3753
confidence: 0.72
```
