# 数据-趋势分析器

## name
数据-趋势分析器

## description
按指定时间粒度（日/周/月/季/年）对时间序列数据进行聚合，计算各周期的汇总值、环比增长率和同比增长率，输出趋势曲线和关键拐点。适用场景：业务指标趋势分析、销售数据聚合、流量趋势监控、财务报表生成。触发词：趋势分析、时间序列聚合、环比同比、趋势曲线。排除词：趋势预测、生命周期判定、异常检测。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 时间序列数据 | array[object] | 带时间戳的数据点 | [{date:"2026-01-01", value:1000}, {date:"2026-01-02", value:1200}, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 聚合粒度 | string | 聚合的时间粒度 | 默认"月"，可选"日"/"周"/"月"/"季"/"年" |
| 聚合函数 | string | 聚合使用的函数 | 默认"SUM"，可选"SUM"/"AVG"/"MAX"/"MIN"/"COUNT" |
| 环比开关 | boolean | 是否计算环比 | 默认true |
| 同比开关 | boolean | 是否计算同比 | 默认true（需跨年数据） |
| 趋势线类型 | string | 趋势线拟合方式 | 默认"线性"，可选"线性"/"移动平均"/"指数" |
| 移动平均窗口 | int | 移动平均的窗口大小 | 默认3，即3期移动平均 |
| 数据范围 | object | 自定义数据范围 | 默认全部数据，可指定起止日期 |

## formula
周期聚合值 = 聚合函数(该周期内所有数据点)

环比增长率 = (本期聚合值 - 上期聚合值) / 上期聚合值 × 100%

同比增长率 = (本期聚合值 - 去年同期聚合值) / 去年同期聚合值 × 100%

移动平均值 = 最近N期聚合值的简单平均

趋势方向:
- 连续3期环比为正: 上升趋势
- 连续3期环比为负: 下降趋势
- 其他: 波动趋势

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 聚合结果 | array[object] | 各周期的聚合值、环比、同比 |
| 总聚合值 | float | 全部数据的聚合值 |
| 周期数 | int | 聚合后的周期数量 |
| 趋势方向 | string | 上升/下降/波动 |
| 平均环比增长率 | float | 各期环比增长率的平均值 |
| 最高周期 | object | 聚合值最高的周期 |
| 最低周期 | object | 聚合值最低的周期 |
| 趋势摘要 | string | 趋势分析总结 |

## example
【输入】
时间序列数据: [
  {date:"2026-01-01", value:1000}, {date:"2026-01-02", value:1200}, ...,
  {date:"2026-06-30", value:1800}
]
聚合粒度: "月"
聚合函数: "SUM"
数据范围: 2026年1月-6月

【输出】
聚合结果:
- 2026-01月: 32000, 环比: N/A, 同比: N/A
- 2026-02月: 35000, 环比: +9.4%, 同比: N/A
- 2026-03月: 38000, 环比: +8.6%, 同比: N/A
- 2026-04月: 36000, 环比: -5.3%, 同比: N/A
- 2026-05月: 40000, 环比: +11.1%, 同比: N/A
- 2026-06月: 42000, 环比: +5.0%, 同比: N/A

总聚合值: 223000
周期数: 6
趋势方向: 上升（4涨2跌，整体向上）
平均环比增长率: +5.76%
最高周期: 2026-06月 (42000)
最低周期: 2026-01月 (32000)

趋势摘要: 6个月数据整体呈上升趋势，月均环比增长5.76%。4月出现小幅回调(-5.3%)，但5月和6月迅速恢复增长。累计增长31.25%，表现良好。
