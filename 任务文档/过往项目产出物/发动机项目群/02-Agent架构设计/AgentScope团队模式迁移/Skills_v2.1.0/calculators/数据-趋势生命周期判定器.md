# 数据-趋势生命周期判定器

## name
数据-趋势生命周期判定器

## description
基于增长率趋势、市场渗透率和竞争格局三个维度，综合判定产品/业务所处的生命周期阶段（导入期/成长期/成熟期/衰退期），并给出判定信心等级。适用场景：产品生命周期管理、市场战略规划、投资决策支持、业务组合分析。触发词：生命周期判定、产品阶段、市场阶段、导入期、成长期、成熟期、衰退期。排除词：软件生命周期、开发生命周期、SDLC。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 增长率趋势 | object | 近几个周期的增长率数据 | {current:0.45, prev:0.50, trend:"减速", periods:4} |
| 市场渗透率 | float | 当前市场渗透率 | 0.15 |
| 竞争格局 | object | 市场竞争态势描述 | {competitors:8, concentration:"分散", barrier:"低"} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 行业基准 | object | 各阶段典型增长率/渗透率/竞争格局 | 默认按通用行业基准，可自定义 |
| 判定权重 | object | 三个维度的权重分配 | 默认: 增长率=0.45, 渗透率=0.30, 竞争格局=0.25 |
| 时间跨度 | string | 数据覆盖的时间范围 | 默认"最近12个月" |
| 过渡期判定 | boolean | 是否识别过渡期（如导入→成长） | 默认false |

## formula
生命周期阶段判定维度:

1. 增长率趋势:
   - 增长率 > 50% 且加速: 导入期特征
   - 增长率 30%-50%: 成长期特征
   - 增长率 5%-30%: 成熟期特征
   - 增长率 < 5% 或负增长: 衰退期特征

2. 市场渗透率:
   - 渗透率 < 5%: 导入期特征
   - 渗透率 5%-20%: 成长期特征
   - 渗透率 20%-50%: 成熟期特征
   - 渗透率 > 50%: 饱和/衰退期特征

3. 竞争格局:
   - 竞争者少(<5家)、格局分散: 导入期特征
   - 竞争者增多、格局开始集中: 成长期特征
   - 格局稳定、头部集中: 成熟期特征
   - 竞争者退出、替代品出现: 衰退期特征

综合得分 = 增长率得分 × 0.45 + 渗透率得分 × 0.30 + 竞争格局得分 × 0.25

阶段判定: 取综合得分对应的阶段

信心等级: 基于三维度一致性
- 三维度一致: 高信心
- 两个维度一致: 中信心
- 三维度各不同: 低信心

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 所处阶段 | string | 导入期/成长期/成熟期/衰退期 |
| 信心等级 | string | 高/中/低 |
| 增长率维度判定 | string | 基于增长率的阶段判定 |
| 渗透率维度判定 | string | 基于渗透率的阶段判定 |
| 竞争格局维度判定 | string | 基于竞争格局的阶段判定 |
| 阶段特征 | string | 当前阶段的典型特征描述 |
| 战略建议 | string | 基于阶段的战略建议 |

## example
【输入】
增长率趋势: {current:0.45, prev:0.50, trend:"减速", periods:4}
市场渗透率: 0.15
竞争格局: {competitors:8, concentration:"分散", barrier:"低"}

【输出】
增长率维度判定: 成长期（增长率45%，减速但仍处高位）
渗透率维度判定: 成长期（渗透率15%，处于5%-20%区间）
竞争格局维度判定: 成长期（竞争者8家，格局分散，壁垒低）

所处阶段: 成长期
信心等级: 高（三维度一致）

阶段特征: 市场处于快速成长期，增长率仍高达45%但开始减速，渗透率15%有较大提升空间，竞争者增多但格局尚未稳定，进入壁垒低。

战略建议: 成长期是抢占市场份额的关键窗口。建议：(1)加大市场投入，快速扩大用户基数；(2)建立品牌壁垒和用户粘性，应对竞争加剧；(3)关注增长率减速趋势，提前布局差异化能力，为进入成熟期做准备。
