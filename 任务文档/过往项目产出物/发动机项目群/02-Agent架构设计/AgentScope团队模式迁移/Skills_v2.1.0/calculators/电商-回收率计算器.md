# 电商-回收率计算器

## name
电商-回收率计算器

## description
计算电商退货商品中可二次销售部分的比例（回收率），衡量退货商品的价值恢复能力。回收率越高，说明退货商品的质量损耗越小，商家的售后损失越低。适用于电商退货资产管理、退货商品处理策略优化、逆向物流成本控制等场景。触发词：回收率、退货回收、二次销售、退货价值恢复、逆向物流回收。排除词：回收（指环保回收/废品回收场景）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| resalable_return_amount | float | 可二次销售的退货商品总金额（元） | 15000.00 |
| total_return_amount | float | 总退货商品金额（元） | 50000.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| resalable_return_count | int | 可二次销售退货件数 | 若未提供，则仅按金额维度计算回收率 |
| total_return_count | int | 总退货件数 | 若未提供，则仅按金额维度计算回收率 |
| discount_rate | float | 二次销售折价率 | 默认0.80（8折）；二次销售通常以折扣价出售 |
| disposal_cost | float | 不可二次销售退货的处理成本（元） | 默认按不可回收金额的5%估算 |
| processing_cost | float | 退货处理成本（质检/翻新/重新包装，元/件） | 默认3元/件 |

## formula
按金额维度：
回收率 = 可二次销售退货金额 / 总退货金额 × 100%

按件数维度：
件数回收率 = 可二次销售退货件数 / 总退货件数 × 100%

综合回收价值：
实际回收价值 = 可二次销售退货金额 × 二次销售折价率 - 退货处理成本

净损失 = 总退货金额 - 实际回收价值 + 不可回收处置成本

计算步骤：
1. 计算金额回收率 = 可二次销售退货金额 / 总退货金额 × 100%
2. 若提供件数数据，计算件数回收率
3. 实际回收价值 = 可二次销售金额 × 折扣率 - 处理成本
4. 净损失 = 总退货金额 - 实际回收价值 + 处置成本
5. 输出回收效率评估

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| recovery_rate_amount | float | 金额回收率（%） |
| recovery_rate_count | float | 件数回收率（%，若提供件数） |
| actual_recovery_value | float | 实际回收价值（元） |
| net_loss | float | 净损失（元） |
| loss_rate | float | 损失率（%） |
| efficiency_grade | string | 回收效率评级（优秀/良好/一般/较差） |

## example
**输入：**
```
resalable_return_amount: 15000.00
total_return_amount: 50000.00
resalable_return_count: 45
total_return_count: 150
discount_rate: 0.80
processing_cost: 3.00
```

**计算过程：**
1. 金额回收率 = 15000 / 50000 × 100% = 30.00%
2. 件数回收率 = 45 / 150 × 100% = 30.00%
3. 实际回收价值 = 15000 × 0.80 - 45 × 3 = 12000 - 135 = 11865元
4. 不可回收处置成本 = (50000 - 15000) × 0.05 = 1750元
5. 净损失 = 50000 - 11865 + 1750 = 39885元
6. 损失率 = 39885 / 50000 × 100% = 79.77%

**输出：**
```
recovery_rate_amount: 30.00
recovery_rate_count: 30.00
actual_recovery_value: 11865.00
net_loss: 39885.00
loss_rate: 79.77
efficiency_grade: "较差"
```
