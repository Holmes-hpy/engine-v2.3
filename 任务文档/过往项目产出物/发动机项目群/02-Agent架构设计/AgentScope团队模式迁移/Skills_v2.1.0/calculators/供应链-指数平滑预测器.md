# 供应链-指数平滑预测器

## name
供应链-指数平滑预测器

## description
使用指数平滑法（Exponential Smoothing / Holt-Winters）对历史需求序列进行预测，支持简单指数平滑、Holt双参数（趋势）和Holt-Winters三参数（趋势+季节性）三种模式。特别适合具有趋势性和季节性特征的需求预测。适用于供应链需求预测、季节性商品备货、促销期需求基准计算等场景。触发词：指数平滑、Holt-Winters、霍尔特-温特斯、季节性预测、平滑预测、ETS模型。排除词：ARIMA（指自回归模型）、促销预测（指促销增量预测）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| historical_demand | array[float] | 历史需求时间序列（按时间顺序） | [120, 135, 110, 145, 130, 150, 125, 140, 155, 128, 160, 148] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| alpha | float | 水平平滑系数（0-1） | 默认自动优化，通过最小化MSE确定最优α；手动设置时建议0.1-0.3 |
| beta | float | 趋势平滑系数（0-1） | 默认自动优化；若序列无趋势可设为0（退化为简单平滑） |
| gamma | float | 季节性平滑系数（0-1） | 默认自动优化；若序列无季节性可设为0（退化为Holt双参数） |
| seasonality_period | int | 季节性周期长度 | 默认自动检测：通过ACF分析确定；常见周期：日数据7(周)、月数据12(年)、季数据4(年) |
| forecast_periods | int | 预测期数 | 默认等于seasonality_period（预测一个完整季节周期） |
| model_type | string | 模型类型(simple/holt/holt_winters) | 默认自动选择：根据数据特征自动判断 |
| confidence_interval | float | 置信区间水平 | 默认0.95 |

## formula
1. 简单指数平滑（无趋势、无季节）：
   水平: L_t = α × y_t + (1-α) × L_{t-1}
   预测: y_{t+h} = L_t

2. Holt双参数（有趋势、无季节）：
   水平: L_t = α × y_t + (1-α) × (L_{t-1} + T_{t-1})
   趋势: T_t = β × (L_t - L_{t-1}) + (1-β) × T_{t-1}
   预测: y_{t+h} = L_t + h × T_t

3. Holt-Winters三参数（有趋势、有季节）：
   水平: L_t = α × (y_t - S_{t-s}) + (1-α) × (L_{t-1} + T_{t-1})
   趋势: T_t = β × (L_t - L_{t-1}) + (1-β) × T_{t-1}
   季节: S_t = γ × (y_t - L_t) + (1-γ) × S_{t-s}
   预测: y_{t+h} = L_t + h × T_t + S_{t+h-s}

   其中：
   - α: 水平平滑系数
   - β: 趋势平滑系数
   - γ: 季节性平滑系数
   - s: 季节周期长度
   - h: 预测步数

自动选择逻辑：
- 若无趋势且无季节性 → 简单指数平滑
- 若有趋势但无季节性 → Holt双参数
- 若有趋势且有季节性 → Holt-Winters三参数

计算步骤：
1. 分析historical_demand，检测趋势性（线性回归斜率显著性检验）
2. 分析historical_demand，检测季节性（ACF/PACF分析）
3. 根据数据特征自动选择模型类型
4. 通过最小化MSE自动优化平滑系数(α, β, γ)
5. 拟合模型并生成预测值
6. 计算预测置信区间

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| forecast_values | array[float] | 预测需求值序列 |
| model_type | string | 使用的模型类型 |
| smoothing_params | object | 最优平滑系数(α, β, γ) |
| seasonality_period | int | 检测到的季节性周期 |
| confidence_intervals | array[object] | 置信区间 |
| model_fit_metrics | object | 拟合优度（RMSE, MAE, MAPE） |
| trend_detected | boolean | 是否检测到趋势 |
| seasonality_detected | boolean | 是否检测到季节性 |

## example
**输入：**
```
historical_demand: [120, 150, 180, 140, 100, 80, 75, 90, 130, 160, 190, 150, 110, 85, 80, 95]
forecast_periods: 4
```

**计算过程：**
1. 趋势检测：存在轻微上升趋势（斜率=0.8，p<0.05）
2. 季节性检测：检测到周期=4的季度性模式（ACF lag4显著）
3. 自动选择Holt-Winters三参数模型，seasonality_period=4
4. 自动优化：α=0.3, β=0.1, γ=0.2
5. 拟合模型，预测未来4期
