# 法律-计费实现率计算器

## name
法律-计费实现率计算器

## description
计算律师事务所或律师个人的计费实现率，即实际收费金额与按标准费率应收费金额的比率，衡量律所收入实现效率和定价策略有效性。适用场景：律所财务管理、律师绩效考核、计费策略评估、律所盈利能力分析。触发词：计费实现率、费率实现率、收费实现率、realization rate。排除词：回收率、利润率、成本率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 实际收费金额 | float | 实际从客户处收取的费用总额 | 850000.00 |
| 标准费率金额 | float | 按标准费率和工作时长计算的应收费总额 | 1000000.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 统计周期 | string | 计费统计的时间范围 | 默认"年度"，可选"月度"/"季度"/"年度" |
| 业务领域拆分 | array[object] | 按业务领域分别统计 | 默认不拆分，需提供各领域实际收费和标准费率金额 |
| 律师维度 | string | 是否按律师个人统计 | 默认"否"，需提供各律师的收费数据 |
| 目标实现率 | float | 目标计费实现率 | 默认85%，行业基准通常在85%-95% |
| 折扣明细 | array[object] | 折扣/减值/转销的明细 | 默认空，按需提供折扣类型和金额 |

## formula
计费实现率 = 实际收费金额 / 标准费率金额 × 100%

折扣/减值总额 = 标准费率金额 - 实际收费金额

实现率等级判定:
- 实现率 ≥ 95%: 优秀（定价能力强，客户认可度高）
- 85% ≤ 实现率 < 95%: 良好（行业正常水平）
- 75% ≤ 实现率 < 85%: 一般（需关注折扣管理）
- 实现率 < 75%: 较差（定价策略需调整）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 计费实现率 | float | 计费实现率百分比 |
| 折扣/减值总额 | float | 标准费率与实际收费的差额 |
| 实现率等级 | string | 优秀/良好/一般/较差 |
| 达标状态 | string | 达标/未达标 |
| 各业务领域实现率 | array[object] | 按业务领域拆分的实现率（如有提供） |
| 趋势分析 | string | 与历史周期的对比（如有历史数据） |
| 改进建议 | string | 提升实现率的建议 |

## example
【输入】
实际收费金额: 850000.00
标准费率金额: 1000000.00
目标实现率: 85%
统计周期: "年度"

【输出】
计费实现率: 85.00%
折扣/减值总额: 150000.00
实现率等级: 良好
达标状态: 达标

改进建议: 当前实现率85%，处于行业良好水平，恰好达标。有15万元（15%）的费率未被实现，建议分析折扣/减值构成：(1)是否为战略性客户折扣，若是则评估客户长期价值；(2)是否为坏账/核销，若是则加强应收账款管理；(3)是否为议价让步，若是则评估定价策略竞争力。目标是将实现率提升至90%以上。
