# 数据-异常检测器

## name
数据-异常检测器

## description
基于实际值与基线值的偏离度计算，标记超出阈值的异常数据点，输出异常数据列表和异常等级。适用场景：业务指标监控、数据质量检查、系统性能异常检测、KPI异动告警。触发词：异常检测、数据异常、偏离度检测、指标异动。排除词：异常预测、趋势分析、根因定位。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 数据 | array[object] | 待检测的数据点，含实际值和基线值 | [{point:"UV", actual:15000, baseline:10000}] |
| 异常阈值 | float | 偏离度超过此阈值视为异常 | 0.20 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 检测方法 | string | 异常检测方法 | 默认"相对偏离度"，可选"相对偏离度"/"Z-score"/"IQR" |
| 异常方向 | string | 关注的异常方向 | 默认"双向"，可选"上升"/"下降"/"双向" |
| 连续异常阈值 | int | 连续N个点异常才告警 | 默认1，降低误报可取2-3 |
| 严重异常阈值 | float | 偏离度超过此值视为严重异常 | 默认0.50，即偏离50%以上 |
| 基线计算方式 | string | 基线值的计算方式 | 默认"预设"，可选"预设"/"移动平均"/"同比" |

## formula
偏离度 = |实际值 - 基线值| / 基线值

异常标记:
- 偏离度 > 异常阈值: 标记为异常
- 偏离度 ≤ 异常阈值: 正常

异常等级:
- 偏离度 > 严重异常阈值: 严重异常（红色告警）
- 异常阈值 < 偏离度 ≤ 严重异常阈值: 一般异常（黄色告警）
- 偏离度 ≤ 异常阈值: 正常（绿色）

异常方向:
- 实际值 > 基线值: 上升异常
- 实际值 < 基线值: 下降异常

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 总数据点数 | int | 检测的数据点总数 |
| 异常点数 | int | 标记为异常的数据点数量 |
| 异常率 | float | 异常点数占总数的比例 |
| 异常数据列表 | array[object] | 异常数据的详细信息，含偏离度和等级 |
| 严重异常数 | int | 严重异常的数据点数量 |
| 上升异常数 | int | 上升方向异常的数量 |
| 下降异常数 | int | 下降方向异常的数量 |
| 告警摘要 | string | 异常摘要说明 |

## example
【输入】
数据: [
  {point:"UV", actual:15000, baseline:10000},
  {point:"订单量", actual:850, baseline:1000},
  {point:"转化率", actual:0.08, baseline:0.10},
  {point:"客单价", actual:250, baseline:240},
  {point:"GMV", actual:200000, baseline:220000}
]
异常阈值: 0.20
严重异常阈值: 0.50

【输出】
总数据点数: 5
异常点数: 3
异常率: 60.0%

异常数据列表:
1. UV — 偏离度: 50.0%, 等级: 严重异常（上升）, 实际:15000 vs 基线:10000
2. 转化率 — 偏离度: 20.0%, 等级: 一般异常（下降）, 实际:0.08 vs 基线:0.10
3. GMV — 偏离度: 9.1%, 等级: 正常
4. 订单量 — 偏离度: 15.0%, 等级: 正常
5. 客单价 — 偏离度: 4.2%, 等级: 正常

严重异常数: 1
上升异常数: 1
下降异常数: 1

告警摘要: 检测到3个异常点。UV出现严重异常（偏离+50%），需立即排查是否为刷量或营销活动导致。转化率出现一般异常（偏离-20%），建议结合UV异常综合分析。GMV虽下降9.1%但未达阈值。
