# 测试-功能覆盖率计算器

## name
测试-功能覆盖率计算器

## description
计算功能覆盖率，即已覆盖的功能需求点数占总功能需求点数的比例，衡量测试对产品需求的覆盖程度。适用场景：需求追踪矩阵验证、测试用例设计完整性评估、产品发布前质量评审。触发词：功能覆盖率、需求覆盖率、功能点覆盖、需求追踪。排除词：代码覆盖率、行覆盖率、分支覆盖率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 已覆盖功能点数 | int | 已有测试用例覆盖的功能需求点数量 | 120 |
| 总功能点数 | int | 产品需求文档中定义的总功能点数量 | 150 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 目标覆盖率 | float | 期望达到的功能覆盖率阈值 | 默认95%，敏捷项目取90%，安全关键系统取100% |
| 优先级权重 | string | 是否按需求优先级加权计算 | 默认"否"，加权模式需额外提供各功能点优先级 |
| 需求分类 | array[string] | 按需求类别分别统计 | 默认空，按需提供分类维度 |

## formula
功能覆盖率 = 已覆盖功能点数 / 总功能点数 × 100%

加权功能覆盖率 = Σ(已覆盖功能点_i × 优先级权重_i) / Σ(总功能点_i × 优先级权重_i) × 100%

判定标准:
- 覆盖率 = 100%: 全覆盖
- 95% ≤ 覆盖率 < 100%: 基本覆盖
- 80% ≤ 覆盖率 < 95%: 部分覆盖，存在风险
- 覆盖率 < 80%: 严重不足

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 功能覆盖率 | float | 功能覆盖率百分比 |
| 达标状态 | string | 达标/未达标 |
| 未覆盖功能点数 | int | 总功能点数 - 已覆盖功能点数 |
| 覆盖率等级 | string | 全覆盖/基本覆盖/部分覆盖/严重不足 |
| 未覆盖功能列表 | array[string] | 未覆盖功能点的清单（如有提供） |
| 风险提示 | string | 基于未覆盖功能的重要性评估 |

## example
【输入】
已覆盖功能点数: 120
总功能点数: 150
目标覆盖率: 95%

【输出】
功能覆盖率: 80.00%
未覆盖功能点数: 30
达标状态: 未达标
覆盖率等级: 部分覆盖，存在风险

风险提示: 当前功能覆盖率80%，远低于目标95%。有30个功能点未被测试覆盖，可能包含关键业务逻辑。建议立即补充测试用例，优先覆盖核心功能和高风险功能点，确保发布前达到目标覆盖率。
