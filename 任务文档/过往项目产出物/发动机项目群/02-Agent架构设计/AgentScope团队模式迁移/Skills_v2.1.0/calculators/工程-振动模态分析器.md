# 工程-振动模态分析器

## name
工程-振动模态分析器

## description
基于结构参数（质量、刚度、激励频率等），计算固有频率、模态振型判定和共振风险评估，输出安全运行区间建议。适用场景：机械结构振动分析、旋转设备共振规避、建筑结构动力特性评估。触发词：振动模态、固有频率、共振分析、模态分析、临界转速。排除词：静力分析、强度校核、疲劳分析。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 等效质量 m | float | 系统的等效质量（kg） | 100 |
| 等效刚度 k | float | 系统的等效刚度（N/m） | 500000 |
| 激励频率 f_excite | float | 外部激励频率（Hz） | 25 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 阻尼比 ζ | float | 系统阻尼比 | 默认0.05，钢结构取0.02-0.05，橡胶减振取0.1-0.2 |
| 自由度数量 | int | 模态分析的自由度数量 | 默认1（单自由度系统），多自由度需提供质量矩阵和刚度矩阵 |
| 振型分析 | boolean | 是否进行多阶振型分析 | 默认false，开启后需提供多阶模态参数 |
| 安全裕度系数 | float | 共振安全裕度倍数 | 默认1.3，即激励频率需在固有频率±30%范围外 |
| 运行转速 | float | 旋转设备转速（rpm） | 默认不填，旋转设备需提供以计算临界转速 |

## formula
固有角频率 ωn = sqrt(k / m) （rad/s）
固有频率 fn = ωn / (2π) （Hz）

频率比 r = f_excite / fn

放大因子（幅频特性）:
MF = 1 / sqrt((1 - r²)² + (2ζr)²)

共振风险判定:
- r < 0.7: 安全区（刚性控制区），振动响应接近静态
- 0.7 ≤ r ≤ 1.3: 共振危险区，需避开
- r > 1.3: 隔离区（弹性控制区），振动响应衰减

临界转速 nc = 60 × fn（rpm）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 固有角频率 ωn | float | 固有角频率（rad/s） |
| 固有频率 fn | float | 固有频率（Hz） |
| 频率比 r | float | 激励频率与固有频率之比 |
| 放大因子 MF | float | 振动放大因子 |
| 共振风险等级 | string | 安全/注意/危险 |
| 运行区间 | string | 刚性控制区/共振危险区/弹性隔离区 |
| 临界转速 nc | float | 临界转速（rpm），仅旋转设备 |
| 安全运行范围 | string | 建议的安全频率或转速范围 |
| 调节建议 | string | 避开共振的调节方向 |

## example
【输入】
等效质量 m: 100 kg
等效刚度 k: 500000 N/m
激励频率 f_excite: 25 Hz
阻尼比 ζ: 0.05

【输出】
固有角频率 ωn: 70.71 rad/s
固有频率 fn: 11.25 Hz
频率比 r: 2.22
放大因子 MF: 0.25
共振风险等级: 安全
运行区间: 弹性隔离区

安全运行范围: 激励频率25Hz处于弹性隔离区（r=2.22 > 1.3），振动响应已衰减至静态的25%，运行安全。

若为旋转设备，临界转速 nc = 675 rpm，当前运行转速（对应25Hz）1500 rpm，超出临界转速2.22倍，安全。

调节建议: 如要进一步提升安全性，可增加刚度或减小质量，使固有频率继续远离激励频率。
