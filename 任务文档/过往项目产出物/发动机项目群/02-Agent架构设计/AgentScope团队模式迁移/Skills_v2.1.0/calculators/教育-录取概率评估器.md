# 教育-录取概率评估器

## name
教育-录取概率评估器

## description
基于考生位次差、目标院校招生计划变化、历年录取趋势等因素，综合评估录取概率区间，输出冲稳保判定和概率等级。适用场景：高考志愿填报风险评估、院校录取概率量化、志愿填报策略优化。触发词：录取概率、录取几率、录取可能性、院校录取评估。排除词：位次分析、选科组合、专业分数。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 位次差 | int | 考生位次 - 院校预测录取位次（正数为优势） | -2000 |
| 招生计划变化 | float | 今年招生计划数变化率（正数为扩招） | 0.05 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 历年波动系数 | float | 录取位次的历史波动程度 | 默认0.03，波动大取0.05-0.08，稳定取0.01-0.03 |
| 院校热度系数 | float | 院校当年报考热度调整 | 默认1.0，热门院校取1.1-1.3，冷门取0.8-0.9 |
| 提前批/普通批 | string | 录取批次 | 默认"普通批"，提前批录取规则不同 |
| 调剂意愿 | boolean | 是否接受专业调剂 | 默认false，接受调剂可提升录取概率 |
| 概率模型 | string | 概率计算模型 | 默认"正态分布"，可选"正态分布"/"逻辑回归"/"经验公式" |

## formula
基础概率（正态分布模型）:
Z = 位次差 / (预测位次 × 历年波动系数)
录取概率 = Φ(Z) （标准正态分布累积分布函数）

招生计划调整:
调整后概率 = min(基础概率 × (1 + 招生计划变化 × 院校热度系数), 0.99)

调剂加成:
最终概率 = 调整后概率 + (1 - 调整后概率) × 调剂加成系数
其中调剂加成系数默认0.2（接受调剂时可提升20%的剩余概率）

概率等级判定:
- 概率 ≥ 80%: 高概率（保底）
- 50% ≤ 概率 < 80%: 中高概率（稳妥偏保）
- 30% ≤ 概率 < 50%: 中等概率（稳妥）
- 10% ≤ 概率 < 30%: 中低概率（冲刺偏稳）
- 概率 < 10%: 低概率（冲刺）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 录取概率 | float | 综合录取概率（%） |
| 概率区间 | string | 概率的置信区间 |
| 概率等级 | string | 高概率/中高概率/中等概率/中低概率/低概率 |
| 冲稳保判定 | string | 冲刺/稳妥/保底 |
| 招计影响 | float | 招生计划变化对概率的调整幅度 |
| 调剂影响 | float | 接受调剂对概率的提升幅度 |
| 风险提示 | string | 基于概率的风险说明 |

## example
【输入】
位次差: -2000
招生计划变化: 0.05 (扩招5%)
预测位次: 14000
历年波动系数: 0.03
院校热度系数: 1.1
调剂意愿: true

【输出】
Z值: -2000 / (14000 × 0.03) = -4.76
基础概率: 32.5%

招生计划调整:
调整后概率 = min(32.5% × (1 + 0.05 × 1.1), 99%) = 34.3%

调剂加成:
最终概率 = 34.3% + (1 - 34.3%) × 0.2 = 47.4%

录取概率: 47.4%
概率区间: [42.1%, 52.7%]（95%置信区间）
概率等级: 中等概率
冲稳保判定: 稳妥

招计影响: 扩招5%提升概率约1.8个百分点
调剂影响: 接受调剂提升概率约13.1个百分点
风险提示: 录取概率约47.4%，属于中等稳妥水平。位次差-2000意味着考生位次略低于院校预测录取位次，但扩招和接受调剂因素起到积极作用。建议将此校作为稳妥志愿，并搭配1-2个保底院校。
