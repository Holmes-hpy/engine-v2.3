# 供应链-周转天数计算器

## name
供应链-周转天数计算器

## description
计算库存周转天数（Inventory Days of Supply），衡量库存从入库到消耗完毕所需的平均天数。周转天数越短，说明库存管理效率越高、资金占用越少；但过短可能意味着缺货风险。适用于库存效率评估、营运资金管理、供应链健康度诊断等场景。触发词：周转天数、库存周转、库存天数、DOS、库存效率、存货周转。排除词：应收账款周转（指财务应收账款周转天数）、资产周转率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| avg_inventory_value | float | 平均库存金额（元） | 500000.00 |
| daily_cogs | float | 日均销售成本（元/天） | 25000.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| period | string | 统计周期（monthly/quarterly/annual） | 默认monthly；日均销售成本 = 月度销售成本 / 30 |
| period_cogs | float | 周期销售成本（元） | 若提供，自动计算日均 = period_cogs / 周期天数 |
| inventory_turnover | float | 库存周转率（次） | 若提供，可直接计算周转天数 = 360/周转率，无需avg_inventory_value和daily_cogs |
| category_benchmark | float | 品类基准周转天数 | 默认：快消品30-45天，电子产品60-90天，服装45-60天，生鲜3-7天 |
| safety_days | int | 安全库存天数 | 默认7天，用于评估当前周转天数是否合理 |

## formula
库存周转天数 = 平均库存金额 / 日均销售成本

等价公式：
- 周转天数 = 360 / 库存周转率（年化）
- 周转天数 = 90 / 库存周转率（季度化）
- 周转天数 = 30 / 库存周转率（月度化）

其中：
- 库存周转率 = 销售成本 / 平均库存金额
- 日均销售成本 = 周期销售成本 / 周期天数

计算步骤：
1. 确定日均销售成本
   - 若直接提供daily_cogs，直接使用
   - 若提供period_cogs和period，计算日均 = period_cogs / 周期天数
   - 月度：30天，季度：90天，年度：360天
2. 库存周转天数 = avg_inventory_value / daily_cogs
3. 库存周转率 = 360 / 周转天数（年化）
4. 与品类基准对比，输出效率评估
5. 若周转天数 > 安全库存天数 × 2，提示可能存在呆滞库存

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| inventory_days | float | 库存周转天数 |
| inventory_turnover | float | 库存周转率（年化，次） |
| avg_inventory_value | float | 平均库存金额 |
| daily_cogs | float | 日均销售成本 |
| benchmark | float | 品类基准周转天数 |
| efficiency_grade | string | 效率评级（优秀/良好/一般/较差） |
| deviation | float | 与基准的偏差（天） |
| alert | string | 异常预警 |

## example
**输入：**
```
avg_inventory_value: 500000.00
daily_cogs: 25000.00
category_benchmark: 45.00
safety_days: 7
```

**计算过程：**
1. 日均销售成本 = 25000元/天
2. 库存周转天数 = 500000 / 25000 = 20天
3. 年化库存周转率 = 360 / 20 = 18次/年
4. 与基准对比：20天 vs 45天基准 → 快于基准25天
5. 安全库存天数7天，20天 > 7 × 2 = 14天，提示可能存在部分呆滞库存

**输出：**
```
inventory_days: 20.00
inventory_turnover: 18.00
avg_inventory_value: 500000.00
daily_cogs: 25000.00
benchmark: 45.00
efficiency_grade: "优秀"
deviation: -25.00
alert: "当前周转天数20天优于基准45天，库存管理效率较高。但周转天数(20天)超过安全库存天数(7天)的2倍，建议检查是否存在部分慢动SKU占用库存"
```
