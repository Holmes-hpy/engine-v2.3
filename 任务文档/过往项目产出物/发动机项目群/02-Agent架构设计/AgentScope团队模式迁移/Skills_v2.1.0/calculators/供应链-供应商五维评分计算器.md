# 供应链-供应商五维评分计算器

## name
供应链-供应商五维评分计算器

## description
通过质量、价格、交期、服务、创新五个维度对供应商进行综合评分，采用加权评分模型输出供应商总得分和分维度得分。帮助采购团队科学评估和比较供应商，支持供应商分级管理和采购决策。适用于供应商评估、供应商准入审核、年度供应商绩效考核、供应商分级管理等场景。触发词：供应商评分、供应商评估、供应商绩效、五维评分、供应商KPI、供应商考核。排除词：供应商风险（指风险维度的单独评估）、供应商准入（指准入流程审批）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| dimension_scores | object | 五个维度的评分（0-100分） | {"quality":85,"price":72,"delivery":90,"service":78,"innovation":65} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| dimension_weights | object | 自定义维度权重 | 默认权重：质量(30%)、价格(25%)、交期(20%)、服务(15%)、创新(10%) |
| sub_dimensions | array[object] | 各维度下的子指标详情 | 若未提供，则仅输出维度级评分 |
| rating_scale | object | 评级标准 | 默认：A级(≥85分)、B级(70-84分)、C级(60-69分)、D级(<60分) |
| category | string | 供应商类别（原材料/零部件/服务/物流） | 不同类别可调整权重，如物流类可提高交期权重至30% |

## formula
加权评分 = Σ(维度得分_i × 权重_i)

各维度默认权重及子指标：
| 维度 | 权重 | 子指标 |
|------|------|--------|
| 质量 | 30% | 来料合格率、批次合格率、质量体系认证、客诉率 |
| 价格 | 25% | 价格竞争力、价格稳定性、付款条件、成本优化意愿 |
| 交期 | 20% | 准时交货率、交货周期、紧急订单响应、产能弹性 |
| 服务 | 15% | 响应速度、售后支持、配合度、沟通效率 |
| 创新 | 10% | 技术能力、新品开发、工艺改进、协同创新 |

计算步骤：
1. 获取各维度评分（0-100分）
2. 应用权重计算加权总分 = 质量×0.30 + 价格×0.25 + 交期×0.20 + 服务×0.15 + 创新×0.10
3. 根据总分匹配评级标准
4. 识别短板维度（得分最低的维度）
5. 输出分维度雷达图数据和改进建议

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| total_score | float | 加权总分（0-100） |
| rating | string | 供应商评级（A/B/C/D） |
| dimension_scores | object | 各维度得分详情 |
| radar_data | array[object] | 雷达图数据 |
| weakness_dimension | string | 短板维度 |
| recommendation | string | 改进建议 |

## example
**输入：**
```
dimension_scores: {
  "quality": 85,
  "price": 72,
  "delivery": 90,
  "service": 78,
  "innovation": 65
}
```

**计算过程：**
| 维度 | 得分 | 权重 | 加权分 |
|------|------|------|--------|
| 质量 | 85 | 0.30 | 25.50 |
| 价格 | 72 | 0.25 | 18.00 |
| 交期 | 90 | 0.20 | 18.00 |
| 服务 | 78 | 0.15 | 11.70 |
| 创新 | 65 | 0.10 | 6.50 |
| **总分** | | | **79.70** |

评级：B级（70-84分区间）
短板维度：创新（65分）
