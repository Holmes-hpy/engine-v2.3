# 工程-螺栓设计计算器

## name
工程-螺栓设计计算器

## description
基于螺栓基本参数（直径、性能等级、扭矩系数等），计算预紧力、拧紧力矩、应力校核及防松判定，验证螺栓连接的可靠性。适用场景：机械装配中螺栓连接设计、高强度螺栓选型、法兰连接校核。触发词：螺栓设计、螺栓校核、预紧力计算、拧紧力矩、螺栓强度。排除词：铆接、焊接、键连接。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 螺栓公称直径 d | float | 螺栓公称直径（mm） | 12 |
| 性能等级 | string | 螺栓性能等级 | "8.8" / "10.9" / "12.9" |
| 扭矩系数 K | float | 拧紧扭矩系数 | 0.2 |
| 工作载荷 F_work | float | 单个螺栓承受的工作载荷（N） | 5000 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 螺距 P | float | 螺纹螺距（mm） | 默认根据公称直径查标准值，M12粗牙取1.75 |
| 连接类型 | string | 连接副类型 | 默认"普通"，可选"铰制孔用"/"普通" |
| 摩擦系数 μ | float | 螺纹副摩擦系数 | 默认0.15，润滑良好取0.10-0.12，干摩擦取0.18-0.25 |
| 残余预紧力系数 | float | 残余预紧力与工作载荷之比 | 默认1.5，受静载荷取1.2-1.5，受动载荷取1.5-2.0 |
| 安全系数 S | float | 许用安全系数 | 默认1.5，重要连接取2.0-3.0 |
| 工作温度 | float | 工作温度（℃） | 默认20℃，高温工况需考虑材料性能折减 |

## formula
根据性能等级计算力学性能：
- 8.8级: σb = 800 MPa, σs = 0.8 × 800 = 640 MPa
- 10.9级: σb = 1000 MPa, σs = 0.9 × 1000 = 900 MPa
- 12.9级: σb = 1200 MPa, σs = 0.9 × 1200 = 1080 MPa

螺纹小径 d1 = d - 1.0825 × P（粗牙螺纹）
公称应力截面积 As = π × (d1 + d2 - H/6)² / 16，简化为 As = π × d1² / 4

预紧力 F0 = 0.7 × σs × As

拧紧力矩 T = K × F0 × d / 1000

残余预紧力 F1 = 残余预紧力系数 × F_work

总拉力 F2 = F1 + F_work

拉应力 σ = F2 / As

许用应力 [σ] = σs / S

| 强度判定 | string | 合格/不合格 |
| 安全裕度 | float | (许用应力-实际应力)/许用应力 × 100% |

## example
【输入】
螺栓公称直径 d: 12 mm
性能等级: "8.8"
扭矩系数 K: 0.2
工作载荷 F_work: 5000 N
螺距 P: 1.75 mm
残余预紧力系数: 1.5
安全系数 S: 1.5

【输出】
螺纹小径 d1: 10.11 mm
公称应力截面积 As: 80.2 mm²
预紧力 F0: 35930 N
拧紧力矩 T: 86.2 N·m
残余预紧力 F1: 7500 N
总拉力 F2: 12500 N
拉应力 σ: 155.9 MPa
许用应力 [σ]: 426.7 MPa
强度判定: 合格
安全裕度: 63.5%

螺栓连接设计满足要求，预紧力35930N对应拧紧力矩86.2N·m，实测应力155.9MPa远低于许用值426.7MPa。
