# 教育-选科组合分析器

## name
教育-选科组合分析器

## description
基于目标专业要求和考生各科成绩，分析不同选科组合对目标专业的覆盖率，并预估赋分后的成绩变化，输出最优选科组合推荐。适用场景：高中选科决策、专业覆盖率分析、赋分制成绩预估。触发词：选科组合、新高考选科、专业覆盖率、赋分预估。排除词：位次分析、录取概率、志愿填报。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 目标专业 | array[string] | 考生意向报考的专业列表 | ["计算机科学与技术", "软件工程", "人工智能"] |
| 各科成绩 | object | 各科原始分数或预估分数 | {物理:85, 化学:78, 生物:72, 历史:65, 地理:70, 政治:68} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 省份 | string | 考生所在省份 | 默认待定，各省选科要求和赋分规则不同 |
| 选科模式 | string | 选科模式 | 默认"3+1+2"，可选"3+3"/"3+1+2" |
| 选科方案数 | int | 需要输出的候选组合数量 | 默认3，输出前3个最优组合 |
| 赋分折扣率 | float | 预估赋分后的折扣率 | 默认0.95，即赋分后成绩约为原始分的95% |
| 专业覆盖率权重 | float | 专业覆盖率在综合评分中的权重 | 默认0.6，成绩权重=0.4 |
| 院校层次 | string | 目标院校层次 | 默认"全部"，可选"985"/"211"/"双一流"/"全部" |

## formula
专业覆盖率 = 候选组合可报专业数 / 目标专业总数 × 100%

赋分预估成绩 = 原始分 × 赋分折扣率

成绩标准化得分 = Σ(各科赋分预估成绩) / Σ(各科满分) × 100

综合评分 = 专业覆盖率 × 专业覆盖率权重 + 成绩标准化得分 × 成绩权重

组合推荐排序按综合评分降序排列。

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 候选组合列表 | array[object] | 各选科组合、专业覆盖率、赋分预估、综合评分 |
| 推荐组合 | string | 综合评分最高的组合 |
| 各组合专业覆盖率 | array[float] | 各组合的专业覆盖率 |
| 各组合赋分预估总分 | array[float] | 各组合的赋分预估总分 |
| 覆盖率最高组合 | string | 专业覆盖率最高的组合（可能不是综合最优） |
| 不可报专业 | array[string] | 推荐组合下无法报考的目标专业 |
| 选科建议 | string | 综合性的选科建议 |

## example
【输入】
目标专业: ["计算机科学与技术", "软件工程", "人工智能", "电子信息工程", "自动化"]
各科成绩: {物理:85, 化学:78, 生物:72, 历史:65, 地理:70, 政治:68}
选科模式: "3+1+2"
省份: "广东省"
专业覆盖率权重: 0.6
赋分折扣率: 0.95

【输出】
候选组合列表:
1. 物理+化学+生物 — 专业覆盖率: 100%, 赋分预估总分: 223.3, 综合评分: 89.3
2. 物理+化学+地理 — 专业覆盖率: 100%, 赋分预估总分: 221.4, 综合评分: 88.6
3. 物理+化学+政治 — 专业覆盖率: 98%, 赋分预估总分: 219.5, 综合评分: 87.6

推荐组合: 物理+化学+生物
不可报专业: 无

选科建议: 物理+化学+生物组合对目标专业覆盖率100%，且赋分预估总分最高，是首选方案。物理+化学+地理覆盖率和成绩接近，可作为备选。注意：物理和化学是关键专业的基础学科，必须选择。
