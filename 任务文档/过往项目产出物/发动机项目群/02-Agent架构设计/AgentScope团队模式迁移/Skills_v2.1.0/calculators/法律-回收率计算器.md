# 法律-回收率计算器

## name
法律-回收率计算器

## description
计算法律业务中的计费回收率，即已实际回收的金额与应收费总金额的比率，衡量律所应收账款回收效率和现金流健康状况。适用场景：律所应收账款管理、现金流分析、客户信用评估、催收策略制定。触发词：法律回收率、计费回收、费率回收、应收账款回收率、collection rate。排除词：电商回收率、退货回收、商品回收、环保回收。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 已回收金额 | float | 在统计周期内实际从客户处收回的金额 | 780000.00 |
| 应收费金额 | float | 统计周期内已开票应收取的总金额 | 1000000.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 统计周期 | string | 回收统计的时间范围 | 默认"年度"，可选"月度"/"季度"/"年度" |
| 客户维度 | string | 是否按客户分别统计 | 默认"否"，需提供各客户回收数据 |
| 目标回收率 | float | 目标回收率 | 默认90%，行业优质律所通常>95% |
| 账龄分段 | boolean | 是否按账龄分段统计回收率 | 默认false，开启后需提供各账龄段的回收金额 |
| 坏账核销 | float | 已核销的坏账金额 | 默认0，核销后从应收费中扣除 |

## formula
回收率 = 已回收金额 / 应收费金额 × 100%

未回收金额 = 应收费金额 - 已回收金额

坏账率 = 坏账核销金额 / 应收费金额 × 100%

回收率等级判定:
- 回收率 ≥ 95%: 优秀（现金流健康，回款能力强）
- 90% ≤ 回收率 < 95%: 良好（行业正常水平）
- 80% ≤ 回收率 < 90%: 一般（需关注回款管理）
- 回收率 < 80%: 较差（存在严重回款问题）

注意：本计算器专门用于法律行业的计费回收率，与电商/零售行业的商品退货回收率是两个完全不同的概念。触发词中明确包含"法律回收率"、"计费回收"等限定词以确保语义区分。

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 回收率 | float | 回收率百分比 |
| 未回收金额 | float | 尚未回收的金额 |
| 坏账率 | float | 坏账核销占比 |
| 回收率等级 | string | 优秀/良好/一般/较差 |
| 达标状态 | string | 达标/未达标 |
| 回款周期 | float | 平均回款天数（如有提供） |
| 风险提示 | string | 回收率过低时的风险提示和催收建议 |

## example
【输入】
已回收金额: 780000.00
应收费金额: 1000000.00
目标回收率: 90%
统计周期: "年度"
坏账核销: 30000.00

【输出】
回收率: 78.00%
未回收金额: 220000.00
坏账率: 3.00%
回收率等级: 较差
达标状态: 未达标（78% < 目标90%）

风险提示: 当前回收率仅78%，远低于90%目标，有22万元应收账款未回收。建议：(1)对账龄超过90天的客户启动催收程序；(2)评估大额未回款客户的信用风险；(3)考虑对新客户实行预付费或阶段性付款安排；(4)3%的坏账率也偏高，建议审查客户授信政策。
