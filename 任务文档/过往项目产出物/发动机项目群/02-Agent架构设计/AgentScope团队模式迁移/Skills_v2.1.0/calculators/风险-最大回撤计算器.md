# 风险-最大回撤计算器

## name
风险-最大回撤计算器

## description
计算投资组合在指定时间段内的最大回撤（Maximum Drawdown，MDD），即从历史最高净值到随后最低净值的最大跌幅百分比。最大回撤是衡量投资策略下行风险的核心指标，反映了投资者在极端不利情况下可能承受的最大损失。适用于策略回测风险评估、基金尽调、止损策略制定等场景。触发词：最大回撤、MDD、回撤、最大亏损、水下曲线、回撤期。排除词：VaR、最大损失（指VaR语境）、夏普比率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| nav_series | array[float] | 投资组合净值序列（按时间顺序排列） | [1.000, 1.020, 1.015, 0.980, 0.995, 1.050, 1.030, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| start_date | string | 回撤分析起始日期 | 默认取净值序列的起始日期 |
| end_date | string | 回撤分析结束日期 | 默认取净值序列的结束日期 |
| return_format | string | 输出格式(percentage/decimal) | 默认percentage，以百分比形式输出 |

## formula
最大回撤 = max(1 - 当前净值 / 此前最高净值)

等价于：MDD = max( (peak - trough) / peak )

其中：
- peak: 当前时点之前净值序列中的最高值（滚动最大值）
- trough: 从peak后净值序列中的最低值

计算步骤：
1. 遍历净值序列，维护"此前最高净值"running_max
2. 对每个时间点t，计算回撤 drawdown_t = (running_max - nav[t]) / running_max
3. 若nav[t] > running_max，更新running_max = nav[t]，drawdown_t = 0
4. 最大回撤 MDD = max(drawdown_1, drawdown_2, ..., drawdown_n)
5. 同时记录最大回撤的起止时间：peakDate 和 troughDate
6. 计算回撤恢复时间：从troughDate恢复到peak水平所需天数

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| max_drawdown | float | 最大回撤值（百分比或小数） |
| peak_date | string | 回撤起始日期（净值最高点） |
| trough_date | string | 回撤最低点日期 |
| recovery_date | string | 回撤恢复日期（若无恢复则为null） |
| drawdown_duration | int | 回撤持续天数 |
| recovery_duration | int | 恢复所需天数 |
| drawdown_series | array[float] | 完整的回撤时间序列 |

## example
**输入：**
```
nav_series: [1.000, 1.020, 1.050, 1.030, 0.980, 0.950, 0.970, 0.990, 1.010, 1.040, 1.060, 1.045]
```

**计算过程：**
| 时间点 | 净值 | 此前最高 | 回撤 |
|--------|------|----------|------|
| t=0 | 1.000 | 1.000 | 0% |
| t=1 | 1.020 | 1.020 | 0% |
| t=2 | 1.050 | 1.050 | 0% |
| t=3 | 1.030 | 1.050 | 1.90% |
| t=4 | 0.980 | 1.050 | 6.67% |
| t=5 | 0.950 | 1.050 | 9.52% |
| t=6 | 0.970 | 1.050 | 7.62% |
| t=7 | 0.990 | 1.050 | 5.71% |
| t=8 | 1.010 | 1.050 | 3.81% |
| t=9 | 1.040 | 1.050 | 0.95% |
| t=10 | 1.060 | 1.060 | 0% |
| t=11 | 1.045 | 1.060 | 1.42% |

最大回撤 = 9.52%（发生在t=5，此前最高峰值在t=2）

**输出：**
```
max_drawdown: 9.52
peak_date: "t=2"
trough_date: "t=5"
recovery_date: "t=10"
drawdown_duration: 3
recovery_duration: 5
drawdown_series: [0, 0, 0, 1.90, 6.67, 9.52, 7.62, 5.71, 3.81, 0.95, 0, 1.42]
```
