# 项目管理-组合ROI计算器

## name
项目管理-组合ROI计算器

## description
计算多个IT项目/产品项目的投资回报率（ROI），对项目组合进行ROI排序和对比，输出各项目ROI、回收期和优先级排序，帮助组织进行多项目资源分配决策。适用场景：IT项目组合管理、多项目资源分配、项目投资决策、PMO项目评审。触发词：组合ROI、多项目ROI、IT项目ROI、项目组合ROI、项目投资回报。排除词：单项目ROI、财务ROI、投资组合ROI（注意：本计算器专注于IT/产品项目组合场景，与财务-ROI计算器的企业财务投资ROI是不同的概念）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 项目列表 | array[object] | 多个项目的收益和成本数据 | [{name:"ERP系统", benefit:5000000, cost:3000000, duration_months:12}] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 贴现率 | float | 资金的时间价值贴现率 | 默认0.08（8%），用于计算NPV |
| 预算上限 | float | 项目组合的总预算约束 | 默认无限制 |
| 排序方式 | string | 排序依据 | 默认"ROI降序"，可选"ROI"/"NPV"/"回收期" |
| 风险调整 | boolean | 是否对收益进行风险折减 | 默认false，开启后高不确定性项目收益按系数折减 |
| 项目依赖 | array[object] | 项目间的依赖关系 | 默认空，影响组合可行性 |

## formula
项目ROI = (项目收益 - 项目成本) / 项目成本 × 100%

净现值 NPV = -成本 + Σ(年收益 / (1+贴现率)^t)，t=1到项目年限

回收期 = 项目成本 / 年均收益

ROI等级:
- ROI ≥ 200%: 极高回报
- 100% ≤ ROI < 200%: 高回报
- 50% ≤ ROI < 100%: 中等回报
- ROI < 50%: 低回报

组合ROI = Σ(各项目收益) / Σ(各项目成本) - 1

注意：本计算器与"财务-ROI计算器"的歧义区分——本计算器专注于IT/产品项目组合场景，关注多项目之间的ROI对比和资源分配；财务-ROI计算器专注于单项目或单一投资的企业财务投资回报分析。

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 项目排序 | array[object] | 按ROI降序的项目列表 |
| 各项目ROI | array[float] | 各项目的ROI百分比 |
| 各项目NPV | array[float] | 各项目的净现值 |
| 各项目回收期 | array[float] | 各项目的投资回收期（年） |
| 组合总成本 | float | 所有项目总成本 |
| 组合总收益 | float | 所有项目总收益 |
| 组合ROI | float | 项目组合的综合ROI |
| 预算约束分析 | string | 在预算约束下的最优项目组合选择 |
| 投资建议 | string | 基于ROI排序的投资建议 |

## example
【输入】
项目列表: [
  {name:"ERP系统", benefit:5000000, cost:3000000, duration_months:12},
  {name:"CRM系统", benefit:3000000, cost:1500000, duration_months:8},
  {name:"数据中台", benefit:4000000, cost:2500000, duration_months:18},
  {name:"移动办公", benefit:1500000, cost:800000, duration_months:6}
]
贴现率: 0.08
预算上限: 5000000

【输出】
项目排序:
1. 移动办公 — ROI: 87.5%, 回收期: 0.53年, NPV: 550,000
2. CRM系统 — ROI: 100.0%, 回收期: 0.50年, NPV: 1,200,000
3. ERP系统 — ROI: 66.7%, 回收期: 0.72年, NPV: 1,600,000
4. 数据中台 — ROI: 60.0%, 回收期: 1.13年, NPV: 1,100,000

组合总成本: 7,800,000
组合总收益: 13,500,000
组合ROI: 73.1%

预算约束分析（预算上限500万）:
最优组合: CRM系统(150万) + 移动办公(80万) + ERP系统(300万) = 530万
注意：超出预算30万，需调整。建议组合: CRM系统(150万) + 移动办公(80万) + 数据中台(250万) = 480万，在预算内。

投资建议: 在500万预算约束下，推荐执行CRM系统、移动办公和数据中台三个项目，总成本480万，预期总收益850万，组合ROI 77.1%。CRM系统ROI最高(100%)且回收期最短(0.5年)，应优先启动。
