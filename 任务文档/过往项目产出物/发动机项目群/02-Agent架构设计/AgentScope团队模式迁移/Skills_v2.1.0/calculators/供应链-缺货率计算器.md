# 供应链-缺货率计算器

## name
供应链-缺货率计算器

## description
计算SKU级别的缺货率（Stockout Rate），衡量在指定时间段内缺货SKU占总SKU的比例。缺货率是供应链服务水平的核心逆向指标，缺货率越低说明供应保障能力越强。适用于供应链服务水平监控、库存策略优化、供应商绩效评估等场景。触发词：缺货率、缺货比例、断货率、stockout、缺货统计、有货率。排除词：缺货成本（指缺货带来的经济损失计算）、滞销率（指滞销商品占比）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| out_of_stock_skus | int | 缺货SKU数（统计时段内任意时刻库存为0的SKU） | 35 |
| total_skus | int | 总SKU数 | 500 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| dimension | string | 统计维度（sku/category/supplier/warehouse） | 默认sku维度 |
| time_period | string | 统计周期（daily/weekly/monthly） | 默认monthly |
| out_of_stock_duration | array[float] | 每个缺货SKU的缺货时长（小时/天） | 若提供，可额外计算缺货时长加权缺货率 |
| out_of_stock_revenue_loss | float | 缺货导致的收入损失（元） | 若提供，可额外计算缺货损失率 |
| total_revenue | float | 总销售收入（元） | 用于计算缺货损失率 |
| target_stockout_rate | float | 目标缺货率 | 默认0.03（3%），用于评估是否达标 |

## formula
缺货率 = 缺货SKU数 / 总SKU数 × 100%

有货率 = 1 - 缺货率

缺货时长加权缺货率 = Σ(缺货SKU_i的缺货时长) / (总SKU数 × 统计周期总时长) × 100%

缺货损失率 = 缺货收入损失 / 总销售收入 × 100%

缺货率等级判定：
- 优秀：缺货率 < 2%
- 良好：缺货率 2-5%
- 一般：缺货率 5-10%
- 较差：缺货率 > 10%

计算步骤：
1. 基础缺货率 = out_of_stock_skus / total_skus × 100%
2. 若提供缺货时长数据，计算加权缺货率
3. 若提供收入和损失数据，计算缺货损失率
4. 与目标缺货率对比，输出达标状态
5. 按等级判定输出效率评级

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| stockout_rate | float | 缺货率（%） |
| fill_rate | float | 有货率（%） |
| stockout_rate_weighted | float | 缺货时长加权缺货率（%，若提供时长数据） |
| revenue_loss_rate | float | 缺货损失率（%，若提供收入数据） |
| target_stockout_rate | float | 目标缺货率 |
| is_target_met | boolean | 是否达标 |
| efficiency_grade | string | 效率评级 |
| recommendation | string | 改进建议 |

## example
**输入：**
```
out_of_stock_skus: 35
total_skus: 500
time_period: "monthly"
target_stockout_rate: 0.03
out_of_stock_revenue_loss: 25000
total_revenue: 2000000
```

**计算过程：**
1. 缺货率 = 35 / 500 × 100% = 7.00%
2. 有货率 = 1 - 7.00% = 93.00%
3. 目标缺货率 = 3%，当前7% > 3% → 未达标
4. 缺货损失率 = 25000 / 2000000 × 100% = 1.25%
5. 效率评级：7%在5-10%区间 → 一般

**输出：**
```
stockout_rate: 7.00
fill_rate: 93.00
revenue_loss_rate: 1.25
target_stockout_rate: 3.00
is_target_met: false
efficiency_grade: "一般"
recommendation: "当前缺货率7.00%未达到3%的目标，缺货率偏高。建议：(1)重点分析缺货SKU的共性特征，是否集中在特定品类或供应商；(2)对该品类适当提高安全库存水平；(3)优化补货触发机制，缩短补货响应时间；(4)缺货损失率1.25%，相当于每月损失25000元收入，ROI角度值得投入库存优化"
```
