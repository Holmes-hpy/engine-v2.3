# 法律-账龄计算器

## name
法律-账龄计算器

## description
根据开票日期计算应收账款的账龄，将应收账款按账龄分组（0-30天/31-60天/61-90天/>90天），输出各账龄段的金额分布和占比，识别坏账风险。适用场景：律所应收账款账龄分析、客户信用管理、坏账准备计提、财务健康度评估。触发词：账龄、应收账款账龄、aging、账龄分析。排除词：固定资产折旧、资产年限、账龄结构。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 应收账款明细 | array[object] | 每条记录包含开票日期和金额 | [{invoice_date:"2026-06-15", amount:50000}] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 当前日期 | string | 账龄计算的基准日期 | 默认当天 |
| 账龄分组 | array[object] | 自定义账龄分组区间 | 默认[0-30天, 31-60天, 61-90天, >90天] |
| 坏账计提比例 | object | 各账龄段的坏账准备计提比例 | 默认: 0-30天=1%, 31-60天=5%, 61-90天=10%, >90天=30% |
| 客户维度 | string | 是否按客户汇总 | 默认"否"，需在明细中提供客户标识 |
| 账龄天数单位 | string | 天数计算方式 | 默认"日历日"，可选"工作日"/"日历日" |

## formula
账龄 = 当前日期 - 开票日期（天数）

账龄分组:
- 0-30天: 账龄 ≤ 30天
- 31-60天: 31天 ≤ 账龄 ≤ 60天
- 61-90天: 61天 ≤ 账龄 ≤ 90天
- >90天: 账龄 > 90天

各组金额 = Σ(该组内的应收账款金额)
各组占比 = 各组金额 / 总应收账款金额 × 100%

坏账准备 = Σ(各组金额 × 该组计提比例)

加权平均账龄 = Σ(各笔金额 × 各笔账龄天数) / 总金额

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 总应收账款 | float | 应收账款总额 |
| 账龄分布 | array[object] | 各账龄段的金额、占比、笔数 |
| 加权平均账龄 | float | 加权平均账龄天数 |
| 坏账准备 | float | 按计提比例计算的坏账准备金 |
| 超过90天金额 | float | 账龄超过90天的应收账款总额 |
| 超过90天占比 | float | 超过90天账款占总应收账款的比例 |
| 账龄健康度 | string | 健康/关注/风险 |
| 催收建议 | string | 针对长账龄款项的催收建议 |

## example
【输入】
应收账款明细: [
  {invoice_date:"2026-07-20", amount:80000},
  {invoice_date:"2026-06-15", amount:50000},
  {invoice_date:"2026-05-01", amount:30000},
  {invoice_date:"2026-03-10", amount:25000},
  {invoice_date:"2026-01-05", amount:15000}
]
当前日期: "2026-07-30"

【输出】
总应收账款: 200000.00

账龄分布:
- 0-30天: 80000.00 (40.0%, 1笔) — 正常
- 31-60天: 50000.00 (25.0%, 1笔) — 正常
- 61-90天: 30000.00 (15.0%, 1笔) — 关注
- >90天: 40000.00 (20.0%, 2笔) — 风险

加权平均账龄: 52.5天

坏账准备:
- 0-30天: 80000 × 1% = 800
- 31-60天: 50000 × 5% = 2500
- 61-90天: 30000 × 10% = 3000
- >90天: 40000 × 30% = 12000
坏账准备合计: 18300.00

超过90天金额: 40000.00
超过90天占比: 20.0%

账龄健康度: 风险

催收建议: 超过90天的应收账款达4万元（占20%），建议立即启动催收程序，重点关注2026年1月和3月的两笔款项。61-90天段的3万元也需跟进，防止进一步恶化。建议对长期未回款客户重新评估信用额度。
