# 测试-缺陷趋势预测器

## name
测试-缺陷趋势预测器

## description
基于历史缺陷数据序列，使用线性回归或指数平滑方法预测未来缺陷趋势，输出缺陷趋势曲线和未来周期的缺陷预估。适用场景：测试计划制定、发布风险评估、质量趋势监控、测试资源规划。触发词：缺陷趋势、缺陷预测、bug趋势、缺陷曲线、质量趋势。排除词：缺陷密度、每千行缺陷、缺陷分类。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 历史缺陷序列 | array[object] | 各时间周期的缺陷数据 | [{period:"第1周", defects:25}, {period:"第2周", defects:20}, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 预测方法 | string | 预测算法 | 默认"线性回归"，可选"线性回归"/"指数平滑"/"移动平均" |
| 预测周期数 | int | 需要预测的未来周期数量 | 默认4，根据迭代长度调整 |
| 置信区间 | float | 预测结果的置信区间 | 默认95%，即95%置信区间 |
| 平滑系数 α | float | 指数平滑系数（0-1） | 默认0.3，数据波动大取0.1-0.3，趋势明显取0.4-0.7 |
| 季节性调整 | boolean | 是否考虑季节性因素 | 默认false，需至少2个完整周期数据 |
| 新增代码量 | float | 预期新增代码量（KLOC） | 默认不填，填了会结合缺陷密度预测 |

## formula
线性回归:
y = a + b × x
其中 b = Σ((x_i - x̄)(y_i - ȳ)) / Σ((x_i - x̄)²)
a = ȳ - b × x̄

指数平滑:
F_t+1 = α × Y_t + (1-α) × F_t
其中 F_t+1 为下一期预测值，Y_t 为当前实际值

趋势判定:
- 斜率 b < 0 且 |b| 较大: 缺陷下降趋势（质量改善）
- 斜率 b ≈ 0: 缺陷稳定（质量持平）
- 斜率 b > 0 且 |b| 较大: 缺陷上升趋势（质量恶化）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 趋势方向 | string | 下降/稳定/上升 |
| 趋势斜率 | float | 线性回归斜率 |
| 当前周期预测值 | float | 当前周期的模型预测值 |
| 未来N期预测 | array[object] | 未来各周期的缺陷预测值及置信区间 |
| 拟合优度 R² | float | 模型的拟合优度 |
| 趋势拐点 | string | 是否检测到趋势拐点及拐点位置 |
| 质量预警 | string | 基于预测的质量预警信息 |

## example
【输入】
历史缺陷序列: [
  {period:"第1周", defects:30},
  {period:"第2周", defects:28},
  {period:"第3周", defects:25},
  {period:"第4周", defects:22},
  {period:"第5周", defects:20},
  {period:"第6周", defects:18}
]
预测方法: "线性回归"
预测周期数: 4
置信区间: 95%

【输出】
趋势方向: 下降
趋势斜率 b: -2.46
拟合优度 R²: 0.98

未来4期预测:
- 第7周: 预测15.3个，置信区间[12.1, 18.5]
- 第8周: 预测12.8个，置信区间[9.2, 16.4]
- 第9周: 预测10.3个，置信区间[6.3, 14.3]
- 第10周: 预测7.8个，置信区间[3.4, 12.2]

质量预警: 无。缺陷呈持续下降趋势，R²=0.98表明线性趋势非常显著，质量正在稳步改善。按此趋势，第10周缺陷数有望降至10个以内，建议届时评估是否可以缩减测试资源投入。
