# 电商-竞品价格分析器

## name
电商-竞品价格分析器

## description
分析竞品价格数据，输出价格带分布、价格定位建议和竞争态势。帮助商家了解自身商品在同品类中的价格位置，制定有竞争力的定价策略。适用于电商选品定价、价格带定位、竞争策略制定等场景。触发词：竞品价格、价格带、价格分布、定价分析、竞品分析、价格定位。排除词：竞品监控（指持续监控场景）、价格爬虫。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| competitor_data | array[object] | 竞品数据列表，含商品名称、价格、销量、评分 | [{"name":"竞品A","price":89,"sales":1200,"rating":4.5}, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| own_price | float | 自身商品价格 | 若未提供，则仅输出竞品分析，不含自身定位建议 |
| own_cost | float | 自身商品成本 | 若未提供，则无法计算毛利率对比 |
| price_bands | int | 价格带分段数 | 默认5个价格带（低/中低/中/中高/高），按数据分布自动分箱 |
| category_benchmark | object | 品类基准数据 | 若未提供，则以竞品数据的中位数作为品类基准 |

## formula
价格带分析：
1. 按价格从低到高排序
2. 将价格区间等分为N个价格带（或按分位数分箱）
3. 统计每个价格带的竞品数量和销量占比

价格定位矩阵：
- 价格分位 = (自身价格 - min(竞品价格)) / (max(竞品价格) - min(竞品价格))
- 定位等级：低端(0-0.2)、中低端(0.2-0.4)、中端(0.4-0.6)、中高端(0.6-0.8)、高端(0.8-1.0)

竞争强度指数 = 同价格带竞品数 / 总竞品数 × 同价格带平均销量

计算步骤：
1. 解析竞品数据，清洗异常值（超过3σ的价格剔除）
2. 计算价格统计量：均值、中位数、标准差、最小/最大值
3. 按价格带分段，统计各段竞品分布
4. 计算竞争强度指数
5. 若提供了自身价格，输出价格定位和竞争策略建议
6. 绘制价格-销量散点图数据

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| price_statistics | object | 价格统计量（均值/中位数/标准差等） |
| price_bands | array[object] | 各价格带的竞品分布 |
| competition_intensity | float | 竞争强度指数（0-1） |
| own_position | object | 自身价格定位（若提供自身价格） |
| strategy_suggestion | string | 定价策略建议 |
| scatter_data | array[object] | 价格-销量散点数据 |

## example
**输入：**
```
competitor_data: [
  {"name": "竞品A", "price": 59, "sales": 3200, "rating": 4.2},
  {"name": "竞品B", "price": 79, "sales": 1800, "rating": 4.5},
  {"name": "竞品C", "price": 89, "sales": 1200, "rating": 4.7},
  {"name": "竞品D", "price": 69, "sales": 2500, "rating": 4.3},
  {"name": "竞品E", "price": 129, "sales": 600, "rating": 4.8},
  {"name": "竞品F", "price": 99, "sales": 900, "rating": 4.6},
  {"name": "竞品G", "price": 49, "sales": 4500, "rating": 4.0}
]
own_price: 75.00
```

**计算过程：**
1. 价格统计：均值=81.86，中位数=79，标准差=25.93，min=49，max=129
2. 价格带分布（按分位数分5段）：
   - 低端(49-59)：2个竞品，销量占比52.5%
   - 中低端(60-74)：1个竞品，销量占比17.0%
   - 中端(75-89)：2个竞品，销量占比20.5%
   - 中高端(90-109)：1个竞品，销量占比6.1%
   - 高端(110-129)：1个竞品，销量占比4.1%
3. 自身价格75元，处于中端价格带
4. 价格分位 = (75-49)/(129-49) = 0.325 → 中低端偏中端
