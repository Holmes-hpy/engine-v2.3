# 法律-诉讼时效计算器

## name
法律-诉讼时效计算器

## description
根据业务领域、管辖区和起算日期，计算诉讼时效截止日期，并考虑时效中断、中止等法定情形，输出时效截止日和剩余天数。适用场景：案件管理、诉讼策略制定、权利保护期限监控。触发词：诉讼时效、时效截止日、时效计算、诉讼期限。排除词：合同期限、专利保护期、诉讼费用。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 业务领域 | string | 法律业务领域 | "合同纠纷" / "侵权责任" / "劳动纠纷" / "知识产权" |
| 管辖区 | string | 适用法律的管辖区 | "中国大陆" / "中国香港" / "美国纽约州" |
| 起算日期 | string | 诉讼时效起算日期（YYYY-MM-DD） | "2023-05-15" |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 时效中断事件 | array[object] | 时效中断事件及日期 | 默认空，需提供中断事件类型和日期 |
| 时效中止事件 | array[object] | 时效中止起止日期 | 默认空，需提供中止起止日期 |
| 特殊规定 | string | 是否适用特殊时效规定 | 默认"否"，如国际货物买卖合同4年时效等 |
| 提醒提前天数 | int | 时效到期前多少天提醒 | 默认30天，可根据案件管理需要调整 |

## formula
基础时效期间（中国大陆，民法典）:
- 一般诉讼时效: 3年
- 国际货物买卖合同: 4年
- 人寿保险金请求权: 5年
- 环境侵权: 3年
- 劳动仲裁: 1年

时效截止日 = 起算日期 + 基础时效期间

时效中断: 从新起算日起重新计算时效期间
时效中止: 时效截止日 = 原截止日 + 中止天数

剩余天数 = 时效截止日 - 当前日期

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 时效截止日 | string | 诉讼时效截止日期 |
| 基础时效期间 | string | 适用的时效期间（如"3年"） |
| 剩余天数 | int | 距离时效截止日的剩余天数 |
| 时效状态 | string | 正常/即将到期/已过期 |
| 中断记录 | array[object] | 时效中断事件及重新计算后的截止日 |
| 中止记录 | array[object] | 时效中止事件及延长的天数 |
| 法律依据 | string | 适用的法律条文引用 |
| 行动建议 | string | 时效即将到期或已过期的应对建议 |

## example
【输入】
业务领域: "合同纠纷"
管辖区: "中国大陆"
起算日期: "2023-05-15"
时效中断事件: [{date:"2024-03-20", type:"提起诉讼"}]
提醒提前天数: 30

【输出】
基础时效期间: 3年（民法典第188条）
原时效截止日: 2026-05-15

时效中断: 2024-03-20提起诉讼，时效中断，重新起算
新时效截止日: 2027-03-20

当前日期: 2026-07-30
剩余天数: 233天
时效状态: 正常

法律依据: 《中华人民共和国民法典》第188条、第195条
行动建议: 时效正常，距截止日还有233天（约7.8个月），建议在到期前30天（2027-02-18）前完成诉讼准备。如案件复杂，可考虑在截止日前再次通过催告等方式中断时效。
