# 电商-竞品价格监控计算器

## name
电商-竞品价格监控计算器

## description
持续监控竞品价格变动，记录价格变化历史、计算变动幅度，并在价格突破阈值时发出趋势预警。与竞品价格分析器（静态分析）不同，本计算器专注于时间维度的动态监控，追踪价格波动趋势。适用于电商定价策略动态调整、竞品价格跟踪、促销活动监测等场景。触发词：竞品价格监控、价格变动、价格趋势、价格预警、竞品跟踪、价格波动。排除词：竞品价格分析（指静态价格带分析）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| competitor_url | string | 竞品商品URL或商品ID | "https://example.com/product/12345" |
| monitoring_period | string | 监控周期（daily/weekly/monthly） | "daily" |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| price_history | array[object] | 历史价格数据（含日期和价格） | 若未提供，则初始化为空，从当前价格开始记录 |
| alert_threshold | object | 预警阈值设置 | 默认：价格变动>10%触发强烈预警，5-10%触发关注预警，<5%正常 |
| competitor_name | string | 竞品名称 | 若未提供，从URL自动提取或使用商品ID |
| current_price | float | 当前价格（元） | 若未提供，需从外部数据源获取 |

## formula
价格变动幅度 = (当前价格 - 上期价格) / 上期价格 × 100%

价格变动趋势：
- 连续上涨：连续N期价格上涨
- 连续下跌：连续N期价格下跌
- 价格震荡：价格在短期内频繁波动（标准差/均值 > 阈值）

预警信号：
- 红色预警：价格变动幅度 > 10%，或连续3期同向变动
- 黄色关注：价格变动幅度 5-10%
- 绿色正常：价格变动幅度 < 5%

计算步骤：
1. 获取当前价格（从数据源或手动输入）
2. 与上期价格对比，计算变动幅度
3. 将当期价格追加到价格历史记录
4. 检测价格趋势模式（连续上涨/下跌/震荡）
5. 根据变动幅度和趋势判定预警等级
6. 生成价格变动记录和趋势图数据

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| current_price | float | 当前价格（元） |
| previous_price | float | 上期价格（元） |
| change_amount | float | 变动金额（元） |
| change_percent | float | 变动幅度（%） |
| price_history | array[object] | 完整价格变动记录 |
| trend | string | 价格趋势（上涨/下跌/平稳/震荡） |
| alert_level | string | 预警等级（红色/黄色/绿色） |
| alert_message | string | 预警信息 |

## example
**输入：**
```
competitor_url: "https://example.com/product/12345"
monitoring_period: "daily"
competitor_name: "竞品X"
price_history: [
  {"date": "2024-01-01", "price": 89.00},
  {"date": "2024-01-02", "price": 89.00},
  {"date": "2024-01-03", "price": 85.00},
  {"date": "2024-01-04", "price": 82.00}
]
current_price: 79.00
```

**计算过程：**
| 日期 | 价格 | 变动金额 | 变动幅度 |
|------|------|----------|----------|
| 01-01 | 89.00 | -- | -- |
| 01-02 | 89.00 | 0 | 0% |
| 01-03 | 85.00 | -4.00 | -4.49% |
| 01-04 | 82.00 | -3.00 | -3.53% |
| 01-05 | 79.00 | -3.00 | -3.66% |

累计变动 = (79.00 - 89.00) / 89.00 × 100% = -11.24%
趋势：连续3期下跌 → 触发红色预警

**输出：**
```
current_price: 79.00
previous_price: 82.00
change_amount: -3.00
change_percent: -3.66
price_history: [
  {"date": "2024-01-01", "price": 89.00},
  {"date": "2024-01-02", "price": 89.00},
  {"date": "2024-01-03", "price": 85.00},
  {"date": "2024-01-04", "price": 82.00},
  {"date": "2024-01-05", "price": 79.00}
]
trend: "持续下跌"
alert_level: "红色"
alert_message: "竞品X价格从89元降至79元，累计跌幅11.24%，连续3期下跌。建议：(1)排查竞品是否在进行促销清仓；(2)评估是否需要跟进降价或调整差异化策略；(3)密切关注该竞品后续价格走势"
```
