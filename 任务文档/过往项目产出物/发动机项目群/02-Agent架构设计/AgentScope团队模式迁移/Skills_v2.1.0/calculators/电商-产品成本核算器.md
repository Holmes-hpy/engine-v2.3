# 电商-产品成本核算器

## name
电商-产品成本核算器

## description
计算电商商品的综合成本，包含进货成本、物流成本、包装成本及平台扣点等全链路费用。帮助商家精准掌握每件商品的真实成本构成，支持定价决策和利润分析。适用于电商运营成本管理、SKU选品评估、定价策略制定等场景。触发词：产品成本、成本核算、电商成本、全链路成本、成本构成。排除词：制造成本（指生产制造场景）、财务成本核算。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| purchase_price | float | 商品进货单价（元） | 50.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| logistics_cost | float | 单件物流成本（元） | 若未提供，按行业均值估算：小件商品3-5元，中件商品5-10元，大件商品10-20元 |
| packaging_cost | float | 单件包装成本（元） | 若未提供，按行业均值估算：普通包装1-3元，礼盒包装5-10元 |
| platform_fee_rate | float | 平台扣点比例（如0.05表示5%） | 若未提供，按主流平台均值估算：天猫/京东约5%，拼多多约0.6%，抖音约2-5% |
| platform_fixed_fee | float | 平台固定技术服务费（元/单） | 默认0元 |
| warehousing_cost | float | 仓储分摊成本（元/件/月） | 默认0.5元/件 |
| return_loss_rate | float | 退货损耗率 | 默认按行业均值3%估算 |
| category | string | 商品品类 | 用于辅助估算各费用的行业均值 |

## formula
产品成本 = 进货价 + 物流成本 + 包装成本 + 平台扣点 + 平台固定费 + 仓储成本

其中，平台扣点 = 商品售价 × platform_fee_rate（若未提供售价则按进货价×1.5估算售价）

总成本（含退货损耗）= 产品成本 / (1 - return_loss_rate)

计算步骤：
1. 收集所有已提供的成本参数
2. 对缺失参数按估值逻辑补充
3. 计算平台扣点 = 售价 × 扣点比例
4. 产品成本 = 进货价 + 物流成本 + 包装成本 + 平台扣点 + 平台固定费 + 仓储成本
5. 总成本（含退货损耗）= 产品成本 / (1 - 退货损耗率)
6. 生成成本构成明细表

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| total_cost | float | 产品总成本（元） |
| total_cost_with_return | float | 含退货损耗的总成本（元） |
| cost_breakdown | object | 成本构成明细 |
| cost_ratios | object | 各项成本占比 |
| estimated_selling_price | float | 建议售价（按建议毛利率推算） |

## example
**输入：**
```
purchase_price: 50.00
logistics_cost: 6.00
packaging_cost: 2.50
platform_fee_rate: 0.05
selling_price: 120.00
```

**计算过程：**
1. 进货价 = 50.00元
2. 物流成本 = 6.00元
3. 包装成本 = 2.50元
4. 平台扣点 = 120.00 × 0.05 = 6.00元
5. 仓储成本 = 0.50元（默认值）
6. 产品成本 = 50.00 + 6.00 + 2.50 + 6.00 + 0.50 = 65.00元
7. 退货损耗率 = 3%（默认），总成本 = 65.00 / (1 - 0.03) = 67.01元
