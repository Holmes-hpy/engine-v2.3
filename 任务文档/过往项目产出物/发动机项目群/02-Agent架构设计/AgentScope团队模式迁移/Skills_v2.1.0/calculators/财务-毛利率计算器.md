# 财务-毛利率计算器

## name
财务-毛利率计算器

## description
计算企业或产品的毛利率（Gross Margin），衡量收入扣除直接成本后的盈利能力。适用于企业盈利能力分析、产品定价决策、同行业毛利对比、成本结构优化。触发词：毛利率、毛利、财务毛利、Gross Margin、毛利率计算。排除词：电商毛利率、平台扣点、净利率、营业利润率、跨境电商毛利率。

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| revenue | number | 收入（营业收入/销售收入） | 1000000 |
| cost | number | 成本（营业成本/销售成本，即直接与产品或服务生产相关的成本） | 600000 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| industry_benchmark | number | 行业平均毛利率 | 按行业估算：软件/SaaS行业通常70-85%；制造业20-40%；零售业20-35%；餐饮业60-70%；金融服务业50-80%。仅用于对比参考，不参与计算 |

## formula
毛利率 = (revenue - cost) / revenue

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| gross_margin | number | 毛利率（小数形式，如0.40表示40%） |
| gross_margin_percentage | number | 毛利率（百分比形式） |
| gross_profit | number | 毛利额 = revenue - cost |
| revenue | number | 回显收入 |
| cost | number | 回显成本 |

## example
**输入：**
- 收入：$1,000,000
- 成本：$600,000

**计算过程：**
毛利率 = (1,000,000 - 600,000) / 1,000,000
      = 400,000 / 1,000,000
      = 0.40

**输出：**
- 毛利率：0.40
- 毛利率百分比：40%
- 毛利额：$400,000
- 收入：$1,000,000
- 成本：$600,000

**解读：**
该企业毛利率为40%，意味着每$1收入中有$0.40可用于覆盖运营费用和产生利润。若为SaaS企业，40%的毛利率偏低（行业通常在70-85%），需要关注成本结构；若为制造业，40%属于较好水平。
