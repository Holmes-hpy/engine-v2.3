# 数据-信息源可信度分级器

## name
数据-信息源可信度分级器

## description
基于来源权威性、数据时效性、数据一致性和可验证性四个维度，对信息源进行可信度综合评估和分级（A/B/C/D），输出可信度评分和分级结果。适用场景：信息源评估、情报分析、研究数据筛选、新闻可信度判断。触发词：信息源可信度、可信度分级、来源评估、信息可靠性。排除词：数据质量、代码可信度、安全可信。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 信息源 | object | 信息源评估信息 | {name:"国家统计局", type:"政府机构", url:"https://www.stats.gov.cn"} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 来源权威性 | float | 来源权威性评分(1-10) | 默认需用户提供，政府/学术机构可给8-10，知名媒体6-8，个人博客1-4 |
| 数据时效性 | float | 数据时效性评分(1-10) | 默认需用户提供，实时数据9-10，近1年数据7-8，1-3年5-6，超过3年1-4 |
| 数据一致性 | float | 与多源交叉验证的一致性评分(1-10) | 默认需用户提供，多源一致9-10，基本一致7-8，部分矛盾4-6，严重矛盾1-3 |
| 可验证性 | float | 数据可追溯验证的程度评分(1-10) | 默认需用户提供，原始数据可查9-10，有引用来源7-8，无可追溯1-3 |
| 各维度权重 | object | 四维度的权重分配 | 默认: 权威性=0.30, 时效性=0.25, 一致性=0.25, 可验证性=0.20 |
| 领域特异性 | string | 特定领域的可信度加成 | 默认空，如金融数据来源在该领域有加成 |

## formula
可信度评分 = 权威性 × 0.30 + 时效性 × 0.25 + 一致性 × 0.25 + 可验证性 × 0.20

分级标准:
- 评分 ≥ 8.0: A级 — 高度可信，可直接引用
- 6.0 ≤ 评分 < 8.0: B级 — 可信，建议交叉验证
- 4.0 ≤ 评分 < 6.0: C级 — 有限可信，需多方验证
- 评分 < 4.0: D级 — 不可信，不建议引用

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 可信度评分 | float | 综合可信度评分(1-10) |
| 可信度分级 | string | A/B/C/D |
| 权威性得分 | float | 来源权威性维度得分 |
| 时效性得分 | float | 数据时效性维度得分 |
| 一致性得分 | float | 数据一致性维度得分 |
| 可验证性得分 | float | 可验证性维度得分 |
| 最低分维度 | string | 得分最低的维度 |
| 使用建议 | string | 基于分级的使用建议 |

## example
【输入】
信息源: {name:"国家统计局", type:"政府机构", url:"https://www.stats.gov.cn"}
来源权威性: 9.5
数据时效性: 8.0
数据一致性: 9.0
可验证性: 8.5

【输出】
可信度评分 = 9.5×0.30 + 8.0×0.25 + 9.0×0.25 + 8.5×0.20 = 8.80

可信度分级: A级（高度可信）

各维度得分:
- 权威性: 9.5 — 国家级政府统计机构，权威性极高
- 时效性: 8.0 — 数据更新及时，时效性良好
- 一致性: 9.0 — 与其他权威来源数据高度一致
- 可验证性: 8.5 — 原始数据和方法论公开可查

最低分维度: 时效性

使用建议: 该信息源为A级（高度可信），可直接引用。国家统计局数据具有最高权威性，建议在引用时注明数据发布日期和具体指标编码。时效性得分为8.0，如对时效性要求极高，可确认数据是否为最新发布版本。
