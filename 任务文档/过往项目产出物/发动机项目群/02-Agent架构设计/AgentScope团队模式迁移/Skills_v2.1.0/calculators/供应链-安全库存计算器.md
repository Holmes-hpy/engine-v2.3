# 供应链-安全库存计算器

## name
供应链-安全库存计算器

## description
计算供应链中的安全库存水平、再订货点（ROP）和经济订货批量（EOQ），帮助企业在满足服务水平目标的前提下最小化库存持有成本。这是库存管理的核心三件套数学工具。适用于库存策略制定、补货计划、仓储容量规划、资金占用优化等场景。触发词：安全库存、再订货点、ROP、EOQ、经济订货批量、库存优化、补货点。排除词：安全库存天数（指以天数为单位的安全库存）、库存周转（指周转率/周转天数）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| demand_data | array[float] | 历史需求数据序列（日/周/月） | [120, 135, 110, 145, 130, 150, 125, 140, 155, 128] |
| lead_time | int | 交货周期（与需求数据同单位） | 7（天） |
| service_level | float | 服务水平目标（0.90-0.999） | 0.95 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| ordering_cost | float | 单次订货成本（元） | 默认100元；含下单、运输、质检等固定成本 |
| holding_cost_per_unit | float | 单位持有成本（元/单位/年） | 默认按产品单价×20%估算；若未提供产品单价则按10元/单位计算 |
| annual_demand | int | 年需求量（单位） | 若未提供，从demand_data推算：日均需求×365 |
| demand_unit | string | 需求数据单位（day/week/month） | 默认day |

## formula
1. 安全库存公式：
   SS = Z × σ_d × √(LT)

   其中：
   - Z: 服务水平对应的标准正态分布分位数
     - 90% → Z=1.28, 95% → Z=1.645, 97.5% → Z=1.96, 99% → Z=2.326
   - σ_d: 需求标准差（与demand_data同单位）
   - LT: 交货周期（与demand_data同单位）

2. 再订货点公式：
   ROP = d × LT + SS

   其中：
   - d: 平均需求（demand_data的均值）
   - LT: 交货周期
   - SS: 安全库存

3. 经济订货批量公式：
   EOQ = √(2 × D × S / H)

   其中：
   - D: 年需求量
   - S: 单次订货成本
   - H: 单位持有成本（年）

计算步骤：
1. 计算需求均值 d = mean(demand_data)
2. 计算需求标准差 σ_d = std(demand_data)
3. 查找Z值（根据service_level）
4. 安全库存 SS = Z × σ_d × √(LT)
5. 再订货点 ROP = d × LT + SS
6. EOQ = √(2 × D × S / H)
7. 输出最优订货策略

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| safety_stock | float | 安全库存量（单位） |
| reorder_point | float | 再订货点（单位） |
| eoq | float | 经济订货批量（单位） |
| avg_demand | float | 平均需求 |
| demand_std | float | 需求标准差 |
| service_level_z | float | 使用的Z值 |
| annual_order_count | float | 年订货次数 |
| total_inventory_cost | float | 年库存总成本（订货+持有） |

## example
**输入：**
```
demand_data: [120, 135, 110, 145, 130, 150, 125, 140, 155, 128]
lead_time: 7
service_level: 0.95
ordering_cost: 200
holding_cost_per_unit: 15
```

**计算过程：**
1. d = mean([120,135,110,145,130,150,125,140,155,128]) = 133.8 单位/天
2. σ_d = std([120,135,110,145,130,150,125,140,155,128]) = 13.72
3. 服务水平95% → Z = 1.645
4. SS = 1.645 × 13.72 × √7 = 1.645 × 13.72 × 2.646 = 59.7 单位
5. ROP = 133.8 × 7 + 59.7 = 936.6 + 59.7 = 996.3 单位
6. D = 133.8 × 365 = 48,837 单位/年
7. EOQ = √(2 × 48,837 × 200 / 15) = √(19,534,800 / 15) = √1,302,320 = 1,141 单位

**输出：**
```
safety_stock: 59.7
reorder_point: 996.3
eoq: 1141.2
avg_demand: 133.8
demand_std: 13.72
service_level_z: 1.645
annual_order_count: 42.8
total_inventory_cost: 17118.00
```
