# 数据-数据质量评估器

## name
数据-数据质量评估器

## description
基于数据集的空值率、重复率和异常率，使用加权扣分模型计算数据质量评分，输出各维度得分和综合质量等级。适用场景：数据仓库质量监控、数据治理评估、数据迁移前质量检查、ETL管道质量审计。触发词：数据质量、质量评分、数据健康度、数据治理评分。排除词：代码质量、软件质量、产品质量。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 数据集 | object | 数据集基本信息及质量统计 | {total_rows:100000, null_count:500, duplicate_count:200, anomaly_count:300} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 空值率权重 | float | 空值率在扣分中的权重 | 默认0.35 |
| 重复率权重 | float | 重复率在扣分中的权重 | 默认0.30 |
| 异常率权重 | float | 异常率在扣分中的权重 | 默认0.35 |
| 空值率容忍度 | float | 空值率低于此值不扣分 | 默认0.01（1%） |
| 重复率容忍度 | float | 重复率低于此值不扣分 | 默认0.005（0.5%） |
| 异常率容忍度 | float | 异常率低于此值不扣分 | 默认0.01（1%） |
| 附加维度 | array[object] | 额外质量维度及权重 | 默认空，如时效性、一致性、完整性等 |
| 数据集名称 | string | 数据集标识名称 | 默认空 |

## formula
空值率 = 空值数 / 总行数
重复率 = 重复数 / 总行数
异常率 = 异常数 / 总行数

空值扣分 = max(0, 空值率 - 空值率容忍度) × 100 × 空值率权重
重复扣分 = max(0, 重复率 - 重复率容忍度) × 100 × 重复率权重
异常扣分 = max(0, 异常率 - 异常率容忍度) × 100 × 异常率权重

总扣分 = 空值扣分 + 重复扣分 + 异常扣分
质量评分 = max(0, 100 - 总扣分)

质量等级:
- 评分 ≥ 95: 优秀
- 85 ≤ 评分 < 95: 良好
- 70 ≤ 评分 < 85: 一般
- 评分 < 70: 较差

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 质量评分 | float | 综合数据质量评分(0-100) |
| 质量等级 | string | 优秀/良好/一般/较差 |
| 空值率 | float | 空值比例 |
| 重复率 | float | 重复值比例 |
| 异常率 | float | 异常值比例 |
| 空值扣分 | float | 空值维度的扣分 |
| 重复扣分 | float | 重复维度的扣分 |
| 异常扣分 | float | 异常维度的扣分 |
| 主要问题 | string | 扣分最多的维度 |
| 改进建议 | string | 提升数据质量的具体建议 |

## example
【输入】
数据集: {total_rows:100000, null_count:500, duplicate_count:200, anomaly_count:300}
空值率权重: 0.35
重复率权重: 0.30
异常率权重: 0.35
空值率容忍度: 0.01
重复率容忍度: 0.005
异常率容忍度: 0.01

【输出】
空值率: 0.50%
重复率: 0.20%
异常率: 0.30%

空值扣分 = max(0, 0.005-0.01) × 100 × 0.35 = 0
重复扣分 = max(0, 0.002-0.005) × 100 × 0.30 = 0
异常扣分 = max(0, 0.003-0.01) × 100 × 0.35 = 0

总扣分: 0
质量评分: 100.0
质量等级: 优秀

主要问题: 无（所有维度均在容忍度范围内）

改进建议: 数据质量优秀，所有指标均低于容忍度阈值。建议继续保持当前的数据治理策略，定期进行数据质量巡检。
