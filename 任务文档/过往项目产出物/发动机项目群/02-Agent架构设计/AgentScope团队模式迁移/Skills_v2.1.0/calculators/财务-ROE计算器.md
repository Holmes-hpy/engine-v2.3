# 财务-ROE计算器

## name
财务-ROE计算器

## description
计算企业的净资产收益率（Return on Equity），衡量股东投入资本的回报效率。适用于企业盈利能力分析、同行业对比、杜邦分析、股东价值评估。触发词：ROE、净资产收益率、股东回报、Return on Equity、股东权益回报率、权益收益率。排除词：ROI、投资回报率、ROA、总资产收益率、ROIC、投入资本回报率。

## category
atomic-calculator

## sub_category
财务

## domain
财务指标

## formula_reference
concept_registry.财务.ROE

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| net_income | number | 净利润（归属于母公司股东的净利润） | 5000000 |
| equity | number | 净资产（股东权益，通常取期初和期末平均值） | 25000000 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| industry_avg_roe | number | 行业平均ROE | 按行业估算：银行/金融通常10-15%；科技/互联网15-25%；消费品15-20%；制造业8-12%；公用事业6-10%。仅用于对比参考 |
| dupont_breakdown | boolean | 是否进行杜邦分解 | 默认false。若为true且用户提供了收入、总资产、净利润，则输出杜邦三因子分解：ROE = 净利润率 × 总资产周转率 × 权益乘数 |

## formula
ROE = net_income / equity

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| roe | number | 净资产收益率（小数形式） |
| roe_percentage | number | 净资产收益率（百分比形式） |
| net_income | number | 回显净利润 |
| equity | number | 回显净资产 |
| dupont_breakdown | object | 杜邦分解（若启用）：净利润率、总资产周转率、权益乘数 |

## example
**输入：**
- 净利润：$5,000,000
- 净资产：$25,000,000

**计算过程：**
ROE = 5,000,000 / 25,000,000 = 0.20

**输出：**
- ROE：0.20
- ROE百分比：20%
- 净利润：$5,000,000
- 净资产：$25,000,000

**解读：**
ROE=20%意味着每$1股东权益创造$0.20的净利润，处于较好水平（一般ROE>15%为优秀）。但需注意：高ROE可能源于高杠杆（权益乘数大），而非经营效率高。建议结合杜邦分析进一步拆解ROE的来源，避免被高杠杆带来的"虚高"ROE所迷惑。

**杜邦分析补充（若用户提供更多数据）：**
假设已知净利润率=10%，总资产周转率=1.0，权益乘数=2.0
则 ROE = 10% × 1.0 × 2.0 = 20%
说明20%的ROE中，一半来自经营效率，一半来自财务杠杆。
