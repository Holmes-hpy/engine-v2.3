# 财务-分部加总估值器

## name
财务-分部加总估值器

## description
使用分部加总法（Sum of the Parts, SOTP）对多元化企业进行估值，将各业务分部独立估值后加总得出企业整体估值。适用于多元化集团估值、业务分拆分析、资产重组评估、控股公司折价分析。触发词：分部加总、SOTP、Sum of the Parts、业务分部估值、分部估值、多元化估值。排除词：DCF、可比公司、单一业务估值。

atomic-calculator

财务

concept_registry.估值.分部加总

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| segment_valuations | array[object] | 各业务分部估值列表，每个对象包含segment_name和valuation | [{"segment_name":"云计算","valuation":5000000000},{"segment_name":"电商","valuation":3000000000},{"segment_name":"金融科技","valuation":2000000000}] |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| holding_discount | number | 控股公司折价率 | 默认0%。多元化控股公司通常存在10-30%的控股公司折价（Conglomerate Discount），反映管理复杂度、资源配置效率低下等问题。若各分部紧密协同，折价可降低 |
| corporate_overhead | number | 集团总部费用对应的负价值 | 默认0。若集团总部费用较高且未在各分部中体现，可单独扣除 |
| net_cash | number | 净现金（现金 - 有息负债） | 默认0。若集团层面有净现金或净债务，需在最后加总 |
| non_core_assets | number | 非核心资产价值 | 默认0。如投资性房地产、股权投资等非经营性资产 |

## formula
总估值 = Σ各业务分部独立估值 × (1 - holding_discount) - corporate_overhead + net_cash + non_core_assets

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| total_valuation | number | 总估值（SOTP估值） |
| segment_valuations_sum | number | 各分部估值简单加总 |
| segment_details | array[object] | 各分部估值明细 |
| holding_discount | number | 回显控股公司折价率 |
| per_share_value | number | 每股价值（若已知总股数） |

## example
**输入：**
- 云计算分部估值：$50亿
- 电商分部估值：$30亿
- 金融科技分部估值：$20亿
- 控股公司折价：15%（LLM估值，基于多元化控股公司折价惯例）
- 净现金：$5亿

**计算过程：**
分部估值简单加总 = 50 + 30 + 20 = $100亿
折价后估值 = 100 × (1 - 0.15) = $85亿
总估值 = 85 + 5 = $90亿

**输出：**
- 总估值（SOTP）：$90亿
- 分部估值简单加总：$100亿
- 分部明细：
  - 云计算：$50亿
  - 电商：$30亿
  - 金融科技：$20亿
- 控股公司折价：15%（LLM估值）
- 净现金：$5亿

**解读：**
分部加总估值$90亿，相比简单加总$100亿打了85折，体现了市场对多元化集团的控股公司折价。若公司宣布分拆某些业务，折价可能缩小，释放价值。投资者常利用SOTP分析寻找"折价套利"机会。
