# 财务-DCF估值器

## name
财务-DCF估值器

## description
使用现金流折现法（Discounted Cash Flow）对企业进行估值，基于未来自由现金流的现值计算企业内在价值。适用于企业估值、投资决策、并购定价、IPO定价参考。触发词：DCF、现金流折现、折现估值、Discounted Cash Flow、内在价值、企业估值-DCF。排除词：可比公司、PE估值、PB估值、PS估值。

## category
atomic-calculator

## sub_category
财务

## domain
估值

## formula_reference
concept_registry.估值.DCF

## inputs
### 必填参数（用户必须提供）
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| free_cash_flows | array[number] | 自由现金流序列（预测期各年FCF），按年份顺序排列 | [100, 120, 140, 160, 180] |
| discount_rate | number | 折现率（小数形式，通常为WACC） | 0.10 |

### 可选参数（用户可提供，不提供则LLM估值）
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| terminal_growth_rate | number | 终值永续增长率 | 默认2-3%，通常取保守估计。发达国家市场取2%，新兴市场取3%。注意：终值增长率不得超过GDP长期增长率，也不得超过折现率 |
| projection_years | number | 预测期数（年） | 默认5年。若free_cash_flows长度与projection_years不一致，以free_cash_flows的实际长度为准 |
| net_debt | number | 净债务（有息负债 - 现金） | 默认0。若用户提供，则用于计算股权价值：股权价值 = 企业价值 - 净债务 |

## formula
企业价值 = Σ(FCF_t / (1 + r)^t) + TV / (1 + r)^n

其中：
- FCF_t = 第t年自由现金流
- r = 折现率
- n = 预测期数
- TV = 终值 = FCF_n × (1 + g) / (r - g)，g为终值永续增长率

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| enterprise_value | number | 企业价值（预测期FCF现值 + 终值现值） |
| pv_fcfs | number | 预测期FCF现值之和 |
| terminal_value | number | 终值（未折现） |
| pv_terminal_value | number | 终值现值 |
| equity_value | number | 股权价值（若提供净债务则计算） |
| discount_rate | number | 回显折现率 |
| terminal_growth_rate | number | 回显终值增长率 |

## example
**输入：**
- 自由现金流序列：[100, 120, 140, 160, 180]（万元）
- 折现率：10%（0.10）
- 预测期数：5年
- 终值增长率：3%（0.03，LLM估值）

**计算过程：**
第1年PV = 100/(1.10)^1 = 90.91
第2年PV = 120/(1.10)^2 = 99.17
第3年PV = 140/(1.10)^3 = 105.18
第4年PV = 160/(1.10)^4 = 109.28
第5年PV = 180/(1.10)^5 = 111.77
预测期FCF现值之和 = 516.31

终值 = 180 × 1.03 / (0.10 - 0.03) = 185.4 / 0.07 = 2,648.57
终值现值 = 2,648.57 / (1.10)^5 = 1,644.50

企业价值 = 516.31 + 1,644.50 = 2,160.81

**输出：**
- 企业价值：2,160.81万元
- 预测期FCF现值之和：516.31万元
- 终值（未折现）：2,648.57万元
- 终值现值：1,644.50万元
- 折现率：10%
- 终值增长率：3%（LLM估值）

**解读：**
终值占企业价值的76%（1,644.50/2,160.81），说明该企业大部分价值来自远期预期，这是DCF模型的典型特征，也提示终值假设对估值结果影响较大，建议进行敏感性分析。
