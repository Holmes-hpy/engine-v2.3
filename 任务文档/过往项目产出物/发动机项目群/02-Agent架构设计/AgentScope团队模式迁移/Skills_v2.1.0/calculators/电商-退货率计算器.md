# 电商-退货率计算器

## name
电商-退货率计算器

## description
计算电商商品的退货率，支持按时间维度、商品维度、品类维度、用户维度等多维度统计。退货率是衡量商品质量、用户满意度和运营健康度的核心指标。适用于电商运营分析、商品质量评估、供应商考核等场景。触发词：退货率、退货比例、退货统计、退款率统计、售后率。排除词：退款金额（指金额计算）、退货原因（指原因分析）。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| return_orders | int | 退货订单数 | 125 |
| total_orders | int | 总订单数 | 5000 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| dimension | string | 分析维度（overall/product/category/user/time） | 默认overall（整体退货率） |
| time_range | object | 时间范围 | 默认最近30天 |
| product_id | string | 指定商品ID（单品维度） | 若提供则计算单品退货率 |
| category_id | string | 指定品类ID（品类维度） | 若提供则计算品类退货率 |
| benchmark | float | 行业基准退货率 | 默认按品类使用行业均值：服装15-25%、电子3-8%、食品1-3%、美妆5-10% |
| return_amount | float | 退货金额（元） | 若提供，可额外计算退货金额占比 |

## formula
退货率 = 退货订单数 / 总订单数 × 100%

退货金额率 = 退货总金额 / 订单总金额 × 100%（若提供金额数据）

多维度计算：
- 单品退货率 = 该商品退货订单数 / 该商品总订单数
- 品类退货率 = 该品类退货订单数 / 该品类总订单数
- 时段退货率 = 指定时段退货订单数 / 该时段总订单数

计算步骤：
1. 根据dimension确定计算口径
2. 退货率 = 退货订单数 / 总订单数 × 100%
3. 若提供金额数据，退货金额率 = 退货金额 / 订单总金额 × 100%
4. 与行业基准对比，输出偏差分析
5. 若偏差过大（超过基准2倍），生成预警

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| return_rate | float | 退货率（%） |
| return_amount_rate | float | 退货金额率（%，若提供金额数据） |
| dimension | string | 分析维度 |
| benchmark | float | 行业基准退货率 |
| deviation | float | 与基准的偏差（百分点） |
| alert_level | string | 预警等级（正常/关注/警告） |
| trend_analysis | string | 趋势分析（若提供了历史数据对比） |

## example
**输入：**
```
return_orders: 125
total_orders: 5000
dimension: "overall"
return_amount: 25000.00
total_amount: 1200000.00
```

**计算过程：**
1. 退货率 = 125 / 5000 × 100% = 2.50%
2. 退货金额率 = 25000 / 1200000 × 100% = 2.08%
3. 假设品类为电子类，基准退货率 = 5%
4. 偏差 = 2.50% - 5.00% = -2.50%（低于行业基准）

**输出：**
```
return_rate: 2.50
return_amount_rate: 2.08
dimension: "overall"
benchmark: 5.00
deviation: -2.50
alert_level: "正常"
trend_analysis: "当前整体退货率2.50%低于电子品类行业基准5%，表现良好。退货金额率2.08%低于订单退货率2.50%，说明退货商品平均单价低于整体，以小件退货为主"
```
