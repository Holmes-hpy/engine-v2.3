# 电商-退货防欺诈评分器

## name
电商-退货防欺诈评分器

## description
综合评估退货行为的欺诈风险，通过加权评分模型对多个危险信号进行量化打分，输出整体欺诈风险等级。帮助电商平台和商家识别恶意退货、掉包退货、虚假退货等欺诈行为。适用于电商退货审核、风控策略制定、退货流程自动化决策等场景。触发词：防欺诈评分、退货欺诈、欺诈风险评估、恶意退货、退货风控、欺诈综合评分。排除词：欺诈指标（指单项指标计算）、信用评分。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| risk_signals | array[object] | 危险信号清单，含信号名称和是否触发 | [{"signal":"高频退货","triggered":true}, ...] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| signal_weights | object | 各危险信号的自定义权重 | 若未提供，使用默认权重：高频退货(25%)、地址异常(20%)、金额异常(15%)、时间异常(10%)、设备异常(10%)、退货理由矛盾(10%)、新账号(5%)、批量退货(5%) |
| user_history | object | 用户历史行为数据 | 用于辅助判断：历史退货率、账号注册时长、历史订单数等 |
| threshold_high | float | 高风险阈值 | 默认0.60（60分以上为高风险） |
| threshold_medium | float | 中风险阈值 | 默认0.35（35-60分为中风险） |

## formula
欺诈评分 = Σ(危险信号_i × 权重_i)

其中：
- 危险信号_i：0或1（未触发/触发）
- 权重_i：各信号对应的权重，所有权重之和为1

默认危险信号及权重：
| 危险信号 | 权重 | 说明 |
|----------|------|------|
| 高频退货 | 0.25 | 近30天退货次数>3或退货率>30% |
| 地址异常 | 0.20 | 退货地址与收货地址不一致，或地址为高风险区域 |
| 金额异常 | 0.15 | 退货金额显著高于同类用户均值2倍以上 |
| 时间异常 | 0.10 | 收货后极短时间内（<1小时）发起退货 |
| 设备异常 | 0.10 | 同一设备关联多个账号，或设备指纹异常 |
| 退货理由矛盾 | 0.10 | 退货理由与商品类目不匹配，或前后理由不一致 |
| 新账号 | 0.05 | 账号注册时间<30天且首次购买即退货 |
| 批量退货 | 0.05 | 同一收货地址短时间内多笔退货 |

风险等级划分：
- 高风险：评分 ≥ 60分 → 建议人工审核
- 中风险：评分 35-59分 → 建议加强验证
- 低风险：评分 < 35分 → 建议自动通过

计算步骤：
1. 解析危险信号清单，识别已触发的信号
2. 对每个触发的信号乘以对应权重
3. 欺诈评分 = 所有触发信号的加权和 × 100
4. 根据阈值判定风险等级
5. 输出各信号的贡献度

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| fraud_score | float | 欺诈评分（0-100分） |
| risk_level | string | 风险等级（高/中/低） |
| triggered_signals | array[object] | 触发的危险信号及贡献度 |
| total_signals_triggered | int | 触发信号总数 |
| action | string | 建议处置动作 |
| confidence | float | 评分置信度（0-1） |

## example
**输入：**
```
risk_signals: [
  {"signal": "高频退货", "triggered": true},
  {"signal": "地址异常", "triggered": true},
  {"signal": "金额异常", "triggered": false},
  {"signal": "时间异常", "triggered": false},
  {"signal": "设备异常", "triggered": true},
  {"signal": "退货理由矛盾", "triggered": false},
  {"signal": "新账号", "triggered": true},
  {"signal": "批量退货", "triggered": false}
]
```

**计算过程：**
| 信号 | 触发 | 权重 | 贡献分 |
|------|------|------|--------|
| 高频退货 | 是 | 0.25 | 25 |
| 地址异常 | 是 | 0.20 | 20 |
| 金额异常 | 否 | 0.15 | 0 |
| 时间异常 | 否 | 0.10 | 0 |
| 设备异常 | 是 | 0.10 | 10 |
| 退货理由矛盾 | 否 | 0.10 | 0 |
| 新账号 | 是 | 0.05 | 5 |
| 批量退货 | 否 | 0.05 | 0 |

欺诈评分 = 25 + 20 + 10 + 5 = 60分

**输出：**
```
fraud_score: 60
risk_level: "高风险"
triggered_signals: [
  {"signal": "高频退货", "contribution": 25, "weight": 0.25},
  {"signal": "地址异常", "contribution": 20, "weight": 0.20},
  {"signal": "设备异常", "contribution": 10, "weight": 0.10},
  {"signal": "新账号", "contribution": 5, "weight": 0.05}
]
total_signals_triggered: 4
action: "建议人工审核——该退货请求触发了4个危险信号，其中高频退货和地址异常为主要风险来源，建议客服介入核实退货真实性"
confidence: 0.85
```
