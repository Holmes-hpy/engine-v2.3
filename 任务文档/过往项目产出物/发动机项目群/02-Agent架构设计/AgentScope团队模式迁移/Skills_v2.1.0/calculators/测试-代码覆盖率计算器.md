# 测试-代码覆盖率计算器

## name
测试-代码覆盖率计算器

## description
计算代码行覆盖率，即已覆盖的可执行代码行数占总可执行代码行数的比例，衡量测试对代码的执行覆盖程度。适用场景：单元测试覆盖率评估、代码质量门禁、CI/CD流水线质量检测。触发词：代码覆盖率、行覆盖率、语句覆盖率、line coverage。排除词：功能覆盖率、需求覆盖率、分支覆盖率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 已覆盖行数 | int | 测试执行过程中至少被执行过一次的代码行数 | 8500 |
| 总行数 | int | 项目中可执行代码的总行数（不含注释、空行） | 10000 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 目标覆盖率 | float | 期望达到的覆盖率阈值 | 默认80%，一般项目取80%，核心系统取90% |
| 排除模式 | array[string] | 排除计算的代码路径/文件模式 | 默认空，可按需排除自动生成代码、测试代码等 |
| 粒度 | string | 覆盖率计算粒度 | 默认"行级"，可选"函数级"/"语句级"/"行级" |

## formula
代码覆盖率 = 已覆盖行数 / 总行数 × 100%

判定标准:
- 覆盖率 ≥ 90%: 优秀
- 80% ≤ 覆盖率 < 90%: 良好
- 60% ≤ 覆盖率 < 80%: 一般，需改进
- 覆盖率 < 60%: 不足，需重点补充测试

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 代码覆盖率 | float | 代码覆盖率百分比 |
| 达标状态 | string | 达标/未达标 |
| 未覆盖行数 | int | 总行数 - 已覆盖行数 |
| 覆盖率等级 | string | 优秀/良好/一般/不足 |
| 改进建议 | string | 针对未覆盖代码的补充测试建议 |

## example
【输入】
已覆盖行数: 8500
总行数: 10000
目标覆盖率: 80%

【输出】
代码覆盖率: 85.00%
未覆盖行数: 1500
达标状态: 达标
覆盖率等级: 良好

改进建议: 当前覆盖率85%，已超过目标80%。仍有1500行代码未被覆盖，建议优先补充核心业务逻辑和异常分支的测试用例，可将覆盖率提升至90%以上。
