# 风险-风险评估矩阵计算器

## name
风险-风险评估矩阵计算器

## description
构建风险评估矩阵（Risk Assessment Matrix），通过综合评估风险事件的影响程度和发生可能性，输出风险等级分类和热力图数据。风险矩阵是风险管理中最直观的定性+定量评估工具，广泛应用于企业风险管理、项目风险评审、合规风险评估等场景。触发词：风险矩阵、风险等级、风险热力图、风险评估、影响程度、发生概率、RACI风险。排除词：风险评分卡（指信用评分场景）、FMEA。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| risk_items | array[object] | 风险项目列表，每项包含名称、影响程度、发生可能性 | [{"name":"市场波动风险","impact":4,"probability":3}, ...] |
| impact_scale | object | 影响程度评分标准（1-5分） | {"1":"可忽略","2":"轻微","3":"中等","4":"严重","5":"灾难性"} |
| probability_scale | object | 发生可能性评分标准（1-5分） | {"1":"极低(<5%)","2":"低(5-20%)","3":"中(20-50%)","4":"高(50-80%)","5":"极高(>80%)"} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| risk_matrix_definition | object | 自定义风险等级矩阵（5×5） | 默认使用标准矩阵：低风险(1-4分)、中风险(5-9分)、高风险(10-19分)、极高风险(20-25分) |
| risk_tolerance | string | 风险容忍度阈值(low/medium/high) | 默认medium；影响最终风险等级判定和处置建议 |
| color_map | object | 热力图颜色映射 | 默认：绿(低风险)、黄(中风险)、橙(高风险)、红(极高风险) |

## formula
风险等级 = 影响程度 × 发生可能性

风险评分 = impact_score × probability_score

标准判定矩阵（5×5）：
| 影响\概率 | 1(极低) | 2(低) | 3(中) | 4(高) | 5(极高) |
|-----------|---------|-------|-------|-------|--------|
| 5(灾难性) | 中(5)   | 高(10)| 高(15)| 极高(20)| 极高(25)|
| 4(严重)   | 低(4)   | 中(8) | 高(12)| 高(16)| 极高(20)|
| 3(中等)   | 低(3)   | 中(6) | 中(9) | 高(12)| 高(15)  |
| 2(轻微)   | 低(2)   | 低(4) | 中(6) | 中(8) | 高(10)  |
| 1(可忽略) | 低(1)   | 低(2) | 低(3) | 低(4) | 中(5)   |

风险等级划分：
- 低风险：评分 1-4
- 中风险：评分 5-9
- 高风险：评分 10-19
- 极高风险：评分 20-25

计算步骤：
1. 对每个risk_item，计算 risk_score = impact × probability
2. 根据risk_score在判定矩阵中定位风险等级
3. 按风险等级分组排序（极高→高→中→低）
4. 生成热力图坐标数据
5. 输出风险处置优先级建议

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| risk_levels | array[object] | 每个风险项的等级（含评分和处置建议） |
| heatmap_data | array[array] | 5×5热力图矩阵数据 |
| risk_distribution | object | 各等级风险数量分布 |
| high_priority_items | array[object] | 需优先处置的高/极高风险项列表 |
| summary | string | 风险评估总体结论 |

## example
**输入：**
```
risk_items: [
  {"name": "市场波动风险", "impact": 4, "probability": 3},
  {"name": "信用违约风险", "impact": 5, "probability": 2},
  {"name": "流动性风险", "impact": 3, "probability": 4},
  {"name": "操作失误风险", "impact": 2, "probability": 3},
  {"name": "合规风险", "impact": 4, "probability": 1}
]
```

**计算过程：**
| 风险名称 | 影响 | 概率 | 评分 | 等级 |
|----------|------|------|------|------|
| 市场波动风险 | 4(严重) | 3(中) | 12 | 高风险 |
| 信用违约风险 | 5(灾难性) | 2(低) | 10 | 高风险 |
| 流动性风险 | 3(中等) | 4(高) | 12 | 高风险 |
| 操作失误风险 | 2(轻微) | 3(中) | 6 | 中风险 |
| 合规风险 | 4(严重) | 1(极低) | 4 | 低风险 |

**输出：**
```

  {"name": "市场波动风险", "score": 12, "level": "高风险", "action": "需制定对冲策略并持续监控"},
  {"name": "流动性风险", "score": 12, "level": "高风险", "action": "需建立流动性储备和应急预案"},
  {"name": "信用违约风险", "score": 10, "level": "高风险", "action": "需加强信用审核和分散化配置"},
  {"name": "操作失误风险", "score": 6, "level": "中风险", "action": "需完善操作流程和定期培训"},
  {"name": "合规风险", "score": 4, "level": "低风险", "action": "常规监控即可"}
]
risk_distribution: {"极高": 0, "高": 3, "中": 1, "低": 1}
high_priority_items: ["市场波动风险", "流动性风险", "信用违约风险"]

```
