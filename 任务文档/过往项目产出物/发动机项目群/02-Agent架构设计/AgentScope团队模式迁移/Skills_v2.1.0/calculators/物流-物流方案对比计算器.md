# 物流-物流方案对比计算器

## name
物流-物流方案对比计算器

## description
基于商品属性、发货地和单量，对多种物流方案进行成本、时效、破损率等多维度综合评分对比，输出最优方案推荐。适用场景：物流供应商选择、快递方案对比、配送模式决策（自营vs第三方）。触发词：物流方案对比、快递对比、配送方案选择、物流供应商评估。排除词：仓网布局、仓库选址、运输路线优化。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 商品信息 | object | 商品类型、重量、体积、价值 | {type:"电子产品", weight_kg:1.5, volume_cm3:3000, value_yuan:5000} |
| 发货地 | string | 发货地址 | "上海市浦东新区" |
| 月单量 | int | 月均发货单量 | 10000 |
| 候选方案列表 | array[object] | 各方案名称、单价、时效、破损率 | [{name:"顺丰标快", price_per_order:12, delivery_hours:24, damage_rate:0.001}] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 成本权重 | float | 成本维度权重 | 默认0.40 |
| 时效权重 | float | 时效维度权重 | 默认0.35 |
| 破损率权重 | float | 破损率维度权重 | 默认0.25 |
| 月增速率 | float | 预计月单量增长率 | 默认0.05，基于行业平均增速估值 |
| 附加服务需求 | array[string] | 是否需要代收货款、保价等 | 默认空，按需启用量化加分 |

## formula
成本得分 = (各方案中最低成本 / 当前方案成本) × 100
时效得分 = (各方案中最短时效 / 当前方案时效) × 100
破损率得分 = (各方案中最低破损率 / 当前方案破损率) × 100

综合评分 = 成本得分 × 40% + 时效得分 × 35% + 破损率得分 × 25%

月度总成本 = 单量 × 单价

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 方案排名 | array[object] | 按综合评分降序排列的方案列表 |
| 各方案综合评分 | array[float] | 各方案的综合评分 |
| 各方案月度总成本 | array[float] | 各方案的月度总成本 |
| 推荐方案 | string | 综合评分最高的方案名称 |
| 推荐理由 | string | 基于评分差异的推荐说明 |

## example
【输入】
商品信息: {type:"服装", weight_kg:0.8, volume_cm3:2000, value_yuan:300}
发货地: "浙江省杭州市"
月单量: 10000
候选方案列表: [
  {name:"顺丰标快", price_per_order:12, delivery_hours:24, damage_rate:0.0005},
  {name:"中通快递", price_per_order:5, delivery_hours:48, damage_rate:0.001},
  {name:"京东物流", price_per_order:8, delivery_hours:36, damage_rate:0.0008},
  {name:"圆通速递", price_per_order:4.5, delivery_hours:52, damage_rate:0.0015}
]

【输出】
方案排名:
1. 京东物流 — 综合评分: 91.3
2. 顺丰标快 — 综合评分: 88.7
3. 中通快递 — 综合评分: 82.5
4. 圆通速递 — 综合评分: 71.8

各方案月度总成本:
- 顺丰标快: 120,000 元/月
- 中通快递: 50,000 元/月
- 京东物流: 80,000 元/月
- 圆通速递: 45,000 元/月

推荐方案: 京东物流
推荐理由: 综合评分最高(91.3)，在成本(80,000元/月)和时效(36小时)之间取得最优平衡，破损率(0.08%)也处于较低水平，性价比最佳。
