# 风险-夏普比率计算器

## name
风险-夏普比率计算器

## description
计算投资组合的夏普比率（Sharpe Ratio），衡量每承担一单位总风险所能获得的超额收益。夏普比率是投资领域最广泛使用的风险调整后收益指标，由诺贝尔奖得主William Sharpe提出。适用于基金业绩比较、策略回测评估、资产配置优化等场景。触发词：夏普比率、Sharpe Ratio、风险调整收益、收益风险比、基金排名。排除词：Sortino比率、信息比率、特雷诺比率、Calmar比率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| portfolio_returns | array[float] | 投资组合的各期收益率序列 | [0.015, 0.022, -0.008, 0.010, 0.018, ...] |
| risk_free_rate | float | 无风险利率（年化），如国债收益率 | 0.03（表示3%） |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| portfolio_std | float | 投资组合收益率标准差（年化） | 若未提供，则从portfolio_returns序列自动计算：先算各期std，再根据period_type年化 |
| period_type | string | 收益率周期类型(daily/weekly/monthly) | 默认daily；年化系数：daily×√252，weekly×√52，monthly×√12 |
| annualize | boolean | 是否输出年化结果 | 默认true；若为false则输出原始周期夏普比率 |

## formula
夏普比率 = (R_p - R_f) / σ_p

其中：
- R_p: 投资组合年化收益率
- R_f: 无风险年化利率
- σ_p: 投资组合年化标准差

年化换算规则：
- 日收益率 → 年化收益率 = 日均收益率 × 252
- 日标准差 → 年化标准差 = 日标准差 × √252
- 周收益率 → 年化收益率 = 周均收益率 × 52
- 周标准差 → 年化标准差 = 周标准差 × √52
- 月收益率 → 年化收益率 = 月均收益率 × 12
- 月标准差 → 年化标准差 = 月标准差 × √12

计算步骤：
1. 计算portfolio_returns均值 μ_p = mean(portfolio_returns)
2. 若未提供portfolio_std，计算 σ_p_raw = std(portfolio_returns)
3. 根据period_type年化：R_p = μ_p × 年化系数；σ_p = σ_p_raw × 年化√系数
4. 夏普比率 = (R_p - R_f) / σ_p

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| sharpe_ratio | float | 夏普比率值 |
| annualized_return | float | 年化收益率 |
| annualized_std | float | 年化标准差 |
| risk_free_rate | float | 使用的无风险利率 |
| interpretation | string | 夏普比率评价（优秀/良好/一般/较差） |
| period_type | string | 使用的周期类型 |

## example
**输入：**
```
portfolio_returns: [0.0015, 0.0022, -0.0008, 0.0010, 0.0018, -0.0005, 0.0025, 0.0012, -0.0010, 0.0020]
risk_free_rate: 0.03
period_type: "daily"
```

**计算过程：**
1. μ_p = mean([0.0015, 0.0022, -0.0008, 0.0010, 0.0018, -0.0005, 0.0025, 0.0012, -0.0010, 0.0020]) = 0.00099
2. σ_p_raw = std([0.0015, 0.0022, -0.0008, 0.0010, 0.0018, -0.0005, 0.0025, 0.0012, -0.0010, 0.0020]) = 0.00126
3. 年化收益率 R_p = 0.00099 × 252 = 0.2495（24.95%）
4. 年化标准差 σ_p = 0.00126 × √252 = 0.00126 × 15.875 = 0.0200（2.0%）
5. 夏普比率 = (0.2495 - 0.03) / 0.0200 = 0.2195 / 0.0200 = 10.98

**输出：**
```
sharpe_ratio: 10.98
annualized_return: 0.2495
annualized_std: 0.0200
risk_free_rate: 0.03
interpretation: "优秀——该策略夏普比率远超2.0，意味着每承担1%的风险能获得约10.98%的超额收益，风险调整后表现极为出色（注意：实际中夏普比率>3通常需警惕数据过拟合或幸存者偏差）"
period_type: "daily"
```
