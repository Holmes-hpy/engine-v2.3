# 供应链-呆滞占比计算器

## name
供应链-呆滞占比计算器

## description
计算呆滞库存金额占总库存金额的比例，衡量库存中滞销、过期、周转缓慢商品的占比。呆滞占比是库存健康度的关键指标，占比过高意味着大量资金被低效占用，且面临跌价损耗风险。适用于库存健康度诊断、库存清理决策、仓储成本优化等场景。触发词：呆滞占比、呆滞库存、滞销库存、慢动库存、库存健康度、库存积压。排除词：呆滞率（有时指呆滞SKU数占比）、库存周转天数。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| obsolete_inventory_value | float | 呆滞库存金额（元） | 85000.00 |
| total_inventory_value | float | 总库存金额（元） | 1000000.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| obsolete_definition | object | 呆滞定义标准 | 默认：超过90天无出库记录（或超过保质期1/3的库存） |
| obsolete_sku_count | int | 呆滞SKU数 | 若提供，可额外计算呆滞SKU占比 |
| total_sku_count | int | 总SKU数 | 用于计算呆滞SKU占比 |
| aging_buckets | array[object] | 库龄分段数据 | 若提供，可输出库龄结构分析 |
| category_benchmark | float | 品类基准呆滞占比 | 默认：快消品5-8%，电子产品8-12%，服装10-15%，生鲜2-3% |
| write_down_estimate | float | 预估跌价准备比例 | 默认按呆滞库龄：30-60天(10%)、60-90天(20%)、90-180天(50%)、>180天(80%) |

## formula
呆滞占比 = 呆滞库存金额 / 总库存金额 × 100%

呆滞SKU占比 = 呆滞SKU数 / 总SKU数 × 100%（若提供SKU数据）

库龄加权呆滞金额 = Σ(各库龄段金额 × 呆滞权重)
- 呆滞权重：0-30天(0)、30-60天(0.1)、60-90天(0.3)、90-180天(0.7)、>180天(1.0)

预估跌价准备 = Σ(各库龄段呆滞金额 × 跌价比例)

呆滞占比等级判定：
- 优秀：呆滞占比 < 5%
- 良好：呆滞占比 5-10%
- 一般：呆滞占比 10-20%
- 较差：呆滞占比 > 20%

计算步骤：
1. 基础呆滞占比 = obsolete_inventory_value / total_inventory_value × 100%
2. 若提供SKU数据，计算呆滞SKU占比
3. 若提供库龄分段数据，计算库龄加权呆滞金额和预估跌价准备
4. 与品类基准对比，输出健康度评估
5. 根据呆滞占比等级输出处置建议

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| obsolete_ratio | float | 呆滞占比（%） |
| obsolete_sku_ratio | float | 呆滞SKU占比（%，若提供） |
| obsolete_inventory_value | float | 呆滞库存金额 |
| healthy_inventory_value | float | 健康库存金额 |
| estimated_write_down | float | 预估跌价准备（元） |
| aging_analysis | object | 库龄分析（若提供） |
| benchmark | float | 品类基准 |
| efficiency_grade | string | 健康度评级 |
| recommendation | string | 处置建议 |

## example
**输入：**
```
obsolete_inventory_value: 85000.00
total_inventory_value: 1000000.00
obsolete_sku_count: 45
total_sku_count: 500
category_benchmark: 8.00
aging_buckets: [
  {"range": "0-30天", "amount": 700000},
  {"range": "30-60天", "amount": 150000},
  {"range": "60-90天", "amount": 65000},
  {"range": "90-180天", "amount": 50000},
  {"range": ">180天", "amount": 35000}
]
```

**计算过程：**
1. 呆滞占比 = 85000 / 1000000 × 100% = 8.50%
2. 呆滞SKU占比 = 45 / 500 × 100% = 9.00%
3. 库龄加权呆滞金额 = 150000×0.1 + 65000×0.3 + 50000×0.7 + 35000×1.0 = 15000 + 19500 + 35000 + 35000 = 104500元
4. 预估跌价准备 = 150000×0.1 + 65000×0.2 + 50000×0.5 + 35000×0.8 = 15000 + 13000 + 25000 + 28000 = 81000元
5. 与基准对比：8.50% vs 8.00% → 略高于基准
