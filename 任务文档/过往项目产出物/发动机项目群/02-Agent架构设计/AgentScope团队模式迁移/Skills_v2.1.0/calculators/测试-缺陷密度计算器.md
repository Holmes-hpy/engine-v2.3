# 测试-缺陷密度计算器

## name
测试-缺陷密度计算器

## description
计算缺陷密度，即每千行代码（KLOC）中的缺陷数量，衡量代码质量的核心指标。适用场景：代码质量评估、版本质量对比、技术债务度量、团队质量绩效评估。触发词：缺陷密度、每千行缺陷、Defect Density、bug density。排除词：缺陷趋势、缺陷预测、缺陷增长率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 缺陷数 | int | 统计周期内发现的缺陷总数 | 45 |
| KLOC | float | 代码规模，以千行代码为单位 | 25.5 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 缺陷严重度加权 | boolean | 是否按严重度加权计算 | 默认false，加权时致命=10, 严重=5, 一般=2, 轻微=1 |
| 行业基准 | string | 行业缺陷密度基准 | 默认"通用软件"，可选"金融"/"医疗"/"航天"/"互联网" |
| 统计周期 | string | 缺陷统计周期 | 默认"发布后30天"，可选"测试阶段"/"发布后30天"/"发布后90天" |
| 目标密度 | float | 缺陷密度目标值 | 默认2.0个/KLOC（通用软件行业平均水平） |

## formula
缺陷密度 = 缺陷数 / KLOC

加权缺陷密度 = Σ(缺陷_i × 严重度权重_i) / KLOC

行业基准参考:
- 航天/军工: < 0.5 个/KLOC
- 医疗设备: < 0.5 个/KLOC
- 金融系统: < 1.0 个/KLOC
- 通用软件: 2.0-5.0 个/KLOC
- 互联网: 5.0-15.0 个/KLOC

质量等级判定:
- 缺陷密度 < 1.0: 优秀
- 1.0 ≤ 缺陷密度 < 2.0: 良好
- 2.0 ≤ 缺陷密度 < 5.0: 一般
- 缺陷密度 ≥ 5.0: 较差

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 缺陷密度 | float | 每千行代码缺陷数 |
| 加权缺陷密度 | float | 严重度加权后的缺陷密度（如启用加权） |
| 质量等级 | string | 优秀/良好/一般/较差 |
| 行业对标 | string | 与行业基准的对比结论 |
| 达标状态 | string | 达标/未达标 |
| 改进建议 | string | 基于缺陷密度的改进建议 |

## example
【输入】
缺陷数: 45
KLOC: 25.5
行业基准: "通用软件"
目标密度: 3.0
缺陷严重度加权: false

【输出】
缺陷密度: 1.76 个/KLOC
质量等级: 良好
行业对标: 优于通用软件行业平均水平（2.0-5.0个/KLOC）
达标状态: 达标（1.76 < 3.0）

改进建议: 当前缺陷密度1.76个/KLOC处于良好水平，但距离优秀（<1.0）仍有差距。建议重点关注代码审查覆盖率和高风险模块的单元测试补充，目标是将缺陷密度降至1.0以下。
