# 教育-位次分析器

## name
教育-位次分析器

## description
基于考生位次和目标院校历年录取位次数据，分析近三年位次变化趋势，判定考生报考的冲稳保区间，输出录取概率评估。适用场景：高考志愿填报、院校录取概率评估、位次对标分析。触发词：位次分析、高考位次、冲稳保、录取位次、排名分析。排除词：选科组合、赋分预估、录取概率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 考生位次 | int | 考生在全省/市的排名 | 15000 |
| 目标院校 | array[object] | 院校名称及近三年最低录取位次 | [{name:"某大学", rank_2023:12000, rank_2024:12800, rank_2025:13500}] |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 科类 | string | 文理科/首选科目类型 | 默认"物理类"，可选"历史类"/"物理类" |
| 省份 | string | 考生所在省份 | 默认"全国"，省份差异影响位次转换 |
| 冲稳保阈值 | object | 自定义冲稳保位次范围 | 默认：冲=位次差<0且绝对值<2000，稳=|位次差|≤2000，保=位次差>2000 |
| 招生计划变化 | float | 今年招生计划数变化率 | 默认0%，根据招生简章查询 |
| 趋势权重 | object | 三年位次的权重分配 | 默认：最新年0.5，上年0.3，前年0.2 |

## formula
加权预测位次 = rank_2025×0.5 + rank_2024×0.3 + rank_2023×0.2

位次差 = 考生位次 - 加权预测位次

冲稳保判定:
- 位次差 < -冲阈值: 冲刺（考生位次低于录取位次，有风险）
- -冲阈值 ≤ 位次差 ≤ 稳阈值: 稳妥（考生位次接近录取位次）
- 位次差 > 稳阈值: 保底（考生位次远高于录取位次）

位次趋势:
- 连续三年录取位次上升（数值变小）: 难度增加
- 连续三年录取位次下降（数值变大）: 难度降低
- 波动: 需关注最新趋势

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 考生位次 | int | 考生位次 |
| 各院校分析 | array[object] | 含加权预测位次、位次差、冲稳保判定、趋势 |
| 冲稳保分类 | object | 按冲/稳/保分类的院校列表 |
| 冲院校数量 | int | 可冲刺的院校数量 |
| 稳院校数量 | int | 稳妥的院校数量 |
| 保院校数量 | int | 保底的院校数量 |
| 填报建议 | string | 结合位次分析和趋势的填报建议 |

## example
【输入】
考生位次: 15000
科类: "物理类"
目标院校: [
  {name:"清华大学", rank_2023:500, rank_2024:480, rank_2025:520},
  {name:"浙江大学", rank_2023:8000, rank_2024:8200, rank_2025:8500},
  {name:"武汉大学", rank_2023:13000, rank_2024:13500, rank_2025:14000},
  {name:"华中科技大学", rank_2023:18000, rank_2024:18500, rank_2025:19000}
]

【输出】
考生位次: 15000

各院校分析:
1. 清华大学 — 加权预测位次: 500, 位次差: -14500, 判定: 冲刺(极激进), 趋势: 稳定
2. 浙江大学 — 加权预测位次: 8290, 位次差: -6710, 判定: 冲刺, 趋势: 难度增加
3. 武汉大学 — 加权预测位次: 13750, 位次差: -1250, 判定: 稳妥, 趋势: 难度增加
4. 华中科技大学 — 加权预测位次: 18650, 位次差: 3650, 判定: 保底, 趋势: 难度增加

冲稳保分类:
- 冲刺: 清华大学、浙江大学
- 稳妥: 武汉大学
- 保底: 华中科技大学

填报建议: 考生位次15000，武汉大学为稳妥选择（位次差仅-1250，但需注意其录取位次连续三年上升），华中科技大学为安全保底。浙江大学和清华大学位次差距过大，不建议作为冲刺目标。
