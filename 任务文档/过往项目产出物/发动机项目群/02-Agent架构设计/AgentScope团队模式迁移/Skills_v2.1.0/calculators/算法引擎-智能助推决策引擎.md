# 算法引擎-智能助推决策引擎

## name
算法引擎-智能助推决策引擎

## description
基于用户行为数据，通过智能算法分析用户当前状态（活跃度/粘性/流失风险），输出助推决策（退避/冲刺/激活），帮助运营团队精准触达用户。适用场景：用户运营策略、用户触达时机决策、用户生命周期管理、精准营销。触发词：智能助推、用户决策引擎、触达决策、退避冲刺激活。排除词：推荐算法、内容推荐、AB测试。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 用户行为数据 | object | 用户近期行为统计 | {active_days_7d:5, session_count_7d:20, avg_session_min:15, last_active_days:1, purchase_count_30d:3, push_open_rate:0.45, churn_signals:["购物车放弃","浏览下降"]} |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| 活跃度阈值 | object | 活跃度各级阈值 | 默认: 高活跃=active_days≥5, 中活跃=3-4, 低活跃=1-2, 沉默=0 |
| 粘性阈值 | object | 用户粘性各级阈值 | 默认: 高粘性=session≥20且时长≥15min, 中粘性=session10-19, 低粘性=session<10 |
| 流失风险权重 | object | 流失信号权重 | 默认: 购物车放弃=0.3, 浏览下降=0.25, 卸载意向=0.5, 差评=0.4 |
| 退避阈值 | float | 触发退避决策的推送打开率上限 | 默认0.60，即打开率>60%时减少推送避免骚扰 |
| 激活阈值 | float | 触发激活决策的推送打开率下限 | 默认0.15，即打开率<15%时需激活用户 |
| 决策模式 | string | 决策倾向 | 默认"均衡"，可选"激进"/"保守"/"均衡" |

## formula
活跃度评分 = 近7天活跃天数 / 7 × 10
粘性评分 = (session_count_7d / 20 × 5 + avg_session_min / 15 × 5)，上限10
流失风险评分 = Σ(流失信号_i × 权重_i) × 10

综合状态分 = 活跃度评分 × 0.35 + 粘性评分 × 0.35 - 流失风险评分 × 0.30

决策规则:
- 综合状态分 ≥ 7.0 且 推送打开率 > 退避阈值: 退避（用户活跃度高，减少打扰）
- 综合状态分 ≥ 5.0 且 推送打开率适中: 冲刺（用户状态良好，可适度增加触达促进转化）
- 综合状态分 < 5.0 或 推送打开率 < 激活阈值: 激活（用户状态下降，需主动触达挽回）
- 流失风险评分 > 5.0: 强制激活（高流失风险，优先触达）

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 活跃度评分 | float | 用户活跃度评分(0-10) |
| 粘性评分 | float | 用户粘性评分(0-10) |
| 流失风险评分 | float | 流失风险评分(0-10) |
| 综合状态分 | float | 综合评分 |
| 助推决策 | string | 退避/冲刺/激活 |
| 决策置信度 | float | 决策的置信度(0-1) |
| 触达建议 | string | 具体触达策略建议 |
| 风险等级 | string | 低/中/高 |

## example
【输入】
用户行为数据: {
  active_days_7d: 5,
  session_count_7d: 20,
  avg_session_min: 15,
  last_active_days: 1,
  purchase_count_30d: 3,
  push_open_rate: 0.45,
  churn_signals: ["购物车放弃", "浏览下降"]
}

【输出】
活跃度评分: 5/7 × 10 = 7.14
粘性评分: (20/20 × 5 + 15/15 × 5) = 10.0
流失风险评分: (0.30 + 0.25) × 10 = 5.50

综合状态分: 7.14 × 0.35 + 10.0 × 0.35 - 5.50 × 0.30 = 2.50 + 3.50 - 1.65 = 4.35

助推决策: 激活
决策置信度: 0.78

风险等级: 中（流失风险评分5.5，存在购物车放弃和浏览下降信号）

触达建议: 用户综合状态分4.35低于激活阈值5.0，且存在流失风险信号（购物车放弃+浏览下降），建议触发激活决策：(1)发送购物车挽回优惠券，针对放弃商品给予限时折扣；(2)推送个性化推荐内容，重新激活浏览兴趣；(3)控制推送频率在每周2-3次，避免过度骚扰。推送打开率45%处于中等水平，说明用户对推送仍有感知但需要更精准的内容匹配。
