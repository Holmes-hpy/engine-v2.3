# 电商-利润测算器

## name
电商-利润测算器

## description
计算电商商品的利润和毛利率，帮助商家评估单品盈利能力。支持多维度利润分析，包括到手价扣除平台优惠后的实际收入与产品成本之间的差额计算。适用于电商定价策略、SKU盈利分析、促销活动ROI评估等场景。触发词：电商利润、电商毛利、单品利润、到手价利润、商品毛利。排除词：财务毛利率（指企业财务报表口径的毛利率）、净利润率。

## inputs
### 必填参数
| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| final_price | float | 用户到手价（扣除平台优惠后商家实际收入，元） | 89.00 |
| product_cost | float | 产品综合成本（元），可通过产品成本核算器获得 | 65.00 |

### 可选参数
| 参数名 | 类型 | 说明 | 估值逻辑 |
|--------|------|------|----------|
| coupon_subsidy | float | 平台补贴/优惠券分摊（元） | 默认0元；若用户使用了平台优惠券，需确认商家是否需要承担部分 |
| ad_cost_per_order | float | 单均广告推广费用（元） | 默认0元；若未提供，按行业均值ROI=3反推：ad_cost=到手价/ROI |
| after_sale_cost | float | 售后维护成本（元/单） | 默认0.5元 |
| target_gross_margin | float | 目标毛利率 | 默认0.30（30%），用于对比实际毛利率与目标的差距 |

## formula
利润 = 到手价 - 产品成本

毛利率 = (到手价 - 产品成本) / 到手价 × 100%

净利润 = 到手价 - 产品成本 - 平台补贴 - 推广费用 - 售后成本

净利率 = 净利润 / 到手价 × 100%

计算步骤：
1. 确认到手价（商家实际收款金额）
2. 确认产品成本（可通过产品成本核算器获得）
3. 毛利润 = 到手价 - 产品成本
4. 毛利率 = 毛利润 / 到手价 × 100%
5. 净利润 = 毛利润 - 平台补贴 - 推广费用 - 售后成本
6. 净利率 = 净利润 / 到手价 × 100%
7. 与目标毛利率对比，输出盈利评估

## output
| 字段名 | 类型 | 说明 |
|--------|------|------|
| gross_profit | float | 毛利润（元） |
| gross_margin | float | 毛利率（%） |
| net_profit | float | 净利润（元） |
| net_margin | float | 净利率（%） |
| profit_status | string | 盈利状态（盈利/保本/亏损） |
| margin_gap | float | 与目标毛利率的差距 |
| recommendation | string | 优化建议 |

## example
**输入：**
```
final_price: 89.00
product_cost: 65.00
ad_cost_per_order: 8.50
target_gross_margin: 0.30
```

**计算过程：**
1. 到手价 = 89.00元
2. 产品成本 = 65.00元
3. 毛利润 = 89.00 - 65.00 = 24.00元
4. 毛利率 = 24.00 / 89.00 × 100% = 26.97%
5. 净利润 = 24.00 - 8.50 - 0.50 = 15.00元
6. 净利率 = 15.00 / 89.00 × 100% = 16.85%
7. 目标毛利率差距 = 30% - 26.97% = 3.03%

**输出：**
```
gross_profit: 24.00
gross_margin: 26.97
net_profit: 15.00
net_margin: 16.85
profit_status: "盈利"
margin_gap: 3.03
recommendation: "当前毛利率26.97%低于目标毛利率30%，差距3.03个百分点。建议：1）优化成本结构，重点关注占比最大的进货成本；2）若产品竞争力强，可考虑上调售价至95元以上；3）控制推广费用，优化ROI"
```
