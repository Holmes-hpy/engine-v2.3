## 按工作流模式分类

### 串行流水线模式（3个）

上游Agent输出 → 下游Agent输入，严格按阶段顺序执行，每个阶段依赖前序结果。

| 团长 | 流水线阶段 |
|------|-----------|
| 销售流程指挥官 | 商机发现 → 客户拓展 → 赢单策略 → Pipeline分析 → 投标策略 |
| 设计流程总监 | UX研究 → UX架构 → UI设计 → 品牌审查 |
| 供应链优化师 | 供应商评估 → 库存预测 → 物流优化 |

### 层级调度模式（8个）

团长先制定策略/框架，再并行创建子Agent执行任务，最后汇总整合。

| 团长 | 调度流程 |
|------|---------|
| 游戏设计总监 | 定设计方向 → 并行创建系统/关卡/叙事设计师 → 汇总GDD |
| 全平台内容营销总监 | 定总策略 → 并行创建8个平台专家 → 整合全平台方案 |
| 海外社交营销协调员 | 定矩阵策略 → 并行创建LinkedIn/Reddit/Instagram/Twitter专家 → 汇总 |
| 增长引擎协调员 | 定增长方向 → 并行创建增长黑客/SEO/行为引擎/内容专家 → 整合 |
| 电商运营总监 | 定电商策略 → 并行创建小红书/跨境/ASO专家 → 汇总 |
| 项目管理总监 | 拆解项目 → 并行创建各职能子Agent → 汇总项目计划 |
| 金融分析协调员 | 定分析框架 → 并行创建预测/投资/税务专家 → 汇总报告 |
| 空间计算技术总监 | 定技术方案 → 并行创建XR交互/界面/渲染专家 → 汇总方案 |

### 辩论模式（1个）

多视角并行辩论，各学科专家先独立分析再交叉辩论，团长主持并综合结论。

| 团长 | 辩论维度 |
|------|---------|
| 学术研究主持人 | 人类学 → 历史学 → 叙事学 → 地理学 → 心理学（三回合交叉辩论） |

## 技术规范

### 统一API接口

所有团长Agent均使用 AgentScope 2.0 团队模式三件套：

| 工具 | 用途 |
|------|------|
| `TeamCreate` | 创建团队，返回 team_id |
| `AgentCreate` | 创建子Agent，指定角色和提示词 |
| `TeamSay` | 向子Agent发送任务，回收结果 |

### 提示词结构

每个团长Agent文件包含：

1. **元数据（Front Matter）**：name、description、emoji、color、version、status
2. **身份定义**：角色、职责、专业背景
3. **团队模式API说明**：TeamCreate/AgentCreate/TeamSay 使用时机
4. **团队角色库**：每个子角色的创建时机、AgentCreate提示词
5. **工作流程**：分阶段的调度步骤，含API调用顺序
6. **输出规范**：交付物模板和格式要求
