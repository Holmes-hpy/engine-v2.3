## 一、对照方法论

### 1.1 三文档对照法

```
B类48个Skill ──→ 原子性判定 ──→ 拆分/保留/重新分类
                                    ↓
计算器注册中心(67个) ──→ 对照确认 ──→ 标记"已注册"/"待补全"
                                    ↓
概念注册表(69个概念) ──→ 公式校验 ──→ 标记"公式已定义"/"待新增"
```

### 1.2 来源标记说明

| 标记 | 含义 |
|------|------|
| ✅ 已注册 | 计算器注册中心已有完整定义 |
| ➕ 待创建 | 注册中心中标记为"待创建"，需在本次补充 |
| 🔧 从B类拆分 | 从复合Skill中拆分出的新原子计算器 |
| 🔄 重新分类 | 原B类Skill拆分后重新归类为C类/A类 |
| 📌 隐性提取 | 从上层Skill（A/C/D/E类）中识别出的隐性计算 |
