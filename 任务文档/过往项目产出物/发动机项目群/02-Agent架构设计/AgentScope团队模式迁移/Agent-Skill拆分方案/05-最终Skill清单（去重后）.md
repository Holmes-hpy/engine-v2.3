> 版本：v1.0 | 日期：2026-07-29

## 八、去重合并说明

### 8.1 主要合并策略

| 合并策略 | 涉及Skill数 | 说明 |
|---------|-----------|------|
| 平台参数化（L1） | 18→4 | 短视频脚本、社交图文、直播策划、跨平台内容日历，按平台参数化合并 |
| 领域全流程合并（L1+L2） | ~120→~40 | 按业务领域将模板/计算/框架/检查清单合并为完整领域Skill |
| 框架体系合并（L2） | 20→5 | 销售方法论、战略分析、估值方法等，按使用场景选择逻辑合并 |
| 保持独立（L3） | ~60 | 输入输出、执行逻辑、应用领域完全不同的Skill保持独立 |

### 8.2 关键去重决策

1. **MEDDPICC vs SPIN vs Gap vs Sandler vs AECR**：L3保持独立，但均归入"销售方法论工具箱"（L2互补合并），内部按场景选择
2. **抖音脚本 vs 快手脚本 vs B站脚本**：L1功能同质，合并为"短视频脚本模板"，平台作为参数
3. **DCF估值 vs 可比估值 vs 分部加总**：L2互补合并为"估值计算引擎"，内部按公司类型选择方法
4. **各平台社交内容模板**：L1功能同质，合并为"社交图文模板"，平台作为参数
5. **尽职调查清单（投资）vs 尽职调查清单（风险）**：L3名称相似但本质不同，保持独立
