# 86个专家 Agent→Skill 拆分方案

> 版本：v1.0 | 日期：2026-07-28
>
> 本文档是对全部86个可迁移专家（等级0：68个 + 等级1：18个）的逐个分析，基于《Agent与Skill分离原则》的四维判定模型，判定每个专家中哪些内容保留为Agent、哪些内容拆分为独立Skill。

---

## 一、总览

### 1.1 分析范围

| 组别 | 专家数 | 部门 |
|------|--------|------|
| 组1：营销+销售+付费媒体 | 28 | 营销部(20)、销售部(6)、付费媒体部(2) |
| 组2：专项部 | 20 | 专项部 |
| 组3：学术+产品+HR+金融+供应链+项目管理 | 20 | 学术部(5)、产品部(3)、人力资源部(1)、金融部(3)、供应链部(3)、项目管理部(5) |
| 组4：设计+游戏+工程+支持+测试+空间计算 | 18 | 设计部(5)、游戏开发部(3)、工程部(2)、支持部(3)、测试部(2)、空间计算部(3) |
| **合计** | **86** | |

### 1.2 核心结论

- **所有86个专家均可拆分**，无一例外存在可独立为Skill的结构化内容
- **预计产出约 347 个 Skill**
- 拆分后Agent聚焦于：角色身份、决策判断、沟通风格、情境化权衡
- 拆分后Skill聚焦于：结构化模板、计算方法、标准化流程、知识库、清单类交付物

### 1.3 不适合拆分特例说明

根据原则文档第4.3节，以下专家被标注为"高度内聚、强行拆分破坏能力"：

| 专家 | 原因 |
|------|------|
| 幕僚长 | 核心能力是"什么情况下做什么判断"，无法标准化，但仍有模板类内容可拆分 |
