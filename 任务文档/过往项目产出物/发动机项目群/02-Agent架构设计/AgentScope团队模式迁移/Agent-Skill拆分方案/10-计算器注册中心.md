# 计算器注册中心（calculator_registry）

> 版本：v1.0 | 日期：2026-07-30
>
> 本文档是所有原子计算器的索引。新增计算器前必须先查此处，避免重复造轮子。
> 每个计算器标注输入、输出、公式引用、依赖关系、被引用列表。
> "被引用"字段在步骤3重构上层Skill时填充。

## 歧义场景预检

以下计算器名称相似但功能不同，已在命名和description中明确区分：

| 歧义场景 | 计算器A | 计算器B | 区分方式 |
|---------|--------|--------|---------|
| ROI歧义 | 项目管理-组合ROI计算器 | 财务-ROI计算器（待创建） | 领域前缀 + description排除词 |
| 毛利率歧义 | 财务-毛利率计算器 | 电商-利润测算器（含毛利率） | 概念注册表变体区分：财务毛利率 vs 电商毛利率 |
| 估值歧义 | 财务-DCF估值器 | 财务-可比公司估值器 | 名称精确化 + 不同公式引用 |
| 覆盖率歧义 | 测试-代码覆盖率计算器 | 测试-功能覆盖率计算器 | 领域前缀 + 名称精确化 |
| 预测歧义 | 供应链-ARIMA预测器 | 供应链-指数平滑预测器 | 名称精确化 + 不同公式引用 |
| 回收率歧义 | 电商-回收率计算器（退货） | 法律-回收率计算器（计费） | 领域前缀 + 概念注册表不同领域 |
| 欺诈歧义 | 电商-退货防欺诈评分器 | 电商-欺诈指标计算器 | 名称精确化：防欺诈评分（综合） vs 欺诈指标（单项） |
