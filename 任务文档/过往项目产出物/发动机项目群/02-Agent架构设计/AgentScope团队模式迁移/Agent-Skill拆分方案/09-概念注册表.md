# 概念注册表（concept_registry）

> 版本：v1.0 | 日期：2026-07-30
>
> 本文档是所有原子计算器公式的权威来源。每个计算器的 `formula_reference` 必须指向本文档中的条目。
> 同一概念的不同领域变体，必须在此明确区分。
> 维护成本极低——定义不会频繁变化，仅在新增计算器时检查是否有冲突。

## 1. 财务通用概念

### 1.1 毛利率
```
公式：毛利率 = (收入 - 成本) / 收入
适用领域：财务通用
变体：
  - 电商毛利率 = (售价 - 进货价 - 平台扣点) / 售价   → 适用领域：电商
使用计算器：财务-毛利率计算器、电商-利润测算器
```

### 1.2 ROI（投资回报率）
```
公式：ROI = 净收益 / 投资成本
适用领域：财务通用
变体：
  - 项目ROI = (收益 - 成本) / 成本   → 适用领域：项目管理
使用计算器：财务-ROI计算器（待创建）、项目管理-组合ROI计算器
```

### 1.3 ROE（净资产收益率）
```
公式：ROE = 净利润 / 净资产
适用领域：财务通用
使用计算器：财务-ROE计算器（待创建）
```

### 1.4 有效税率（ETR）
```
公式：有效税率 = 所得税费用 / 税前利润
适用领域：财务-税务
使用计算器：财务-有效税率计算器
```

### 1.5 现金流Runway
```
公式：Runway（月） = 现金余额 / 月净烧钱率
适用领域：财务-现金流
使用计算器：财务-现金流Runway计算器
```

### 1.6 稀释比例
```
公式：稀释比例 = 新融资金额 / (投前估值 + 新融资金额)
适用领域：财务-融资
使用计算器：财务-稀释测算器
```

### 1.7 估值锚定
```
公式：建议估值区间 = ARR × 可比公司倍数 × 增长率溢价系数
适用领域：财务-融资
使用计算器：财务-估值锚定器
```

## 2. SaaS指标概念

### 2.1 MRR（月经常性收入）
```
公式：MRR = 付费客户数 × ARPU（平均月付费额）
适用领域：SaaS
使用计算器：财务-MRR计算器
```

### 2.2 ARR（年经常性收入）
```
公式：ARR = MRR × 12
适用领域：SaaS
使用计算器：财务-ARR计算器
依赖：MRR计算器输出
```

### 2.3 NDR（净收入留存率）
```
公式：NDR = (期初ARR + 扩张ARR - 收缩ARR - 流失ARR) / 期初ARR
适用领域：SaaS
使用计算器：财务-NDR计算器
```

### 2.4 LTV（客户生命周期价值）
```
公式：LTV = ARPU × 毛利率 / 月流失率
适用领域：SaaS
使用计算器：财务-LTV计算器
```

### 2.5 CAC（客户获取成本）
```
公式：CAC = 销售营销总费用 / 新获客户数
适用领域：SaaS
使用计算器：财务-CAC计算器
```

## 3. 估值概念

### 3.1 DCF估值（自由现金流折现）
```
公式：企业价值 = Σ(FCF_t / (1+r)^t) + TV / (1+r)^n
  其中：FCF_t = 第t年自由现金流
        r = 折现率（WACC）
        TV = 终值 = FCF_n × (1+g) / (r-g)
        g = 终值增长率
适用领域：财务-估值
使用计算器：财务-DCF估值器
```

### 3.2 可比公司估值
```
公式：估值区间 = 可比公司倍数中位数 × 目标公司对应财务指标
  常用倍数：EV/EBITDA、P/E、P/S、P/B
适用领域：财务-估值
使用计算器：财务-可比公司估值器
```

### 3.3 分部加总估值
```
公式：总估值 = Σ各业务分部独立估值
适用领域：财务-估值（多元化企业）
使用计算器：财务-分部加总估值器
```

## 4. 风险管理概念

### 4.1 Beta系数
```
公式：Beta = Cov(R_i, R_m) / Var(R_m)
  其中：R_i = 个股收益率序列
        R_m = 市场收益率序列
适用领域：风险
使用计算器：风险-Beta计算器
```

### 4.2 VaR（在险价值）
```
公式（参数法）：VaR = μ + σ × Z_α
  其中：μ = 平均收益率
        σ = 收益率标准差
        Z_α = 置信水平α对应的Z值
适用领域：风险
使用计算器：风险-VaR计算器
```

### 4.3 夏普比率
```
公式：夏普比率 = (R_p - R_f) / σ_p
  其中：R_p = 组合收益率
        R_f = 无风险利率
        σ_p = 组合标准差
适用领域：风险
使用计算器：风险-夏普比率计算器
```

### 4.4 最大回撤
```
公式：最大回撤 = max(1 - 当前净值 / 此前最高净值)
适用领域：风险
使用计算器：风险-最大回撤计算器
```

### 4.5 风险评估矩阵
```
公式：风险等级 = 影响程度 × 发生可能性
输出：风险热力图（高风险/中风险/低风险）
适用领域：风险-通用
使用计算器：风险-风险评估矩阵计算器
```

## 5. 电商概念

### 5.1 产品成本
```
公式：产品成本 = 进货价 + 物流成本 + 包装成本 + 平台扣点
适用领域：电商
使用计算器：电商-产品成本核算器
```

### 5.2 利润
```
公式：利润 = 到手价 - 产品成本
  变体：毛利率 = (到手价 - 产品成本) / 到手价
适用领域：电商
使用计算器：电商-利润测算器
```

### 5.3 退款金额
```
公式：退款金额 = 按支付方式 × 退款比例 × 退货商品价值
  退款比例参考：
    全额退款：商品完好未使用
    部分退款：商品部分损坏/使用
    不退：商品严重损坏/非本店商品
适用领域：电商-退货
使用计算器：电商-退款金额计算器
```

### 5.4 退货率
```
公式：退货率 = 退货订单数 / 总订单数
适用领域：电商-退货
使用计算器：电商-退货率计算器
```

### 5.5 回收率
```
公式：回收率 = 可二次销售退货金额 / 总退货金额
适用领域：电商-退货
使用计算器：电商-回收率计算器
```

### 5.6 欺诈评分
```
公式：欺诈评分 = Σ(危险信号_i × 权重_i)
  危险信号：退货频率异常、地址异常、金额异常、时间异常等
适用领域：电商-退货
使用计算器：电商-退货防欺诈评分器、电商-欺诈指标计算器
```

### 5.7 竞品价格分析
```
公式：价格带分布 = 按价格区间统计竞品数量
  定位建议：低于市场中位数/等于市场中位数/高于市场中位数
适用领域：电商-价格
使用计算器：电商-竞品价格分析器
```

## 6. 供应链概念

### 6.1 安全库存
```
公式：安全库存 = Z × σ_d × sqrt(LT)
  其中：Z = 服务水平对应的Z值（95%→1.65）
        σ_d = 需求标准差
        LT = 交货周期（天）
适用领域：供应链
使用计算器：供应链-安全库存计算器
```

### 6.2 ROP（再订货点）
```
公式：ROP = d × LT + SS
  其中：d = 日均需求量
        LT = 交货周期
        SS = 安全库存
适用领域：供应链
使用计算器：供应链-安全库存计算器（含ROP计算）
```

### 6.3 EOQ（经济订货量）
```
公式：EOQ = sqrt(2 × D × S / H)
  其中：D = 年需求量
        S = 每次订货成本
        H = 单位持有成本
适用领域：供应链
使用计算器：供应链-安全库存计算器（含EOQ计算）
```

### 6.4 周转天数
```
公式：库存周转天数 = 平均库存金额 / 日均销售成本
适用领域：供应链
使用计算器：供应链-周转天数计算器
```

### 6.5 缺货率
```
公式：缺货率 = 缺货SKU数 / 总SKU数  （或 缺货次数/总需求次数）
适用领域：供应链
使用计算器：供应链-缺货率计算器
```

### 6.6 呆滞占比
```
公式：呆滞占比 = 呆滞库存金额 / 总库存金额
  呆滞定义：超过N天未动销的库存（N按品类设定）
适用领域：供应链
使用计算器：供应链-呆滞占比计算器
```

### 6.7 供应商五维评分
```
公式：加权评分 = Σ(维度得分_i × 权重_i)
  五维度：质量(30%)、价格(25%)、交期(20%)、服务(15%)、创新(10%)
适用领域：供应链
使用计算器：供应链-供应商五维评分计算器
```

## 7. 需求预测概念

### 7.1 ARIMA预测
```
公式：ARIMA(p,d,q)模型
  p = 自回归阶数
  d = 差分阶数
  q = 移动平均阶数
适用领域：供应链-预测
使用计算器：供应链-ARIMA预测器
```

### 7.2 指数平滑预测（Holt-Winters）
```
公式：水平：L_t = α(Y_t - S_{t-s}) + (1-α)(L_{t-1} + T_{t-1})
      趋势：T_t = β(L_t - L_{t-1}) + (1-β)T_{t-1}
      季节：S_t = γ(Y_t - L_t) + (1-γ)S_{t-s}
  其中：α=水平平滑系数, β=趋势平滑系数, γ=季节平滑系数
适用领域：供应链-预测
使用计算器：供应链-指数平滑预测器
```

### 7.3 促销增量
```
公式：促销增量需求 = 基线需求 × 促销弹性系数
  促销弹性系数：按促销类型（满减/折扣/秒杀/赠品）取不同值
适用领域：供应链-预测
使用计算器：供应链-促销增量预测器
```

## 8. 物流概念

### 8.1 仓网布局对比
```
公式：对比维度 = 总成本、平均时效、覆盖范围
  单仓模式：总成本低、边缘地区时效差
  多仓模式：总成本高、全域时效好
适用领域：物流
使用计算器：物流-仓网布局优化计算器
```

### 8.2 物流方案对比
```
公式：综合评分 = 成本得分 × 40% + 时效得分 × 35% + 破损率得分 × 25%
适用领域：物流
使用计算器：物流-物流方案对比计算器
```

## 9. 工程概念

### 9.1 齿轮接触强度
```
公式：按GB/T 3480 / ISO 6336标准
  接触应力 σ_H = Z_H × Z_E × Z_ε × sqrt(F_t/(b×d_1) × (u+1)/u)
  判定：σ_H ≤ σ_HP（许用接触应力）
适用领域：机械工程
使用计算器：工程-齿轮强度计算器
```

### 9.2 齿轮弯曲强度
```
公式：按GB/T 3480 / ISO 6336标准
  弯曲应力 σ_F = F_t/(b×m_n) × Y_Fa × Y_Sa × Y_ε × Y_β
  判定：σ_F ≤ σ_FP（许用弯曲应力）
适用领域：机械工程
使用计算器：工程-齿轮强度计算器
```

### 9.3 轴弯扭合成应力
```
公式：σ_ca = sqrt(σ^2 + 3τ^2)
  或按第三强度理论：σ_eq = sqrt(σ^2 + 4τ^2)
适用领域：机械工程
使用计算器：工程-轴疲劳校核器
```

### 9.4 轴疲劳安全系数
```
公式：n = σ_{-1} / (K_σ × σ_a + ψ_σ × σ_m)
  其中：σ_{-1} = 对称循环疲劳极限
        K_σ = 应力集中系数
        σ_a = 应力幅值
        σ_m = 平均应力
适用领域：机械工程
使用计算器：工程-轴疲劳校核器
```

### 9.5 螺栓预紧力
```
公式：预紧力 F_0 = T / (K × d)
  其中：T = 拧紧力矩
        K = 扭矩系数（通常0.15-0.25）
        d = 螺栓公称直径
适用领域：机械工程
使用计算器：工程-螺栓设计计算器
```

### 9.6 拧紧力矩
```
公式：T = K × F_0 × d
适用领域：机械工程
使用计算器：工程-螺栓设计计算器
```

### 9.7 固有频率
```
公式：f_n = (1/2π) × sqrt(k/m)
  其中：k = 刚度系数
        m = 质量
适用领域：机械工程
使用计算器：工程-振动模态分析器
```

### 9.8 共振判定
```
公式：共振风险 = |f_excitation - f_natural| / f_natural
  判定：< 10% → 高风险（共振区）
        10%-30% → 中风险
        > 30% → 低风险
适用领域：机械工程
使用计算器：工程-振动模态分析器
```

## 10. 测试概念

### 10.1 代码覆盖率
```
公式：代码覆盖率 = 已覆盖行数 / 总行数
适用领域：测试
使用计算器：测试-代码覆盖率计算器
```

### 10.2 功能覆盖率
```
公式：功能覆盖率 = 已覆盖功能点数 / 总功能点数
适用领域：测试
使用计算器：测试-功能覆盖率计算器
```

### 10.3 缺陷密度
```
公式：缺陷密度 = 缺陷数 / KLOC（千行代码）
适用领域：测试
使用计算器：测试-缺陷密度计算器
```

### 10.4 失败分类
```
公式：按类别/模块/严重度维度聚合失败记录
  输出：失败分布（饼图/帕累托图）
适用领域：测试
使用计算器：测试-失败分类统计器
```

### 10.5 根因频率分析
```
公式：帕累托分析 → 80/20法则识别主要根因
  输出：根因排序（按频率降序）
适用领域：测试
使用计算器：测试-根因频率分析器
```

### 10.6 缺陷趋势预测
```
公式：线性回归：缺陷数 = a × t + b
  或指数平滑：F_{t+1} = α × Y_t + (1-α) × F_t
适用领域：测试
使用计算器：测试-缺陷趋势预测器
```

### 10.7 质量门禁评分
```
公式：评分 = Σ(指标_i × 权重_i)
  指标：测试通过率、代码覆盖率、性能SLA达标率、缺陷密度
适用领域：测试
使用计算器：测试-质量门禁评分器
```

## 11. 教育概念

### 11.1 位次分析
```
公式：位次差 = 考生位次 - 院校录取最低位次
  判定：位次差 > 0 → 冲（录取概率低）
        位次差 ≈ 0 → 稳
        位次差 < 0 → 保（录取概率高）
适用领域：教育-高考
使用计算器：教育-位次分析器
```

### 11.2 选科组合覆盖率
```
公式：覆盖率 = 可选专业数 / 总专业数
  按目标专业和成绩计算候选组合
适用领域：教育-高考
使用计算器：教育-选科组合分析器
```

### 11.3 录取概率
```
公式：录取概率 = f(位次差, 招生计划变化率)
  位次差越大（考生位次远高于院校线）→ 概率越高
  招生计划增加 → 概率上升
  招生计划减少 → 概率下降
适用领域：教育-高考
使用计算器：教育-录取概率评估器
```

## 12. 产品管理概念

### 12.1 RICE优先级
```
公式：RICE = Reach × Impact × Confidence / Effort
  其中：Reach = 影响用户数（1-10分）
        Impact = 影响程度（1-10分）
        Confidence = 信心水平（0-100%）
        Effort = 工作量（人月）
适用领域：产品管理
使用计算器：产品-RICE优先级计算器
```

### 12.2 ICE优先级
```
公式：ICE = Impact × Confidence × Ease
  其中：Impact = 影响程度（1-10分）
        Confidence = 信心水平（1-10分）
        Ease = 实施难度（1-10分，越高越容易）
适用领域：增长
使用计算器：增长-ICE优先级计算器
```

## 13. 法律概念

### 13.1 信托账户对账
```
公式：差异 = 银行余额 - 账簿余额 - 未达账项
  三方对账：银行对账单、律所账簿、信托账户明细
适用领域：法律
使用计算器：法律-信托账户对账器
```

### 13.2 诉讼时效
```
公式：时效截止日 = 起算日期 + 法定时效期间
  不同业务领域和管辖区时效不同
适用领域：法律
使用计算器：法律-诉讼时效计算器
```

### 13.3 计费实现率
```
公式：计费实现率 = 实际收费金额 / 标准费率金额
适用领域：法律-计费
使用计算器：法律-计费实现率计算器
```

### 13.4 回收率
```
公式：回收率 = 已回收金额 / 应收费金额
适用领域：法律-计费
使用计算器：法律-回收率计算器
```

### 13.5 账龄
```
公式：账龄 = 当前日期 - 开票日期
  按账龄分组：0-30天、31-60天、61-90天、>90天
适用领域：法律-计费
使用计算器：法律-账龄计算器
```

## 14. 咨询概念（法国ESN）

### 14.1 ESN利润架构
```
公式：净收入 = TJM brut - 各项扣减
  路径一（portage salarial）：净收入 = TJM × 天数 × (1-管理费%) - 社保
  路径二（micro-entreprise）：净收入 = TJM × 天数 × (1-减免%) - 税费
  路径三（SASU）：净收入 = TJM × 天数 - 工资 - 社保 - 企业税
适用领域：咨询-法国
使用计算器：咨询-ESN利润计算器
```

## 15. 数据概念

### 15.1 异常检测
```
公式：异常标记 = |实际值 - 基线值| / 基线值 > 阈值
  阈值：按指标类型设定（如达成率偏差>20%）
适用领域：数据-通用
使用计算器：数据-异常检测器
```

### 15.2 数据质量评分
```
公式：质量评分 = 100 - 扣分项
  扣分项：空值率×权重 + 重复率×权重 + 异常率×权重
适用领域：数据-通用
使用计算器：数据-数据质量评估器
```

### 15.3 趋势聚合
```
公式：按时间粒度（月/季/年）聚合数据
  月聚合：SUM(当月数据)
  季聚合：SUM(当月数据，3个月)
  年聚合：SUM(当月数据，12个月)
适用领域：数据-通用
使用计算器：数据-趋势分析器
```

### 15.4 趋势生命周期判定
```
公式：判定维度 = 增长率趋势 + 市场渗透率 + 竞争格局
  阶段：导入期 → 成长期 → 成熟期 → 衰退期
适用领域：数据-通用
使用计算器：数据-趋势生命周期判定器
```

### 15.5 信息源可信度分级
```
公式：可信度 = f(来源权威性, 数据时效性, 一致性, 可验证性)
  分级：A级（权威来源）→ B级 → C级 → D级（不可靠）
适用领域：数据-通用
使用计算器：数据-信息源可信度分级器
```

## 16. 实验统计概念

### 16.1 A/B测试显著性
```
公式：Z = (p1 - p2) / sqrt(p_pool × (1-p_pool) × (1/n1 + 1/n2))
  其中：p1, p2 = 实验组/对照组转化率
        p_pool = 合并转化率
  判定：|Z| > 1.96 → 显著（α=0.05）
适用领域：数据分析
使用计算器：数据-实验统计分析器
```

### 16.2 置信区间
```
公式：CI = p ± Z_{α/2} × sqrt(p(1-p)/n)
适用领域：数据分析
使用计算器：数据-实验统计分析器
```

## 18. 估值补充概念（新增）

### 18.1 WACC（加权平均资本成本）
```
公式：WACC = E/V × Re + D/V × Rd × (1-T)
  其中：E = 股权市值
        D = 债务市值
        V = E + D
        Re = 股权成本（CAPM：Re = Rf + β × (Rm - Rf)）
        Rd = 债务成本
        T = 企业所得税率
适用领域：财务-估值
使用计算器：财务-WACC计算器
依赖：风险-Beta计算器（用于Re计算）
```

## 19. 电商退货补充概念（新增）

### 19.1 退货原因分类
```
公式：按原因代码聚合，计算各原因占比
  分类维度：
    - 质量问题：商品破损/瑕疵/功能异常
    - 尺寸不合：尺码偏大/偏小/版型不适
    - 描述不符：颜色/材质/规格与描述不一致
    - 不想要：改变主意/重复购买/比价后退款
    - 其他：物流损坏/发错货/未收到
  输出：退货原因分布（帕累托图）
适用领域：电商-退货
使用计算器：电商-退货原因分类器
```

## 20. 供应链预测补充概念（新增）

### 20.1 需求预测方法选择
```
公式：按数据特征评分推荐预测方法
  评分维度：
    - 趋势性（有/无）：数据是否呈现持续上升/下降趋势
    - 季节性（有/无）：数据是否呈现周期性波动
    - 促销频率（高/低）：促销活动是否频繁影响需求
    - 数据量（充足/不足）：历史数据点数量
  
  推荐矩阵：
    | 趋势性 | 季节性 | 促销频率 | 推荐方法 |
    |--------|--------|---------|---------|
    | 有     | 有     | 低      | Holt-Winters指数平滑 |
    | 有     | 无     | 低      | ARIMA |
    | 有     | 有     | 高      | 促销增量预测 |
    | 无     | 无     | 低      | 简单指数平滑 |
    | 无     | 有     | 低      | 季节分解 |
    | 任意   | 任意   | 高      | 促销增量预测 |

适用领域：供应链-预测
使用计算器：供应链-需求预测方法选择器
```
