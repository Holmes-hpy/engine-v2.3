## 二、执行逻辑

### 步骤1：收益率计算

**日收益率：**
```
对于每个资产i，在时间t：
  Ri,t = ln(Pt / Pt-1)  （对数收益率）
  或
  Ri,t = (Pt - Pt-1) / Pt-1  （简单收益率）

投资组合日收益率：
  Rp,t = Σ(wi × Ri,t)
  其中 wi = 资产i在组合中的权重

年化收益率：
  R_annual = (Π(1+Rp,t))^(252/T) - 1
  其中 T = 交易日数，252 = 年交易日数
```

**收益率统计：**
```
均值 μ = Σ(Rp,t) / T
标准差 σ = √(Σ(Rp,t - μ)² / (T-1))
偏度 S = Σ(Rp,t - μ)³ / ((T-1) × σ³)
峰度 K = Σ(Rp,t - μ)⁴ / ((T-1) × σ⁴) - 3
```

### 步骤2：Beta计算

**Beta（β）：**
```
β = Cov(Rp, Rm) / Var(Rm)

其中：
  Rp = 投资组合收益率序列
  Rm = 基准（市场）收益率序列
  Cov(Rp, Rm) = Σ((Rp,t - μp) × (Rm,t - μm)) / (T-1)
  Var(Rm) = Σ(Rm,t - μm)² / (T-1)

Beta解读：
  β = 1.0：与市场同步波动
  β > 1.0：比市场波动更大（激进型）
  β < 1.0：比市场波动更小（防御型）
  β < 0：与市场反向波动（对冲型）

Alpha（α）：
  α = Rp_annual - (Rf + β × (Rm_annual - Rf))
  其中 Rf = 无风险利率

  α > 0：超额收益为正
  α < 0：超额收益为负
```

**滚动Beta（用于稳定性分析）：**
```
计算60日滚动窗口的Beta值
输出：Beta均值、标准差、最小、最大
```

### 步骤3：VaR计算（三种方法）

**方法1：历史模拟法（Historical Simulation）**
```
1. 收集过去T个交易日的投资组合日收益率
2. 将收益率从低到高排序
3. VaR = 第(1 - confidence_level) × T 个最差收益率 × 投资组合价值

示例：
  T=252天，confidence_level=95%
  位置 = (1-0.95) × 252 = 12.6 → 第13个最差收益率
  如果第13个最差日收益率为-2.3%
  VaR = 2.3% × 组合价值

优点：无需假设分布，捕捉厚尾
缺点：依赖历史数据，无法预测新极端事件
```

**方法2：参数法（Parametric/Variance-Covariance）**
```
假设收益率服从正态分布：

VaR = μ × Δt + Z × σ × √(Δt) × PortfolioValue

其中：
  μ = 日均收益率
  σ = 日收益率标准差
  Δt = 持有期（天）
  Z = 标准正态分位数
  
  95%置信水平：Z = -1.645
  99%置信水平：Z = -2.326

注意：μ通常很小，近似为0时：
  VaR ≈ Z × σ × √(Δt) × PortfolioValue

示例：
  组合价值=1,000,000，σ_daily=0.015，95%置信水平
  VaR = 1.645 × 0.015 × 1,000,000 = 24,675元
  含义：95%概率下，单日最大亏损不超过24,675元
```

**方法3：蒙特卡洛模拟（Monte Carlo）**
```
1. 估计资产的均值向量μ和协方差矩阵Σ
2. 进行Cholesky分解：Σ = L × L'
3. 生成N个独立标准正态随机向量 ε ~ N(0,I)
4. 合成相关收益率：R = μ + L × ε
5. 计算每个模拟路径的投资组合收益率
6. 重复步骤3-5 M次（默认10000次）
7. VaR = 第(1-confidence_level) × M 个最差模拟结果

优点：可处理复杂分布和非线性资产
缺点：计算量大，依赖模型假设
```

**VaR方法自动选择：**
```
if var_method == "auto":
    if 收益率偏度绝对值 > 1.0 or 峰度 > 3.0:
        method = "monte_carlo"  # 非正态分布，使用MC
    elif 历史数据长度 < 252:
        method = "parametric"  # 数据不足，使用参数法
    else:
        method = "historical"  # 默认使用历史模拟法
```

**VaR回测：**
```
Kupiec检验：
  例外次数 = 实际亏损超过VaR的天数
  期望例外比例 = 1 - confidence_level
  检验统计量 LR = -2ln((1-p)^(T-N) × p^N) + 2ln((1-N/T)^(T-N) × (N/T)^N)
  
  if LR > 3.84（χ²(1) 95%分位数）:
      VaR模型不准确，拒绝
```

### 步骤4：夏普比率

```
夏普比率 = (Rp_annual - Rf) / σp_annual

其中：
  Rp_annual = 投资组合年化收益率
  Rf = 无风险利率
  σp_annual = 投资组合年化标准差 = σ_daily × √252

夏普比率解读：
  < 0：不如无风险资产
  0-0.5：较差
  0.5-1.0：一般
  1.0-2.0：良好
  > 2.0：优秀
```

### 步骤5：最大回撤

```
最大回撤 MDD = max((Pt - Ppeak) / Ppeak)

其中 Ppeak = 回撤前最高净值

计算步骤：
  1. 计算累计净值曲线
  2. 遍历每个时间点，追踪历史最高净值
  3. 计算当前回撤 = (当前净值 - 历史最高) / 历史最高
  4. 最大回撤 = 所有回撤中的最小值（负数）

回撤持续时间：
  回撤开始 = 净值开始下降的时间点
  回撤结束 = 净值恢复到前高的时间点
  回撤持续时间 = 回撤结束 - 回撤开始

Calmar比率：
  Calmar = R_annual / |MDD|
  衡量每单位最大回撤带来的年化收益
```

### 步骤6：索提诺比率与信息比率

**索提诺比率（Sortino Ratio）：**
```
索提诺比率 = (Rp_annual - Rf) / σ_downside

其中：
  σ_downside = 下行标准差
  = √(Σ(min(Ri - Rf, 0)²) / (T-1)) × √252

与夏普比率的区别：
  索提诺只惩罚下行风险（负收益），不惩罚上行波动
  适用于：收益率分布不对称的情况
```

**信息比率（Information Ratio）：**
```
信息比率 = (Rp_annual - Rb_annual) / σ_tracking_error

其中：
  Rb_annual = 基准年化收益率
  σ_tracking_error = 跟踪误差
  = StdDev(Rp - Rb) × √252

信息比率解读：
  > 0.5：较好
  > 1.0：优秀
  衡量主动管理能力
```

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 资产价格数据缺失（部分日期无数据） | 使用前向填充（forward fill），标注缺失比例 |
| 价格数据长度不足（<60个交易日） | 提示数据不足，风险指标可能不可靠，标注"数据不足，结果仅供参考" |
| 组合权重之和不为1 | 自动归一化，标注"权重已自动归一化" |
| 基准数据缺失 | 使用组合自身均值作为基准替代，标注"基准数据缺失，Alpha/Beta/信息比率无法计算" |
| 收益率分布极端非正态（偏度>2或峰度>6） | 参数法VaR不可靠，自动切换为历史模拟法，标注"收益率非正态，参数法VaR可能低估风险" |
| 蒙特卡洛模拟收敛失败 | 增加模拟次数至50000次，如仍不收敛则降级为历史模拟法 |
| 无风险利率为0或负值 | 使用0.5%作为默认值，标注"无风险利率异常，已使用默认值0.5%" |
| 资产类别包含加密货币 | 波动率放大1.5倍，VaR计算使用t分布替代正态分布，标注"加密资产高波动性已做调整" |
