# 估值计算引擎

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `valuation_method` | string | 是 | 估值方法，三选一：`DCF` / `comparable` / `sum_of_parts` | `DCF` |
| `company_name` | string | 是 | 目标公司名称 | `XX科技有限公司` |
| `financial_data` | object | 条件必填 | 财务数据，DCF方法必填 | 见下方DCF输入结构 |
| `scenarios` | array | 否 | 多场景配置，默认启用基准/乐观/悲观三场景 | 见下方场景配置 |
| `comparable_companies` | array | 条件必填 | 可比公司列表，`comparable`方法必填 | `["公司A","公司B","公司C"]` |
| `business_segments` | array | 条件必填 | 业务分部数据，`sum_of_parts`方法必填 | 见下方分部结构 |
| `discount_rate` | object | 否 | 折现率参数，默认使用WACC模式 | `{"wacc": 0.10, "terminal_growth": 0.03}` |
| `sensitivity` | object | 否 | 敏感度分析配置 | `{"variables": ["wacc","growth"], "range_pct": 0.10}` |
| `currency` | string | 否 | 货币单位，默认CNY | `CNY` / `USD` / `HKD` |

## 二、执行逻辑

### 方法选择决策树

```
输入估值方法
├── DCF → 执行§2.1 DCF估值流程
├── comparable → 执行§2.2 可比公司分析流程
└── sum_of_parts → 执行§2.3 分部加总流程
```

### 2.1 DCF估值流程

**步骤1：预测自由现金流（FCF）**

对每一年 t（t=1至5），计算：

```
EBITDA_t = Revenue_t × EBITDA_Margin_t
EBIT_t = EBITDA_t - Depreciation_t
NOPAT_t = EBIT_t × (1 - Tax_Rate)
FCF_t = NOPAT_t + Depreciation_t - Capex_t - Change_in_WC_t
```

**示例**：假设第1年收入100亿，EBITDA利润率25%，折旧8亿，资本支出15亿，营运资本变动2亿，税率25%。

```
EBITDA_1 = 100 × 0.25 = 25亿
EBIT_1 = 25 - 8 = 17亿
NOPAT_1 = 17 × (1 - 0.25) = 12.75亿
FCF_1 = 12.75 + 8 - 15 - 2 = 3.75亿
```

**步骤2：计算终值（Terminal Value）**

```
Terminal_Value = FCF_5 × (1 + terminal_growth) / (WACC - terminal_growth)
```

**步骤3：折现求和**

```
Enterprise_Value = Σ(FCF_t / (1 + WACC)^t) + Terminal_Value / (1 + WACC)^5
Equity_Value = Enterprise_Value - Net_Debt
Target_Price = Equity_Value / Shares_Outstanding
```

**步骤4：多场景加权**

```
最终的Equity_Value = Σ(各场景Equity_Value × 场景权重)
```

### 2.2 可比公司分析流程

**步骤1：可比公司筛选**

- 行业相同或相近（SIC/GICS行业分类匹配）
- 业务模式相似（B2B/B2C、轻资产/重资产）
- 规模可比（收入规模在0.5x-2x范围内）
- 地域市场重叠（国内/海外收入占比接近）

**步骤2：倍数计算**

```
对每个可比公司计算：
- PE (市盈率) = Market_Cap / Net_Income
- EV/EBITDA = Enterprise_Value / EBITDA
- PS (市销率) = Market_Cap / Revenue
- PB (市净率) = Market_Cap / Book_Value

取中位数或加权平均（按市值加权）作为目标倍数。
```

**步骤3：应用折扣/溢价**

```
调整后倍数 = 中位数倍数 × (1 - 流动性折扣) × (1 + 控制权溢价)
```

**步骤4：计算目标估值**

```
隐含股权价值_PE = 目标公司净利润 × 调整后PE
隐含股权价值_EV_EBITDA = 目标公司EBITDA × 调整后EV/EBITDA - 净债务
隐含股权价值_PS = 目标公司收入 × 调整后PS

最终股权价值 = 各方法隐含价值取平均（或根据可信度赋权）
```

### 2.3 分部加总流程

**步骤1：各分部独立估值**

对每个业务分部，根据其指定的方法（DCF或可比）独立计算企业价值。

**步骤2：加总并扣减**

```
总企业价值 = Σ(各分部企业价值)
股权价值 = 总企业价值 - 净债务 - 集团层面费用
目标价 = 股权价值 / 总股本
```

**步骤3：交叉验证**

确保各分部估值逻辑一致，不存在重复计算或遗漏。

### 2.4 敏感度分析

对关键变量（WACC、永续增长率、收入增长率）进行±10%扰动，生成敏感度矩阵：

```
WACC / Growth  |  2.5%    |   3.0%    |   3.5%
--------------------------------------------------
  8.0%         |  XX元    |   XX元    |   XX元
  9.0%         |  XX元    |   XX元    |   XX元
 10.0%         |  XX元    |   XX元    |   XX元
```

### 异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 永续增长率 >= WACC | 终止计算，提示"永续增长率不能大于等于WACC，请调整参数" |
| FCF为负且持续恶化 | 给出警告："公司未来现金流为负，DCF估值参考性有限，建议补充可比公司或清算价值分析" |
| 可比公司少于3家 | 降低可信度标记，提示"可比公司样本不足，建议扩大筛选范围" |
| 可比公司倍数差异超过2倍标准差 | 标记异常值，使用截尾均值或中位数代替平均值 |
| 分部间存在大量内部交易 | 提示"需对内部交易做抵消处理，当前估值可能偏高/偏低" |
