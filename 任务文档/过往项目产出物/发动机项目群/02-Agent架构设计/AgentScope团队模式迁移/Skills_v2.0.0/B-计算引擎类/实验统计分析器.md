---
name: 实验统计分析器
version: 2.0.0
category: B-计算引擎类
description: >
  执行A/B测试统计分析，输入实验组和对照组数据（样本量/转化次数/均值/标准差），
  输出显著性检验（Z检验/T检验/卡方检验）、置信区间（95%/99%）、效果大小
  （Cohen's d/相对提升）、统计功效（Power），适用于产品A/B测试、营销活动效果评估、
  UI改版验证场景，支持多种实验设计（简单A/B测试/多臂老虎机/贝叶斯/因果推断）。
---

## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 | 示例 |
|--------|------|------|------|------|
| `experiment_type` | string | 实验设计类型 | 是 | `"simple_ab"` / `"multi_arm"` / `"bayesian"` / `"causal"` |
| `control_group` | object | 对照组数据 | 是 | `{"sample_size": 10000, "conversions": 500, "mean": 12.5, "std": 3.2}` |
| `treatment_groups` | array | 实验组数据列表 | 是 | `[{"name":"实验组A","sample_size":10000,"conversions":580,...}]` |
| `metric_type` | string | 指标类型 | 是 | `"conversion_rate"` / `"continuous"` / `"count"` |
| `confidence_level` | float | 置信水平 | 否 | `0.95`（默认）/ `0.99` |
| `alpha` | float | 显著性水平 | 否 | `0.05`（默认）/ `0.01` |
| `mde` | float | 最小可检测效应 | 否 | `0.02`（相对提升2%） |
| `power_target` | float | 目标统计功效 | 否 | `0.80`（默认）/ `0.90` |
| `correction_method` | string | 多重比较校正 | 否 | `"bonferroni"` / `"holm"` / `"bh"`（默认 holm） |
| `prior_parameters` | object | 贝叶斯先验参数 | 条件 | `{"alpha":1, "beta":1}`（Beta分布先验，bayesian模式必填） |
| `randomization_unit` | string | 随机化单元 | 否 | `"user"` / `"session"` / `"pageview"` |
| `stratification_vars` | array | 分层变量 | 否 | `["device_type", "country"]` |

### 对照组/实验组数据对象字段说明

| 字段 | 类型 | 说明 | 适用指标类型 |
|------|------|------|-------------|
| `sample_size` | int | 样本量 | 所有类型 |
| `conversions` | int | 转化次数 | conversion_rate |
| `mean` | float | 均值 | continuous |
| `std` | float | 标准差 | continuous |
| `count` | float | 事件计数 | count |
| `variance` | float | 方差（可选，优先于std） | continuous |

## 二、执行逻辑

### 步骤1：输入校验与预处理

1. 校验 `experiment_type` 是否为合法值，非法则抛出异常
2. 校验 `control_group` 和 `treatment_groups` 的必填字段完整性
3. 若 `metric_type` 为 `conversion_rate`，必须包含 `conversions` 和 `sample_size`
4. 若 `metric_type` 为 `continuous`，必须包含 `mean` 和 `std`（或 `variance`）
5. 若采用 `causal` 实验设计，检查是否提供了 `randomization_unit` 和协变量信息
6. 对 `treatment_groups` 中每个组，计算基础指标（转化率/均值/标准误）

### 步骤2：显著性检验

根据 `metric_type` 和数据结构自动选择检验方法：

**转化率类指标（conversion_rate）：**

```
Z检验（两组比例检验）：
  p_pooled = (conversions_c + conversions_t) / (n_c + n_t)
  SE = sqrt(p_pooled * (1 - p_pooled) * (1/n_c + 1/n_t))
  Z = (p_t - p_c) / SE
  p_value = 2 * (1 - Φ(|Z|))  // 双尾检验
```

**连续类指标（continuous）：**

```
当样本量 > 30 且方差已知：
  Z检验：
    SE = sqrt(std_c²/n_c + std_t²/n_t)
    Z = (mean_t - mean_c) / SE
    
当样本量 ≤ 30 或方差未知：
  Welch's T检验（不假设方差齐性）：
    t = (mean_t - mean_c) / sqrt(std_c²/n_c + std_t²/n_t)
    df = (std_c²/n_c + std_t²/n_t)² / ((std_c²/n_c)²/(n_c-1) + (std_t²/n_t)²/(n_t-1))
    p_value = 2 * pt(-|t|, df)  // 双尾检验
```

**计数类指标（count）：**

```
卡方检验（适用于计数数据）：
  χ² = Σ (O_i - E_i)² / E_i
  df = (rows - 1) * (cols - 1)
  p_value = 1 - pchisq(χ², df)
```

### 步骤3：多重比较校正

当 `treatment_groups` 数量 > 1 时，自动应用多重比较校正：

```
Holm校正（默认）：
  1. 将所有p值从小到大排序：p₁ ≤ p₂ ≤ ... ≤ pₘ
  2. 对第i个p值，调整后阈值 = α / (m - i + 1)
  3. 从最小的p值开始比较，第一个不显著的p值后所有p值均不显著
  4. 报告adjusted_p_value = min(p_i * (m - i + 1), 1)

Bonferroni校正（当指定correction_method="bonferroni"）：
  adjusted_p_value = min(p_value * m, 1)
```

### 步骤4：置信区间计算

**转化率差异的置信区间：**

```
CI = (p_t - p_c) ± Z_{α/2} * sqrt(p_c*(1-p_c)/n_c + p_t*(1-p_t)/n_t)
其中 Z_{0.025} = 1.96（95%置信），Z_{0.005} = 2.576（99%置信）
```

**均值差异的置信区间：**

```
CI = (mean_t - mean_c) ± t_{α/2, df} * sqrt(std_c²/n_c + std_t²/n_t)
```

### 步骤5：效果大小计算

**Cohen's d（连续指标）：**

```
pooled_std = sqrt(((n_c-1)*std_c² + (n_t-1)*std_t²) / (n_c + n_t - 2))
d = (mean_t - mean_c) / pooled_std

效果大小判定：
  |d| < 0.2  → 可忽略
  0.2 ≤ |d| < 0.5 → 小
  0.5 ≤ |d| < 0.8 → 中
  |d| ≥ 0.8 → 大
```

**相对提升（转化率指标）：**

```
relative_lift = (p_t - p_c) / p_c * 100%
absolute_lift = p_t - p_c
```

**Cohen's h（转化率指标，效应量）：**

```
h = 2 * (arcsin(sqrt(p_t)) - arcsin(sqrt(p_c)))
判定标准同Cohen's d
```

### 步骤6：统计功效（Power）计算

```
单尾检验的Power：
  Z_power = (|p_t - p_c| / SE) - Z_{1-α}
  Power = Φ(Z_power)

其中 SE = sqrt(p_c*(1-p_c)/n_c + p_t*(1-p_t)/n_t)

Power ≥ 0.80 → 功效充足
0.50 ≤ Power < 0.80 → 功效不足，建议增加样本量
Power < 0.50 → 严重不足
```

### 步骤7：样本量建议

若 `Power < power_target`，计算所需最小样本量：

```
最小样本量（每组）：
  n = (Z_{1-α/2} + Z_{power_target})² * (p_c*(1-p_c) + p_t*(1-p_t)) / (p_t - p_c)²
```

### 步骤8：多臂老虎机模式（multi_arm_bandit）

当 `experiment_type = "multi_arm_bandit"` 时，额外执行：

```
Thompson Sampling：
  对每个臂 k：
    α_k = 先验alpha + 成功次数
    β_k = 先验beta + 失败次数
    从 Beta(α_k, β_k) 中采样，选择采样值最大的臂

输出：各臂的胜出概率、最优臂推荐、遗憾值（regret）
```

### 步骤9：贝叶斯模式（bayesian）

当 `experiment_type = "bayesian"` 时：

```
后验分布：
  Beta(α_prior + conversions, β_prior + (sample_size - conversions))

P(实验组优于对照组)：
  通过蒙特卡洛模拟从两组的后验分布中采样N=10000次
  计算 P(p_t > p_c) = 实验组样本大于对照组的比例

损失阈值（Expected Loss）：
  E[Loss] = ∫ max(0, p_c - p_t) * f(p_c, p_t) dp_c dp_t
  若 E[Loss] < 0.001（阈值），可提前停止实验
```

### 步骤10：因果推断模式（causal）

当 `experiment_type = "causal"` 时：

```
1. 检查随机化有效性（平衡性检验）
2. 计算ATE（Average Treatment Effect）：
   ATE = E[Y(1) - Y(0)]
3. 若有分层变量，计算CATE（Conditional ATE）
4. 执行双重稳健估计（Doubly Robust）：
   DR = μ₁(X) - μ₀(X) + (T/e(X))*(Y - μ₁(X)) - ((1-T)/(1-e(X)))*(Y - μ₀(X))
   其中 e(X) = P(T=1|X) 为倾向得分
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 样本量不足（n < 30） | 自动切换为T检验，并在报告中标注"小样本，检验功效可能不足" |
| 转化率为0或100% | 对转化率做拉普拉斯平滑处理：p_smooth = (conversions + 1) / (sample_size + 2) |
| 方差为0（两组完全一致） | 无法计算检验统计量，返回"两组数据无差异，无需检验" |
| 实验组数量 > 10 | 建议进行多重比较校正，并提示"组数过多可能导致第一类错误膨胀" |
| 贝叶斯模式缺少先验参数 | 默认使用无信息先验 Beta(1, 1) |
| 输入数据包含异常值 | 使用IQR方法标记异常值，提示用户确认是否剔除 |
| 功效计算结果为负 | 说明当前效应量太小，所需样本量超过实际可行范围，建议终止实验或调整MDE |
