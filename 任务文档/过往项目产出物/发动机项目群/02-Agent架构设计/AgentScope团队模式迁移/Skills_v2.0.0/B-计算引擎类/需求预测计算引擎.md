description: >
  执行库存需求预测，适用于零售库存补货、电商大促备货、供应链计划场景，
  支持按商品生命周期（新品/成长期/成熟期/衰退期）和季节特性
  （常规/强季节性/节日驱动）选择预测方法。
  支持ARIMA时间序列分析、指数平滑法（Holt-Winters）、促销增量预测三种方法，
  输入历史销售数据（最低12个月），输出未来1-6个月需求量预测（含置信区间）。

## 二、执行逻辑

### 步骤1：方法选择（自动模式）

**决策树：**
```
if forecast_method == "auto":
    if len(historical_sales) < 24:
        # 数据不足24个月，使用指数平滑
        if seasonality_type == "regular":
            method = "holt_winters"  # 使用Holt-Winters加法模型
        else:
            method = "holt_winters"  # 使用Holt-Winters乘法模型
    elif 数据有明显的趋势+季节性:
        if seasonality_type == "strong_seasonal":
            method = "holt_winters"  # HW对季节性分解更好
        else:
            method = "arima"  # ARIMA对趋势建模更好
    elif product_lifecycle == "new":
        method = "holt_winters"  # 新品数据少，HW更健壮
    elif promotion_plan 存在且 promotion_plan 非空:
        method = "promotion_incremental"  # 有促销计划时使用增量法
    else:
        method = "arima"  # 默认使用ARIMA
```

**方法特性对比：**

| 方法 | 适用场景 | 最低数据量 | 趋势 | 季节性 | 促销 | 计算复杂度 |
|------|---------|-----------|------|--------|------|-----------|
| ARIMA | 成熟期、常规商品 | 24个月 | 优秀 | 需差分 | 不支持 | 高 |
| Holt-Winters | 强季节性、新品 | 12个月 | 良好 | 优秀 | 不支持 | 中 |
| 促销增量 | 有大促计划 | 6个月 | 基线 | 基线 | 专门支持 | 中 |

### 步骤2：ARIMA时间序列分析

**ARIMA(p,d,q)模型：**
```
ARIMA(p,d,q) = AR(p) + I(d) + MA(q)

1. 差分（I(d)）：
   d次差分将非平稳序列转化为平稳序列
   yt' = yt - yt-1（一阶差分）
   yt'' = yt' - yt-1'（二阶差分）
   
   差分阶数d的选择：
   - ADF检验（Augmented Dickey-Fuller）p值 < 0.05 → 序列平稳
   - 一般d=0,1,2，极少超过2

2. 自回归（AR(p)）：
   yt = c + φ1·yt-1 + φ2·yt-2 + ... + φp·yt-p + εt
   p的选择：通过PACF图（偏自相关函数）截尾点确定

3. 移动平均（MA(q)）：
   yt = μ + εt + θ1·εt-1 + θ2·εt-2 + ... + θq·εt-q
   q的选择：通过ACF图（自相关函数）截尾点确定

4. 模型选择准则：
   AIC = 2k - 2ln(L)  （Akaike信息准则）
   BIC = k·ln(n) - 2ln(L)  （贝叶斯信息准则）
   选择AIC/BIC最小的(p,d,q)组合
```

**预测输出：**
```
点预测 ŷt+h：
  ŷt+h = 根据ARIMA模型递推计算

置信区间（95%置信水平）：
  下界 = ŷt+h - 1.96 × σh
  上界 = ŷt+h + 1.96 × σh

其中 σh 为h步预测标准误：
  σh = σ × √(1 + ψ1² + ψ2² + ... + ψh-1²)
  （ψ为MA无穷表示系数）
```

### 步骤3：指数平滑法（Holt-Winters）

**Holt-Winters加法模型（适用于加法季节性）：**
```
水平（Level）：
  Lt = α × (yt - St-m) + (1-α) × (Lt-1 + Tt-1)

趋势（Trend）：
  Tt = β × (Lt - Lt-1) + (1-β) × Tt-1

季节（Seasonal）：
  St = γ × (yt - Lt) + (1-γ) × St-m

预测：
  ŷt+h = Lt + h × Tt + St+h-m

其中：
  m = 季节周期（月度数据m=12）
  α = 水平平滑系数（0-1）
  β = 趋势平滑系数（0-1）
  γ = 季节平滑系数（0-1）
```

**Holt-Winters乘法模型（适用于乘法季节性）：**
```
水平：
  Lt = α × (yt / St-m) + (1-α) × (Lt-1 + Tt-1)

趋势：
  Tt = β × (Lt - Lt-1) + (1-β) × Tt-1

季节：
  St = γ × (yt / Lt) + (1-γ) × St-m

预测：
  ŷt+h = (Lt + h × Tt) × St+h-m
```

**季节特性→模型选择：**
```
if seasonality_type == "regular":
    使用加法模型（季节性波动幅度相对稳定）
elif seasonality_type == "strong_seasonal" or "holiday_driven":
    使用乘法模型（季节性波动幅度随趋势变化）
```

**平滑系数优化：**
```
使用最小二乘法或最大似然法优化α, β, γ：
  minimize Σ(yt - ŷt)²
  约束：0 ≤ α,β,γ ≤ 1
```

**预测区间：**
```
ŷt+h 的预测区间：
  [ŷt+h - z × σh, ŷt+h + z × σh]

其中 z 为标准正态分位数：
  80%置信水平：z = 1.282
  90%置信水平：z = 1.645
  95%置信水平：z = 1.960
  99%置信水平：z = 2.576
```

### 步骤4：促销增量预测

**基线+增量模型：**
```
总需求 = 基线需求 + 促销增量

1. 基线需求计算：
   使用历史非促销期的数据，通过Holt-Winters建立基线模型
   基线预测 ŷbaseline = Holt-Winters(非促销数据)

2. 促销增量计算：
   促销增量 = 基线预测 × 促销提升系数 × 衰减因子

   促销提升系数（Lift Factor）：
   - 基于历史同类型促销的平均提升率
   - 折扣深度30% → 提升系数1.5-2.0
   - 折扣深度50% → 提升系数2.0-3.5
   - 折扣深度70% → 提升系数3.0-5.0

   衰减因子（Decay Factor）：
   - 促销前（预购蚕食）：前1-3天，衰减因子0.8-0.9
   - 促销中：衰减因子1.0
   - 促销后（透支）：后1-7天，衰减因子0.5-0.7

3. 促销叠加处理：
   if 多个促销时间重叠:
       总提升 = 1 + Σ(各促销提升系数 - 1) × 0.7
       （重叠促销效果递减，取70%叠加）
```

**大促系数参考表：**

| 大促类型 | 非大促月系数 | 预热期 | 爆发期 | 返场期 | 月环比 |
|---------|------------|--------|--------|--------|--------|
| 618 | 1.0 | 1.3-1.5 | 2.5-4.0 | 1.5-2.0 | 0.8-0.9（7月） |
| 双十一 | 1.0 | 1.5-2.0 | 3.0-5.0 | 1.5-2.0 | 0.7-0.8（12月） |
| 年货节 | 1.0 | 1.2-1.4 | 2.0-3.0 | 1.3-1.5 | 1.0 |
| 38节 | 1.0 | 1.1-1.3 | 1.5-2.5 | 1.2-1.5 | 1.0 |

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 历史数据不足12个月 | 提示数据不足，降级使用简单移动平均法，标注"数据不足，预测精度有限(±30%)" |
| 数据中存在大量缺失值 | 使用线性插值或前值填充，标注缺失比例和处理方式 |
| 数据存在异常值（如单月销量暴增） | 使用IQR法检测异常值（>Q3+1.5*IQR），标记为异常点，可选择剔除或保留 |
| 残差非白噪声 | 提示模型拟合不足，建议增加AR/MA阶数或换用其他方法 |
| MAPE > 30% | 预测精度差，建议增加数据量或引入外部变量，标注"预测精度不足，建议人工复核" |
| 促销计划数据不完整 | 仅使用已知促销数据，未知月份按无促销处理，输出中标注 |
| 商品生命周期为new（新品） | 如果历史数据<6个月，建议使用类比法（同类老品数据），标注"新品数据不足，使用类比预测" |
