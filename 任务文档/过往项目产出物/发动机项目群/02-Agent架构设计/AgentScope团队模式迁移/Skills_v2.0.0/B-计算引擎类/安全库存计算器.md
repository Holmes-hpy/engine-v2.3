category: B-计算引擎类
description: >
  计算安全库存与补货参数，适用于零售库存管理、原材料采购规划、电商仓库运营场景，
  支持按ABC分类（A类核心品/B类常规品/C类长尾品）和补货策略
  （定期补货/定量补货/按需补货）定制参数。
  输入服务水平目标（Z值）、交货周期均值和标准差、需求均值和标准差，
  输出ROP（再订货点）、EOQ（经济订货量）、安全库存量、最大库存水平。
---

| 参数名 | 类型 | 说明 | 必填 | 示例 |
|--------|------|------|------|------|

## 二、执行逻辑

### 步骤1：Z值确定

**服务水平 → Z值映射表：**

| 服务水平 | Z值 | 缺货概率 | 含义 |
|---------|-----|---------|------|
| 0.80 | 0.842 | 20% | 5次中1次缺货 |
| 0.85 | 1.036 | 15% | 约7次中1次缺货 |
| 0.90 | 1.282 | 10% | 10次中1次缺货 |
| 0.95 | 1.645 | 5% | 20次中1次缺货 |
| 0.97 | 1.881 | 3% | 约33次中1次缺货 |
| 0.98 | 2.054 | 2% | 50次中1次缺货 |
| 0.99 | 2.326 | 1% | 100次中1次缺货 |
| 0.995 | 2.576 | 0.5% | 200次中1次缺货 |
| 0.999 | 3.090 | 0.1% | 1000次中1次缺货 |

**ABC分类自动调整Z值：**
```
if abc_class == "A":
    Z_adjusted = Z(service_level)  # 保持原始Z值
elif abc_class == "B":
    Z_adjusted = Z(service_level) × 0.85  # 降低15%服务水平
elif abc_class == "C":
    Z_adjusted = Z(service_level) × 0.70  # 降低30%服务水平
```

### 步骤2：安全库存计算

**核心公式：**

```
安全库存 SS（需求与交货周期均不确定时）：
  SS = Z × √(LT_mean × σd² + d_mean² × σLT²)

其中：
  Z   = 服务水平对应的标准正态分位数
  LT_mean = 平均交货周期（天）
  σd  = 需求标准差（天）
  d_mean = 平均需求（天）
  σLT = 交货周期标准差（天）

简化情况：
  1. 仅需求不确定（σLT≈0）：
     SS = Z × σd × √(LT_mean)
  
  2. 仅交货周期不确定（σd≈0）：
     SS = Z × d_mean × σLT
  
  3. 两者均不确定（通用公式）：
     SS = Z × √(LT_mean × σd² + d_mean² × σLT²)
```

**按补货策略调整安全库存：**

```
定期补货（Periodic Review）：
  SS_periodic = Z × √((LT_mean + R) × σd² + d_mean² × σLT²)
  其中 R = review_period（盘点周期）
  
  说明：定期补货需要覆盖"盘点周期+交货周期"内的需求波动

定量补货（Continuous Review）：
  SS_continuous = Z × √(LT_mean × σd² + d_mean² × σLT²)
  
  说明：定量补货只需要覆盖"交货周期"内的需求波动

按需补货（On-Demand）：
  引入缺货成本优化：
  SS_on_demand = 使得边际持有成本 = 边际缺货成本的安全库存水平
  
  最优缺货概率 = holding_cost / (holding_cost + stockout_cost)
  例如：持有成本12元，缺货成本200元
  最优缺货概率 = 12/(12+200) = 5.66%
  对应Z值 ≈ 1.58
```

### 步骤3：EOQ经济订货量

**EOQ公式：**
```
EOQ = √(2 × D × S / H)

其中：
  D = 年需求量（annual_demand）
  S = 单次订货成本（ordering_cost）
  H = 单件年持有成本（holding_cost_per_unit）

计算示例：
  D = 36500件/年，S = 500元，H = 12元/件/年
  EOQ = √(2 × 36500 × 500 / 12) = √3041667 ≈ 1744件

约束条件：
  EOQ_actual = max(EOQ, supplier_min_order)
  if EOQ_actual > max_storage_capacity / 2:
      EOQ_actual = max_storage_capacity / 2
      标注"仓储容量限制，EOQ已调整"
```

### 步骤4：ROP再订货点

```
ROP = d_mean × LT_mean + SS

其中：
  d_mean × LT_mean = 交货周期内的预期需求
  SS = 安全库存

订货触发条件：
  if current_inventory + in_transit ≤ ROP:
      触发订货，订货量 = EOQ_actual
```

### 步骤5：最大库存水平

```
最大库存 M：
  M = SS + EOQ_actual

或（定期补货模式）：
  M = d_mean × (LT_mean + R) + SS_periodic

库存周转率：
  Inventory Turnover = annual_demand / ((SS + EOQ_actual/2))
  
  注：平均库存 ≈ SS + EOQ/2（安全库存+半个订货量）

库存天数：
  Days of Inventory = 365 / Inventory Turnover
```

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 需求标准差为0 | 使用最小安全库存（1天需求量），标注"需求稳定，无波动，使用最小安全库存" |
| 交货周期标准差为0 | 简化公式为 SS = Z × σd × √(LT_mean)，标注"交货周期稳定" |
| 年度需求为0 | 无法计算EOQ，返回错误提示"年度需求为0，请提供有效需求数据" |
| 持有成本为0 | 无法计算EOQ，提示"持有成本为0会导致无限订货量，请提供有效持有成本" |
| 计算出的EOQ < 供应商最小起订量 | 自动调整为最小起订量，标注"已按供应商最小起订量调整" |
| 最大库存超过仓储容量 | 调整EOQ或建议增加仓储容量，标注"仓储容量限制" |
| 服务水平不在0.80-0.999范围内 | 默认使用0.95，标注"服务水平已设为默认值95%" |
| 补货策略为on_demand但缺货成本为0 | 降级为continuous策略，标注"缺货成本未提供，降级为定量补货策略" |
