## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 | 示例 |
|--------|------|------|------|------|
| `platform` | string | 平台 | 是 | `"淘宝"` / `"京东"` / `"拼多多"` / `"抖音"` |
| `query_type` | string | 查询类型 | 是 | `"commission"`（扣点佣金） / `"promotion"`（促销规则） / `"advertising"`（广告投放） / `"all"`（全部） |
| `product_category` | string | 产品品类 | 条件 | `"服饰"` / `"美妆"` / `"3C数码"` / `"家居"` / `"食品"` |
| `store_type` | string | 店铺类型 | 条件 | `"旗舰店"` / `"专卖店"` / `"专营店"` / `"个人店"` / `"自营"` |
| `promotion_activity` | string | 促销活动 | 条件 | `"聚划算"` / `"百亿补贴"` / `"限时秒杀"` / `"618"` / `"双十一"` |
| `selling_price` | float | 售价（元） | 否 | `199.00` |
| `cost_price` | float | 成本价（元） | 否 | `80.00` |
| `monthly_sales_volume` | int | 月销量 | 否 | `1000` |

## 二、执行逻辑

### 步骤1：平台识别与规则加载

```
根据 platform 参数加载对应平台规则库：

淘宝 → 加载淘宝规则（天猫扣点/淘宝扣点/淘金币/淘客/聚划算/活动规则）
京东 → 加载京东规则（自营/POP/京喜/京东物流/活动规则）
拼多多 → 加载拼多多规则（百亿补贴/限时秒杀/多多进宝/活动规则）
抖音 → 加载抖音规则（精选联盟/千川/商城活动/直播间规则）
```

### 步骤2：淘宝/天猫定价规则

**一、平台扣点（佣金/技术服务费）：**

| 品类 | 天猫扣点 | 淘宝扣点 |
|------|---------|---------|
| 服饰 | 5% | 0%（个人店）/ 按类目 |
| 鞋类箱包 | 5% | 按类目 |
| 美妆/个护 | 4% | 按类目 |
| 3C数码 | 2% | 按类目 |
| 家用电器 | 2-5% | 按类目 |
| 家居用品 | 5% | 按类目 |
| 食品/保健 | 2-3% | 按类目 |
| 母婴 | 2-5% | 按类目 |
| 运动户外 | 5% | 按类目 |
| 珠宝配饰 | 5% | 按类目 |
| 图书音像 | 2% | 按类目 |

扣点计算方式：技术服务费 = 实际成交价 × 扣点比例
注意：天猫扣点按年销售额阶梯返还（年销售额达标可返还部分技术服务费）

**二、淘金币：**
- 卖家设置淘金币抵扣比例：1-10%（可自定义）
- 淘金币抵扣金额 = 售价 × 抵扣比例
- 100淘金币 = 1元
- 费用由卖家承担

**三、淘客佣金（淘宝联盟）：**

| 品类 | 通用佣金率范围 | 最低佣金率 |
|------|-------------|-----------|
| 服饰 | 5-30% | 5% |
| 美妆 | 10-40% | 5% |
| 3C | 1-5% | 1% |
| 家居 | 5-20% | 3% |
| 食品 | 10-30% | 5% |

淘客佣金 = 实际成交价 × 佣金率
技术服务费 = 淘客佣金 × 10%（淘宝收取）
实际到手 = 成交价 - 扣点 - 淘客佣金 - 淘客技术服务费

**四、聚划算规则：**
- 报名门槛：店铺DSR ≥ 4.6，商品评价 ≥ 10条
- 价格要求：聚划算价 ≤ 近30天最低成交价的9折
- 费用：基础坑位费（3-8万/场）+ 佣金扣点（3%）
- 注意：聚划算价格计入30天最低价

**五、其他活动规则：**
- 天天特卖：报名费 2-5万/场，无额外扣点
- 百亿补贴（淘宝）：需全网最低价，平台出补贴费用
- 88VIP：会员专享95折，差价由商家承担

**六、综合定价公式：**
```
淘宝/天猫零售价定价模型：
  零售价 = 成本 / (1 - 目标毛利率)
  
  实际到手价 = 零售价 × (1 - 扣点率 - 淘客佣金率 - 淘金币抵扣率)
              - 淘客技术服务费
              - 活动报名费
              - 推广费
```

### 步骤3：京东定价规则

**一、平台扣点：**

| 品类 | 京东自营 | 京东POP | 京喜 |
|------|---------|---------|------|
| 服饰 | 供货价模式(毛利25-30%) | 8% | 5% |
| 美妆 | 供货价模式(毛利25-35%) | 5-8% | 5% |
| 3C数码 | 供货价模式(毛利5-10%) | 5-8% | 3% |
| 家用电器 | 供货价模式(毛利10-15%) | 5-8% | 3% |
| 家居 | 供货价模式(毛利25-30%) | 8% | 5% |
| 食品 | 供货价模式(毛利20-25%) | 5% | 3% |
| 母婴 | 供货价模式(毛利20-25%) | 5-8% | 5% |
| 图书 | 供货价模式(毛利20%) | 5% | - |

京东自营模式说明：
- 供应商将商品卖给京东（供货价），京东负责销售和定价
- 京东要求的毛利空间 = (零售价 - 供货价) / 零售价
- 实际结算：供货价 - 返利/折扣

京东POP模式：
- 技术服务费 = 成交价 × 扣点率
- 无年费

**二、京东物流费率：**

| 服务类型 | 价格（首重1kg） | 续重（每kg） | 时效 |
|----------|---------------|-------------|------|
| 京东快递（标准） | 12-16元 | 2-5元 | 1-3天 |
| 211限时达 | 16-20元 | 3-6元 | 当日/次日 |
| 京准达 | 20-25元 | 4-8元 | 指定时段 |
| 特快送 | 18-25元 | 3-8元 | 次日 |
| 特惠送 | 8-12元 | 1-3元 | 2-4天 |
| 重货（30kg+） | 按重量阶梯 | 体积折算 | 2-4天 |

**三、京东活动规则：**
- 京东秒杀：坑位费 2-6万/场，综合扣点 3-5%
- PLUS会员价：商家设置，差价由商家承担
- 京东白条：免息手续费由商家承担（3期约1.5%，6期约3%，12期约6%）
- 618/双十一：跨店满减（每满299减50），商家承担

**四、综合定价公式：**
```
京东POP零售价定价模型：
  零售价 = 成本 / (1 - 目标毛利率)
  
  实际到手价 = 零售价 × (1 - 扣点率) - 物流成本 - 活动费用 - 推广费

京东自营供货价定价模型：
  供货价 = 零售价 × (1 - 京东要求毛利率)
  实际到手价 = 供货价 - 返利扣点 - 物流成本
```

### 步骤4：拼多多定价规则

**一、平台扣点：**

| 品类 | 扣点率 | 备注 |
|------|--------|------|
| 全品类（除特殊） | 0.6% | 支付手续费，非佣金 |
| 虚拟商品 | 1% | - |

拼多多名义上"0佣金"，仅收取0.6%支付手续费。
但实际通过其他方式收费（广告、活动报名费等）。

**二、多多进宝佣金：**

| 品类 | 通用佣金率范围 | 建议佣金率 |
|------|-------------|-----------|
| 服饰 | 10-40% | 20-30% |
| 百货 | 10-35% | 15-25% |
| 美妆 | 15-45% | 25-35% |
| 食品 | 10-30% | 15-25% |
| 3C | 1-5% | 1-3% |

多多进宝佣金 = 成交价 × 佣金率
技术服务费 = 佣金 × 10%

**三、百亿补贴规则：**
- 报名门槛：店铺评分/商品评价/价格竞争力
- 价格要求：全网最低价（需提供比价证明）
- 补贴方式：平台补贴 + 商家让利（通常各承担50%）
- 商家承担部分：通常为售价的10-15%
- 费用：无额外坑位费，但价格必须是全网最低

**四、限时秒杀/9.9特卖：**
- 限时秒杀报名费：1-3万/场
- 9.9特卖：无报名费，但价格需 ≤ 9.9元
- 价格要求：需为30天最低价

**五、综合定价公式：**
```
拼多多零售价定价模型：
  零售价 = 成本 / (1 - 目标毛利率)
  
  实际到手价 = 零售价 × (1 - 0.6%支付手续费 - 多多进宝佣金率)
              - 多多进宝技术服务费
              - 活动报名费
              - 推广费（拼多多广告费占比通常较高，10-25%）
```

### 步骤5：抖音电商定价规则

**一、平台扣点：**

| 品类 | 扣点率 |
|------|--------|
| 服饰 | 5% |
| 美妆 | 5% |
| 3C数码 | 2% |
| 家居 | 5% |
| 食品 | 2% |
| 珠宝文玩 | 5% |
| 图书 | 2% |
| 虚拟商品 | 10% |

技术服务费 = 实际成交价 × 扣点率

**二、精选联盟佣金：**

| 品类 | 建议佣金率 |
|------|-----------|
| 服饰 | 20-30% |
| 美妆 | 25-40% |
| 食品 | 20-30% |
| 家居日用 | 15-25% |
| 3C数码 | 5-10% |

精选联盟佣金 = 成交价 × 佣金率
达人实际到手 = 佣金 × (1 - 10%平台技术服务费)

**三、巨量千川投放：**

| 投放目标 | 建议出价方式 | 参考成本 |
|----------|------------|---------|
| 直播间引流 | oCPM | 0.5-2元/人次 |
| 短视频引流直播间 | oCPM | 0.3-1元/人次 |
| 商品卡推广 | oCPM | 0.2-0.5元/点击 |
| 账号涨粉 | oCPM | 1-3元/粉丝 |

千川广告费 = 实际消耗金额
ROI = 广告成交额 / 广告消耗

**四、抖音商城活动规则：**
- 超值购：需低价（类目低价TOP 30%），无额外费用
- 大促活动：618/双十一/年货节，跨店满减，商家承担
- 品牌馆：品牌旗舰店专属，需品牌资质
- 活动机制：平台满减券 + 店铺券 + 达人券三券叠加

**五、直播间成本构成：**
- 平台扣点：5%
- 达人佣金：20-30%（精选联盟）
- 千川投流：5-15%（占GMV）
- 直播间运营：主播/场控/设备（固定成本）
- 合计：约占GMV的 35-55%

**六、综合定价公式：**
```
抖音零售价定价模型：
  零售价 = 成本 / (1 - 目标毛利率)
  
  实际到手价 = 零售价 × (1 - 扣点率 - 精选联盟佣金率 - 千川投流占比)
              - 直播间运营成本分摊
              - 活动费用
```

### 步骤6：多平台比价与成本对比

```
多平台成本对比（以服饰品类、售价199元为例）：

| 成本项 | 淘宝(天猫) | 京东(POP) | 拼多多 | 抖音 |
|--------|-----------|----------|--------|------|
| 平台扣点 | 5% (9.95) | 8% (15.92) | 0.6% (1.19) | 5% (9.95) |
| 推广佣金 | 15% (29.85) | - | 20% (39.80) | 25% (49.75) |
| 物流成本 | 5元 | 8元(京东物流) | 3元 | 5元 |
| 活动费 | 3元/单 | 2元/单 | 1元/单 | 2元/单 |
| 合计成本 | 47.80 | 25.92 | 44.99 | 66.70 |
| 到手价 | 151.20 | 173.08 | 154.01 | 132.30 |

结论：京东POP到手率最高（87.0%），抖音到手率最低（66.5%），
但抖音客单价和GMV天花板最高，需综合评估。
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 品类不在预设范围 | 返回"该品类具体扣点请以平台最新规则为准，建议登录商家后台查看" |
| 活动规则已过期 | 标注"以下规则为截至知识截止日期，最新规则请以平台公告为准" |
| 查询平台组合不合法 | 提示一次只能查询一个平台，如需多平台比价请分次查询 |
| 多平台同时查询 | 自动执行多平台比价模式，输出对比表格 |
| 无法确定具体扣点（如京东自营） | 返回扣点范围，说明"京东自营为供货价模式，具体扣点需与采销沟通" |
| 促销活动拼写/命名不准确 | 模糊匹配最接近的活动，提示用户确认 |
