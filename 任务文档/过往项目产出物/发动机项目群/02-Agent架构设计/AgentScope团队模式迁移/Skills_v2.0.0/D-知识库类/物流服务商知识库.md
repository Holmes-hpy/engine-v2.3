  提供中国物流服务商信息查询，覆盖顺丰（时效/价格/服务类型/覆盖范围）、
  通达系（中通/圆通/韵达/申通的时效/价格/覆盖范围/电商件优势）、京东物流
  （211限时达/京准达/特快送/重货服务）、极兔（价格优势/下沉市场覆盖/

  和时效要求（当日达/次日达/经济件）筛选推荐。

## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 | 示例 |
|--------|------|------|------|------|
| `query_type` | string | 查询类型 | 是 | `"single"`（单家查询） / `"compare"`（多选对比） / `"recommend"`（推荐） |
| `carrier` | string | 物流商（单家查询时） | 条件 | `"顺丰"` / `"中通"` / `"圆通"` / `"韵达"` / `"申通"` / `"京东物流"` / `"极兔"` / `"邮政"` |
| `carriers` | array | 物流商列表（对比时） | 条件 | `["顺丰","中通","极兔"]` |
| `product_type` | string | 商品类型 | 否 | `"标品"` / `"生鲜"` / `"大件"` / `"危险品"` / `"文件"` |
| `timeliness` | string | 时效要求 | 否 | `"当日达"` / `"次日达"` / `"经济件"` / `"不限制"` |
| `package_weight` | float | 包裹重量（kg） | 否 | `1.5` |
| `origin` | string | 发货地 | 否 | `"杭州"` |
| `destination` | string | 目的地 | 否 | `"北京"` |
| `monthly_volume` | int | 月发货量（件） | 否 | `5000` |
| `budget_per_order` | float | 单件物流预算（元） | 否 | `5.00` |

## 二、执行逻辑

### 步骤1：查询模式识别

```
根据 query_type 确定执行模式：
  single → 步骤2：查询单家物流商详细信息
  compare → 步骤3：对比多家物流商
  recommend → 步骤4：根据商品类型和时效要求推荐
```

**电商件价格（月结）：**
- 月发货量 > 3000件：标快 3.5-5元/票（3kg以内）
- 月发货量 > 10000件：标快 3-4元/票（3kg以内）

**优势：**

**适用场景：**
- 高客单价商品（3C/奢侈品/品牌）
- 时效敏感商品（生鲜/医药/急件）
- 品牌形象要求高的商家
- 商务件/文件

### 步骤10：按商品类型推荐

```
推荐算法：
  1. 根据 product_type 筛选可服务的物流商
  2. 根据 timeliness 筛选满足时效要求的物流商
  3. 根据 budget_per_order 筛选价格合适的物流商
  4. 按综合评分排序

综合评分 = 时效分 × 0.3 + 价格分 × 0.3 + 服务分 × 0.2 + 覆盖分 × 0.2

推荐结果：

标品（服饰/百货/家居）：
  - 首选：中通（性价比最优）
  - 备选：圆通/韵达/申通
  - 高客单：顺丰标快
  - 拼多多：极兔

生鲜：
  - 首选：顺丰冷链（品质保障）
  - 备选：京东冷链
  - 常温短保：中通冷链

大件（家电/家具）：
  - 首选：京东物流（重货服务好，送货上门）
  - 备选：顺丰重货
  - 经济型：德邦/跨越（需额外查询）

危险品（含锂电池/化工品）：
  - 顺丰（有危险品运输资质）
  - 京东物流（部分品类）
  - 注意：大多数通达系不承接危险品

文件/证件：
  - 首选：EMS（法律效力/安全性）
  - 备选：顺丰特快
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 商品类型为"危险品" | 返回"危险品运输需特殊资质，建议直接联系顺丰或京东物流客服确认，本知识库仅供参考" |
| 时效要求为"当日达"但发货地与目的地距离 > 500km | 返回"当日达在跨省场景下不可行，建议调整为次日达" |
| 月发货量太低导致无法享受电商件价格 | 返回零售价，附加"当月发货量达到1000件后可享受电商件价格" |
| 查询的物流商不在预设范围 | 返回"该物流商暂未收录，建议查询顺丰/通达系/京东物流/极兔/邮政" |
| 预算过低无法匹配任何物流商 | 返回"在您设定的预算下无可匹配的物流商，建议：1) 提高预算 2) 降低时效要求 3) 考虑邮政快递包裹" |
| 偏远地区（新疆/西藏/青海/内蒙古） | 自动过滤不覆盖该区域的物流商，优先推荐邮政 |
