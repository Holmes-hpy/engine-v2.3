## 二、执行逻辑

### 步骤1：齿轮强度校核

**按选定标准执行：**

**GB/T 3480（等同ISO 6336）齿面接触强度校核：**

```
计算接触应力 σH：
  σH = ZH × ZE × Zε × Zβ × √(Ft/(b×d1) × (u+1)/u × KA × KV × KHβ × KHα)

其中：
  ZH  = 节点区域系数（取决于压力角α和螺旋角β）
  ZE  = 弹性系数（取决于材料，钢-钢：189.8 √N/mm²）
  Zε  = 重合度系数
  Zβ  = 螺旋角系数 = √(cosβ)
  Ft  = 名义切向力 = 2000×T/d1
  b   = 齿宽
  d1  = 小齿轮分度圆直径 = m×z1/cosβ
  u   = 齿数比 = z2/z1
  KA  = 使用系数（工况系数，1.0-2.5）
  KV  = 动载系数
  KHβ = 齿向载荷分布系数
  KHα = 齿间载荷分配系数

许用接触应力 σHP：
  σHP = σHlim × ZNT × ZL × ZV × ZR × ZW / SHmin

其中：
  σHlim = 试验齿轮接触疲劳极限（根据材料和热处理查表）
  ZNT   = 寿命系数
  ZL    = 润滑剂系数
  ZV    = 速度系数
  ZR    = 粗糙度系数
  ZW    = 工作硬化系数
  SHmin = 最小安全系数（一般1.0-1.3）

安全系数：
  SH = σHP / σH
  判定：SH ≥ SHmin → 通过
```

**齿根弯曲强度校核：**
```
计算弯曲应力 σF：
  σF = Ft/(b×mn) × YF × YS × Yβ × Yε × KA × KV × KFβ × KFα

其中：
  mn  = 法向模数
  YF  = 齿形系数
  YS  = 应力修正系数
  Yβ  = 螺旋角系数
  Yε  = 重合度系数

许用弯曲应力 σFP：
  σFP = σFlim × YST × YNT × YδrelT × YRrelT × YX / SFmin

安全系数：
  SF = σFP / σF
  判定：SF ≥ SFmin → 通过
```

**校核输出格式：**

| 齿轮对 | 接触应力σH | 许用σHP | SH | 弯曲应力σF | 许用σFP | SF | 判定 |
|--------|-----------|---------|-----|-----------|---------|-----|------|
| Z1-Z2 | ... | ... | ... | ... | ... | ... | ✅/❌ |

### 步骤2：轴疲劳与刚度校核

**弯扭合成强度校核（第三强度理论）：**

```
计算弯矩 M：
  M = √(Mx² + My²)  （x和y方向弯矩合成）

计算扭矩 T：
  T = 9550 × P(kW) / n(rpm)

弯扭合成应力 σca：
  σca = √(σ² + 3τ²) = √((M/W)² + 3(T/Wt)²)

其中：
  W  = 抗弯截面系数（实心圆轴：πd³/32）
  Wt = 抗扭截面系数（实心圆轴：πd³/16）

安全系数：
  S = σs / σca  （σs为材料屈服强度）
  判定：S ≥ 1.5-2.5（按工况取值）
```

**疲劳安全系数校核：**
```
弯曲疲劳安全系数 Sσ：
  Sσ = σ-1 / (Kσ×σa/(εσ×β) + ψσ×σm)

扭转疲劳安全系数 Sτ：
  Sτ = τ-1 / (Kτ×τa/(ετ×β) + ψτ×τm)

综合安全系数 S：
  S = Sσ × Sτ / √(Sσ² + Sτ²)

其中：
  σ-1, τ-1 = 材料疲劳极限
  Kσ, Kτ   = 应力集中系数
  εσ, ετ   = 尺寸系数
  β        = 表面质量系数
  ψσ, ψτ   = 平均应力折算系数
  σa, τa   = 应力幅
  σm, τm   = 平均应力

判定：S ≥ [S]（许用安全系数，一般1.5-2.5）
```

**挠度校核：**
```
最大挠度 ymax：
  （根据载荷和支撑形式计算，常用公式）
  简支梁集中载荷：ymax = PL³/(48EI)
  悬臂梁集中载荷：ymax = PL³/(3EI)

其中：
  E = 弹性模量
  I = 截面惯性矩（实心圆轴：πd⁴/64）

许用挠度 [y]：
  一般轴：[y] = (0.0003-0.0005) × L（轴承跨度）
  齿轮轴：[y] ≤ 0.01 × mn（模数）

判定：ymax ≤ [y] → 通过
```

### 步骤3：螺栓连接设计

**预紧力计算：**
```
预紧力 F0：
  按扭矩法：F0 = T / (K × d)
  其中：T = 拧紧力矩，K = 扭矩系数（0.15-0.25），d = 公称直径

  按转角法：θ = 360° × F0 × L / (E × A × P)
  其中：L = 夹紧长度，E = 弹性模量，A = 截面积，P = 螺距
```

**应力校核：**
```
螺栓拉应力 σ：
  σ = 4 × F0 / (π × d1²)
  其中 d1 = 螺纹小径

扭应力 τ：
  τ = 16 × T1 / (π × d1³)
  其中 T1 = F0 × d2 × tan(ρ+λ) / 2

等效应力 σeq（第四强度理论）：
  σeq = √(σ² + 3τ²)

安全系数：
  S = σs / σeq
  判定：S ≥ 1.5-2.0
```

**防松方案选择：**

| 防松方式 | 原理 | 适用场景 | 可靠性 | 成本 |
|---------|------|---------|--------|------|
| 弹簧垫圈 | 弹性防松 | 一般振动 | 中 | 低 |
| 双螺母 | 摩擦防松 | 重要连接 | 高 | 低 |
| 尼龙嵌件螺母 | 摩擦防松 | 一般振动 | 高 | 中 |
| 施必牢螺纹 | 机械防松 | 剧烈振动 | 很高 | 中 |
| 螺纹锁固胶 | 化学防松 | 不可拆卸 | 很高 | 低 |
| 开口销+槽型螺母 | 机械防松 | 关键安全件 | 极高 | 中 |

### 步骤4：振动模态分析

**固有频率计算（简化法）：**

```
单自由度系统固有频率：
  fn = (1/2π) × √(k/m)

其中：
  k = 刚度（N/m）
  m = 质量（kg）

多自由度系统（矩阵法）：
  [M]{ẍ} + [C]{ẋ} + [K]{x} = {F(t)}
  求解特征值：det([K] - ω²[M]) = 0
  固有频率：fn_i = ωi / (2π)
```

**共振避让准则：**
```
共振裕度 = |工作频率 - 固有频率| / 固有频率 × 100%

判定标准：
- 共振裕度 ≥ 20%：安全
- 共振裕度 10%-20%：关注，建议增加阻尼或调整刚度
- 共振裕度 < 10%：危险，必须整改

坎贝尔图（Campbell Diagram）分析：
  绘制激励频率线（fn = N × RPM/60，N为谐波阶次）
  与固有频率线交叉点即为潜在共振点
  工作转速应避开交叉点 ±10%
```

**公差链分析：**
```
封闭环公差 = √(Σ(各组成环公差² × 传递比²))
最坏情况公差 = Σ|各组成环公差 × 传递比|

判定：
  if 统计公差 ≤ 功能要求公差:
      通过
  elif 最坏情况公差 ≤ 功能要求公差:
      通过（需加强过程控制）
  else:
      不通过，需调整公差分配
```

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 齿轮参数不完整（缺少模数/齿数） | 提示必填参数缺失，列出缺失项，无法执行校核 |
| 安全系数不达标 | 给出具体调整建议：增大模数/齿宽/材料等级，并重新计算 |
| 设计标准与材料数据不匹配 | 使用最接近标准的数据替代，标注"材料数据按{standard}标准近似" |
| 轴挠度超限 | 建议增大轴径或调整轴承间距，重新计算 |
| 共振裕度不足 | 建议调整轴径/增加刚度/增加阻尼/改变转速，输出整改方案 |
| 螺栓载荷数据缺失 | 跳过螺栓校核，标注"螺栓连接数据缺失，请补充" |
| 生产批量为prototype | 安全系数降低20%，标注"样机阶段，可适当降低安全系数" |
