## 二、执行逻辑

### 步骤1：场景识别与目标拆解

1. 根据 `live_goal` 确定核心KPI：
   - rush_gmv → 核心关注：GMV、UV价值、千次成交
   - clear_inventory → 核心关注：售罄率、库存消化率
   - grow_fans → 核心关注：新增粉丝数、粉丝转化率、互动率

2. 根据 `scene_type` 确定策略基调：
   - brand_self → 强调品牌调性、信任建设、产品深度讲解
   - talent_daihuo → 强调人设匹配、信任转嫁、节奏紧凑
   - new_product_launch → 强调造势预热、稀缺感、体验感

3. 根据 `platform` 加载平台特性参数：
   - douyin：推荐feed流为核心，千川投流，福袋功能
   - kuaishou：老铁文化，私域流量，信任关系
   - tiktok：跨境物流时效，多语言，时区适配

### 步骤2：商品排品结构设计

**排品矩阵分类规则：**

| 款型 | 占比 | 毛利率范围 | 核心作用 | 排品策略 |
|------|------|-----------|----------|----------|
| 引流款 | 10%-15% | 0%-15% | 拉停留、拉互动 | 开场放，极低价，限量 |
| 福利款 | 15%-20% | 15%-30% | 促转化、冲销量 | 爆款后穿插，限时秒杀 |
| 爆款 | 25%-30% | 30%-50% | 冲GMV、核心成交 | 黄金时段循环返场 |
| 利润款 | 35%-40% | 50%+ | 保利润、拉客单 | 搭配爆款关联推荐 |

**排品节奏公式：**
- 开播前30分钟：引流款×2 → 福利款×1 → 爆款×1
- 黄金时段（开播30-120分钟）：爆款循环（每15-20分钟一个爆款，中间穿插利润款关联）
- 收尾阶段（最后30分钟）：福利款返场 → 利润款清仓 → 下期预告

**SKU分配算法：**
```
总SKU数 = ceil(live_duration / 15)  // 平均每15分钟一个品
引流款数 = ceil(总SKU数 × 0.12)
福利款数 = ceil(总SKU数 × 0.18)
爆款数 = ceil(总SKU数 × 0.28)
利润款数 = 总SKU数 - 引流款数 - 福利款数 - 爆款数
```

### 步骤3：直播流程节奏编排

**时间轴分段（以240分钟为例）：**

| 阶段 | 时间区间 | 时长 | 核心任务 | 关键动作 |
|------|---------|------|----------|----------|
| 开场 | 0-15min | 15min | 拉停留、聚人气 | 福利预告、今日剧透、引导点赞 |
| 预热 | 15-30min | 15min | 互动破冰 | 引流款上架、福袋抽奖、评论互动 |
| 爆款1 | 30-60min | 30min | 首波冲量 | 爆款A深度讲解、场景化演示、首单福利 |
| 互动 | 60-75min | 15min | 拉升互动 | 福利款秒杀、抽奖互动、评论抽奖 |
| 爆款2 | 75-105min | 30min | 持续冲量 | 爆款B讲解、用户证言、限时优惠 |
| 互动 | 105-120min | 15min | 维持热度 | 福袋开奖、利润款推荐 |
| 爆款3 | 120-150min | 30min | 冲GMV | 爆款C返场、组合优惠套装 |
| 互动 | 150-165min | 15min | 粉丝互动 | 粉丝问答、弹幕抽奖 |
| 爆款4 | 165-195min | 30min | 爆款A返场 | 限量补货、最后机会 |
| 收尾 | 195-240min | 45min | 收尾转化 | 福利款清仓、明日预告、引导关注 |

**节奏决策逻辑：**
```
if live_goal == "rush_gmv":
    爆款阶段占比提升至70%，爆款循环次数+1
elif live_goal == "clear_inventory":
    福利款和利润款占比提升，增加"组合秒杀"环节
elif live_goal == "grow_fans":
    互动环节增加，加入"关注抽奖"独立环节，每60分钟一次
```

### 步骤4：话术重点设计

**四维话术框架：**

1. **痛点话术（停留）**
   - 公式：场景描述 + 痛点放大 + 后果联想
   - 示例："姐妹们洗完脸是不是觉得紧绷绷的？那是皮肤屏障受损了，长期下去细纹就找上来了..."

2. **场景话术（种草）**
   - 公式：使用场景 + 使用体验 + 效果对比
   - 示例："早上出门前涂一层，一整天都不干，到晚上卸妆的时候皮肤还是水润的..."

3. **信任话术（决策）**
   - 公式：成分背书 + 检测报告 + 用户证言
   - 示例："这个成分是华熙生物的专利，SGS检测报告编号我放在屏幕上，大家截图去看..."

4. **逼单话术（成交）**
   - 公式：限时限量 + 价格对比 + 风险逆转
   - 示例："这个价格只有今天直播间有，库存就200单，拍完就没了！七天无理由退换，不好用直接退！"

**话术分配比例：**
- 开场20分钟：痛点话术40% + 场景话术40% + 信任话术20%
- 爆款讲解阶段：信任话术40% + 场景话术30% + 逼单话术30%
- 逼单环节：逼单话术70% + 痛点话术20% + 信任话术10%

### 步骤5：互动设计

**互动工具矩阵：**

| 工具 | 触发时机 | 频率 | 目的 | 平台支持 |
|------|---------|------|------|---------|
| 福袋 | 每30分钟 | 8次/240min | 拉停留时长 | douyin/快手 |
| 点赞抽奖 | 达到点赞目标后 | 按目标触发 | 拉升直播间热度 | 全平台 |
| 评论抽奖 | 爆款品讲解后 | 每爆款品1次 | 拉升评论互动 | 全平台 |
| 秒杀 | 福利款上架时 | 每福利款1次 | 促进快速转化 | 全平台 |
| 关注抽奖 | 每60分钟 | 4次/240min | 涨粉 | 全平台 |

**互动节奏设计：**
```
开播0分钟：福袋1（口令"来了来了"）
开播15分钟：点赞目标5万，解锁福利
开播30分钟：秒杀福利款
开播45分钟：评论抽奖（爆款A相关）
开播60分钟：关注抽奖 + 福袋2
...（循环）
```

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| SKU数量不足（<5个） | 提示用户最少需要5个SKU，建议补充产品线或合并款型 |
| 时长<60分钟 | 提示不具备完整直播节奏，建议缩短为"快闪直播"模式，简化排品结构 |
| 目标GMV与SKU库存不匹配 | 计算最大GMV = 平均售价 × 库存总量，若目标GMV > 最大GMV × 0.8，提示需增加库存或调整目标 |
| 不支持的平台参数 | 降级为通用平台模板，标注"平台特性待补充" |
| 缺少历史数据 | 使用行业平均数据作为默认值，在输出中标注"基于行业均值估算" |
| 投流预算为0 | 纯自然流量模式，调整GMV预期为自然流量预估，场观预估取平台平均自然推荐量 |
