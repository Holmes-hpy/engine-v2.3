# 供应商评估模板

## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 |
|--------|------|------|------|
| industry | string | 行业类型，可选值：manufacturing（制造）、retail（零售）、tech（科技） | 是 |
| evaluation_purpose | string | 评估目的，可选值：sourcing（采购寻源）、annual_review（年度评审）、optimization（供应链优化） | 是 |
| weight_config | object | 五维权重配置，格式：{quality:40, price:25, delivery:15, service:10, innovation:10}，总和必须为100 | 否 |
| evaluation_mode | string | 评估模式，可选值：quick（快速评估，仅评分卡）、full（完整评估，含验厂报告+分级管理），默认quick | 否 |
| supplier_count | number | 待评估供应商数量，用于批量评估场景 | 否 |
| existing_suppliers | string | 现有供应商信息（JSON格式），用于年度评审场景 | 否 |
| risk_focus | string[] | 重点关注的风险维度，可选值：quality_risk, supply_risk, compliance_risk, financial_risk, geopolitical_risk | 否 |

## 二、执行逻辑

### 步骤1：确定评估行业和评估目的

根据 `industry` 和 `evaluation_purpose` 参数，确定评估侧重点和默认权重：

#### 行业默认权重配置

| 行业 | 质量权重 | 价格权重 | 交期权重 | 服务权重 | 创新权重 | 理由 |
|------|----------|----------|----------|----------|----------|------|
| 制造 | 40% | 25% | 15% | 10% | 10% | 质量是制造业生命线，交期影响生产连续性 |
| 零售 | 25% | 30% | 20% | 15% | 10% | 价格敏感度高，交期影响库存周转 |
| 科技 | 30% | 20% | 15% | 15% | 20% | 创新权重显著高于其他行业，技术迭代快 |

#### 评估目的侧重点

| 评估目的 | 侧重维度 | 特殊要求 |
|----------|----------|----------|
| 采购寻源（sourcing） | 质量+价格 | 重点关注准入检查清单，评分卡用于横向对比 |
| 年度评审（annual_review） | 交期+服务 | 基于历史数据评分，关注升降级规则触发 |
| 供应链优化（optimization） | 创新+服务 | 关注供应商分级管理，识别战略合作机会 |

### 步骤2：配置五维评分权重并生成评分卡

#### 2.1 五维评分卡结构

每个维度包含子指标，子指标可独立评分，按权重汇总。

**质量维度（Quality）子指标**：

| 子指标 | 权重 | 评分标准(1-5分) | 数据来源 |

| 退货率/客诉率 | 25% | 5分:≤0.5%, 4分:≤1%, 3分:≤2%, 2分:≤5%, 1分:>5% | 退货/客诉记录 |
| 质量管理体系 | 20% | 5分:ISO9001+行业认证, 4分:ISO9001, 3分:有体系未认证, 2分:有基本流程, 1分:无体系 | 认证文件审核 |

```
【评分汇总】
| 维度 | 权重 | 维度得分 | 加权得分 | 评级 |
|------|------|----------|----------|------|
| 质量 Quality | XX% | X.XX | X.XX | S/A/B/C/D |

| 交期 Delivery | XX% | X.XX | X.XX | S/A/B/C/D |

| 创新 Innovation | XX% | X.XX | X.XX | S/A/B/C/D |
|----------------|------|------|--------|------|
| 总加权得分 | 100% |  -   | X.XX | S/A/B/C/D |

【维度得分计算说明】
维度得分 = Σ(子指标得分 × 子指标权重)
加权得分 = 维度得分 × 维度权重
总加权得分 = Σ(所有维度加权得分)

【评分等级】
  S级（≥4.5）：战略合作供应商
  A级（≥4.0）：优选供应商
  B级（≥3.0）：合格供应商
  C级（≥2.0）：观察供应商
  D级（<2.0）：淘汰供应商
================================================================================
```

### 步骤4：生成分级管理规则

#### 4.1 S/A/B/C/D五级分级标准

```
| 等级 | 名称 | 得分范围 | 定义 | 采购策略 | 管理频率 |
|------|------|----------|------|----------|----------|
| S | 战略合作 | ≥4.5 | 在各维度均表现卓越，具有长期战略价值 | 优先分配订单，年度框架协议 | 每季度review |
| A | 优选 | 4.0-4.4 | 综合表现优秀，可稳定合作 | 稳定订单，年度合同 | 每半年review |
| B | 合格 | 3.0-3.9 | 基本满足要求，存在改进空间 | 正常采购，滚动订单 | 每半年review |
| C | 观察 | 2.0-2.9 | 存在明显短板，需限期整改 | 控制订单量，缩短账期 | 每季度review |
| D | 淘汰 | <2.0 | 不满足基本要求，风险高 | 停止新订单，启动退出 | 每月review |
```

#### 4.2 升降级规则

```
升级规则：
  C→B: 连续2次评估≥3.0分，且质量维度≥3.0
  B→A: 连续2次评估≥4.0分，且无重大质量事故
  A→S: 连续3次评估≥4.5分，且有成功创新合作案例

降级规则：
  S→A: 单次评估<4.5分，或发生重大质量事故
  A→B: 连续2次评估<4.0分，或年度内有2次以上交期违约
  B→C: 单次评估<3.0分，或发生重大质量事故
  C→D: 连续2次评估<2.0分，或整改期限内未完成整改

一票降级规则（触发后直接降至D级）：
  - 发生重大质量事故导致客户投诉/退货
  - 发生诚信问题（偷工减料、伪造资质）
  - 发生严重合规问题（环保、劳工、安全）
  - 财务状况恶化导致供货风险
  - 发生重大安全事故
```

#### 4.3 分级管理策略

```
S级供应商管理策略：
  - 建立联合创新实验室/项目
  - 共享3-5年战略规划
  - 优先付款，最佳付款条件
  - 年度战略合作峰会邀请
  - 联合品牌/市场活动

A级供应商管理策略：
  - 年度框架合同
  - 定期技术交流
  - 参与新产品开发早期阶段
  - 提供需求预测，帮助产能规划

B级供应商管理策略：
  - 明确改进要求，设定改进时间表
  - 提供培训/技术支持帮助提升
  - 保持竞争压力，维持备选供应商

C级供应商管理策略：
  - 发送整改通知书，明确整改期限
  - 减少订单分配比例
  - 启动备选供应商开发
  - 缩短付款周期，控制风险

D级供应商管理策略：
  - 停止新订单
  - 制定退出计划，确保过渡期供应
  - 启动新供应商寻源
  - 法律/合规风险评估
```
