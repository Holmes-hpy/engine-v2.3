# 短视频脚本模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `topic` | string | 是 | 视频主题/标题 | `5分钟搞懂DCF估值模型` |
| `platform` | string | 是 | 发布平台，`douyin` / `kuaishou` / `bilibili` / `xiaohongshu` / `tiktok` / `youtube` | `bilibili` |
| `style` | string | 是 | 内容风格，`entertainment` / `knowledge` / `commerce` / `lifestyle` | `knowledge` |
| `duration` | number | 否 | 目标时长（秒），未填则按平台默认值 | `300` |
| `target_audience` | string | 否 | 目标受众画像 | `25-35岁金融从业者` |
| `tone` | string | 否 | 语气风格，`professional` / `casual` / `humorous` / `emotional` | `professional` |
| `key_points` | array | 否 | 必须覆盖的核心要点 | `["DCF定义","计算步骤","常见误区"]` |
| `cta` | string | 否 | 行动号召（Call to Action） | `关注获取更多金融知识` |
| `creator_name` | string | 否 | 创作者名称（用于口播脚本署名） | `XX财经` |

### 平台参数对照表

| 平台 | 代码 | 默认时长 | 视频比例 | 核心特征 | 内容偏好 |
|------|------|----------|----------|----------|----------|
| 抖音 | `douyin` | 15-60秒 | 9:16 | 快节奏、强钩子、重音乐 | 娱乐化、挑战赛、话题性 |
| 快手 | `kuaishou` | 15-60秒 | 9:16 | 接地气、真实感、老铁文化 | 生活化、才艺、社交属性 |
| B站 | `bilibili` | 3-10分钟 | 16:9 | 中长视频、弹幕互动、深度内容 | 知识科普、二次元、教程 |
| 小红书 | `xiaohongshu` | 30-90秒 | 3:4 | 精致图文+短视频、种草 | 美妆、穿搭、生活方式 |
| TikTok | `tiktok` | 15-60秒 | 9:16 | 国际化、创意、潮流 | 舞蹈、挑战、搞笑 |
| YouTube | `youtube` | 5-10分钟 | 16:9 | 长视频、章节标记、SEO | 教程、评测、Vlog |

## 二、执行逻辑

### 整体流程

```
输入 (topic, platform, style, ...)
├── 步骤1：平台适配（确定时长、比例、结构模板）
├── 步骤2：生成黄金3秒钩子（Hook）
├── 步骤3：分段内容撰写（每段含画面/旁白/字幕/特效）
├── 步骤4：添加平台特定元素
├── 步骤5：CTA结尾设计
└── 步骤6：输出完整分镜脚本
```

### 步骤1：平台适配

根据 `platform` 参数选择对应的结构模板。

**抖音/快手/TikTok 模板（短视频，15-60秒）：**

```
| 时间 | 段落 | 功能 |
|------|------|------|
| 0-3秒 | 钩子 | 吸引注意力，制造悬念或冲突 |
| 3-15秒 | 展开 | 快速展开核心信息，节奏密集 |
| 15-30秒 | 高潮 | 信息密度最高点，反转/金句 |
| 30-45秒 | 收尾 | 总结+CTA，引导互动 |
| 45-60秒 | 可选补充 | 花絮/彩蛋/互动引导 |
```

**B站/YouTube 模板（中长视频，3-10分钟）：**

```
| 时间 | 段落 | 功能 |
|------|------|------|
| 0-15秒 | 片头钩子 | 问题/悬念/预告 |
| 15-30秒 | 自我介绍 | 频道定位+本期预告 |
| 0:30-1:30 | 背景铺垫 | 建立上下文，为什么这个话题重要 |
| 1:30-6:00 | 主体内容 | 分段讲解，每段3-5分钟 |
| 6:00-8:00 | 总结 | 知识回顾+金句 |
| 8:00-10:00 | 结尾 | CTA（三连/关注/评论）+下期预告 |
```

**小红书模板（短视频，30-90秒）：**

```
| 时间 | 段落 | 功能 |
|------|------|------|
| 0-3秒 | 封面标题 | 强视觉冲击+文字标题 |
| 3-10秒 | 痛点引入 | 共鸣感，激发观看欲望 |
| 10-60秒 | 干货分享 | 步骤化、清单化呈现 |
| 60-90秒 | 总结+CTA | 收藏/点赞引导 |
```

### 步骤2：生成黄金3秒钩子

根据 `style` 和 `topic` 生成不同策略的钩子。

**钩子策略库：**

| 策略 | 适用场景 | 示例 |
|------|----------|------|
| 数字冲击 | 知识/数据类 | "99%的人都不知道，DCF估值其实只要三步" |
| 反常识 | 知识/娱乐 | "你每天用的这个功能，其实正在偷走你的隐私" |
| 痛点共鸣 | 生活/带货 | "为什么你天天加班，升职的却是那个准点下班的同事？" |
| 悬念制造 | 娱乐/知识 | "这个估值方法，让巴菲特赚了5000亿" |
| 直接提问 | 知识/教程 | "招股书里的估值模型，你真的看懂了吗？" |
| 场景代入 | 生活/带货 | "想象一下，如果你能用3分钟算出任何一家公司的真实价值" |

### 步骤3：分段内容撰写

每段内容包含四个要素：

```
段落结构 = {
  "画面描述": "镜头画面内容描述，含景别/构图/动作",
  "旁白/口播": "完整口播文字稿",
  "字幕": "关键字幕文案（加粗/高亮标记）",
  "特效/转场": "特效类型、转场方式、音效"
}
```

**景别说明：**
- 远景（WS）：展示环境氛围
- 中景（MS）：人物腰部以上，适合口播
- 近景（CU）：人物胸部以上，强调表情
- 特写（ECU）：细节展示，如产品、数据

### 步骤4：平台特定元素

| 平台 | 特定元素 | 实现方式 |
|------|----------|----------|
| 抖音 | 挑战话题 | 脚本末尾添加 `#话题标签`，配合热门BGM |
| 快手 | 老铁互动 | 口播中加入"老铁们觉得呢？双击666" |
| B站 | 弹幕互动点 | 脚本中标注 `[弹幕互动点]` 位置，设计引发弹幕的梗 |
| 小红书 | 封面图 | 单独设计封面文案和视觉风格 |
| TikTok | Hashtag | 添加热门英文Hashtag，配合trending sound |
| YouTube | 章节标记 | 按时间戳输出章节标题，用于视频描述区 |

### 步骤5：CTA结尾设计

```
根据style选择CTA策略：
- knowledge: "关注我，下期带你拆解XX模型"
- entertainment: "点赞过万，下期继续整活"
- commerce: "链接在评论区，手慢无"
- lifestyle: "关注收藏，下次照着做"
```

### 步骤6：输出完整分镜脚本

将以上所有内容整合为完整分镜表。

## 三、输出格式

### 标准输出结构

```markdown
# 短视频脚本 — {topic}

## 基本信息
- **平台**：{platform_name}
- **风格**：{style_name}
- **目标时长**：{duration}秒
- **视频比例**：{aspect_ratio}
- **目标受众**：{target_audience}
- **创作者**：{creator_name}

## 脚本总览

| 段落 | 时间 | 时长 | 功能 |
|------|------|------|------|
| 钩子 | 0:00-0:03 | 3秒 | {hook_strategy} |
| 引入 | 0:03-0:15 | 12秒 | 背景铺垫 |
| 主体1 | 0:15-1:00 | 45秒 | {key_point_1} |
| 主体2 | 1:00-2:00 | 60秒 | {key_point_2} |
| 主体3 | 2:00-2:45 | 45秒 | {key_point_3} |
| 总结 | 2:45-3:15 | 30秒 | 知识回顾 |
| CTA | 3:15-3:30 | 15秒 | 行动号召 |

## 分镜脚本

### 段落1：钩子（0:00-0:03）

| 项目 | 内容 |
|------|------|
| **画面描述** | 近景拍摄，主播直视镜头，背景虚化，画面左侧出现动态文字。 |

| **字幕** | **{加粗关键字幕}** |

### 段落2：引入（0:03-0:15）

| 项目 | 内容 |
|------|------|
| **画面描述** | {画面描述} |
| **旁白/口播** | {旁白文字} |

### 段落3：主体内容1（0:15-1:00）

| 项目 | 内容 |
|------|------|
| **画面描述** | {画面描述——建议使用中景+图表/数据可视化画面切换} |

| **字幕** | {字幕内容} |
| **特效/转场** | {特效描述} |

...(后续段落按同样格式展开)...

| 项目 | 内容 |
|------|------|

| **旁白/口播** | {CTA文案} |
| **字幕** | 关注+点赞+转发 |
| **特效/转场** | 淡出效果 |

## 平台特定元素

### B站弹幕互动点（若平台为B站）
| 时间点 | 弹幕互动设计 | 预期弹幕 |
|--------|-------------|----------|

### 抖音话题标签（若平台为抖音）
```

```

### YouTube章节标记（若平台为YouTube）
```
00:00 引言：为什么你需要懂估值

```
## BGM建议
- **主BGM**：{BGM名称/风格}
- **高潮部分BGM**：{BGM名称/风格}
- **音量节奏**：口播时降低至30%，过渡段恢复100%

## 制作备注
- 本脚本按{platform}平台{aspect_ratio}比例设计
- 口播语速建议：{words_per_minute}字/分钟
- 实际录制时长约{estimated_recording_time}分钟
- 建议后期剪辑软件：{editing_software}
```

### 异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 时长超过平台限制 | 给出"本脚本时长{actual_duration}秒，超出{platform}推荐时长上限{max_duration}秒，建议拆分为系列视频" |
| 关键点过多导致节奏过密 | 提示"建议每30秒聚焦1个核心要点，当前{key_points_count}个要点建议至少{min_duration}秒" |
| 风格与平台不匹配 | 给出提示"{style}风格在{platform}平台表现一般，建议调整为{recommended_style}" |
| 平台不支持 | 返回错误："不支持平台{platform}，当前支持：douyin/kuaishou/bilibili/xiaohongshu/tiktok/youtube" |
| 主题过于宽泛 | 提示"建议将主题聚焦到1-2个核心概念，当前主题'{topic}'覆盖范围较宽，可拆分为N个视频" |
