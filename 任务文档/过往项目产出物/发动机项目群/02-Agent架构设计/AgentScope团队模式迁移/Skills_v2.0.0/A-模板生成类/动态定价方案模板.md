## 二、执行逻辑

### 步骤1：全链路成本核算

**成本公式：**

```
单件全链路成本 = 采购成本 + 物流成本 + 平台扣点 + 推广分摊 + 退货损耗 + 包装成本 + 人工分摊

1. 采购成本 = purchase_cost（直接输入）

2. 物流成本 = weight_kg × logistics_cost_per_kg + packaging_cost_per_order

3. 平台扣点 = 预估到手价 × platform_rate
   注：到手价在步骤3确定，此处先用当前价格迭代计算

4. 推广分摊 = promotion_budget / Σ(各SKU预期销量)
   预期销量 = avg_daily_sales × 大促系数（618: 3-5x, 双11: 5-8x, 年货节: 2-3x, 38: 1.5-2x）

5. 退货损耗 = (采购成本 + 物流成本) × return_rate × 0.5
   （假设退货商品50%残值可二次销售）

6. 包装成本 = packaging_cost_per_order

7. 人工分摊 = labor_cost_per_order
```

|-----|---------|------|---------|---------|---------|------|------|-----------|
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

### 步骤2：竞品价格带分析

**价格带分布分析：**

1. 收集竞品当前价格，按价格区间分组：
   ```
   价格带 = [最低价, P25, P50, P75, 最高价]
   ```

2. 定位建议：
   ```
   if 品牌定位 == "高端":
       建议定价区间 = [P75, P75 × 1.2]
   elif 品牌定位 == "中端":
       建议定价区间 = [P25, P75]
   elif 品牌定位 == "性价比":
       建议定价区间 = [最低价, P50]
   ```

3. 价格弹性估计：
   ```
   价格弹性 = 竞品价格变化率 / 竞品销量变化率
   （若缺少竞品数据，按品类默认值：标品1.2-1.8，非标品0.6-1.0）
   
   预计销量变化 = (新价格 - 当前价格) / 当前价格 × 价格弹性 × 当前销量
   ```

**竞品价格带可视化（文字描述）：**
```
竞品价格带分布：
├── [min_price - P25]：{count}个竞品，代表低价区
├── [P25 - P50]：{count}个竞品，代表中低价区
├── [P50 - P75]：{count}个竞品，代表中高价区  ← 建议定位
└── [P75 - max_price]：{count}个竞品，代表高价区
```

### 步骤3：大促定价方案

**阶梯定价逻辑：**

大促阶段划分及折扣策略：

| 阶段 | 折扣力度 | 核心目的 | 适用SKU |
|------|---------|---------|---------|
| 预售期 | 日常价×0.85-0.90 | 锁定需求、测款 | 爆款+利润款 |
| 预热期 | 日常价×0.90-0.95 | 蓄水、加购 | 全店SKU |
| 爆发期 | 日常价×0.75-0.85 | 冲GMV | 爆款+引流款 |
| 返场期 | 日常价×0.85-0.90 | 尾货清仓 | 库存剩余SKU |

**定价决策算法：**
```
for each SKU:
    全链路成本 = 步骤1计算结果
    建议到手价范围 = 竞品价格带[P25, P75]
    
    for each 大促阶段:
        阶段折扣 = promotion_timeline[phase].discount_floor
        建议到手价 = current_price × 阶段折扣
        到手价毛利率 = (建议到手价 - 全链路成本) / 建议到手价 × 100%
        
        if 到手价毛利率 < target_margin:
            建议到手价 = 全链路成本 / (1 - target_margin/100)
            标注"毛利率保护，价格上调"
        
        if 建议到手价 > 建议到手价范围上限:
            标注"高于竞品价格带，可能影响转化"
        
        if 建议到手价 < 全链路成本:
            标注"⚠️ 亏损预警：到手价低于成本"
            # 触发亏损保护：建议不做该折扣或者调整促销策略
    
    到手价 = 平台券后价 + 店铺券后价
    标价 = 到手价 / (1 - 综合折扣率)
```

**组合优惠策略：**
- 跨店满减：满300-50，每满200-30
- 店铺券：满200-20，满500-60
- 前N件特价：前100件5折
- 买赠策略：买2件送小样/赠品

### 步骤4：利润测算

**利润计算：**
```
单件毛利率 = (到手价 - 全链路成本) / 到手价 × 100%
单件毛利 = 到手价 - 全链路成本
预计销量 = avg_daily_sales × 大促系数 × 价格弹性调整
总毛利 = Σ(单件毛利 × 预计销量)
总GMV = Σ(到手价 × 预计销量)
综合毛利率 = 总毛利 / 总GMV × 100%
ROI = (总GMV - 总成本) / 总推广费用
```

**敏感度分析：**
```
利润对价格的敏感度：
  价格每变动1%，毛利变动约 = 1% / 毛利率 × 100%
  举例：毛利率35%，价格降1%，毛利降约2.86%

利润对销量的敏感度：
  销量每变动1%，毛利变动约1%

利润对退货率的敏感度：
  退货率每增加1个百分点，毛利减少约(退货率/毛利率)%
```

## 四、异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 到手价低于全链路成本 | 触发亏损保护，自动上调到手价至成本价以上，标注"毛利率保护调整" |
| 竞品数据缺失 | 使用平台同类目均价作为替代，标注"竞品数据缺失，使用类目均价替代" |
| 库存不足以支撑预期销量 | 分阶段限量发售，标注"库存不足，建议按预售→现货分批释放" |
| 推广预算为0 | 不计算推广分摊，仅计算自然流量下的成本，标注"自然流量模式，GMV预估保守" |
| 大促时间线与平台规则冲突 | 以平台公告时间为准，自动调整时间线，标注"已按平台规则更新" |
| SKU数超过50个 | 按品类/价格带分组展示，核心SKU（销量前20%）单独展示，其余合并为品类组 |
| 多平台价格策略冲突 | 优先保证各平台到手价一致性，标注"跨平台价格统一策略" |
