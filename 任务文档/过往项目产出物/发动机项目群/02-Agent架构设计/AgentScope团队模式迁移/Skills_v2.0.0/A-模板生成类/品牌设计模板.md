# 品牌设计模板

## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 |
|--------|------|------|------|
| brand_type | string | 品牌类型，可选值：B2B（企业对企业）、B2C（企业对消费者）、DTC（直接面向消费者） | 是 |
| brand_name | string | 品牌名称 | 是 |
| industry | string | 行业领域，如：科技/金融/消费品/教育/医疗/制造 | 是 |
| target_audience | string | 目标受众描述，包含年龄/职业/收入/痛点/需求 | 是 |
| position_keywords | string[] | 品牌定位关键词，逗号分隔，如：创新,专业,温暖,高效 | 是 |
| existing_assets | string | 现有品牌资产描述（Logo描述/色板/已有字体等），品牌重塑场景必填，新建品牌可空 | 否 |
| competitors | string | 主要竞品品牌名称，用于差异化定位分析 | 否 |
| output_format | string | 输出格式，可选值：full（完整品牌手册）、brief（速览版，仅核心要素）、design_token_only（仅Design Token） | 否 |
| copy_style | string | 文案风格偏好，可选值：professional（专业正式）、conversational（对话式）、bold（大胆前卫）、minimal（极简克制） | 否 |

## 二、执行逻辑

### 步骤1：确定品牌类型和定位

根据 `brand_type` 和 `position_keywords` 确定品牌定位基调：

| 品牌类型 | 视觉基调 | 语音基调 | 关键差异点 |
|----------|----------|----------|-----------|
| B2B | 专业、可信、稳健 | 权威、清晰、价值导向 | 强调ROI、专业能力、长期合作 |
| B2C | 情感、共鸣、亲和 | 温暖、故事化、场景化 | 强调生活方式、情感连接、即时满足 |
| DTC | 真实、透明、社群感 | 直接、真诚、用户视角 | 强调透明度、用户共创、价值观共鸣 |

**品牌定位声明生成模板**：

```
对于[目标受众]，
[品牌名称]是[行业领域]中
唯一能提供[差异化价值主张]的品牌，
因为[核心支撑理由]。
```

### 步骤2：生成品牌基础框架

生成以下五个核心模块：

#### 2.1 品牌目的（Brand Purpose）

品牌存在的根本原因，超越盈利的更高意义。

**模板**：
```
[品牌名称] 存在的意义是 [动词 + 对象 + 结果]，
我们相信 [核心信念]，
因此我们致力于 [具体行动]。
```

#### 2.2 品牌愿景（Brand Vision）

品牌希望创造的未来图景，5-10年的长期目标。

**模板**：
```
成为 [行业/领域] 的 [角色/地位]，
让 [目标受众] 能够 [实现的改变/价值]。
```

#### 2.3 品牌使命（Brand Mission）

品牌每天在做的事情，实现愿景的具体路径。

**模板**：
```
通过 [方法/手段]，
为 [目标受众] 提供 [核心价值]，
帮助其 [达成目标/解决问题]。
```

#### 2.4 品牌价值观（Brand Values）

指导品牌决策和行为的核心原则，通常3-5个。

**模板**：
```
| 价值观 | 定义 | 行为准则（Do） | 行为红线（Don't） |
|--------|------|---------------|------------------|
| [价值观1] | [一句话定义] | [具体行为] | [禁止行为] |
| [价值观2] | [一句话定义] | [具体行为] | [禁止行为] |
| [价值观3] | [一句话定义] | [具体行为] | [禁止行为] |
```

#### 2.5 品牌个性（Brand Personality）

品牌像人一样的性格特征，使用"如果一个品牌是一个人"的比喻。

**模板（基于Jennifer Aaker品牌个性维度框架）**：

```
| 维度 | 子维度 | 评分(1-5) | 品牌表现 |
|------|--------|-----------|---------|
| 真诚 Sincerity | 务实/诚实/健康/愉悦 | __ |          |
| 刺激 Excitement | 大胆/活泼/有想象力/现代 | __ |        |
| 能力 Competence | 可靠/聪明/成功 | __ |              |
| 精致 Sophistication | 上流/迷人 | __ |             |
| 粗犷 Ruggedness | 户外/强韧 | __ |                |

品牌人格一句话描述：
如果 [品牌名称] 是一个人，TA 会是 [职业/角色]，
喜欢 [爱好]，说话方式 [语调特征]，
朋友圈里 TA 是 [社交角色]。
```

### 步骤3：生成视觉形象系统（Design Token）

#### 3.1 色彩系统（Color System）

**主色（Primary Color）**：品牌核心识别色，占视觉应用60%以上。

**辅色（Secondary Color）**：与主色搭配，用于区分内容层级，占视觉应用30%。

**强调色（Accent Color）**：用于CTA按钮、重要提示，占视觉应用10%。

**中性色（Neutral Color）**：文本、背景、边框等基础色。

```
/* CSS Design Token - 色彩系统 */
:root {
  /* === 主色 === */
  --color-primary-50:  #......;  /* 最浅，背景用 */
  --color-primary-100: #......;
  --color-primary-200: #......;
  --color-primary-300: #......;
  --color-primary-400: #......;
  --color-primary-500: #......;  /* 基准色 */
  --color-primary-600: #......;
  --color-primary-700: #......;
  --color-primary-800: #......;
  --color-primary-900: #......;  /* 最深，文本用 */

  /* === 辅色 === */
  --color-secondary-50:  #......;
  --color-secondary-100: #......;
  --color-secondary-500: #......;  /* 基准色 */
  --color-secondary-900: #......;

  /* === 强调色 === */
  --color-accent:        #......;
  --color-accent-hover:  #......;
  --color-accent-active: #......;

  /* === 中性色 === */
  --color-neutral-0:   #FFFFFF;  /* 白色 */
  --color-neutral-50:  #......;
  --color-neutral-100: #......;
  --color-neutral-200: #......;
  --color-neutral-300: #......;
  --color-neutral-400: #......;
  --color-neutral-500: #......;  /* 中等灰 */
  --color-neutral-600: #......;
  --color-neutral-700: #......;
  --color-neutral-800: #......;
  --color-neutral-900: #......;  /* 近黑 */
  --color-neutral-1000: #000000; /* 纯黑 */

  /* === 语义色 === */
  --color-success: #......;
  --color-warning: #......;
  --color-error:   #......;
  --color-info:    #......;
}
```

**色彩应用规则**：

| 用途 | 推荐色值 | 对比度要求 |
|------|----------|-----------|
| 正文文本 | neutral-900 | AA级（4.5:1以上） |
| 辅助文本 | neutral-600 | AA级（4.5:1以上） |
| 链接文本 | primary-600 | AA级（4.5:1以上） |
| CTA按钮 | primary-500 + white | AAA级（7:1以上） |
| 浅色背景 | neutral-50 | N/A |
| 深色背景 | primary-800 | 白色文本4.5:1以上 |

#### 3.2 排版系统（Typography）

**字体层级**：

```
/* CSS Design Token - 排版系统 */
:root {
  /* === 字体族 === */
  --font-family-heading:  'FontName', sans-serif;  /* 标题字体 */
  --font-family-body:     'FontName', sans-serif;  /* 正文字体 */
  --font-family-mono:     'FontName', monospace;   /* 代码字体 */

  /* === 字号 === */
  --font-size-xs:   0.75rem;   /* 12px - 辅助信息 */
  --font-size-sm:   0.875rem;  /* 14px - 次要文本 */
  --font-size-base: 1rem;      /* 16px - 正文基准 */
  --font-size-md:   1.125rem;  /* 18px - 强调正文 */
  --font-size-lg:   1.25rem;   /* 20px - 小标题 */
  --font-size-xl:   1.5rem;    /* 24px - H4 */
  --font-size-2xl:  1.875rem;  /* 30px - H3 */
  --font-size-3xl:  2.25rem;   /* 36px - H2 */
  --font-size-4xl:  3rem;      /* 48px - H1 */
  --font-size-5xl:  3.75rem;   /* 60px - Hero标题 */

  /* === 字重 === */
  --font-weight-light:   300;
  --font-weight-regular: 400;
  --font-weight-medium:  500;
  --font-weight-semibold: 600;
  --font-weight-bold:    700;

  /* === 行高 === */
  --line-height-tight:   1.2;   /* 标题 */
  --line-height-normal:  1.5;   /* 正文 */
  --line-height-relaxed: 1.75;  /* 长文本 */
}
```

**排版层级规范**：

| 层级 | 标签 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|------|
| Hero | H1 | 5xl | bold | tight | 首页主标题 |
| 页面标题 | H1 | 4xl | bold | tight | 内页标题 |
| 章节标题 | H2 | 3xl | semibold | tight | 内容分区 |
| 小节标题 | H3 | 2xl | semibold | tight | 子分区 |
| 卡片标题 | H4 | xl | medium | tight | 卡片/模块标题 |
| 引言 | blockquote | lg | regular | relaxed | 引用/强调 |
| 正文 | p | base | regular | normal | 正文内容 |
| 辅助文本 | small | sm | regular | normal | 说明/注释 |
| 微文本 | caption | xs | regular | normal | 标签/徽章 |

#### 3.4 Logo规范

**Logo变体**：

| 变体 | 用途 | 最小尺寸 | 安全间距 |
|------|------|----------|---------|
| 主Logo（横式） | 网站导航、文档页眉 | 高度≥40px | 四周≥logo高度的50% |
| 主Logo（竖式） | 社交媒体头像、App图标 | 高度≥64px | 四周≥logo高度的25% |
| 图标（Icon） | Favicon、App图标 | ≥16px | N/A |
| 反白Logo | 深色背景 | 高度≥40px | 四周≥logo高度的50% |
| 单色Logo | 打印/单色场景 | 高度≥40px | 四周≥logo高度的50% |

**Logo使用禁区**：
```
- 禁止拉伸/压缩/变形
- 禁止改变Logo颜色（除指定变体外）
- 禁止添加阴影/描边/滤镜效果
- 禁止旋转Logo
- 禁止在复杂背景上使用，确保对比度
- 禁止与其他元素组合成新Logo
```

### 步骤4：生成品牌语音与消息架构

#### 4.1 品牌语音特征（Brand Voice）

基于 `brand_type` 和 `copy_style` 参数，定义品牌语音的四个维度：

| 维度 | 定义 | B2B推荐 | B2C推荐 | DTC推荐 |
|------|------|---------|---------|---------|
| 正式度 | 语言的正规程度 | 中高 | 中低 | 中低 |
| 情感度 | 情感表达的丰富程度 | 中 | 高 | 高 |
| 复杂度 | 用词和句式的复杂程度 | 中 | 低 | 低 |
| 幽默度 | 幽默元素的运用频率 | 低 | 中 | 中高 |

**品牌语音特征卡**：

```
| 维度 | 我们是这样 | 我们不是这样 |
|------|-----------|-------------|
| 正式度 | 专业但不冷漠 | 刻板/官僚 |
| 情感度 | 有温度但不煽情 | 冷淡/机械 |
| 复杂度 | 清晰但不简化 | 晦涩/堆砌术语 |
| 幽默度 | 机智但不轻浮 | 搞笑/不严肃 |
```

#### 4.2 语调变体（Tone of Voice）

同一品牌在不同场景下的语调调整：

| 场景 | 语调调整 | 示例 |
|------|----------|------|
| 营销落地页 | 激动人心 + 自信 | "让你的团队效率翻倍，今天就开始。" |
| 产品文档 | 清晰 + 帮助性 | "点击右上角的设置按钮，进入配置页面。" |
| 客服回复 | 理解 + 解决问题 | "非常理解您的困扰，我们马上帮您排查。" |
| 错误提示 | 友好 + 指引 | "页面暂时无法加载，请刷新重试或联系客服。" |
| 社交媒体 | 轻松 + 互动 | "大家周一早上都是靠什么续命的？" |
| 危机公关 | 真诚 + 负责 | "我们深刻认识到问题的严重性，以下是我们的处理方案。" |

#### 4.3 消息框架（Message Architecture）

**核心消息层级**：

```
层级1：品牌主张（Tagline）
  一句话概括品牌价值，5-8个字，用于Logo下方

层级2：价值主张（Value Proposition）
  一段话说明品牌为谁解决什么问题，30-50字，用于首页Hero

层级3：支柱消息（Pillar Messages）
  3个核心卖点，每个10-15字，用于首页/产品页

层级4：支撑消息（Supporting Messages）
  每个支柱消息下的2-3个具体证明点，每个15-25字

层级5：证据点（Proof Points）
  数据、案例、客户证言，用于详情页
```

**消息框架模板**：

```
【品牌主张】
[一句话品牌标语]

【价值主张】
我们帮助 [目标受众] 通过 [核心方法] 实现 [核心价值]，
不同于 [竞品/替代方案]，我们 [差异化优势]。

【支柱消息】
支柱1：[核心卖点1]
  - 支撑消息：[具体证明]
  - 证据点：[数据/案例]

支柱2：[核心卖点2]
  - 支撑消息：[具体证明]
  - 证据点：[数据/案例]

支柱3：[核心卖点3]
  - 支撑消息：[具体证明]
  - 证据点：[数据/案例]
```

#### 4.4 写作指南（Writing Guide）

**用词原则**：

| 原则 | 说明 | 好例子 | 坏例子 |
|------|------|--------|--------|
| 动词优先 | 多用主动动词，少用名词化 | "我们帮您管理客户" | "我们提供客户管理解决方案" |
| 第二人称 | 多用"你"而非"用户/客户" | "你的数据安全是我们的首要任务" | "用户数据安全是产品的核心考量" |
| 正向表达 | 多说能做什么，少说不能做什么 | "保存后可在任意设备查看" | "未保存的内容不会同步" |
| 具体而非抽象 | 用具体数字和场景代替模糊描述 | "3分钟完成部署" | "快速部署" |
| 一个句子一个意思 | 避免长句嵌套 | "点击按钮。选择文件。上传完成。" | "点击按钮后选择需要上传的文件即可完成上传操作" |

**禁用词清单**：

```
- 行业黑话/术语：赋能、抓手、闭环、打法、底层逻辑（除非目标受众熟悉）
- 虚词堆砌：卓越的、领先的、一流的、顶级的（无数据支撑时）
- 性别歧视用语：根据场景自动检测
- 年龄歧视用语：年轻化、老派等（需语境判断）
- 过度承诺：保证、100%、绝对、永远
```

### 步骤5：生成品牌交付文档清单

根据 `output_format` 参数，输出对应的交付文档：

| 交付物 | full模式 | brief模式 | design_token_only |
|--------|----------|-----------|-------------------|
| 品牌基础框架 | 完整版 | 简化版 | 无 |
| 视觉形象系统 | 完整版含Design Token | 仅核心色板+字体 | 完整Design Token |

| Logo规范 | 完整版 | 仅使用禁区 | 无 |
| 品牌应用示例 | 5个场景 | 2个场景 | 无 |
| 品牌检查清单 | 完整版 | 简化版 | 无 |
