## 二、执行逻辑

### 步骤1：数据预处理与清洗

```
1. 检查历史数据完整性：
   - 最小数据量要求：ARIMA需≥24个月，指数平滑需≥12个月
   - 检测缺失值：使用线性插值或前值填充
   - 检测异常值：使用 IQR 方法（Q1 - 1.5*IQR, Q3 + 1.5*IQR）

2. 促销数据标记：
   - 将 promo=true 的时段标记为异常时段
   - 计算促销系数：lift = 促销期销量 / 非促销期平均销量

3. 季节性分解：
   - 使用 STL（Seasonal-Trend decomposition using LOESS）分解
   - 提取：趋势分量(T_t) + 季节分量(S_t) + 残差(R_t)
   - 季节指数 = 各月均值 / 总体均值
```

### 步骤2：需求预测方法选择

```
决策树（按优先级）：
├── 数据量 ≥ 24个月 且 有明显趋势/季节性？
│   ├── 是 → 使用 ARIMA/SARIMA
│   └── 否 → 下行
├── 数据量 ≥ 12个月 且 产品处于成熟期？
│   ├── 是 → 使用 Holt-Winters 指数平滑（三重）
│   └── 否 → 下行
└── 数据量 < 12个月 或 产品处于导入期？
    └── 使用简单指数平滑 + 类比法（参考相似产品）

ARIMA(p,d,q) 参数选择：
  1. 使用 ADF 检验确定差分阶数 d
  2. 使用 ACF/PACF 图确定 p 和 q
  3. 使用 AIC 准则选择最优模型
  4. 公式：Y_t = c + φ₁Y_{t-1} + ... + φ_pY_{t-p} + ε_t + θ₁ε_{t-1} + ... + θ_qε_{t-q}

Holt-Winters 三重指数平滑：
  Level:     L_t = α(Y_t - S_{t-m}) + (1-α)(L_{t-1} + T_{t-1})
  Trend:     T_t = β(L_t - L_{t-1}) + (1-β)T_{t-1}
  Seasonal:  S_t = γ(Y_t - L_t) + (1-γ)S_{t-m}
  Forecast:  F_{t+h} = L_t + h*T_t + S_{t+h-m}

促销增量预测：
  促销期预测 = 基线预测 × 促销系数
  其中促销系数 = max(1, 历史同类促销平均lift × 衰减因子)
  衰减因子：同一促销重复时，效果通常以 0.85-0.95 的速率衰减
```

### 步骤3：安全库存模型选择

```
决策树：
├── 需求服从正态分布 且 服务水平要求高（≥95%）？
│   └── 使用经典安全库存公式：
│        SS = Z_{service_level} × σ_d × sqrt(LT)
│        其中 Z_{0.95}=1.645, Z_{0.99}=2.326
│        σ_d = 需求标准差（日/周）
│        LT = 提前期（天/周）
│
├── 需求波动大 且 缺货成本高？
│   └── 使用 ROP（Reorder Point）模型：
│        ROP = d_avg × LT + SS
│        当库存降至ROP时触发补货
│
├── 需求稳定 且 持有成本高？
│   └── 使用 EOQ（Economic Order Quantity）模型：
│        EOQ = sqrt(2DS / H)
│        D = 年需求量
│        S = 单次订货成本
│        H = 单位持有成本 = 单价 × holding_cost_rate
│
└── 生鲜/短保质期商品？
    └── 使用报童模型（Newsvendor）：
        Q* = F⁻¹(cu / (cu + co))
        cu = 缺货成本（underage cost）
        co = 过期成本（overage cost）
        F⁻¹ = 需求分布的逆CDF
```

### 步骤4：ABC分类管理

```
ABC分类逻辑：
  1. 计算每个SKU的年度销售额 = 单价 × 年销量
  2. 按年度销售额降序排列
  3. 计算累计销售额占比：
     A类：累计占比前 70-80%（通常占SKU数的10-20%）
     B类：累计占比 80-95%（通常占SKU数的20-30%）
     C类：累计占比 95-100%（通常占SKU数的50-70%）

分类管理策略：

| 类别 | 盘点频率 | 安全库存 | 补货策略 | 管理重点 |
|------|---------|---------|---------|---------|
| A类 | 每日/每周 | 低（以周转率为核心） | 连续盘点（s, S） | 精准预测、紧密跟踪、JIT补货 |
| B类 | 每两周/每月 | 中 | 定期盘点（R, S） | 正常管理、定期优化 |
| C类 | 每季度 | 高（避免缺货） | 双堆法/两箱法 | 简化管理、批量补货 |

(s, S) 策略：库存降至s时补货至S
(R, S) 策略：每R周期检查一次，补货至S
```

### 步骤5：多渠道库存分配策略

```
当 warehouse_count > 1 或 channels > 1 时执行：

1. 渠道优先级排序：
   综合评分 = 渠道利润率 × 0.4 + 渠道稳定性 × 0.3 + 战略重要性 × 0.3
   按综合评分降序排列，评分高的渠道优先分配

2. 库存分配算法：
   阶段1 - 预留分配：
     对每个渠道，分配 min(渠道日均需求 × lead_time, 总库存 × 渠道权重)
   
   阶段2 - 动态分配：
     剩余库存 = 总库存 - 已分配库存
     按渠道实时消耗速率比例分配剩余库存
     
   阶段3 - 安全库存保障：
     确保每个渠道分配到至少 min_display 库存

3. 跨仓调拨决策：
   当某仓库库存 < ROP 且 另一个仓库库存 > 2×ROP 时：
     调拨量 = min(缺货仓库缺口, 盈余仓库超出ROP部分 × 0.5)
     调拨决策需考虑：调拨成本 vs 缺货成本
```

### 步骤6：行业定制策略

**快消行业：**
```
特征：SKU多、周转快、促销频繁、季节性明显
策略重点：
  - 预测：Holt-Winters + 促销系数（快消促销影响大）
  - 安全库存：使用报童模型处理促销不确定性
  - ABC：A类聚焦Top 50 SKU，C类考虑淘汰
  - 盘点：A类周盘，B类月盘，C类季盘
  - 关键指标：库存周转天数（目标30-45天）
```

**服装行业：**
```
特征：SKU生命周期短、尺码/颜色SKU爆炸、季节性强、预测极难
策略重点：
  - 预测：类比法（新品参考相似款历史数据）+ 时尚指数调整
  - 安全库存：对基础款用经典SS公式，对时尚款用报童模型
  - 首单/追单策略：首单满足预测的60-70%，根据售罄率决定追单
  - 尺码配比：基于历史尺码销售分布自动推荐配比
  - 关键指标：售罄率（目标60-70%）、库销比（目标3-4）
```

**3C行业：**
```
特征：单价高、降价快、技术迭代快、退货率高
策略重点：
  - 预测：ARIMA + 产品生命周期调整（引入期上调、衰退期下调）
  - 安全库存：对成熟期产品降低SS（避免跌价损失），对导入期产品提高SS
  - 跌价风险：在EOQ中增加跌价成本因子
  - 退货处理：预估退货率，在库存中预留退货缓冲
  - 关键指标：库龄（目标<60天）、跌价准备率
```

**生鲜行业：**
```
特征：保质期极短、损耗高、需求波动大、补货频率高
策略重点：
  - 预测：简单指数平滑（日度预测），因为生鲜不需要长期趋势
  - 安全库存：报童模型（核心是准确估算cu和co）
  - 补货策略：每日补货，下午根据当日销售调整次日订单
  - 损耗管理：FIFO严格管理，设置临期折扣策略
  - 关键指标：损耗率（目标<3%）、缺货率（目标<5%）
```

### 步骤7：关键KPI仪表盘

```
库存管理核心KPI：
  1. 库存周转率 = 销售成本 / 平均库存
  2. 库存周转天数 = 365 / 库存周转率
  3. 缺货率 = 缺货SKU数 / 总SKU数
  4. 服务水平 = 1 - 缺货次数 / 总需求次数
  5. 库销比 = 月末库存 / 月销售额
  6. 呆滞库存占比 = 库龄>90天库存 / 总库存
  7. 库存准确率 = 盘点准确SKU数 / 总SKU数
  8. GMROI = 毛利额 / 平均库存成本
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 历史数据不足12个月 | 降级使用简单指数平滑，并在报告中标注"数据不足，预测精度有限" |
| 需求不服从正态分布 | 使用Gamma分布或对数正态分布替代，或使用非参数方法（如Bootstrap） |
| 促销数据缺失 | 假设促销系数为1.0（无促销影响），并提示用户补充促销日历 |
| EOQ计算结果为0或负数 | 检查输入参数，提示"持有成本或订货成本参数异常" |
| 库存分配超过仓库容量 | 按优先级降级分配，低优先级渠道会有缺货风险，需明确提示 |
| 生鲜品类报童模型cu/co估算困难 | 使用行业经验值：cu = 售价 - 成本，co = 成本 - 残值 |
| 多仓库网络复杂度过高 | 简化为两阶段优化：先做仓库间分配，再做仓库内渠道分配 |
