  提供社交媒体策略方法论，包含跨平台活动管理（目标设定/受众分层/内容开发/
  预算分配/效果追踪）、KOL金字塔投放（头部/腰部/尾部KOC的筛选标准和组合策略，

## 一、输入要求

| 参数名 | 类型 | 说明 | 必填 | 示例 |
|--------|------|------|------|------|
| `campaign_type` | string | 活动类型 | 是 | `"brand_building"` / `"new_product_launch"` / `"crisis_pr"` / `"daily_operation"` |
| `industry` | string | 行业 | 是 | `"快消"` / `"汽车"` / `"科技"` / `"金融"` |
| `platforms` | array | 平台组合 | 是 | `["微博","微信","小红书","抖音","B站"]` |
| `budget_total` | float | 总预算（元） | 是 | `500000` |
| `target_audience` | object | 目标受众 | 是 | `{"age_range":"25-35","gender":"female","tier":"一二线"}` |
| `campaign_duration_days` | int | 活动周期（天） | 是 | `30` |
| `kol_tiers` | object | KOL投放层级配置 | 否 | `{"head":2,"mid":10,"koc":50}` |
| `content_themes` | array | 内容主题方向 | 否 | `["产品功效","使用场景","用户证言","品牌故事"]` |
| `crisis_level` | string | 舆情等级（crisis_pr时必填） | 条件 | `"red"` / `"orange"` / `"yellow"` / `"blue"` |
| `crisis_detail` | object | 舆情详情（crisis_pr时必填） | 条件 | `{"event":"...","spread_scope":"...","sentiment":"..."}` |
| `competitor_benchmark` | array | 竞品社媒数据 | 否 | `[{"brand":"...","followers":...,"engagement":...}]` |

## 二、执行逻辑

### 步骤1：目标设定与KPI体系

```
根据 campaign_type 自动建立目标体系：

品牌建设型（brand_building）：
  主要目标：品牌声量/认知度
  核心KPI：
    - 品牌搜索指数提升率
    - 品牌社交声量（总提及量/互动量）
    - 正面舆情占比
    - 粉丝净增长
    - 品牌词搜索UV

新品上市型（new_product_launch）：
  主要目标：产品认知→购买转化
  核心KPI：
    - 新品话题阅读量/播放量
    - 种草笔记/视频数量
    - 电商搜索UV提升率
    - UGC内容数量
    - 预售/首销转化率

危机公关型（crisis_pr）：
  主要目标：舆情控制/声誉修复
  核心KPI：
    - 负面舆情降温速度
    - 正面声量占比恢复率
    - 官方声明阅读/互动量
    - 媒体/KOL正面发声数量
    - 品牌NPS恢复情况

日常运营型（daily_operation）：
  主要目标：粉丝活跃/粘性
  核心KPI：
    - 粉丝互动率（点赞/评论/分享/收藏）
    - 内容发布频率
    - 粉丝增长
    - 私域引流效率
```

### 步骤2：受众分层与平台匹配

```
受众分层模型：
  1. 核心受众（Core）：品牌忠实用户/高频购买者
     - 占比：10-15%
     - 策略：深度互动、UGC激励、会员专属内容
     - 平台：微信私域为主
  
  2. 兴趣受众（Interest）：品牌相关品类兴趣人群
     - 占比：25-35%
     - 策略：教育内容、种草内容、场景化植入
     - 平台：小红书+抖音为主
  
  3. 泛受众（Broad）：人群包定向的潜在人群
     - 占比：50-65%
     - 策略：话题营销、热点借势、广泛曝光
     - 平台：微博+抖音为主

平台-受众匹配矩阵：
| 平台 | 核心受众 | 兴趣受众 | 泛受众 | 内容形态 |
|------|---------|---------|--------|---------|
| 微博 | 中 | 中 | 高 | 话题/图文/短视频 |
| 微信 | 高 | 高 | 低 | 图文/长文/H5 |
| 小红书 | 中 | 高 | 中 | 图文笔记/短视频 |
| 抖音 | 中 | 高 | 高 | 短视频/直播 |
| B站 | 中 | 高 | 中 | 中长视频/图文 |
```

### 步骤3：跨平台内容策略

**各平台内容调性：**

```
微博：
  - 内容调性：热点化、话题化、公共化
  - 发布频率：3-5条/天
  - 内容配比：话题互动40% + 品牌宣传30% + 用户互动20% + 行业观点10%
  - 黄金时段：8-9点、12-14点、20-22点

微信（公众号+视频号）：
  - 内容调性：深度化、品质化、私域化
  - 发布频率：公众号1-2篇/周，视频号2-3条/周
  - 内容配比：品牌故事30% + 产品深度25% + 用户案例20% + 福利活动25%
  - 黄金时段：12-13点、18-20点

小红书：
  - 内容调性：真实感、种草向、场景化
  - 发布频率：品牌号3-5篇/周，KOC笔记按计划
  - 内容配比：产品种草40% + 使用教程25% + 生活场景20% + 干货分享15%
  - 内容形式：图文笔记60% + 短视频40%
  - 关键词策略：长尾词+场景词+品类词组合

抖音：
  - 内容调性：趣味化、节奏快、强视觉
  - 发布频率：品牌号1-2条/天
  - 内容配比：创意内容35% + 产品展示30% + 达人合作25% + 直播10%
  - 关键指标：完播率 > 互动率 > 关注转化

B站：
  - 内容调性：圈层化、深度化、社区化
  - 发布频率：1-2条/周
  - 内容配比：深度测评40% + 创意内容30% + 知识科普20% + 社区互动10%
  - 关键：尊重社区文化，避免硬广，弹幕互动是核心
```

### 步骤4：预算分配模型

```
预算分配框架（以新品上市为例）：

总预算 = 内容制作 + KOL投放 + 信息流投放 + 互动运营 + 应急储备

默认分配比例：
  内容制作：    15-20%（品牌素材/视频制作/图文创作）
  KOL投放：     40-50%（头部20% + 腰部50% + KOC 30%）
  信息流投放：   20-25%（抖音千川+小红书聚光+微博粉丝通）
  互动运营：     5-10%（抽奖/互动礼品/直播运营）
  应急储备：     5%（舆情应对/追加投放）

平台预算分配建议（基于行业）：
| 行业 | 微博 | 微信 | 小红书 | 抖音 | B站 |
|------|------|------|--------|------|-----|
| 快消 | 20% | 20% | 25% | 25% | 10% |
| 汽车 | 25% | 15% | 10% | 20% | 30% |
| 科技 | 15% | 10% | 15% | 20% | 40% |
| 金融 | 30% | 30% | 15% | 15% | 10% |

ROI预估模型：
  预期曝光量 = 预算 × 行业CPM
  预期互动量 = 预期曝光量 × 行业平均互动率
  预期转化 = 预期互动量 × 行业平均转化率
```

### 步骤5：KOL金字塔投放策略

```
KOL金字塔层级定义：

头部KOL（粉丝>500万）：
  角色：话题引爆器、品牌背书
  占比：预算的20%
  筛选标准：
    - 粉丝画像与目标受众匹配度 > 60%
    - 近30天互动率 > 1.5%（微博）/ > 3%（抖音/小红书）
    - 无负面舆情/翻车历史
    - 过往商单转化数据（CPM/CPE/CPV）
  内容要求：1条深度合作内容 + 话题参与
  效果评估：CPM < 50元，互动率 > 基准值

腰部KOL（粉丝50万-500万）：
  角色：内容放大器、圈层渗透
  占比：预算的50%
  筛选标准：
    - 垂类匹配度优先于粉丝量
    - 近30天互动率 > 3%（微博）/ > 5%（抖音/小红书）
    - 内容质量（原创度/专业性/审美水平）
    - 粉丝真实性（剔除水号，异常粉丝占比 < 10%）
  内容要求：差异化内容矩阵，避免同质化
  效果评估：CPE < 3元，种草率 > 行业均值

尾部KOC（粉丝<50万，尤其是1-5万素人）：
  角色：真实口碑、长尾覆盖
  占比：预算的30%
  筛选标准：
    - 内容真实性（生活化/真实体验）
    - 互动率 > 5%（小体量互动率应更高）
    - 内容调性匹配品牌形象
    - 愿意真实使用/体验产品
  内容要求：真实体验分享，允许适度批评
  效果评估：UGC内容量、长尾搜索覆盖

KOL组合效果评估：
  种草效率 = 总互动量 / 总投放金额
  转化效率 = 可追踪转化 / 总投放金额
  品牌提升 = 投放前后品牌搜索指数变化
```

### 步骤6：舆情应急响应（四色分级）

**红色预警（重大危机）：**
```
触发条件：
  - 涉及人身安全/产品质量重大问题
  - 主流媒体跟进报道（央视/人民日报/新华社）
  - 微博热搜前10持续超过2小时
  - 负面舆情占比 > 70%且持续增长

响应流程：
  T+0-1小时：内部紧急会议，确认事实，启动危机小组
  T+1-2小时：发布官方声明（承认问题+表明态度+承诺行动）
  T+2-4小时：全平台同步声明，关闭评论区（必要时）
  T+4-24小时：持续监测舆情，准备第二波回应（具体措施）
  T+24-72小时：执行补救措施，通过KOL/媒体发布正面声音
  T+72小时+：持续修复，评估影响，调整策略

回应策略：
  - 态度：诚恳、不推诿、不沉默
  - 内容：事实确认 + 道歉（如需要） + 解决措施 + 时间表
  - 渠道：全平台官方账号 + 主流媒体 + 核心KOL
  - 升级机制：CEO/VP出面回应
```

**橙色预警（中度危机）：**
```
触发条件：
  - 涉及服务质量/体验问题
  - 行业媒体/自媒体集中报道
  - 微博热搜前50
  - 负面舆情占比 50-70%

响应流程：
  T+0-2小时：核实事实，准备回应
  T+2-6小时：发布官方声明
  T+6-24小时：配合KOL正面声量对冲
  T+24小时+：持续监测，评估降级

回应策略：
  - 态度：专业、及时、透明
  - 渠道：官方账号 + 行业媒体
  - 升级机制：部门负责人出面
```

**黄色预警（轻度争议）：**
```
触发条件：
  - 涉及产品/服务细节争议
  - 部分用户/自媒体讨论
  - 负面舆情占比 30-50%

响应流程：
  T+0-4小时：评估是否需要回应
  T+4-12小时：如需要，发布温和回应/澄清
  T+12小时+：引导正面讨论覆盖

回应策略：
  - 态度：幽默/轻松化解，或数据分析澄清
  - 渠道：单平台回应即可
  - 注意：有时不回应是最好的回应
```

**蓝色标注（常规监测）：**
```
触发条件：
  - 日常运营中的负面反馈
  - 负面舆情占比 < 30%

响应流程：
  - 常规客服回应
  - 记录并纳入产品改进
  - 周期性汇总分析

回应策略：
  - 态度：友好、专业、个性化
  - 渠道：评论回复/私信
```

### 步骤7：行业定制策略

**快消行业：**
```
特征：决策快、冲动消费、感官驱动
策略重点：
  - 内容：场景化种草（"使用前/使用后"视觉效果）
  - KOL：腰部+KOC为主，重真实体验
  - 平台：小红书+抖音双引擎
  - 节奏：高频次、快节奏、追热点
  - 关键指标：种草笔记量、UGC率、电商搜索UV
```

**汽车行业：**
```
特征：决策周期长、高客单价、理性+感性
策略重点：
  - 内容：深度测评、技术科普、生活方式
  - KOL：头部+专业垂类KOL（如车评人）
  - 平台：微博+B站+抖音
  - 节奏：长线经营，大事件引爆
  - 关键指标：品牌美誉度、试驾转化、线索收集
```

**科技行业：**
```
特征：技术驱动、极客文化、圈层传播
策略重点：
  - 内容：技术深度、产品拆解、行业趋势
  - KOL：科技垂类头部+数码博主
  - 平台：B站+微博+知乎
  - 节奏：发布会节点引爆，日常技术内容沉淀
  - 关键指标：技术讨论深度、Geek人群渗透率
```

**金融行业：**
```
特征：强监管、信任门槛高、内容限制多
策略重点：
  - 内容：财经知识、产品解读、用户故事
  - KOL：财经垂类+生活类（软性植入）
  - 平台：微信+微博+抖音（知识类）
  - 节奏：稳健经营，合规先行
  - 关键指标：信任度、合规率、有效转化
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 平台组合不包含主流平台 | 提示用户确认，可能遗漏重要流量入口 |
| KOL投放数量不合理（头重脚轻或头轻脚重） | 建议调整至推荐比例（头部20%+腰部50%+KOC30%），给出调整理由 |
| 预算不足覆盖目标平台 | 按优先级排序，建议砍掉ROI最低的平台，集中资源 |
| 舆情等级升级（如黄→橙） | 自动升级响应方案，通知更高级别决策者 |
| KOL翻车/负面舆情 | 立即暂停与该KOL合作，评估连带影响，准备切割声明 |
| 行业不在预设范围内 | 提示用户手动指定行业参数，或使用最接近的预设行业 |
| 活动期间遇到不可抗力（如自然灾害/社会事件） | 建议暂停商业推广，调整为公益/关怀内容，等待合适时机恢复 |
