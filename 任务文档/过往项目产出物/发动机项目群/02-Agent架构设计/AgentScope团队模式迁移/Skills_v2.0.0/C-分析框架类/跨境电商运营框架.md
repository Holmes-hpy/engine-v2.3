## 二、执行逻辑

### 步骤1：选品评估模型（五维度量化）

```
维度一：市场容量（权重 25%）
  评分标准：
    10分：头部产品月销 > 5000单，类目Top 100月销 > 500
    8分：头部产品月销 2000-5000单
    6分：头部产品月销 500-2000单
    4分：头部产品月销 100-500单
    2分：头部产品月销 < 100单
    0分：类目无销售数据/完全冷门

  数据来源：Jungle Scout / Helium 10 / 卖家精灵

维度二：利润空间（权重 30%）
  利润计算：
    售价 = competitor_avg_price × 0.9（新进入者定价策略）
    平台佣金 = 售价 × 平台佣金率（Amazon 15%, Shopee 5-7%）
    物流成本 = 头程 + 尾程配送费（FBA费用/自发货邮费）
    毛利率 = (售价 - 采购成本 - 佣金 - 物流成本) / 售价 × 100%
  
  评分标准：
    10分：毛利率 > 50%
    8分：毛利率 35-50%
    6分：毛利率 25-35%
    4分：毛利率 15-25%
    2分：毛利率 5-15%
    0分：毛利率 < 5% 或亏损

维度三：竞争格局（权重 20%）
  竞争强度 = 竞品数量 × 平均评论集中度
  评论集中度 = Top 3产品评论数 / 总评论数
  
  评分标准：
    10分：低竞争（Top 3评论集中度 < 30%，新品有机会）
    8分：中低竞争（集中度 30-45%）
    6分：中等竞争（集中度 45-60%）
    4分：中高竞争（集中度 60-75%）
    2分：高竞争（集中度 75-90%）
    0分：垄断（集中度 > 90%，或存在绝对品牌壁垒）

维度四：合规风险（权重 15%）
  评分标准：
    10分：无特殊要求，普货
    8分：需要基本认证（如CE/FCC）
    6分：需要特定认证（如FDA/UL/CPC）
    4分：需要多项认证 + 知识产权风险
    2分：存在专利风险/类目受限
    0分：禁止销售/需要特殊资质

维度五：物流可行性（权重 10%）
  物流成本率 = 总物流成本 / 售价
  
  评分标准：
    10分：物流成本率 < 10%，体积小重量轻
    8分：物流成本率 10-15%
    6分：物流成本率 15-20%
    4分：物流成本率 20-30%
    2分：物流成本率 30-40%
    0分：物流成本率 > 40% 或特殊物流要求（危险品/超大件）

综合评分 = Σ(维度得分 × 权重)
推荐阈值：
  综合评分 ≥ 7.5：强烈推荐
  6.0 ≤ 综合评分 < 7.5：可考虑
  综合评分 < 6.0：不推荐
```

### 步骤2：多站点运营策略对比

**Amazon（北美/欧洲/日本）：**
```
核心逻辑：产品为王 + 流量分发
优势：
  - 全球最大流量池（北美月活2亿+）
  - FBA物流体验极佳（Prime会员2日达）
  - 用户信任度高，转化率优于其他平台
劣势：
  - 竞争激烈，头部效应明显
  - 佣金高（多数品类15%）
  - 政策严格，封号风险
  - 广告成本持续上涨

利润率模型：
  售价：$29.99
  采购成本：-$6.00
  头程物流：-$2.00
  FBA费用：-$5.50
  平台佣金（15%）：-$4.50
  广告费（15%）：-$4.50
  退货/损耗（3%）：-$0.90
  ──────────────
  净利润：$6.59（净利率 22%）

运营重点：
  1. Listing优化（标题/五点/描述/A+页面/关键词）
  2. 评论管理（Vine计划/售后服务卡/合规索评）
  3. 广告投放（SP/SB/SD组合策略）
  4. 库存管理（避免断货，IPI分数维护）
  5. 品牌注册（Brand Registry，防跟卖+品牌工具）
```

**Shopee（东南亚/拉美/台湾）：**
```
核心逻辑：社交电商 + 低价驱动
优势：
  - 东南亚市场占有率第一
  - 低佣金（5-7%）+ 免佣期长
  - 移动端体验好，社交功能强
  - 入驻门槛低，对新手友好
劣势：
  - 客单价低（均值$5-15）
  - 价格战严重
  - 物流基础设施参差不齐
  - 退货率较高

利润率模型：
  售价：$9.99
  采购成本：-$2.00
  物流成本：-$1.50
  平台佣金（6%）：-$0.60
  广告费（8%）：-$0.80
  退货/损耗（5%）：-$0.50
  ──────────────
  净利润：$4.59（净利率 46%）

运营重点：
  1. 店铺装修与粉丝运营（关注有礼/直播）
  2. 低价引流款 + 利润款组合策略
  3. 关键词广告（注意小语种关键词）
  4. 聊聊（Chat）快速响应（响应率影响权重）
  5. 参与平台大促（9.9/11.11/12.12）
```

**Lazada（东南亚）：**
```
核心逻辑：品牌化 + 天猫模式
优势：
  - 阿里系，与天猫模式接近
  - 品牌化趋势明显，品牌旗舰店有优势
  - 物流体系（LGS）相对成熟
  - 高品质用户占比高
劣势：
  - 市场份额被Shopee蚕食
  - 佣金较高（4-8%）
  - 运营门槛较高
  - 移动端体验不如Shopee

运营重点：
  1. 品牌旗舰店装修
  2. 内容营销（Lazada Feed/LazLive）
  3. 参与LazMall品牌认证
  4. 利用Lazada Sponsored广告
  5. 多国站点统一管理（六国一站）
```

**独立站（Shopify/WooCommerce）：**
```
核心逻辑：品牌自主 + 私域流量
优势：
  - 无平台佣金，利润全归自己
  - 品牌完全自主，用户数据自有
  - 无跟卖/封号风险
  - 可定制化体验
劣势：
  - 需要自己获取流量（广告/SEO/社媒）
  - 前期投入大（建站/广告/运营）
  - 信任建立周期长
  - 技术运维要求高

利润率模型：
  售价：$29.99
  采购成本：-$6.00
  物流成本：-$3.00
  支付手续费（3%）：-$0.90
  广告费（25%）：-$7.50
  建站/SaaS（月费分摊）：-$0.50
  退货/损耗（3%）：-$0.90
  ──────────────
  净利润：$11.19（净利率 37%）

运营重点：
  1. 广告投放（Facebook/Google/TikTok Ads）
  2. SEO优化（内容营销/外链建设）
  3. 邮件营销（EDM自动化流程）
  4. 社交媒体运营（TikTok/Instagram/Pinterest）
  5. CRO（转化率优化：落地页/加购/结账）
```

### 步骤3：Amazon PPC分阶段投放策略

**新品期（0-3个月，目标：曝光+出单）：**
```
策略：自动广告为主，获取初始数据
  广告类型：自动广告（Auto Campaign）
  竞价策略：固定竞价（Fixed Bids）
  出价：建议竞价 × 1.2
  每日预算：$20-30/产品
  否定关键词：先不设，积累数据后再优化

关键操作：
  1. 运行2周后，下载搜索词报告
  2. 提取高转化搜索词 → 用于手动广告
  3. 提取低转化/无关搜索词 → 添加否定关键词
  4. 根据数据调整Listing（标题/搜索词中包含高转化词）

ACOS目标：新品期放宽至 40-50%（以获取数据和评论为主）
预算分配：自动广告 100%
```

**成长期（3-12个月，目标：排名提升+盈利）：**
```
策略：手动精准广告为主，自动广告补充
  广告类型：
    - 手动精准（Exact）：覆盖高转化核心词，占比 40%
    - 手动短语（Phrase）：覆盖长尾词，占比 30%
    - 手动广泛（Broad）：探索新词，占比 20%
    - 自动广告（Auto）：持续发现新词，占比 10%

  竞价策略：动态竞价 - 仅降低（Dynamic Bids - Down Only）
  每日预算：$50-100/产品
  关键词管理：
    - 每周优化：暂停ACOS > 目标×2的关键词
    - 出价调整：ACOS < 目标×0.5 → 提价20%；ACOS > 目标×1.5 → 降价20%
    - 否定关键词：持续添加无效点击词

SB（品牌推广广告）：
  引流至品牌旗舰店，预算占比 10-15%
  SB视频广告优先（转化率高于图文SB）

ACOS目标：逐步降至 20-30%
预算分配：手动 80% + 自动 10% + SB 10%
```

**成熟期（12个月+，目标：品牌防御+利润最大化）：**
```
策略：品牌防御为主，精准投放
  广告类型：
    - 品牌词防御（Exact）：保护品牌词，防止竞对截流，占比 30%
    - 核心词精准（Exact）：维持高转化词排名，占比 30%
    - SD（展示型广告）：再营销+竞品定向，占比 20%
    - SB品牌旗舰店：持续引流，占比 15%
    - 自动广告：仅用于发现新词，占比 5%

  竞价策略：根据位置调整（Adjust Bids by Placement）
    - 搜索结果顶部（Top of Search）：+30-50%
    - 产品页面（Product Pages）：-20-30%

  SD广告策略：
    - 再营销受众：浏览过但未购买的用户
    - 竞品定向：定向竞品ASIN（需评估ROI）
    - 类目定向：定向互补品类目

ACOS目标：10-20%（成熟期利润优先）
预算分配：品牌防御 30% + 核心词 30% + SD 20% + SB 15% + 自动 5%
```

### 步骤4：目标市场定制策略

**北美市场：**
```
特征：成熟市场，竞争激烈，消费者要求高
策略重点：
  - 产品：品质优先，差异化优先（不要卖大路货）
  - 价格：中高端定位，$15-50为黄金价格带
  - 物流：FBA必备（非FBA转化率低30-50%）
  - 合规：严格（CPC/FDA/UL认证，知识产权风险）
  - 广告：Amazon PPC为主，Facebook/Google补充
  - 关键：评论积累（Vine/售后卡）、品牌注册
  - 避坑：专利侵权（美国专利诉讼成本极高）
```

**东南亚市场：**
```
特征：增长快，价格敏感，移动端为主
策略重点：
  - 产品：性价比优先，$5-20为黄金价格带
  - 价格：低价策略，薄利多销
  - 物流：Shopee SLS/Lazada LGS为主，海外仓做爆款
  - 合规：相对宽松，但注意宗教/文化敏感品
  - 广告：站内广告为主，TikTok效果显著
  - 关键：多站点铺开（六国一站）、直播带货
  - 避坑：COD（货到付款）拒收率高，小语种翻译准确性
```

**欧洲市场：**
```
特征：监管严格，多语言，VAT复杂
策略重点：
  - 产品：CE认证必备，环保/可持续是加分项
  - 价格：中高端，€20-60为黄金价格带
  - 物流：FBA欧洲（Pan-EU）/ 海外仓（注意VAT）
  - 合规：极严格（CE/WEEE/包装法/EPR/UKCA）
  - 广告：Amazon PPC为主，注意多语言关键词
  - 关键：VAT合规（各国注册/申报/缴税）、多语言Listing
  - 避坑：VAT注册遗漏导致封号，英国脱欧后北爱尔兰特殊规则
```

**中东市场：**
```
特征：高客单价，宗教文化敏感，物流挑战
策略重点：
  - 产品：品质优先，奢侈品/高端电子有市场
  - 价格：中高端定位，$20-100为黄金价格带
  - 物流：COD为主（占70%+），注意拒收风险
  - 合规：宗教/文化合规（如避免猪/酒/暴露图案）
  - 广告：社交媒体（Instagram/TikTok）效果优于搜索广告
  - 关键：阿拉伯语本地化、斋月/开斋节大促
  - 避坑：COD拒收率高达30-40%，地址系统不完善
```

### 步骤5：综合运营仪表盘

```
核心KPI体系：
  1. 销售额（GMV）= 流量 × 转化率 × 客单价
  2. 毛利率 = (售价 - 成本 - 佣金 - 物流) / 售价
  3. 净利润率 = 毛利率 - 广告费率 - 退货率 - 其他费用率
  4. ACOS = 广告花费 / 广告销售额
  5. TACOS = 总广告花费 / 总销售额（含自然流量）
  6. 库存周转天数 = 365 / 库存周转率
  7. 退货率 = 退货数量 / 总订单数
  8. 评论率 = 获得评论数 / 总订单数
  9. 星级评分 = 平均产品评分
  10. BSR（Best Sellers Rank）= 类目排名

健康度诊断：
  TACOS < 10% → 优秀（自然流量占比高）
  TACOS 10-20% → 健康
  TACOS 20-30% → 依赖广告，需提升自然排名
  TACOS > 30% → 广告依赖严重，利润堪忧
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 候选产品缺少竞品数据 | 使用类目平均数据作为替代，标注"估算值"，建议用户通过工具获取精确数据 |
| 多站点场景中站点组合不合理 | 提示不同站点的适合品类和运营难度，建议调整站点组合 |
| ACOS超过目标2倍以上 | 触发紧急优化：暂停高ACOS词、检查Listing相关性、检查竞品动态 |
| 利润率为负 | 逐项分析成本构成，找出问题环节（采购成本/物流/广告/佣金），给出止损建议 |
| VAT合规缺失 | 强烈提示合规风险，列出目标市场必需的VAT注册要求 |
| 退货率超过行业基准2倍 | 分析退货原因（质量问题/描述不符/尺码问题/物流破损），逐项给出解决方案 |
| 库存断货预警 | 计算FBA补货时效，建议紧急空运补货方案，评估断货对排名的影响 |
