  提供投标赢标策略方法论，包含赢标主题矩阵（3-5主题+客户需求映射+差异化论证+
  证据链+出现章节映射）、三幕式方案叙事（理解挑战→方案旅程→转变后的状态）、
  执行摘要架构（五段式：背景/需求/方案/差异化/行动号召），适用于B2B投标、
  政府项目竞标、企业服务方案撰写场景，支持按行业（IT/工程/咨询/医疗）和
  客户类型（政府/国企/民企/外企）定制叙事策略。

## 二、执行逻辑

### 步骤1：客户需求深度解析

```
1. 从 client_info.pain_points 中提取5个核心需求
2. 按紧迫性排序：紧急且重要 > 重要不紧急 > 紧急不重要
3. 对每个需求标注：
   - 显性需求（招标文件明确提及）
   - 隐性需求（推导得出，客户未明说）
   - 情感需求（决策者个人诉求）
4. 输出需求映射表，格式：需求 → 我方解决方案 → 竞对能力 → 差异化点
```

### 步骤2：竞对分析矩阵

```
SWOT竞对对比：
  对每个竞对：
    - 优势（S）：竞对的核心竞争力和历史中标记录
    - 劣势（W）：竞对的短板（技术/服务/价格/经验）
    - 机会（O）：竞对劣势中我方可利用的突破点
    - 威胁（T）：竞对优势中可能对我方造成威胁的点

竞对定位图：
  X轴：价格竞争力（低→高）
  Y轴：技术能力（低→高）
  将我方和所有竞对标注在矩阵中，确定我方定位策略

价格博弈策略：
  - 若我方技术评分预估领先 > 15分：采用"高价高质"策略
  - 若我方技术评分预估领先 5-15分：采用"中价高质"策略
  - 若我方技术评分与竞对持平：采用"价格渗透"策略
  - 若我方技术评分落后：评估是否低价冲标
```

### 步骤3：赢标主题矩阵构建

```
赢标主题 = 客户核心需求 + 我方差异化能力 + 竞对无法复制

对于每个赢标主题（3-5个），完整填写以下矩阵：

| 主题编号 | 主题名称 | 映射客户需求 | 差异化论证 | 证据链 | 出现章节 | 针对竞对 |
|---------|---------|-------------|-----------|--------|---------|---------|
| Theme 1 | ... | 需求1/需求3 | 我们独有的... | 案例/数据/认证 | 第2/5/7章 | 竞对A弱点 |
| Theme 2 | ... | 需求2 | ... | ... | ... | ... |

主题设计原则：
1. 每个主题必须是"客户关心的"而非"我们想说的"
2. 每个主题必须有可验证的证据链
3. 主题之间形成递进关系（覆盖→深化→升华）
4. 至少有一个主题是针对头号竞对的致命弱点设计的
```

### 步骤4：三幕式方案叙事框架

**第一幕：理解挑战（占方案篇幅 20%）**

```
目标：让客户感受到"你懂我"
内容：
  1. 行业背景与趋势分析（引用权威数据）
  2. 客户当前面临的挑战（用客户的语言复述其痛点）
  3. 不改的后果（量化不解决问题的损失）
  4. 改变的愿景（描绘解决后的理想状态）

关键技巧：
  - 使用客户访谈中的原话/关键词
  - 展示对客户业务的理解深度，而非泛泛而谈
  - 埋下伏笔：暗示问题如何解决，但不展开
```

**第二幕：方案旅程（占方案篇幅 55%）**

```
目标：让客户相信"你能做到"
内容：
  1. 总体方案架构（一张图说清楚整体逻辑）
  2. 分模块详细方案（每个模块对应一个赢标主题）
  3. 实施路径与里程碑（甘特图/路线图）
  4. 风险管控与质量保障
  5. 团队配置与关键人员介绍

关键技巧：
  - 每个方案模块开头用"因为您提到...所以我们设计..."的句式
  - 用"对比"强调差异化：通常做法 vs 我们的做法
  - 关键人员必须有"说头"：头衔/经历/证书/项目
  - 风险部分要展示"我们比你想得更周全"
```

**第三幕：转变后的状态（占方案篇幅 25%）**

```
目标：让客户期待"和你合作"
内容：
  1. 预期收益量化（ROI计算，用客户自己的数据）
  2. 成功案例与客户证言（最好是同行业/同规模）
  3. 售后服务与持续优化承诺
  4. 行动号召（下一步是什么？为什么是现在？）

关键技巧：
  - ROI计算要具体到数字，有公式推导过程
  - 案例用"客户名称/项目规模/实施效果"三段式
  - 行动号召要有紧迫感但不压迫感
```

### 步骤5：执行摘要架构（五段式）

```
第一段 - 背景（1-2句）：
  "在当前[行业趋势]背景下，[客户名称]面临着[核心挑战]..."

第二段 - 需求（2-3句）：
  "基于对招标文件的深入理解和对贵方业务的调研，我们识别出[项目名称]的
   核心需求包括：[需求1]、[需求2]、[需求3]..."

第三段 - 方案（3-4句）：
  "我们为贵方量身定制的[方案名称]从[维度1]、[维度2]、[维度3]三个维度切入，
   通过[核心方法]实现[核心目标]..."

第四段 - 差异化（2-3句）：
  "区别于其他方案，我们的核心优势在于：
   [差异化1]：具体说明...
   [差异化2]：具体说明...
   [差异化3]：具体说明..."

第五段 - 行动号召（1-2句）：
  "我们已准备好[具体行动]，期待与贵方携手[愿景]。"
```

### 步骤6：行业与客户类型定制

**按行业定制叙事策略：**

| 行业 | 叙事重点 | 避坑要点 |
|------|---------|---------|
| IT | 强调技术先进性、架构可扩展性、安全合规 | 避免过度技术术语，客户决策者可能非技术背景 |
| 工程 | 强调工期保障、质量管控、安全记录 | 避免忽视当地关系和政府审批流程 |
| 咨询 | 强调方法论独特性、团队行业经验、落地能力 | 避免只谈方法论不谈执行 |
| 医疗 | 强调合规性（HIPAA/等保）、临床价值、数据安全 | 避免忽视医疗行业特有的伦理和合规要求 |

**按客户类型定制叙事策略：**

| 客户类型 | 决策逻辑 | 叙事重点 | 避坑要点 |
|---------|---------|---------|---------|
| 政府 | 合规优先、程序正确、不出错 | 强调合规性、成功案例、服务保障 | 避免过于创新/激进的方案措辞 |
| 国企 | 稳定可靠、领导认可、风险可控 | 强调行业经验、团队实力、长期合作 | 避免过于强调价格优势（国企不是价格敏感型） |
| 民企 | 性价比、落地速度、实际效果 | 强调ROI、快速见效、灵活服务 | 避免过于复杂的方案架构 |
| 外企 | 专业性、全球化、合规 | 强调国际标准、数据安全、全球化能力 | 避免忽视总部决策链（本地说了不算） |

### 步骤7：合规检查清单

```
根据 bid_requirements 生成合规检查清单：

1. 资质文件：
   □ 营业执照副本（加盖公章）
   □ 法定代表人授权书
   □ 资质证书（ISO/行业资质/安全资质）
   □ 财务报表（近三年审计报告）
   □ 纳税证明和社保缴纳证明

2. 格式要求：
   □ 投标文件密封要求
   □ 正副本份数要求
   □ 签字盖章要求
   □ 电子版要求（U盘/CD）

3. 评分细则映射：
   □ 技术评分项逐条对应方案章节
   □ 商务评分项逐条对应资质文件
   □ 价格评分项对应报价策略
```

## 四、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 竞对信息不完整 | 标注"基于公开信息推断"，在输出中明确标注不确定的部分 |
| 客户需求模糊 | 基于行业典型需求和项目类型进行合理推断，标注"推断" |
| 我方劣势明显（如价格高30%以上） | 建议采用"价值重构"策略，将比较维度从价格转向TCO（总拥有成本） |
| 决策链信息缺失 | 默认按"业务部门→采购部门→高层领导"的经典决策链建模 |
| 行业不在预设范围内 | 提示用户手动指定行业特征参数，或使用最接近的预设行业 |
| 赢标主题数量设置不合理 | 3个主题为最小推荐值，5个为最大推荐值，超出范围自动调整 |
