# 业务规则

## 用户管理规则
1. 用户必须通过邮箱验证才能使用完整功能
2. 用户名长度必须在3-20个字符之间
3. 密码长度必须至少8个字符，包含大小写字母和数字
4. 用户可以修改个人信息，但不能修改邮箱
5. 账户连续3次登录失败将被锁定15分钟

## 权限规则
- **超级管理员**: 拥有所有权限
- **管理员**: 可以管理用户和内容
- **编辑者**: 可以创建和编辑内容
- **普通用户**: 只能查看和使用内容
- **访客**: 只能查看公开内容

## 数据规则
1. 用户数据保存期限为账户注销后1年
2. 所有敏感数据必须加密存储
3. 日志数据保存期限为90天
4. 备份数据保存期限为30天
5. 数据导出请求必须在7个工作日内处理

## 支付规则
1. 支持的支付方式: 支付宝、微信支付、信用卡
2. 订单支付超时时间为30分钟
3. 退款申请处理时间为3-5个工作日
4. 虚拟商品不支持退款
5. 订阅服务可以随时取消，但不退还已支付费用

## 内容规则
1. 用户发布的内容必须符合法律法规
2. 禁止发布色情、暴力、政治敏感内容
3. 平台有权删除违规内容并封禁账户
4. 用户对自己发布的内容承担全部责任
