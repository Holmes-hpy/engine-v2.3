# 投资回报测算器

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `total_land_area` | number | 是 | 总用地面积（亩） | `1000` |
| `land_cost_per_mu` | number | 是 | 土地成本（万元/亩） | `50` |
| `construction_cost` | object | 是 | 各类建筑建安成本 | 见下方格式 |
| `supporting_cost` | object | 否 | 配套成本 | 见下方格式 |
| `annual_revenue` | object | 是 | 年度收入预测 | 见下方格式 |

## 二、计算公式

### 总投资额
```
总投资 = 土地成本 + 建安成本 + 配套成本 + 前期费用 + 不可预见费
土地成本 = 总用地面积 × 土地单价
建安成本 = Σ(各类建筑面积 × 单位建安成本)
配套成本 = 景观 + 道路 + 市政管网 + 智慧化系统
前期费用 = (土地成本 + 建安成本) × 3-5%
不可预见费 = (土地成本 + 建安成本 + 配套成本) × 5-8%
```

### 净现值（NPV）
```
NPV = Σ(CF_t / (1 + r)^t) - 初始投资
其中 CF_t = 第t年净现金流，r = 折现率
```

### 内部收益率（IRR）
```
使 NPV = 0 的折现率 r 即为 IRR
```

### 静态回收期
```
静态回收期 = 累计净现金流首次为正的年份 - 1 + (上年累计净现金流绝对值 / 当年净现金流)
```

### 动态回收期
```
动态回收期 = 累计折现净现金流首次为正的年份 - 1 + (上年累计折现净现金流绝对值 / 当年折现净现金流)
```

### 敏感性分析
```
分别测算以下因素变动±10%、±20%对IRR的影响：
- 土地成本变动
- 建安成本变动
- 租金收入变动
- 空置率变动
```
