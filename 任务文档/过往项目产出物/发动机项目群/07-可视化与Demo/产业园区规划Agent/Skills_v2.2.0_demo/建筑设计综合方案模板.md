# 建筑设计综合方案模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `park_name` | string | 是 | 园区名称 | `XX智慧生态产业园` |
| `space_plan` | string | 是 | 空间规划方案（空间规划Agent输出） | 空间规划方案全文 |
| `building_indicators` | string | 是 | 建筑指标数据（园区建筑指标计算器输出） | 指标表全文 |
| `design_style` | string | 否 | 建筑风格偏好 | `现代简约` / `工业科技风` / `生态园林风` |
| `special_buildings` | array | 否 | 特殊建筑需求 | `["会展中心","人才公寓","企业总部"]` |

## 二、执行逻辑

### 步骤1：标准化厂房设计

| 厂房类型 | 层数 | 层高(m) | 柱距(m) | 楼面荷载(kN/㎡) | 适用产业 |
|----------|:---:|:---:|:---:|:---:|------|
| 单层厂房 | 1 | 8-12 | 12-18 | 20-50 | 重型装备制造 |
| 多层厂房 | 3-6 | 4.5-6 | 8-10 | 8-15 | 电子信息、精密制造 |
| 高层厂房 | 7-12 | 4.5-5.5 | 8-9 | 5-10 | 研发中试、轻工制造 |

标准化厂房设计要点：
- 平面布局：矩形为主，长宽比1:1.5-2.0，便于生产线布置
- 垂直交通：货梯≥2部（载重≥3吨），客梯≥1部
- 货运月台：进深≥20m，含雨棚，月台高度1.2m（与货车车厢齐平）
- 设备管井：强弱电井、给排水井、通风井集中布置
- 屋顶利用：预留光伏安装荷载（≥0.5kN/㎡）

### 步骤2：研发办公楼设计

| 建筑要素 | 设计参数 |
|----------|----------|
| 标准层面积 | 1000-2000㎡，核心筒居中 |
| 层高 | 首层4.5m（大堂），标准层3.9m |
| 柱网 | 8.4m×8.4m，开放式办公布局 |
| 电梯配置 | 客梯2-4部，服务楼层≤15层 |
| 立面风格 | 玻璃幕墙+铝板，科技感与现代感 |
| 配套设施 | 共享会议室、咖啡厅、健身房、地下车库 |

### 步骤3：配套商业建筑设计

| 业态 | 面积(m²) | 层数 | 位置 | 设计要求 |
|------|:---:|:---:|------|------|
| 员工食堂 | 2000-3000 | 1-2 | 邻近生产区 | 满足500-1000人同时就餐 |
| 商业配套 | 3000-5000 | 2-3 | 邻近生活区 | 便利店、银行、药店、餐饮 |
| 人才公寓 | 15000-30000 | 6-12 | 独立组团 | 户型30-60㎡，精装修 |
| 文体中心 | 2000-3000 | 2-3 | 生活区核心 | 篮球场、健身房、阅览室 |

## 三、输出格式

```markdown
# [园区名称]建筑设计方案

## 1. 设计理念与风格定位
- 整体设计理念
- 建筑风格定位
- 与周边环境的协调策略

## 2. 标准化厂房方案
- 厂房类型选择及理由
- 典型平面图（文字描述）
- 结构体系与荷载标准
- 货运物流组织

## 3. 研发办公楼方案
- 建筑规模与层数
- 标准层平面布局
- 立面设计
- 垂直交通系统

## 4. 配套建筑方案
- 人才公寓设计
- 商业配套设计
- 公共服务建筑设计

## 5. 建筑风貌导则
- 色彩体系
- 材料选择
- 标识系统
- 夜景照明

## 6. 绿色建筑策略
- 节能设计
- 雨水利用
- 可再生能源利用
- 绿色建筑星级目标
```

## 四、质量检查清单

- [ ] 厂房设计满足目标产业的生产工艺需求
- [ ] 建筑指标与空间规划方案一致
- [ ] 配套设施满足园区人口容量需求
- [ ] 绿色建筑策略有具体措施（非空洞口号）
- [ ] 建筑风格统一且有辨识度
