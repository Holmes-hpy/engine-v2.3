# 智慧园区综合方案模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `park_name` | string | 是 | 园区名称 | `XX智慧生态产业园` |
| `space_plan` | string | 是 | 空间规划方案 | 空间规划Agent输出 |
| `building_plan` | string | 否 | 建筑设计方案 | 建筑设计Agent输出 |
| `smart_level` | string | 否 | 智慧化等级 | `基础级` / `标准级` / `标杆级` |
| `budget_for_smart` | number | 否 | 智慧化专项预算（万元） | `5000` |

## 二、执行逻辑

### 步骤1：智慧物业系统

| 子系统 | 功能 | 覆盖范围 | 技术方案 |
|--------|------|------|------|
| 智能门禁 | 人脸识别+手机扫码+访客预约 | 园区入口+各楼栋 | 人脸识别终端+云平台 |
| 智慧停车 | 车位引导+无感支付+车位预约 | 全部停车场 | 地磁/视频桩+诱导屏+APP |
| 设备监控 | 电梯/空调/给排水/供配电实时监控 | 全部公共设备 | IoT传感器+BA系统 |
| 智慧报修 | 扫码报修+自动派单+进度追踪 | 园区全域 | 小程序+工单系统 |
| 环境监测 | 空气质量/噪音/温湿度实时监测 | 关键区域 | 环境传感器+大屏展示 |

### 步骤2：能源管理系统

| 模块 | 功能 | 节能目标 |
|------|------|:---:|
| 智能电表 | 分区分户计量，实时采集 | 管理节能5-8% |
| 光伏发电 | 屋顶分布式光伏，自发自用余电上网 | 覆盖20-30%用电 |
| 储能系统 | 峰谷套利+应急备电 | 削峰填谷 |
| 智能照明 | 感应控制+分时调光+路灯单灯控制 | 节能30-50% |
| 空调节能 | 变频控制+日程管理+分区控制 | 节能15-25% |
| 能耗监测平台 | 实时监测+异常告警+能效分析 | 管理节能10-15% |

### 步骤3：安防系统

| 子系统 | 功能 | 技术方案 |
|--------|------|------|
| 视频监控 | 园区全覆盖，AI智能分析 | 高清摄像头+AI算法（人脸/车牌/行为识别） |
| 周界防护 | 电子围栏+红外对射+震动光纤 | 入侵报警+视频联动 |
| 消防联动 | 烟感+温感+手动报警+自动喷淋 | 消防主机+物联网平台 |
| 应急指挥 | 预案管理+一键调度+视频会商 | 应急指挥中心+大屏系统 |
| 电子巡更 | NFC打卡+轨迹记录+异常上报 | 巡更APP+管理平台 |

## 三、输出格式

```markdown
# [园区名称]智慧园区建设方案

## 1. 建设目标与定位
- 智慧化等级定位
- 对标案例分析
- 分阶段建设目标

## 2. 智慧物业方案
- 各子系统功能设计
- 技术架构
- 部署计划

## 3. 能源管理方案
- 能源管理架构
- 可再生能源利用方案
- 节能措施与预期效果

## 4. 安防系统方案
- 安防体系架构
- 各子系统方案
- 应急联动机制

## 5. 技术平台架构
- 物联网平台
- 数据中台
- 数字孪生
- 综合管理驾驶舱

## 6. 投资估算与实施计划
- 各子系统投资估算
- 分期实施计划
- 运维成本预估
```

## 四、质量检查清单

- [ ] 各子系统覆盖园区主要场景
- [ ] 技术方案有明确的供应商/产品参考
- [ ] 节能措施有量化目标
- [ ] 安防系统满足消防规范要求
- [ ] 投资估算与实施计划匹配
