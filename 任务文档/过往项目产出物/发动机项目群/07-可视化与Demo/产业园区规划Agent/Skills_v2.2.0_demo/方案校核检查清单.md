# 方案校核检查清单

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `full_report` | string | 是 | 全案整合报告 |
| `check_scope` | string | 否 | 校核范围 | `全部` / `仅数据` / `仅逻辑` |

## 二、校核维度与检查项

### 维度1：逻辑一致性（权重25%）

| 检查项 | 检查方法 | 通过标准 |
|--------|------|------|
| 产业→空间一致性 | 产业规划中提到的产业方向，是否在空间规划中有对应功能区 | 一一对应 |
| 空间→建筑一致性 | 空间规划中的建筑规模，是否与建筑设计中的建筑面积一致 | 偏差<5% |
| 建筑→投资一致性 | 建筑设计中的建筑规模，是否与投资测算中的建安成本匹配 | 偏差<10% |
| 投资→运营一致性 | 投资测算中的收入预测，是否与运营方案中的租金策略一致 | 逻辑自洽 |
| 智慧→建筑一致性 | 智慧园区方案中的设备部署，是否与建筑设计中的管井/机房匹配 | 物理可行 |

### 维度2：数据准确性（权重30%）

| 检查项 | 检查方法 | 通过标准 |
|--------|------|------|
| 用地面积加总 | 各功能区面积之和是否等于总用地面积 | 偏差<1% |
| 建筑面积加总 | 各建筑类型面积之和是否等于总建筑面积 | 偏差<1% |
| 投资额加总 | 各成本项之和是否等于总投资额 | 偏差<1% |
| 指标计算 | 容积率/密度/绿地率是否按公式正确计算 | 计算无误 |
| 单位一致性 | 全文是否统一使用同一种单位体系 | 无混用 |

### 维度3：完整性（权重20%）

| 检查项 | 检查方法 | 通过标准 |
|--------|------|------|
| 章节完整性 | 全案报告是否覆盖所有必要章节 | 7章+附录 |
| 表格完整性 | 关键表格是否无空行/空列 | 全部填充 |
| 图表标注 | 是否有图表编号和标题 | 全部标注 |
| 术语定义 | 专业术语是否有解释 | 首次出现时定义 |
| 版本信息 | 是否有版本号、日期、编制人 | 文末明确 |

### 维度4：合规性（权重15%）

| 检查项 | 检查方法 | 通过标准 |
|--------|------|------|
| 用地合规 | 容积率/密度/高度是否在控规允许范围内 | 无超标 |
| 环保合规 | 是否满足环评要求 | 有环保措施 |
| 消防合规 | 消防通道宽度/防火分区是否满足规范 | 满足GB 50016 |
| 政策合规 | 招商政策是否有上位依据 | 有政策出处 |

### 维度5：可操作性（权重10%）

| 检查项 | 检查方法 | 通过标准 |
|--------|------|------|
| 时间节点明确 | 关键里程碑是否有具体时间 | 年/月明确 |
| 责任主体明确 | 关键任务是否有责任方 | 责任方明确 |
| 投资来源明确 | 资金来源是否有明确渠道 | 渠道明确 |
| 风险预案 | 主要风险是否有应对措施 | 有对应预案 |

## 三、输出格式

```markdown
# [园区名称]方案校核报告

## 1. 校核概要
- 校核范围
- 校核方法
- 总体评分

## 2. 分维度校核结果

| 维度 | 满分 | 得分 | 通过率 |
|------|:---:|:---:|:---:|
| 逻辑一致性 | 25 | | |
| 数据准确性 | 30 | | |
| 完整性 | 20 | | |
| 合规性 | 15 | | |
| 可操作性 | 10 | | |
| **总分** | **100** | | |

## 3. 问题清单

| 编号 | 问题描述 | 严重程度 | 涉及章节 | 修改建议 |
|------|------|:---:|------|------|
| | | 🔴/🟡/🟢 | | |

## 4. 修改优先级

### 必须修改（🔴阻断性问题）
- 问题1：xxx

### 建议修改（🟡优化建议）
- 问题2：xxx

### 可选修改（🟢锦上添花）
- 问题3：xxx

## 5. 校核结论
- 是否达到交付标准
- 需修改后方可交付的项
- 总体评价
```

## 四、评分标准

| 总分 | 等级 | 处理建议 |
|:---:|:---:|------|
| ≥90 | 优秀 | 可直接交付 |
| 80-89 | 良好 | 建议修改后交付 |
| 70-79 | 合格 | 必须修改后交付 |
| <70 | 不合格 | 需重新编制 |
