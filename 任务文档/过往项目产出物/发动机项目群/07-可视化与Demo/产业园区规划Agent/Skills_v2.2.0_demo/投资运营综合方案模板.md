# 投资运营综合方案模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `park_name` | string | 是 | 园区名称 | `XX智慧生态产业园` |
| `industry_plan` | string | 是 | 产业规划方案 | 产业规划Agent输出 |
| `space_plan` | string | 是 | 空间规划方案 | 空间规划Agent输出 |
| `building_plan` | string | 否 | 建筑设计方案 | 建筑设计Agent输出 |
| `operation_mode` | string | 否 | 运营模式偏好 | `政府主导` / `政企合作` / `企业主导` |

## 二、执行逻辑

### 步骤1：运营模式选择

| 模式 | 适用场景 | 优势 | 劣势 | 收益分配 |
|------|------|------|------|------|
| 政府主导 | 战略性新兴产业、基础研究型园区 | 政策支持力度大、土地成本低 | 市场灵活性不足、运营效率较低 | 政府100% |
| PPP模式 | 综合性园区、需要社会资本参与 | 风险共担、专业运营 | 合同复杂、协调成本高 | 按合约比例 |
| BOT模式 | 大型基础设施类园区 | 建设-运营-移交，责任清晰 | 特许经营期长(20-30年) | 运营期归企业 |
| 企业主导 | 产业集聚度高、市场化程度高 | 效率高、贴近市场 | 政策支持可能不足 | 企业100% |

### 步骤2：招商运营策略

| 阶段 | 时间 | 核心任务 | 入驻率目标 |
|------|------|------|:---:|
| 启动期 | 第1年 | 龙头企业签约、标杆项目落地 | 15-20% |
| 成长期 | 第2-3年 | 产业链招商、配套企业入驻 | 40-60% |
| 成熟期 | 第3-5年 | 满租运营、增值服务 | 80-90% |
| 稳定期 | 第5年+ | 腾笼换鸟、提质增效 | 稳定85%+ |

租金定价策略：
- 基准租金：参考周边同类园区均价
- 浮动机制：按楼层/朝向/面积/产业类型差异化定价
- 优惠政策：龙头企业≥30%折扣，高新技术企业≥20%折扣
- 年增长率：3-5%（与CPI挂钩）

### 步骤3：收益分成机制

| 收益来源 | 占比 | 说明 |
|----------|:---:|------|
| 租金收入 | 50-60% | 厂房/办公/商业租金 |
| 物业服务费 | 10-15% | 基础物业+增值服务 |
| 增值服务 | 10-15% | 检测认证、金融对接、人才培训 |
| 政策补贴 | 5-10% | 各级政府产业扶持资金 |
| 资产增值 | 10-15% | 土地/物业增值收益（退出时实现） |

### 步骤4：退出路径设计

| 退出方式 | 适用条件 | 预期收益 | 时间节点 |
|----------|------|------|------|
| REITs上市 | 运营成熟期，现金流稳定 | 资本溢价+持续分红 | 第5-8年 |
| 资产转让 | 物业增值达到预期 | 一次性现金回报 | 第3-5年 |
| 股权转让 | 引入战略投资者 | 部分退出+保留运营权 | 任何阶段 |
| 政府回购 | PPP/BOT模式到期 | 按约定价格回购 | 特许经营期满 |

## 三、输出格式

```markdown
# [园区名称]投资运营方案

## 1. 运营模式选择
- 推荐模式及理由
- 模式对比分析
- 合作方选择标准

## 2. 招商策略
- 分阶段招商计划
- 租金定价方案
- 招商优惠政策
- 入驻企业准入门槛

## 3. 运营管理体系
- 组织架构
- 物业管理方案
- 增值服务体系
- 绩效考核指标

## 4. 收益预测
- 收入结构
- 运营成本
- 利润预测（3-5年）

## 5. 退出机制
- 推荐退出路径
- 退出时间规划
- 风险预案
```

## 四、质量检查清单

- [ ] 运营模式与园区定位匹配
- [ ] 招商计划有明确的时间节点和量化目标
- [ ] 收益预测有合理假设依据
- [ ] 退出路径可行且有时限
- [ ] 风险预案覆盖主要风险场景
