# 产业匹配度计算器

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `target_industries` | array | 是 | 园区目标产业方向列表 | `["电子信息","生物医药","新能源"]` |
| `candidate_enterprises` | array | 是 | 候选企业列表，每个企业含各项指标 | 见下方格式 |
| `weights` | object | 否 | 自定义权重，默认权重见下方 | `{"fitness":0.35,"investment":0.25,"tax":0.20,"employment":0.10,"environmental":0.10}` |

### 候选企业数据格式

```json
{
  "enterprises": [
    {
      "name": "XX科技",
      "industry": "电子信息",
      "sub_industry": "半导体设计",
      "annual_revenue": 50000,
      "investment_per_mu": 300,
      "estimated_tax_per_mu": 25,
      "employees": 500,
      "environmental_level": "A"
    }
  ]
}
```

## 二、评分维度与默认权重

| 维度 | 权重 | 评分标准（1-5分） |
|------|------|------------------|
| 产业契合度 | 35% | 5=完全匹配主导产业，4=强相关，3=一般相关，2=弱相关，1=不相关 |
| 投资强度 | 25% | 5=超500万/亩，4=300-500万/亩，3=200-300万/亩，2=100-200万/亩，1=<100万/亩 |
| 税收贡献 | 20% | 5=>40万/亩·年，4=30-40万，3=20-30万，2=10-20万，1=<10万 |
| 就业带动 | 10% | 5=>1000人，4=500-1000人，3=200-500人，2=100-200人，1=<100人 |
| 环保指标 | 10% | 5=零排放/循环经济，4=环境友好A级，3=达标排放B级，2=需治理C级，1=高污染 |

## 三、计算公式

```
综合得分 = Σ(维度得分 × 维度权重)
```

其中维度得分按上述评分标准映射为1-5分。

## 四、输出格式

| 企业名称 | 产业契合度(35%) | 投资强度(25%) | 税收贡献(20%) | 就业带动(10%) | 环保指标(10%) | 综合得分 | 优先级 |
|----------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| | | | | | | | |

并附优先级排序说明：

```markdown
## 招商优先级排序

### 第一梯队（综合得分≥4.0）：优先引进
- 企业A：理由
- 企业B：理由

### 第二梯队（综合得分3.0-3.9）：重点跟进
- 企业C：理由

### 第三梯队（综合得分<3.0）：储备跟踪
- 企业D：理由
```

## 五、使用说明

1. 输入候选企业数据，可手动填写或从招商数据库导入
2. 如需调整权重（如环保要求高的园区提高环保指标权重），修改 `weights` 参数
3. 评分标准中的阈值可根据园区实际情况调整
4. 输出结果供招商团队制定优先级策略
