# 智慧园区技术选型手册

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `smart_level` | string | 是 | 智慧化等级 | `基础级` / `标准级` / `标杆级` |
| `budget` | number | 否 | 技术平台预算（万元） | `2000` |
| `scale` | string | 否 | 园区规模 | `小型(<500亩)` / `中型(500-2000亩)` / `大型(>2000亩)` |

## 五、5G/通信专网方案

| 方案 | 适用场景 | 优势 | 成本 |
|------|------|------|:---:|
| 运营商5G公网切片 | 通用场景 | 免自建，快速开通 | 中 |
| 5G专网（UPF下沉） | 高安全要求 | 数据不出园区 | 高 |
| WiFi6全覆盖 | 低成本场景 | 成本低，终端兼容好 | 低 |
| LoRaWAN物联网 | 低功耗传感 | 覆盖远，功耗低 | 低 |
