# 绿色建筑评估卡

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `building_plan` | string | 是 | 建筑设计方案 | 建筑设计Agent输出 |
| `target_star` | string | 是 | 目标星级 | `一星级` / `二星级` / `三星级` |
| `local_climate` | string | 否 | 当地气候区 | `夏热冬冷地区` |

## 二、评估维度（对标GB/T 50378）

| 评估项 | 权重 | 一星级要求 | 二星级要求 | 三星级要求 |
|--------|:---:|------|------|------|
| 安全耐久 | 15% | 基础项达标 | 基础项+2加分项 | 基础项+4加分项 |
| 健康舒适 | 15% | 基础项达标 | 基础项+2加分项 | 基础项+4加分项 |
| 生活便利 | 10% | 基础项达标 | 基础项+1加分项 | 基础项+3加分项 |
| 资源节约 | 30% | 基础项达标 | 基础项+3加分项 | 基础项+5加分项 |
| 环境宜居 | 15% | 基础项达标 | 基础项+2加分项 | 基础项+4加分项 |
| 提高与创新 | 15% | — | 2项 | 4项 |

## 三、关键措施对照表

| 措施类别 | 具体措施 | 是否采用 | 对应星级 |
|----------|----------|:---:|:---:|
| 围护结构节能 | 外墙保温+Low-E中空玻璃 | | 一星级 |
| 可再生能源 | 屋顶光伏发电 | | 二星级 |
| 雨水收集 | 雨水回用系统（灌溉+冲厕） | | 二星级 |
| 自然通风 | 地道风预冷/预热系统 | | 二星级 |
| 智能控制 | 楼宇自控系统（BA） | | 二星级 |
| 装配式建筑 | 预制率≥30% | | 三星级 |
| 近零能耗 | 被动式设计+高效设备 | | 三星级 |
| 碳排放计算 | 全生命周期碳排放核算 | | 三星级 |
| 海绵城市 | 透水铺装+下凹绿地+调蓄池 | | 三星级 |
