# 空间规划综合方案模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `park_name` | string | 是 | 园区名称 | `XX智慧生态产业园` |
| `total_area` | number | 是 | 总占地面积（亩） | `1000` |
| `industry_plan` | string | 是 | 产业规划方案（产业规划Agent输出） | 产业规划方案全文 |
| `terrain_desc` | string | 否 | 地形地貌描述 | `平原为主，南侧临河，北侧靠山` |
| `surrounding_roads` | array | 否 | 周边道路情况 | `["东侧：国道G104","西侧：高速入口"]` |
| `special_constraints` | string | 否 | 特殊限制条件 | `需保留20亩古树保护区` |

## 二、执行逻辑

### 步骤1：功能分区规划

根据产业规划确定的功能需求，划分四大功能区：

| 功能区 | 面积占比 | 核心内容 | 布局原则 |
|--------|:---:|------|------|
| 研发创新区 | 15-20% | 研发中心、孵化器、实验室、检测中心 | 靠近主入口，环境安静，配套便利 |
| 生产制造区 | 40-50% | 标准厂房、定制厂房、仓储物流 | 靠近货运通道，远离生活区，预留扩展用地 |
| 生活配套区 | 10-15% | 人才公寓、食堂、商业、文体设施 | 独立组团，动静分离，步行可达生产区 |
| 生态景观区 | 15-20% | 中央绿地、滨水景观、生态廊道 | 串联各功能区，形成生态骨架 |

### 步骤2：交通组织方案

外部交通衔接：
- 主入口设置：对接城市主干道，满足客货分流
- 次入口设置：对接次干道，服务生活配套区
- 货运通道：独立设置，避免与客运交叉

内部交通组织：
- 主干路：红线宽度24-30m，双向四车道，串联各功能区
- 次干路：红线宽度16-20m，双向两车道，功能区内连接
- 支路：红线宽度9-12m，服务地块内部
- 人车分流：人行道+非机动车道+绿化隔离
- 停车配置：按建筑面积配比，地面+地下结合

### 步骤3：景观体系设计

| 景观层级 | 内容 | 指标要求 |
|----------|------|----------|
| 中央景观轴 | 园区的核心绿廊，串联主要公共空间 | 宽度≥50m，长度贯穿园区 |
| 组团绿地 | 各功能区内的小型绿地 | 服务半径≤300m |
| 滨水景观 | 利用自然水系打造亲水空间 | 岸线生态化处理 |
| 防护绿地 | 工业区与生活区之间的隔离带 | 宽度≥20m |
| 道路绿化 | 各级道路两侧绿化 | 主干路绿带≥5m，次干路≥3m |

## 四、质量检查清单

- [ ] 功能分区面积占比合理（总和100%）
- [ ] 交通组织满足客货分流
- [ ] 绿地率≥15%（工业类园区最低标准）
- [ ] 建筑指标符合当地控规要求
- [ ] 各功能区之间有明确的交通连接
