# 园区建筑指标计算器

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `total_land_area` | number | 是 | 总用地面积（㎡） | `666667` |
| `zone_areas` | object | 是 | 各功能区建筑面积 | 见下方格式 |
| `local_regulation` | object | 否 | 当地控规上限 | `{"far_max":2.0,"density_max":45,"green_min":20,"height_max":60}` |
| `parking_standard` | object | 否 | 停车配比标准 | `{"factory":"0.3/100㎡","office":"0.8/100㎡","commercial":"1.0/100㎡"}` |

### 功能区建筑面积格式

```json
{
  "研发创新区": {"land_area": 100000, "floor_area": 150000},
  "生产制造区": {"land_area": 300000, "floor_area": 450000},
  "生活配套区": {"land_area": 80000, "floor_area": 120000},
  "生态景观区": {"land_area": 120000, "floor_area": 0},
  "道路广场": {"land_area": 66667, "floor_area": 0}
}
```

## 二、计算公式

### 容积率（FAR）
```
容积率 = 总建筑面积 / 总用地面积
总建筑面积 = Σ(各功能区建筑面积)
注意：地下建筑面积通常不计入容积率
```

### 建筑密度
```
建筑密度 = 建筑基底总面积 / 总用地面积 × 100%
建筑基底总面积 ≈ 总建筑面积 / 平均层数
```

### 绿地率
```
绿地率 = 绿地面积 / 总用地面积 × 100%
绿地面积 = 生态景观区面积 + 各功能区附属绿地面积
```

### 停车位配比
```
总停车位 = Σ(各功能区建筑面积 × 对应配比标准)
```

### 建筑高度分区
```
研发创新区：≤60m（高层办公）
生产制造区：≤24m（多层厂房）
生活配套区：≤50m（高层公寓）
```
