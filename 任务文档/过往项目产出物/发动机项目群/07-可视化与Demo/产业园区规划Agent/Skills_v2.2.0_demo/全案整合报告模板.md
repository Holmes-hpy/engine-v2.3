# 全案整合报告模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `park_name` | string | 是 | 园区名称 |
| `industry_plan_output` | string | 是 | 产业规划Agent输出 |
| `space_plan_output` | string | 是 | 空间规划Agent输出 |
| `building_plan_output` | string | 是 | 建筑设计Agent输出 |
| `investment_plan_output` | string | 是 | 投资运营Agent输出 |
| `smart_plan_output` | string | 是 | 智慧园区Agent输出 |
| `client_name` | string | 否 | 客户/委托方名称 |
| `report_date` | string | 否 | 报告日期 |

## 二、整合逻辑

### 步骤1：结构对齐

将各Agent输出按全案章节映射，确保各模块内容完整覆盖：

| 全案章节 | 来源Agent | 映射关系 |
|----------|------|------|
| 第一章 项目概述 | 团长（提炼） | 从各Agent输出中提取关键信息 |
| 第二章 产业规划 | 产业规划Agent | 直接映射 |
| 第三章 空间规划 | 空间规划Agent | 直接映射 |
| 第四章 建筑设计 | 建筑设计Agent | 直接映射 |
| 第五章 投资运营 | 投资运营Agent | 直接映射 |
| 第六章 智慧园区 | 智慧园区Agent | 直接映射 |
| 第七章 实施保障 | 团长（综合） | 从各Agent提取风险+保障措施 |
| 附录 | 各Agent | 计算底稿+数据表 |

### 步骤2：格式统一

- 统一标题层级（H1→H2→H3）
- 统一表格样式（表头加粗，居中对齐）
- 统一术语（同一概念使用相同表述）
- 统一单位（万元/㎡/亩/%）

### 步骤3：交叉引用

- 产业规划中提到的产业方向 → 空间规划中是否有对应功能区
- 空间规划中的建筑规模 → 投资测算中是否一致
- 建筑设计中的绿色措施 → 智慧园区中是否有系统支撑
