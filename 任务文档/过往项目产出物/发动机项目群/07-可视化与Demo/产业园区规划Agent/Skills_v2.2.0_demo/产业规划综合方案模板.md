# 产业规划综合方案模板

## 一、输入要求

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `park_name` | string | 是 | 园区名称 | `XX智慧生态产业园` |
| `location` | string | 是 | 园区所在城市/区域 | `浙江省杭州市余杭区` |
| `total_area` | number | 是 | 总占地面积（亩） | `1000` |
| `local_industries` | array | 是 | 本地现有主导产业 | `["电子信息","生物医药","装备制造"]` |
| `resource_advantages` | array | 否 | 区域资源优势 | `["高校聚集","交通枢纽","政策扶持"]` |
| `target_scale` | string | 否 | 目标规模（产值/企业数） | `年产值100亿，入驻企业200家` |
| `special_requirements` | string | 否 | 特殊要求 | `需兼顾环保零排放标准` |

## 二、执行逻辑

### 步骤1：产业定位分析

根据本地产业基础、资源禀赋、政策导向，输出产业定位矩阵：

| 维度 | 分析内容 |
|------|----------|
| 上位规划衔接 | 对照国家/省/市产业规划，确认园区定位与上位规划的一致性 |
| 区域竞合分析 | 周边50km内同类园区差异化定位，避免同质竞争 |
| 资源禀赋匹配 | 人才供给、科研资源、交通物流、能源成本等要素匹配度 |
| 市场前景判断 | 目标产业的市场规模、增长率、技术趋势 |

### 步骤2：产业链拆解

按"主导产业→支撑产业→配套产业"三层结构拆解：

```
主导产业（核心引擎）
├── 细分方向1：具体产品/服务
├── 细分方向2：具体产品/服务
└── 细分方向3：具体产品/服务

支撑产业（产业链延伸）
├── 上游：原材料/核心零部件
├── 中游：加工制造/系统集成
└── 下游：应用服务/终端市场

配套产业（服务保障）
├── 现代服务业：金融/物流/会展
├── 生活服务业：餐饮/住宿/教育
└── 公共服务：政务/检测/认证
```

## 三、输出格式

```markdown
# [园区名称]产业规划方案

## 1. 区域产业基础分析
- 本地产业现状
- 区域竞争优势
- 发展瓶颈与机遇

## 2. 产业定位
- 总体定位
- 主导产业选择及理由
- 与上位规划衔接说明

## 3. 产业链设计
- 产业链全景图（文字描述）
- 主导产业细分方向
- 支撑产业与配套产业

## 4. 招商方向
- 招商目标企业画像（龙头企业/高成长/配套）
- 招商优先级排序
- 招商策略建议（产业链招商/以商招商/飞地招商）

## 5. 政策支撑体系
- 适用政策清单
- 政策红利测算
- 政策申请路径

## 6. 发展目标与里程碑
- 近期（1-2年）目标
- 中期（3-5年）目标
- 远期（5-10年）目标
```

## 四、质量检查清单

- [ ] 产业定位与上位规划一致
- [ ] 产业链拆解覆盖上下游关键环节
- [ ] 招商方向有明确的筛选标准
- [ ] 政策匹配覆盖四级政府
- [ ] 发展目标有时间节点和量化指标
