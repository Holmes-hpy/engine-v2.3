# AgentScope 2.0 + Dify 本地安装指南

## 📦 已完成安装

### ✅ AgentScope 2.0.4.post1
- **Python版本**: 3.11.3（系统默认3.10不满足要求，需用python3.11）
- **安装方式**: 从GitHub源码可编辑安装
- **源码位置**: `frameworks/agentscope/`
- **验证命令**:
  ```bash
  python3.11 -c "import agentscope; print(agentscope.__version__)"
  ```

### ✅ Dify 源码
- **源码位置**: `frameworks/dify/`
- **版本**: GitHub main分支
- **部署方式**: Docker Compose（需要先安装Docker）

---

## 🚧 需要手动完成：安装Docker Desktop

由于沙箱权限限制，Docker Desktop需要您手动安装：

### 安装步骤：

1. **下载Docker Desktop for Mac**
   - 访问: https://www.docker.com/products/docker-desktop/
   - 或者用Homebrew在终端执行（需要输入密码）:
     ```bash
     brew install --cask docker
     ```

2. **安装并启动Docker**
   - 双击下载的.dmg文件
   - 将Docker拖拽到Applications文件夹
   - 从Launchpad启动Docker
   - 等待Docker状态栏图标变绿（表示启动成功）

3. **验证Docker安装**
   ```bash
   docker --version
   docker compose version
   ```

---

## 🚀 启动Dify

Docker安装完成后，按以下步骤启动Dify：

```bash
# 进入Dify docker目录
cd frameworks/dify/docker

# 复制环境配置文件
cp .env.example .env

# 启动所有服务（首次启动需要拉取镜像，耐心等待）
docker compose up -d

# 查看启动状态
docker compose ps

# 查看日志（可选）
docker compose logs -f
```

### Dify访问地址
- **Web界面**: http://localhost/install
- **默认端口**: 80
- **首次访问**: 设置管理员邮箱和密码

## ⚠️ 注意事项

1. **Python版本**: AgentScope 2.0需要Python >= 3.11，请使用`python3.11`命令
2. **Docker内存**: Dify建议分配至少8GB内存给Docker Desktop（在设置中调整）
3. **端口占用**: Dify默认使用80端口，确保没有其他服务占用
4. **首次启动**: Dify首次启动需要拉取大量Docker镜像，请保持网络畅通
