## 核心学习要点

### 成功的选股特征
1. **价值评分>75分** - 准确率100%，最可靠的信号
2. **RSI处于40-60区间** - 不超买不超卖，安全边际好
3. **价格处于布林带30%-70%** - 走势稳健
4. **成交量温和放大** - 有资金关注但不疯狂
5. **KDJ多方信号** - 短期动能向好

### 失败的教训
1. **近期涨幅>8%时追高危险** - 宁德时代、长电科技均因此失败
2. **技术策略单独使用准确率仅25%** - 必须与价值/动量策略组合
3. **高价股(>1000元)技术信号滞后** - 茅台横盘说明高价股需特殊处理
4. **动量策略需设止损** - 趋势反转时亏损速度快

### 策略优化建议
1. **优先使用价值策略** - 100%准确率，应占选股权重50%以上
2. **技术策略需要加过滤条件** - 增加近期涨幅<5%的限制
3. **动量策略需设涨幅上限** - 近期涨幅>8%的股票应排除
4. **考虑组合策略** - 价值+动量双重确认可能提高准确率
