## 六、任务执行检查清单

> 以下检查单必须在任务关键节点逐项确认。所有项勾选后方可进入下一阶段。

### 阶段一：启动前检查（Pre-Flight）

- [ ] 任务基本信息已完整填充
- [ ] 适用的规则已勾选并确认加载
- [ ] 所需专家已邀请并就位
- [ ] 项目当前状态已阅读并理解
- [ ] 任务边界声明已明确，无歧义
- [ ] 对话记录文件已创建（空模板即可）

### 阶段二：执行中检查（In-Flight）

- [ ] 每轮对话后已更新 `对话记录.md`
- [ ] 每轮对话后已检查是否需要知识沉淀
- [ ] 产出物已按 `任务文档/{任务ID}/产出物/` 存放
- [ ] 代码变更已按版本管理规范提交
- [ ] 遇阻塞项已在任务状态中标出

### 阶段三：收尾检查（Post-Flight）

- [ ] 所有产出物已确认完整并存放到指定位置
- [ ] 版本号已按规范确定并标记
- [ ] 知识沉淀已完成，沉淀日志已更新
- [ ] 任务状态已更新（完成/部分完成/中止）
- [ ] 对话记录已完整归档
- [ ] 下一任务建议或待办事项已记录
