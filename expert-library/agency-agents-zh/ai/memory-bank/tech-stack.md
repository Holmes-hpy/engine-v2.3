# 技术栈说明

## 前端技术栈
- **框架**: React 18 / Vue 3 / Angular 17
- **构建工具**: Vite 5 / Webpack 5
- **UI框架**: Bootstrap 5 / Ant Design / Material UI
- **状态管理**: Redux Toolkit / Pinia / Zustand
- **路由**: React Router / Vue Router
- **HTTP客户端**: Axios / Fetch API
- **CSS预处理器**: SCSS / Less / Tailwind CSS
- **测试工具**: Jest / Vitest / Cypress
- **代码规范**: ESLint + Prettier

## 后端技术栈
- **语言**: Node.js / Python / Java / Go
- **框架**: Express / FastAPI / Spring Boot / Gin
- **数据库**: PostgreSQL 16 / MySQL 8 / MongoDB 7
- **缓存**: Redis 7
- **消息队列**: RabbitMQ / Kafka
- **搜索引擎**: Elasticsearch
- **ORM**: Prisma / Sequelize / SQLAlchemy
- **认证**: JWT / OAuth 2.0 / Auth0
- **API文档**: Swagger / OpenAPI

## 基础设施
- **云服务**: AWS / 阿里云 / 腾讯云
- **容器化**: Docker + Docker Compose
- **编排**: Kubernetes
- **CI/CD**: GitHub Actions / GitLab CI / Jenkins
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack / Loki
- **CDN**: Cloudflare / 阿里云CDN

## 开发工具
- **IDE**: VS Code / IntelliJ IDEA
- **版本控制**: Git + GitHub/GitLab
- **API测试**: Postman / Insomnia
- **数据库工具**: DBeaver / Navicat
