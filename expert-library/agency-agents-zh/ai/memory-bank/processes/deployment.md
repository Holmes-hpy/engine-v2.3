# 部署流程

## 开发环境部署
1. 开发者提交代码到develop分支
2. GitHub Actions自动运行测试和代码检查
3. 测试通过后自动部署到开发环境
4. 开发者在开发环境进行测试

## 测试环境部署
1. 从develop分支创建release分支
2. 手动触发GitHub Actions部署到测试环境
3. QA团队在测试环境进行测试
4. 发现问题在release分支修复并重新部署

## 生产环境部署
1. 将release分支合并到main分支
2. 打版本标签(vX.Y.Z)
3. 手动触发GitHub Actions部署到生产环境
4. 监控系统运行状态
5. 验证生产环境功能

## 回滚流程
1. 发现生产环境问题
2. 立即停止新的部署
3. 确定需要回滚的版本
4. 手动触发回滚操作
5. 验证回滚后的系统状态
6. 分析问题原因并修复
